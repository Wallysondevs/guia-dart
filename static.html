Dart Membros static

Até agora, cada campo de uma classe era de cada objeto: o café tem o seu preço, o pão tem o seu. Mas algumas informações são da classe inteira: quantos pedidos a padaria já recebeu, a taxa de entrega que vale para todos, uma conta de conversão que não depende de nenhum produto. Para isso existe a palavra static ("estático"): um campo ou método static pertence à classe, e se usa pelo nome dela: Pedido.total, int.parse('42').

Você vai aprender
  • A diferença entre um campo de cada objeto e um campo static, que é um só para todos.
  • Como contar quantos objetos foram criados com um campo static.
  • static const: constantes que fazem parte da classe.
  • Métodos static: funções que ficam "guardadas" na classe e não precisam de um objeto.
  • Que você já usou vários: int.parse, double.maxFinite, DateTime.daysPerWeek.
  • Os erros reais mais comuns com static.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a comanda e o painel de senhas

Na padaria, cada cliente recebe uma comanda, com o nome dele e o que pediu. Cada comanda é de um cliente só. Na parede, há um painel que mostra quantos pedidos já foram feitos hoje. Existe um painel para a padaria inteira; não faz sentido cada comanda ter o seu.

  • Os campos comuns são a comanda: um para cada objeto.
  • Os campos static são o painel: um só, da classe, que todos os objetos enxergam.

1. Um campo static: o contador de pedidos

class Pedido {
  static int total = 0;

  final String cliente;
  final int numero;

  Pedido(this.cliente) : numero = total + 1 {
    total++;
  }
}

void main() {
  print('Pedidos no começo: ${Pedido.total}');
  final a = Pedido('Ana');
  final b = Pedido('Bia');
  final c = Pedido('Caio');
  print('${a.cliente}: pedido ${a.numero}');
  print('${b.cliente}: pedido ${b.numero}');
  print('${c.cliente}: pedido ${c.numero}');
  print('Pedidos no fim: ${Pedido.total}');
}
static int total = 0;
Um campo static: existe um só, guardado na classe Pedido, e não um em cada pedido. Ele já existe antes de qualquer pedido ser criado, valendo 0.
final String cliente; final int numero;
Campos comuns: cada pedido tem os seus.
: numero = total + 1
Na lista de inicialização, o número deste pedido é o total até agora, mais 1. Dentro da classe, o campo static se usa só pelo nome.
{ total++; }
O corpo do construtor soma 1 no painel. Como o total é um só, todos os pedidos somam no mesmo lugar.
Pedido.total
Fora da classe, o campo static se usa pelo nome da classe, um ponto e o nome do campo. Nenhum objeto é preciso: na primeira linha do main, ainda não havia pedido nenhum.
$ dart run contador.dart
Pedidos no começo: 0
Ana: pedido 1
Bia: pedido 2
Caio: pedido 3
Pedidos no fim: 3

Se total não fosse static, cada pedido teria o seu próprio total, começando em 0, e todos seriam o "pedido 1".

2. static const: as constantes da classe

Valores fixos que fazem parte de uma classe (o nome da padaria, a taxa de entrega, o pedido mínimo) ficam bem como static const: um só para todos (static) e que nunca muda (const; veja final e const).

class Padaria {
  static const String nome = 'Padaria do Bairro';
  static const double taxaEntrega = 5.0;
  static const int pedidoMinimo = 20;
}

void main() {
  print(Padaria.nome);
  print('Entrega: R\$ ${Padaria.taxaEntrega}');
  print('Pedido mínimo: R\$ ${Padaria.pedidoMinimo}');
}

$ dart run constante.dart
Padaria do Bairro
Entrega: R$ 5.0
Pedido mínimo: R$ 20

Nenhum objeto Padaria foi criado: a classe aqui serve só de "gaveta" com nome, que agrupa as constantes. Se a taxa mudar, você muda um lugar do código. Um campo comum não pode ser const; dentro de uma classe, const só existe junto com static. No lab, class A { const int x = 1; } deu Error: Only static fields can be declared as const. ("só campos static podem ser declarados como const"), com a sugestão de usar final ou acrescentar static.

3. Métodos static

Um método static é uma função guardada dentro da classe. Ele se chama pelo nome da classe e não trabalha com um objeto específico:

class Conversor {
  static double celsiusParaFahrenheit(double c) => c * 9 / 5 + 32;

  static double reaisParaCentavos(double reais) => reais * 100;
}

void main() {
  print(Conversor.celsiusParaFahrenheit(25));
  print(Conversor.reaisParaCentavos(18.9));
}

$ dart run metodo.dart
77.0
1889.9999999999998

As duas contas só usam os parâmetros: não precisam de um "conversor" com campos próprios, então são static. (O 1889.9999999999998 não é erro do static: é como o computador guarda números com vírgula. Veja Números. Para dinheiro, contar em centavos inteiros evita isso.)

Campos, métodos e static juntos

Uma classe normal costuma misturar as duas coisas: o que é de cada objeto e o que é da classe.

class Produto {
  static const double descontoMaximo = 0.3;
  static int cadastrados = 0;

  final String nome;
  final double preco;

  Produto(this.nome, this.preco) {
    cadastrados++;
  }

  double comDesconto(double porcento) {
    final d = porcento > descontoMaximo ? descontoMaximo : porcento;
    return preco * (1 - d);
  }

  static Produto maisBarato(List<Produto> lista) {
    var menor = lista.first;
    for (final p in lista) {
      if (p.preco < menor.preco) menor = p;
    }
    return menor;
  }
}

void main() {
  final lista = [Produto('café', 18.9), Produto('pão', 1.0), Produto('leite', 5.5)];
  print('Cadastrados: ${Produto.cadastrados}');
  print('Mais barato: ${Produto.maisBarato(lista).nome}');
  print('Café com 50% (máx. 30%): ${lista[0].comDesconto(0.5).toStringAsFixed(2)}');
}

$ dart run juntos.dart
Cadastrados: 3
Mais barato: pão
Café com 50% (máx. 30%): 13.23
comDesconto
Método comum: precisa de um produto (usa o preco dele) e se chama no objeto: lista[0].comDesconto(0.5). Ele pode usar o descontoMaximo, que é static: um método comum enxerga tudo.
static Produto maisBarato(List<Produto> lista)
Método static: trabalha com vários produtos, que chegam por parâmetro, e não com "este" produto. Chama-se pela classe: Produto.maisBarato(lista).
A regra de ouro

Um membro static não sabe de nenhum objeto. Por isso, dentro de um método static, não existem this nem os campos comuns: só os parâmetros e outros membros static. Já um método comum pode usar tudo, inclusive os static.

Formas diferentes: static ou solto no arquivo?

No Dart, uma função ou constante não precisa morar dentro de uma classe: ela pode ficar solta no arquivo, como o main e o pi. Então quando usar static?

SituaçãoQual usar
Algo que é de cada objeto (nome, preço)Campo/método comum
Algo compartilhado pelos objetos da classe (contador de criados, cache)Campo static
Constante que é claramente "da" classe (Produto.descontoMaximo)static const
Função ligada à classe, que cria ou compara objetos dela (Produto.maisBarato)Método static (ou um construtor nomeado/factory, se cria um objeto)
Função geral, que não é "de" nenhuma classeFunção solta no arquivo (o estilo oficial do Dart prefere isso a uma classe só com static)

"Nome não definido: nome" (e preco). Um método static não tem "este produto": de qual produto seria o nome? "Membro não encontrado: Produto.etiqueta." É o caso inverso: etiqueta é de cada objeto, e não da classe. Como consertar: crie o objeto e chame nele: Produto('café').etiqueta().

Missão final: o maior saldo

Missão: escreva na classe Conta o método static Conta maiorSaldo(List<Conta> contas), que percorre a lista e devolve a conta com o maior saldo. O main deve mostrar Maior saldo: Bia (R$ 250.0).

class Conta {
  final String dona;
  final double saldo;

  Conta(this.dona, this.saldo);

  // escreva o método static maiorSaldo aqui
}

void main() {
  final contas = [Conta('Ana', 120), Conta('Bia', 250), Conta('Caio', 80)];
  // final m = Conta.maiorSaldo(contas);
  // print('Maior saldo: ${m.dona} (R\$ ${m.saldo})');
}

class Conta {
  final String dona;
  final double saldo;

  Conta(this.dona, this.saldo);

  static Conta maiorSaldo(List<Conta> contas) {
    var maior = contas.first;
    for (final c in contas) {
      if (c.saldo > maior.saldo) maior = c;
    }
    return maior;
  }
}

void main() {
  final contas = [Conta('Ana', 120), Conta('Bia', 250), Conta('Caio', 80)];
  final m = Conta.maiorSaldo(contas);
  print('Maior saldo: ${m.dona} (R\$ ${m.saldo})');
}

Resumo

  • static quer dizer "da classe", e não de cada objeto. Existe um só, e ele existe mesmo sem nenhum objeto criado.
  • Fora da classe, usa-se pelo nome dela: Pedido.total, Conversor.celsiusParaFahrenheit(25), int.parse('42'). Pelo objeto, não compila.
  • static const guarda constantes que fazem parte da classe.
  • Um método static não tem this nem campos do objeto: só parâmetros e outros static.
  • Função geral, que não é "de" classe nenhuma, fica melhor solta no arquivo.
