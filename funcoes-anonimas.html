Dart Funções Anônimas

Nas aulas anteriores, toda função tinha um nome: void saudar(), double media(…). Você declarava a função num lugar e chamava pelo nome em outro. Muitas vezes, porém, uma função é usada uma vez só, num lugar só, e dar nome a ela seria desperdício. Para isso existe a função anônima ("anônima" = sem nome): você escreve a função direto onde ela vai ser usada.

Você vai aprender
  • Como se escreve uma função sem nome: (parâmetros) { corpo }.
  • A forma curta com a seta: (item) => print(item).
  • Onde ela aparece de verdade: no forEach (para cada), no sort (ordenar) e no where (filtrar).
  • Que o Dart descobre sozinho o tipo dos parâmetros, e o que o print mostra de uma função (Closure: (int) => int).
  • O _ para um parâmetro que você não vai usar.
  • Os erros reais: o ; esquecido depois do }), a seta com chaves, parâmetros a mais e de tipo errado, e como uma função anônima aparece no stack trace (main.<anonymous closure>).

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com dart run arquivo.dart (veja Rodando um Programa).

A ideia: o bilhete preso na encomenda

A Ana manda o sobrinho ao mercado com a lista de compras. Ela pode fazer de dois jeitos:

  • escrever num caderno uma "receita" chamada "Como conferir um item" e dizer: "para cada item, siga a receita Como conferir um item" (é a função com nome);
  • ou simplesmente dizer: "para cada item, risque da lista quando pegar". A instrução vai junto com o pedido, sem título, sem caderno (é a função anônima).

Se a instrução só serve para aquela ida ao mercado, o segundo jeito é mais rápido e fica tudo num lugar só. É exatamente para isso que servem as funções anônimas.

1. A primeira função anônima: forEach

Toda lista do Dart tem o método forEach (em inglês, "para cada"). Ele recebe uma função e a chama uma vez para cada item da lista, entregando o item como argumento. Em vez de criar uma função com nome para isso, a Ana escreve a função ali mesmo, entre os parênteses do forEach:

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  compras.forEach((item) {
    print('- $item');
  });
}

$ dart run compras.dart
- arroz
- feijão
- café
compras.forEach( … );
Chama o método forEach da lista. Tudo o que está entre os parênteses dele é um argumento só: a função anônima inteira. O ; do fim fecha a chamada do forEach, como em qualquer chamada.
(item)
A lista de parâmetros da função, como numa função normal, só que sem tipo de retorno e sem nome na frente. Cada vez que o forEach chama a função, o item recebe um elemento da lista: 'arroz', depois 'feijão', depois 'café'.
{ print('- $item'); }
O corpo da função, entre chaves, igual ao de qualquer função. Pode ter quantas linhas você quiser.
})
A } fecha o corpo da função anônima; o ) fecha os parênteses do forEach. Esse par }); é muito comum em Dart: acostume o olho a ele.

Compare com a mesma coisa feita com uma função com nome (veja Funções):

void mostrarItem(String item) {
  print('- $item');
}

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  compras.forEach(mostrarItem);
}

A saída é a mesma. A diferença é só onde a função mora. Repare que, para passar a função com nome, escreve-se mostrarItem sem parênteses: você está entregando a função, não chamando. (Esse assunto, a função tratada como um valor, é a próxima aula: Funções como Valores.)

2. A forma curta: a seta =>

Quando o corpo é uma expressão só, dá para trocar as chaves pela seta, como você viu em Funções de Uma Linha. Com função anônima, isso é ainda mais comum:

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  compras.forEach((item) => print('- $item'));
}

$ dart run seta.dart
- arroz
- feijão
- café

(item) => print('- $item') quer dizer "receba um item e devolva o resultado de print('- $item')". Sem chaves, sem return, sem ; dentro. O único ; é o do fim da linha, que fecha o forEach.

A seta que devolve um valor: ordenar e filtrar

No forEach, ninguém usa o que a função devolve. Em outros métodos, o valor devolvido é o que importa. O sort (ordenar) pergunta à sua função: "entre a e b, quem vem primeiro?". A resposta é um número: negativo (a antes), zero (empate) ou positivo (b antes), e o compareTo já calcula esse número:

void main() {
  final precos = [12.90, 4.50, 8.75, 3.20];
  precos.sort((a, b) => a.compareTo(b));
  print(precos);
  precos.sort((a, b) => b.compareTo(a));
  print(precos);
}

$ dart run ordenar.dart
[3.2, 4.5, 8.75, 12.9]
[12.9, 8.75, 4.5, 3.2]

A função anônima tem dois parâmetros, a e b. Trocando a ordem (b.compareTo(a)), a lista fica do mais caro para o mais barato. (Repare que o Dart mostra 12.9, não 12.90: o zero do fim não muda o número; veja Números.)

O where ("onde") pergunta à sua função: "este item fica?". A função devolve true ou false:

void main() {
  final notas = [8.5, 5.0, 7.0, 9.5, 4.0];
  final boas = notas.where((nota) => nota >= 7);
  print(boas);
}

$ dart run aprovados.dart
(8.5, 7.0, 9.5)

Ficaram só as notas para as quais nota >= 7 deu true. (Os parênteses em vez de colchetes não são engano: o where devolve um Iterable, e não uma List. O sort, o where e companhia têm aulas próprias: Métodos de Lista e map, where, reduce e Outros.)

Missão: agora a professora quer as notas de quem ficou de recuperação: as menores que 7. Mude só a condição dentro da função anônima.

3. E o tipo dos parâmetros?

Em (item) => print(item) não se escreveu String item, e mesmo assim o Dart sabe que item é uma String: o forEach de uma List<String> só aceita uma função que receba String, e o Dart deduz o tipo daí (isso se chama inferência de tipo). Você pode escrever o tipo, se ajudar a ler: (String item) => print(item). O que não pode é escrever um tipo diferente (veja Quando dá errado).

Uma função anônima também pode ser guardada numa variável. Aí não há um forEach para dar a dica, e é bom escrever o tipo do parâmetro:

void main() {
  final dobro = (int x) => x * 2;
  print(dobro(21));
  print(dobro);
  print((String nome) => 'Olá, $nome');
}

$ dart run tipo.dart
42
Closure: (int) => int
Closure: (String) => String
42
dobro(21) chamou a função guardada na variável, como se ela tivesse nome.
Closure: (int) => int
O que o print mostra quando você imprime a função (sem chamar): "uma função que recebe um int e devolve um int". O Dart chama toda função anônima de closure (o motivo do nome está na aula Closures).
Closure: (String) => String
Até uma função escrita direto dentro do print é um valor que pode ser mostrado. Ela nunca foi chamada: o Olá não aparece.

4. Mais de um parâmetro, e o _

Para numerar a lista, a Ana usa o asMap(), que transforma a lista num mapa de posição → item (veja Mapas). O forEach de um mapa entrega dois argumentos, então a função anônima tem dois parâmetros:

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  compras.asMap().forEach((i, item) {
    final numero = i + 1;
    print('$numero. $item');
  });
}

$ dart run dois.dart
1. arroz
2. feijão
3. café

Quando um dos parâmetros não interessa, escreva _ (sublinhado) no lugar do nome: é um aviso para quem lê, "este eu recebo, mas não uso". No estoque da padaria, só as quantidades:

void main() {
  final estoque = {'pão': 30, 'leite': 12};
  estoque.forEach((_, quantidade) => print(quantidade));
}

$ dart run underscore.dart
30
12

Dart 3.7 A partir do Dart 3.7, o _ é um coringa (wildcard) de verdade: ele não cria variável nenhuma, e você pode usar _ em mais de um parâmetro da mesma função, como (_, _) => ….

5. Chamar na hora: a função que roda uma vez

Uma função anônima pode ser chamada no mesmo lugar em que é escrita, com () logo depois da }. É útil para calcular um valor que precisa de várias linhas:

void main() {
  final mensagem = () {
    final hora = 9;
    return hora < 12 ? 'Bom dia!' : 'Boa tarde!';
  }();
  print(mensagem);
}

$ dart run imediata.dart
Bom dia!

() { … } é uma função sem parâmetros; o () do fim a chama na hora, e o que ela devolve ('Bom dia!') vai para mensagem. A variável hora só existe lá dentro. É um uso raro no dia a dia; o mais comum, de longe, é passar a função para um método, como nas seções 1 e 2.

Formas diferentes de fazer a mesma coisa

Mostrar cada item da lista pode ser escrito de quatro jeitos. Todos mostram a mesma saída:

// 1) for-in: sem função nenhuma
for (final item in compras) {
  print('- $item');
}

// 2) forEach com função anônima de bloco
compras.forEach((item) {
  print('- $item');
});

// 3) forEach com função anônima de seta
compras.forEach((item) => print('- $item'));

// 4) forEach com função com nome
compras.forEach(mostrarItem);
SituaçãoQual usar
Só percorrer uma lista e fazer algo com cada itemfor (final item in lista) (veja for-in). O guia de estilo do Dart (Effective Dart) prefere o for-in ao forEach com função anônima: ele aceita break, await e é mais fácil de ler.
Um método pede uma função (sort, where, map, any…) e a regra é curtaFunção anônima de seta: (a, b) => a.compareTo(b)
A regra tem várias linhas, mas só é usada aliFunção anônima de bloco: (x) { …; return …; }
A mesma regra é usada em vários lugares, ou merece um nome que expliqueFunção com nome, passada sem parênteses: lista.forEach(mostrarItem)

Resumo

  • Uma função anônima é uma função sem nome, escrita onde vai ser usada: (parâmetros) { corpo } ou, com uma expressão só, (parâmetros) => expressão.
  • O uso mais comum é passá-la para um método que pede uma função: forEach, sort, where. O método decide quantas vezes chamá-la e com quais argumentos.
  • O tipo dos parâmetros é opcional: o Dart deduz pelo método. Um tipo diferente, ou parâmetros a mais, dá The argument type … can't be assigned ….
  • Seta ou chaves, nunca => { … }. E a chamada do método termina em });.
  • print de uma função mostra Closure: (int) => int; no stack trace, ela aparece como main.<anonymous closure>.
  • Para só percorrer uma lista, o for-in costuma ser mais claro que o forEach.
