Dart Métodos de String

Na aula Strings você aprendeu a criar textos e a juntar variáveis neles. Mas um texto também sabe fazer coisas: dizer o próprio tamanho, virar maiúsculas, tirar os espaços das pontas, procurar uma palavra, ser cortado em pedaços. Cada uma dessas ações é um método: uma função que "pertence" ao texto e se chama com um ponto: nome.toUpperCase().

Você vai aprender
  • O que é um método e como se chama (texto.metodo()), e a diferença para uma propriedade (texto.length, sem parênteses).
  • Tamanho e letras: length, isEmpty, [0].
  • Maiúsculas e minúsculas, aparar espaços: toUpperCase, toLowerCase, trim.
  • Procurar: contains, startsWith, endsWith, indexOf.
  • Cortar, trocar e dividir: substring, replaceAll, split (e o join, que faz o caminho de volta).
  • Alinhar: padLeft e padRight.
  • Por que uma String nunca muda, e como encadear vários métodos.
  • Os erros reais: método que não existe, parênteses esquecidos, posição fora do texto.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook), com dart run arquivo.dart.

A ideia: o texto que sabe se cuidar

Pense numa etiqueta de preço da padaria. Você pode perguntar coisas a ela ("quantas letras você tem?", "você contém a palavra queijo?") e pedir versões dela ("me dá você em letras grandes", "me dá só os 3 primeiros caracteres"). A etiqueta original continua igual; o que você recebe é uma etiqueta nova. É exatamente assim que os métodos de String funcionam.

1. Tamanho e letras: length, isEmpty e [ ]

void main() {
  final nome = 'Ana Souza';
  print(nome.length);
  print(nome.isEmpty);
  print(''.isEmpty);
  print(nome.isNotEmpty);
  print(nome[0]);
  print(nome[nome.length - 1]);
}

$ dart run tamanho.dart
9
false
true
true
A
a
nome.length → 9
"Comprimento": quantos caracteres o texto tem. O espaço conta: Ana (3) + espaço (1) + Souza (5) = 9.
isEmpty / isNotEmpty
"Está vazio?" e "não está vazio?". Devolvem bool (veja Booleanos). '', o texto sem nada, é o único vazio.
nome[0] → A
O caractere na posição 0. As posições começam do zero: em Ana Souza, o A é a posição 0, o n a 1, o a a 2, o espaço a 3…
nome[nome.length - 1] → a
O último caractere. Se o texto tem 9 caracteres, as posições vão de 0 a 8, então a última é length - 1.
Acentos e emojis

'José'.length dá 4, como esperado. Já um emoji pode contar como 2: no lab, '😀'.length deu 2. O Dart guarda o texto em pedaços de 16 bits (UTF-16), e alguns símbolos ocupam dois. Para contar símbolos de verdade, existe '😀'.runes.length, que deu 1. Para textos em português comum, o length funciona bem.

2. Maiúsculas, minúsculas e espaços

void main() {
  final produto = 'Pão de Queijo';
  print(produto.toUpperCase());
  print(produto.toLowerCase());
  print(produto);
}

$ dart run caixa.dart
PÃO DE QUEIJO
pão de queijo
Pão de Queijo

toUpperCase = "para caixa alta" (maiúsculas); toLowerCase = "para caixa baixa" (minúsculas). Os acentos acompanham: Ã, ã (no lab, 'café'.toUpperCase() deu CAFÉ). E repare na última linha: produto continua Pão de Queijo. O método devolveu um texto novo, sem mexer no original (seção 7).

trim: aparar os espaços das pontas

Quando alguém digita (veja Lendo o Teclado), é comum vir espaço sobrando antes ou depois. Os colchetes no print abaixo mostram onde o texto começa e termina:

void main() {
  final digitado = '   ana@email.com  ';
  print('[$digitado]');
  print('[${digitado.trim()}]');
  print('[${digitado.trimLeft()}]');
  print('[${digitado.trimRight()}]');
}

$ dart run aparar.dart
[   ana@email.com  ]
[ana@email.com]
[ana@email.com  ]
[   ana@email.com]

trim tira dos dois lados; trimLeft, só da esquerda; trimRight, só da direita. Os espaços do meio ficam: ' pão de queijo '.trim() é 'pão de queijo'.

Missão: a Ana digitou o nome com espaços sobrando e em minúsculas. Faça o programa mostrar [ANA SOUZA]: aparado e em maiúsculas.

void main() {
  final digitado = '   ana souza ';
  final limpo = digitado;
  print('[$limpo]');
}

void main() {
  final digitado = '   ana souza ';
  final limpo = digitado.trim().toUpperCase();
  print('[$limpo]');
}

4. Cortar um pedaço: substring

substring(inicio, fim) devolve o pedaço que começa na posição inicio e vai até antes da posição fim. Sem o fim, vai até o final:

void main() {
  final data = '19/10/2026';
  print(data.substring(0, 2));
  print(data.substring(3, 5));
  print(data.substring(6));
}

$ dart run pedaco.dart
19
10
2026
Posição0123456789
Caractere19/10/2026

substring(0, 2) pega as posições 0 e 1 (o 2 fica de fora): 19. substring(3, 5): posições 3 e 4, 10. substring(6): da 6 até o fim, 2026. Um jeito de lembrar: o tamanho do pedaço é fim - inicio.

Juntando [0], toUpperCase e substring, dá para pôr só a primeira letra em maiúscula:

void main() {
  final nome = 'ana';
  final bonito = nome[0].toUpperCase() + nome.substring(1);
  print(bonito);
}

$ dart run maiuscula.dart
Ana

5. Trocar e dividir: replaceAll, split e join

void main() {
  final preco = '12,90';
  print(preco.replaceAll(',', '.'));
  final recado = 'bom dia, bom almoço, bom jantar';
  print(recado.replaceAll('bom', 'ótimo'));
  print(recado.replaceFirst('bom', 'ótimo'));
}

$ dart run trocar.dart
12.90
ótimo dia, ótimo almoço, ótimo jantar
ótimo dia, bom almoço, bom jantar

replaceAll(velho, novo) troca todas as ocorrências; replaceFirst, só a primeira. O primeiro uso, trocar a vírgula do preço por ponto, é o que permite converter 12,90 em número com double.tryParse (veja Lendo o Teclado).

split: de um texto para uma lista

void main() {
  final lista = 'arroz,feijão,café';
  final itens = lista.split(',');
  print(itens);
  print(itens.length);
  print(itens[1]);
  print('a b  c'.split(' '));
  print('Ana'.split(''));
  print(itens.join(' - '));
}

$ dart run dividir.dart
[arroz, feijão, café]
3
feijão
[a, b, , c]
[A, n, a]
arroz - feijão - café
split(',')
"Dividir" o texto em cada vírgula. O resultado é uma lista de textos (List<String>), mostrada entre colchetes (veja Listas). A vírgula some: ela só marcava onde cortar.
itens[1] → feijão
Como nos textos, as posições da lista começam do zero.
'a b c'.split(' ') → [a, b, , c]
Com dois espaços seguidos, entre eles sobra um texto vazio. Cuidado com isso ao dividir frases digitadas.
'Ana'.split('') → [A, n, a]
Com o texto vazio como separador, cada caractere vira um item.
itens.join(' - ')
O caminho de volta: "juntar" a lista num texto só, com ' - ' entre os itens. (O join é da lista, não da String.)

Missão: o preço chegou com vírgula e o programa não consegue convertê-lo (sai null). Use replaceAll para trocar a vírgula por ponto antes do double.tryParse, até aparecer R$ 12.90.

void main() {
  final texto = '12,90';
  final preco = double.tryParse(texto);
  print('R\$ ${preco?.toStringAsFixed(2)}');
}

void main() {
  final texto = '12,90';
  final preco = double.tryParse(texto.replaceAll(',', '.'));
  print('R\$ ${preco?.toStringAsFixed(2)}');
}

6. Alinhar: padLeft e padRight

"Preencher à esquerda/direita" até o texto ter um tamanho certo. Ótimo para números com zeros na frente e para tabelinhas alinhadas:

void main() {
  print('7'.padLeft(3, '0'));
  print('42'.padLeft(5) + '|');
  print('Pão'.padRight(10, '.') + 'R\$ 0,75');
  print('Leite'.padRight(10, '.') + 'R\$ 5,49');
  print('ha' * 3);
}

$ dart run alinhar.dart
007
   42|
Pão.......R$ 0,75
Leite.....R$ 5,49
hahaha

padLeft(3, '0'): completa com 0 à esquerda até ter 3 caracteres. Sem o segundo argumento, completa com espaços. Se o texto já for maior, nada muda. E o * repete um texto: 'ha' * 3 é hahaha.

7. Uma String nunca muda

Este é o detalhe que mais confunde quem começa. Nenhum método muda o texto original: todos devolvem um texto novo. Se você não guardar o resultado, ele se perde:

void main() {
  var nome = 'ana';
  nome.toUpperCase();
  print(nome);
  nome = nome.toUpperCase();
  print(nome);
}

$ dart run imutavel.dart
ana
ANA

Na linha 3, o ANA foi criado e jogado fora, porque ninguém o guardou: o print mostrou ana. Na linha 5, o resultado foi guardado de volta na variável (por isso ela é var), e aí sim apareceu ANA. Diz-se que a String do Dart é imutável ("não muda").

Encadear métodos

Como cada método devolve uma String nova, dá para chamar outro método direto no resultado, em fila. O Dart faz da esquerda para a direita:

void main() {
  final digitado = '  pão DE queijo ';
  final limpo = digitado.trim().toLowerCase().replaceAll(' ', '-');
  print(limpo);
}

$ dart run encadear.dart
pão-de-queijo

' pão DE queijo ' → trim() → 'pão DE queijo' → toLowerCase() → 'pão de queijo' → replaceAll(' ', '-') → 'pão-de-queijo'. Se a fila ficar comprida demais, quebre em várias variáveis com nomes que expliquem cada passo.

Missão: a padaria quer o nome do produto sem acento, para o endereço do site. Acrescente mais um replaceAll na fila para trocar ã por a, até aparecer pao-de-queijo.

void main() {
  final digitado = '  pão DE queijo ';
  final limpo = digitado.trim().toLowerCase().replaceAll(' ', '-');
  print(limpo);
}

void main() {
  final digitado = '  pão DE queijo ';
  final limpo = digitado.trim().toLowerCase().replaceAll(' ', '-').replaceAll('ã', 'a');
  print(limpo);
}

Esqueceu os parênteses do método 
void main() {
  final nome = 'ana';
  print(nome.toUpperCase);
}

$ dart run err2.dart
Closure: () => String from Function 'toUpperCase':.

Não deu erro, mas também não deu ANA. Sem os parênteses, você não chamou o método: você pegou o próprio método, e o print mostrou uma descrição dele ("uma função que devolve String"; veja Funções como Valores). Como consertar: nome.toUpperCase().

Pôs parênteses numa propriedade 
void main() {
  final nome = 'Ana';
  print(nome.length());
}

$ dart run err6.dart
err6.dart:3:20: Error: 'length' isn't a function or method and can't be invoked.
  print(nome.length());
                   ^^^^^...

"length não é uma função nem método, e não pode ser chamado." O contrário do caso anterior: length é uma informação, não uma ação. Como consertar: nome.length, sem parênteses. (O mesmo vale para isEmpty e isNotEmpty.)

Tentou mudar uma letra 
void main() {
  var nome = 'ana';
  nome[0] = 'A';
  print(nome);
}

$ dart run err3.dart
err3.dart:3:7: Error: The operator '[]=' isn't defined for the type 'String'.
Try correcting the operator to an existing operator, or defining a '[]=' operator.
  nome[0] = 'A';
      ^

"O operador []= não existe para String": dá para ler uma letra com nome[0], mas não trocar, porque a String é imutável (seção 7). Como consertar: monte um texto novo: nome = nome[0].toUpperCase() + nome.substring(1);.

Chamou o método e esqueceu de guardar

O nome.toUpperCase(); sozinho numa linha não muda nada (seção 7). O Dart não acusa erro. Como consertar: nome = nome.toUpperCase();, ou guarde numa variável nova.

Missão final: as iniciais

Missão: mostre as iniciais do nome da Ana, Iniciais: A.S.. Divida o nome em partes com split(' ') e junte a primeira letra de cada parte (partes[0][0] e partes[1][0]), cada uma seguida de ponto.

void main() {
  final nome = 'ana souza';
  // divida o nome em partes e monte as iniciais
  final iniciais = '';
  print('Iniciais: $iniciais');
}

void main() {
  final nome = 'ana souza';
  final partes = nome.toUpperCase().split(' ');
  final iniciais = '${partes[0][0]}.${partes[1][0]}.';
  print('Iniciais: $iniciais');
}

Resumo

  • Método = ação do texto, com parênteses (t.trim()); propriedade = informação, sem parênteses (t.length).
  • As posições começam em 0; a última é length - 1. Passar dela dá RangeError.
  • toUpperCase/toLowerCase, trim, contains, indexOf, substring, replaceAll, split e padLeft resolvem a maior parte do trabalho com textos.
  • A String é imutável: todo método devolve um texto novo. Guarde o resultado.
  • Dá para encadear: t.trim().toLowerCase().replaceAll(' ', '-').
