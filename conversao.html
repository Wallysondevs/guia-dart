Dart Conversão de Tipos

Tudo o que a pessoa digita no teclado chega ao programa como texto. Se ela digita 30, o programa recebe '30', dois caracteres, e não o número trinta. Antes de fazer conta, é preciso converter. O caminho de volta também acontece: transformar o número em texto para mostrar bonito. Nesta aula você aprende as duas direções, e o que acontece quando o texto não é um número.

Você vai aprender
  • Como transformar texto em número: int.parse, double.parse e num.parse.
  • Como converter sem risco de parar o programa: int.tryParse, que devolve null.
  • Como transformar número em texto: toString(), toStringAsFixed e a interpolação.
  • Como passar de int para double e de volta.
  • Como lidar com o preço digitado com vírgula (4,50).
  • Os erros reais: FormatException, texto numa variável int, int? num int, e o as que não converte.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: o número escrito no papel

Na padaria, a cliente deixa um bilhete: "30 pães". Esse "30" no papel é tinta: você não consegue somar 1 ao papel. Primeiro você lê o bilhete e entende "trinta"; aí, sim, faz a conta de cabeça. Depois, para responder, você escreve o resultado num papel de novo.

No Dart é igual. '30' (com aspas) é o bilhete: uma String. 30 (sem aspas) é o número de verdade: um int. Ler o bilhete é o parse (em inglês, "analisar"); escrever de volta é o toString ("para texto"). O Dart nunca faz essa troca sozinho: você pede.

1. De texto para número: parse

void main() {
  var textoIdade = '30';
  var textoPreco = '4.50';
  int idade = int.parse(textoIdade);
  double preco = double.parse(textoPreco);
  print(idade + 1);
  print(preco * 2);
  print(textoIdade + '1');
  print(double.parse('7'));
  print(num.parse('7'));
  print(num.parse('7.5'));
  print(int.parse(' 42 '));
  print(int.parse('-15'));
  print(int.parse('ff', radix: 16));
}

Repare na forma: int.parse(…) é uma função que pertence ao tipo int, não a uma variável. Você chama pelo nome do tipo que quer receber.

Missão: a quantidade e o preço chegaram como texto, e o programa nem compila (multiplicar dois textos não faz sentido). Converta textoQtd com int.parse e textoPreco com double.parse, guarde em variáveis e mostre Total: R$ 7.50.

void main() {
  var textoQtd = '3';
  var textoPreco = '2.50';
  print('Total: R\$ ${textoQtd * textoPreco}');
}

void main() {
  var textoQtd = '3';
  var textoPreco = '2.50';

  var preco = double.parse(textoPreco);

Se você rodar o código inicial, verá o erro real: A value of type 'String' can't be assigned to a variable of type 'int'. (o * de um texto espera um int, o número de repetições, como em '-' * 20).

2. Converter sem parar o programa: tryParse

E se o texto não for um número? Com parse, o programa para com uma exceção (veja Quando dá errado). Quando o texto vem de uma pessoa, que pode digitar qualquer coisa, use o tryParse ("tentar analisar"):

void main() {
  print(int.tryParse('42'));
  print(int.tryParse('abc'));
  print(int.tryParse('4.5'));
  print(double.tryParse('4,50'));
  var quantidade = int.tryParse('doze') ?? 0;
  print(quantidade);
}

$ dart run tryparse.dart

int.tryParse('42')
Deu certo: devolve 42.

Não é número: em vez de parar, devolve null, o "nada" do Dart.

Tem ponto: não é um int válido, null.

Com vírgula, nem o double entende: null.
int.tryParse('doze') ?? 0
O ?? quer dizer "se der null, use este outro valor". Aqui, 0. É o par perfeito do tryParse (aula ?. , ?? e ??=).

Por poder devolver null, o tipo do resultado de int.tryParse não é int: é int? ("int ou nada"). O Dart cobra que você trate o caso do null; o porquê está em Null Safety.

3. De número para texto: toString

void main() {
  int paes = 7;
  double preco = 0.8;
  String a = paes.toString();
  String b = preco.toString();
  String c = (paes * preco).toStringAsFixed(2);
  String d = '$paes';
  print(a + ' pães');
  print(b);
  print(c);
  print(d.length);
  print(255.toRadixString(2));
}

$ dart run tostring.dart

paes.toString()
O int 7 vira o texto '7'. Agora o + ' pães' funciona.

'$paes'
A interpolação também converte: '$paes' é o texto '7', de tamanho 1. Na prática, é o jeito mais usado.

4. Entre int e double

void main() {
  int inteiro = 7;
  double decimal = 7.9;
  print(inteiro.toDouble());
  print(decimal.toInt());
  print(decimal.round());
  print(decimal.floor());
  print(decimal.ceil());
}

$ dart run numeros.dart
7.0
7
8
7
8

toDouble() nunca perde nada. Já de double para int você escolhe o que fazer com as casas decimais: toInt() corta (7.9 vira 7), round() arredonda (8), floor() vai para baixo (7), ceil() vai para cima (8). Detalhes em int e double.

5. O preço digitado com vírgula

No Brasil, a Ana digita 4,50. O double.parse só entende ponto. A solução é trocar a vírgula por ponto antes de converter:

void main() {
  var digitado = '4,50';
  var preco = double.parse(digitado.replaceAll(',', '.'));
  print(preco);
}

$ dart run virgula.dart
4.5

O replaceAll(',', '.') ("trocar todos") devolve um texto novo, '4.50', e o parse lê esse texto. Mais métodos de texto em Métodos de String. (Para ler do teclado de verdade, veja Lendo o Teclado.)

"O tipo String não é um subtipo do tipo int, na conversão de tipo (type cast)." O as não transforma nada: ele só afirma "confie em mim, isto já é um int". Missão final: o caixa que não quebra

Missão: a cliente digitou o preço 12,90 (com vírgula) e a quantidade dois (por extenso). O programa para com FormatException. Conserte: use int.tryParse(…) ?? 1 na quantidade (se não der, conta 1) e troque a vírgula por ponto antes do double.parse. A saída deve ser Quantidade: 1 e Total: R$ 12.90.

void main() {
  var digitado = '12,90';
  var quantidade = int.parse('dois');
  var preco = double.parse(digitado);
  var total = preco * quantidade;
  print('Quantidade: $quantidade');
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

void main() {
  var digitado = '12,90';
  var quantidade = int.tryParse('dois') ?? 1;
  var preco = double.parse(digitado.replaceAll(',', '.'));
  var total = preco * quantidade;
  print('Quantidade: $quantidade');
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

No lab, a solução mostrou:

$ dart run caixa.dart
Quantidade: 1
Total: R$ 12.90

Resumo

  • O Dart não converte tipos sozinho: '30' (texto) e 30 (número) são coisas diferentes.
  • Texto → número: int.parse, double.parse, num.parse. Se o texto não for número, o programa para com FormatException.
  • int.tryParse / double.tryParse devolvem null em vez de parar; o tipo é int?, e ?? valor dá um valor para o caso do null.
  • Número → texto: '$n', toString(), toStringAsFixed(2).
  • int → double: toDouble(). double → int: toInt(), round(), floor(), ceil().
  • Preço com vírgula: replaceAll(',', '.') antes do parse. E o as não converte: só afirma o tipo.
