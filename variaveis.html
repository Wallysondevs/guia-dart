Dart Variáveis (var)

Até aqui, os programas mostravam sempre o mesmo texto, escrito direto no print. Programas de verdade precisam guardar informações: quantos pães sobraram, o nome da cliente, o preço do café. Para isso servem as variáveis: espaços com nome onde o programa guarda um valor para usar depois, quantas vezes quiser, e trocar quando precisar.

Você vai aprender
  • O que é uma variável e como criá-la com var.
  • A usar a variável no print e em contas.
  • A trocar o valor guardado, inclusive usando o valor antigo (paes = paes - 4).
  • Que o Dart descobre o tipo da variável sozinho, e que esse tipo não muda mais.
  • A escrever o tipo no lugar do var: int, double, String.
  • A criar a variável agora e dar o valor depois.
  • Os erros reais: usar antes de criar, criar duas vezes, trocar o tipo, usar sem valor e errar o nome.

Os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook), na pasta pessoal dela, com dart run arquivo.dart.

A ideia: potes com etiqueta

Na lojinha da Ana há uma prateleira de potes. Cada pote tem uma etiqueta com um nome ("balas", "troco") e, dentro, uma coisa. Para saber quanto troco há, ela não precisa decorar: olha o pote com a etiqueta "troco". E pode esvaziar o pote e pôr outra quantidade.

1. Criando uma variável com var

void main() {
  var nome = 'Ana';
  print(nome);
  print(nome);
}

$ dart run primeira.dart
Ana
Ana
var
De variable, "variável": "vou criar um pote novo". Criar uma variável se chama declarar.
nome
A etiqueta. Você escolhe, seguindo regras (aula Nomes de Variáveis): sem espaços, sem acento, começando com letra minúscula.
=
Não é o "igual" da matemática: quer dizer "guarde". Pegue o que está à direita e ponha na variável da esquerda. Isso se chama atribuir.
'Ana'
O valor guardado: o texto Ana.
print(nome)
Sem aspas, nome é a etiqueta: o print mostra o que está dentro do pote. Usamos duas vezes; o valor continua lá.
Com aspas é texto; sem aspas é variável 
void main() {
  var nome = 'Ana';
  print('nome');
  print(nome);
}

$ dart run aspas.dart
nome
Ana

'nome' é a palavra "nome", e é ela que aparece. nome é a variável, e aparece o que ela guarda.

2. Usando variáveis em contas e textos

Uma variável pode entrar em qualquer lugar onde entraria o valor dela:

void main() {
  var item = 'café';
  var quantidade = 2;
  var preco = 18.5;
  print(item);
  print(quantidade * preco);
  print('Comprar $quantidade de $item');
}

$ dart run compras.dart
café
37.0
Comprar 2 de café
quantidade * preco
O Dart troca cada nome pelo valor (2 * 18.5) e calcula: 37.0. O .0 aparece porque a conta envolve um número com casas decimais (aula Números).
'Comprar $quantidade de $item'
Dentro de um texto, $ seguido do nome da variável é trocado pelo valor dela. Isso é a interpolação, que tem a sua própria aula: Interpolação.

Missão: mude só os valores das variáveis (não mexa no print) para o programa mostrar Comprar 3 de pão.

void main() {
  var item = 'café';
  var quantidade = 2;
  print('Comprar $quantidade de $item');
}

void main() {
  var item = 'pão';
  var quantidade = 3;
  print('Comprar $quantidade de $item');
}

3. Trocando o valor

O nome diz: variável é o que varia. Para trocar o valor, use o = de novo, agora sem o var (o pote já existe):

void main() {
  var paes = 30;
  print(paes);
  paes = 25;
  print(paes);
  paes = paes - 4;
  print(paes);
}

$ dart run estoque.dart
30
25
21
var paes = 30;
Cria o pote paes com 30 dentro.
paes = 25;
Joga fora o 30 e guarda 25. O valor antigo se perde.
paes = paes - 4;
Em matemática, isso seria absurdo. Aqui, lembre que = é "guarde": primeiro o Dart calcula o lado direito com o valor atual (25 - 4 = 21), depois guarda o resultado em paes. Quatro pães foram vendidos.

Repare na ordem: cada print mostra o valor daquele momento. O programa roda de cima para baixo, e a variável guarda só o último valor atribuído. Há atalhos para esse tipo de conta (paes -= 4, paes--), na aula Atribuição e Incremento.

Missão: o pote tem 12 balas e a Bia comprou 5. Depois do primeiro print, tire 5 do valor de balas usando o próprio balas (sem escrever o 7), e mostre de novo.

void main() {
  var balas = 12;
  print(balas);
}

void main() {
  var balas = 12;
  print(balas);
  balas = balas - 5;
  print(balas);
}

4. O tipo: o Dart descobre e não esquece

Toda variável tem um tipo: o tipo de valor que ela aceita. Com var, o Dart olha o primeiro valor e decide sozinho (isso se chama inferência de tipo):

DeclaraçãoTipo que o Dart descobreQuer dizer
var nome = 'Ana';StringTexto
var quantidade = 2;intNúmero inteiro
var preco = 18.5;doubleNúmero com casas decimais

Depois de decidido, o tipo não muda mais. O pote de paes é um pote de números inteiros: guardar um texto nele é erro (veja em "Quando dá errado"). Os tipos têm aula própria: Os Tipos Básicos.

Escrevendo o tipo no lugar do var

Você também pode dizer o tipo com todas as letras:

void main() {
  String cliente = 'Bia';
  int pedidos = 3;
  double troco = 2.5;
  print(cliente);
  print(pedidos);
  print(troco);
}

$ dart run tipada.dart
Bia
3
2.5

O resultado é o mesmo que com var. Repare que String começa com maiúscula, e int e double, com minúscula: é assim que eles se chamam.

Criar agora, guardar depois

Com o tipo escrito, dá para criar a variável sem valor e atribuir mais tarde, desde que seja antes de usá-la:

void main() {
  int total;
  total = 12 + 8;
  print(total);
}

$ dart run depois.dart
20

FormaExemploQuando usar

Tipo sem valorint total;Quando o valor só vai ser conhecido mais adiante.

  coisa = 10;
  print(coisa);

$ dart run var_vazio.dart

Sem um valor inicial, o Dart não tem como descobrir o tipo, e a variável vira dynamic ("dinâmico"): aceita qualquer coisa, número agora, texto depois. Parece cômodo, mas você perde a proteção que o Dart dá conferindo os tipos antes de rodar, e nenhuma ferramenta reclama. Se não tem o valor ainda, escreva o tipo: int coisa;. Mais em dynamic e Object.

Usar antes de criar 
void main() {
  print(nome);
  var nome = 'Ana';
}

$ dart run antes.dart
antes.dart:2:9: Error: Undefined name 'nome'.
  print(nome);
        ^^^^
antes.dart:2:9: Error: Local variable 'nome' can't be referenced before it is declared.
  print(nome);
        ^^^^
antes.dart:3:7: Context: This is the declaration of the variable 'nome'.
  var nome = 'Ana';
      ^^^^
$ echo $?
254
Undefined name 'nome'.
"Nome não definido": na linha 2, ainda não existe nada chamado nome.
Local variable 'nome' can't be referenced before it is declared.
"A variável local nome não pode ser usada antes de ser declarada." O Dart percebeu que ela existe, só que mais abaixo.
Context: This is the declaration of the variable 'nome'.
Uma mensagem de contexto (não é outro erro): "esta é a declaração da variável", apontando a linha 3.

O programa roda de cima para baixo: primeiro crie o pote, depois use. Como consertar: troque as duas linhas de lugar.

Criar duas vezes 
void main() {
  var paes = 30;
  var paes = 25;
  print(paes);
}

$ dart run duas_vezes.dart
duas_vezes.dart:3:7: Error: 'paes' is already declared in this scope.
  var paes = 25;
      ^^^^
duas_vezes.dart:2:7: Context: Previous declaration of 'paes'.
  var paes = 30;
      ^^^^

"paes já foi declarada neste escopo" (escopo é o pedaço do código onde o nome vale; aqui, o main). O contexto mostra a "declaração anterior", na linha 2. Não dá para ter dois potes com a mesma etiqueta na mesma prateleira. A Ana queria só trocar o valor. Como consertar: tire o var da linha 3: paes = 25;.

Guardar um valor de outro tipo 
void main() {
  var paes = 30;
  paes = 'trinta';
  print(paes);
}

$ dart run muda_tipo.dart
muda_tipo.dart:3:10: Error: A value of type 'String' can't be assigned to a variable of type 'int'.
  paes = 'trinta';
         ^

"Um valor do tipo String não pode ser atribuído a uma variável do tipo int". O var paes = 30 fez de paes uma variável int para sempre. Como consertar: guarde um número, paes = 30;; se você precisa de um texto, crie outra variável.

Usar sem ter guardado nada 
void main() {
  int total;
  print(total);
}

$ dart run sem_valor.dart
sem_valor.dart:3:9: Error: Non-nullable variable 'total' must be assigned before it can be used.
  print(total);
        ^^^^^

"A variável não anulável total precisa receber um valor antes de ser usada." O pote foi criado vazio e ninguém pôs nada dentro. Não anulável (non-nullable) quer dizer que ela não pode ficar "vazia" (null): é a null safety do Dart, que tem um grupo inteiro de aulas, começando em Null Safety. Como consertar: atribua antes de usar, total = 20;, ou já crie com valor: int total = 20;.

Nome escrito errado 
void main() {
  var quantidade = 3;
  print(quantidde);
}

$ dart run digitou.dart
digitou.dart:3:9: Error: Undefined name 'quantidde'.
  print(quantidde);
        ^^^^^^^^^

Faltou um a. Para o Dart, quantidde é um nome que ninguém criou. O mesmo vale para maiúsculas: Quantidade e quantidade são variáveis diferentes. Como consertar: copie o nome exatamente como foi declarado (no VS Code, o editor completa o nome enquanto você digita).

  var pago = 30;

}

void main() {
  var cliente = 'Bia';
  var quantidade = 4;
  var preco = 6;
  var pago = 30;
  var total = quantidade * preco;

  print('Troco: $troco');
}

Resumo

  • Uma variável é um pote com etiqueta: um nome que guarda um valor. var nome = valor; cria e guarda.
  • O = quer dizer "guarde": calcula a direita e guarda na esquerda. paes = paes - 4 usa o valor atual.
  • Para trocar o valor, sem var. Cada print mostra o valor daquele momento.
  • Com var, o Dart descobre o tipo pelo primeiro valor (int, double, String), e ele não muda mais. Também dá para escrever o tipo: int paes = 30;.
  • int total; cria sem valor, mas é preciso guardar algo antes de usar. Evite var sem valor (vira dynamic).
  • Sem aspas é a variável; com aspas é o texto.
  • Erros: Undefined name (nome errado ou ainda não criado), already declared (var repetido), tipo diferente, e must be assigned before it can be used.
