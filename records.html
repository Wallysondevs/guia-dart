Dart Records Dart 3.0

Uma lista guarda vários valores do mesmo tipo: várias notas, vários nomes. Mas às vezes você quer juntar valores diferentes que andam juntos: o nome de uma aluna e a idade dela; o nome de um produto e o preço. Para isso, o Dart 3.0 trouxe os records (em inglês, "registros"): um pacotinho com alguns valores, escrito entre parênteses, como ('Ana', 30).

Você vai aprender
  • Como criar um record e ler os campos dele com $1, $2…
  • Como dar nome aos campos: (nome: 'café', preco: 18.9).
  • Como se escreve o tipo de um record: (String, int).
  • O uso mais comum: uma função que devolve dois valores de uma vez.
  • Que dois records com os mesmos valores são iguais (==), e que um record não pode ser mudado.
  • Quando usar record, lista, mapa ou classe, e os erros reais do Dart.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart. Records existem desde o Dart 3.0 (maio de 2023); num Dart 2, eles não existem (veja o fim da seção Quando dá errado).

A ideia: a etiqueta do produto

Na padaria, cada produto tem uma etiqueta com duas informações: o nome e o preço. As duas andam sempre juntas; não faz sentido um preço solto, sem saber de quê. E a etiqueta é pequena: ninguém vai criar uma ficha completa para ela.

Um record é essa etiqueta: um pacotinho com poucos valores, de tipos que podem ser diferentes, que viajam juntos. Ele é mais simples que uma classe (que você vai ver adiante) e mais organizado que dois valores soltos.

1. O primeiro record

void main() {
  final aluna = ('Ana', 30);
  print(aluna);
  print(aluna.$1);
  print(aluna.$2);
}
('Ana', 30)
Um record: valores entre parênteses, separados por vírgula. Aqui, um texto e um número. Cada valor é um campo.
final aluna = …;
Guarda o record numa variável, como qualquer outro valor.
aluna.$1
O primeiro campo. Os campos sem nome se chamam $1, $2, $3… e a contagem começa em 1 (e não em 0, como nas listas).
aluna.$2
O segundo campo: 30.
$ dart run primeiro.dart
(Ana, 30)
Ana
30

O tipo de um record

O tipo se escreve do mesmo jeito que o valor: os tipos dos campos entre parênteses. (String, int) quer dizer "um record com um texto e depois um inteiro".

void main() {
  (String, int) aluna = ('Ana', 30);
  (String, double, bool) produto = ('café', 18.9, true);
  print(aluna);
  print(produto);
  print('${produto.$1} custa R\$ ${produto.$2}');
  print(aluna.runtimeType);
}

$ dart run tipo.dart
(Ana, 30)
(café, 18.9, true)
café custa R$ 18.9
(String, int)

O runtimeType ("tipo em tempo de execução") confirma: o tipo é (String, int). A ordem importa: (String, int) e (int, String) são tipos diferentes. O \$ dentro do texto é um cifrão de verdade, e não o começo de uma interpolação.

Missão: o record aluna tem o nome e a idade. Complete o print usando aluna.$1 e aluna.$2 para mostrar Bia tem 25 anos.

void main() {
  final aluna = ('Bia', 25);
  print('??? tem ??? anos');
}

void main() {
  final aluna = ('Bia', 25);
  print('${aluna.$1} tem ${aluna.$2} anos');
}

2. Campos com nome

$1 e $2 são fáceis de confundir: qual era o preço mesmo? Dá para dar um nome a cada campo, escrevendo nome: valor:

void main() {
  final produto = (nome: 'café', preco: 18.9);
  print(produto);
  print(produto.nome);
  print(produto.preco);

  ({String nome, int idade}) aluna = (nome: 'Bia', idade: 25);
  print('${aluna.nome} tem ${aluna.idade} anos');
}

$ dart run nomeados.dart
(nome: café, preco: 18.9)
café
18.9
Bia tem 25 anos
(nome: 'café', preco: 18.9)
Um record com dois campos nomeados. Lê-se como uma etiqueta: nome café, preço 18.9.
produto.nome
Lê o campo pelo nome. Bem mais claro que $1.
({String nome, int idade})
O tipo de um record com campos nomeados: os campos vão entre chaves, dentro dos parênteses, cada um com tipo e nome.

Misturando os dois

Um record pode ter campos sem nome e com nome ao mesmo tempo. Os sem nome continuam sendo $1, $2…:

void main() {
  final venda = ('pão', 3, total: 4.5, pago: true);
  print(venda);
  print(venda.$1);
  print(venda.$2);
  print(venda.total);
  print(venda.pago);
}

$ dart run misto.dart
(pão, 3, pago: true, total: 4.5)
pão
3
4.5
true

Repare no print(venda): no código, total vinha antes de pago, mas o Dart mostrou pago primeiro. Para um record, a ordem dos campos com nome não importa (só a dos sem nome importa); no lab, o print os mostrou em ordem alfabética.

3. Devolver dois valores de uma função

Este é o motivo número um para usar records. Uma função devolve um valor com return. Se ela precisa devolver dois (a menor e a maior nota, por exemplo), basta devolver um record com os dois:

(int, int) menorEMaior(List<int> notas) {
  var menor = notas.first;
  var maior = notas.first;
  for (final n in notas) {
    if (n < menor) menor = n;
    if (n > maior) maior = n;
  }
  return (menor, maior);
}

void main() {
  final resultado = menorEMaior([7, 9, 4, 10, 6]);
  print(resultado);
  print('Menor: ${resultado.$1}');
  print('Maior: ${resultado.$2}');

  final (menor, maior) = menorEMaior([5, 8, 3]);
  print('Menor: $menor, maior: $maior');
}
(int, int) menorEMaior(…)
O tipo de retorno da função é um record com dois inteiros.
return (menor, maior);
Devolve os dois valores juntos, num record.
final resultado = …; resultado.$1
Um jeito de usar: guardar o record e ler os campos.
final (menor, maior) = …;
Outro jeito: desmontar o record em duas variáveis numa linha só. Isso se chama desestruturação e é assunto da próxima aula, Patterns e Desestruturação.
$ dart run funcao.dart
(4, 10)
Menor: 4
Maior: 10
Menor: 3, maior: 8

Com campos nomeados, quem chama a função não precisa decorar a ordem:

({double total, int itens}) fecharConta(List<double> precos) {
  var soma = 0.0;
  for (final p in precos) {
    soma += p;
  }
  return (total: soma, itens: precos.length);
}

void main() {
  final conta = fecharConta([4.5, 12.9, 3.25]);
  print(conta);
  print('${conta.itens} itens, total R\$ ${conta.total.toStringAsFixed(2)}');
}

$ dart run nomeadafuncao.dart
(itens: 3, total: 20.65)
3 itens, total R$ 20.65

Missão: a função dividir deve devolver o quociente (a ~/ b) e o resto (a % b) juntos, num record. Troque o tipo de retorno para (int, int) e o return para devolver os dois. Para 14 dividido por 10, o resultado deve ser (1, 4).

int dividir(int a, int b) {
  return a ~/ b;
}

void main() {
  print(dividir(14, 10));
}

(int, int) dividir(int a, int b) {
  return (a ~/ b, a % b);
}

void main() {
  print(dividir(14, 10));
}

4. Comparando records

Dois records são iguais (==) quando têm os mesmos campos com os mesmos valores:

void main() {
  final a = ('Ana', 30);
  final b = ('Ana', 30);
  final c = ('Ana', 31);
  print(a == b);
  print(a == c);
  print((nome: 'Ana', idade: 30) == (idade: 30, nome: 'Ana'));
}

$ dart run igual.dart
true
false
true

a e b foram criados separadamente, mas têm o mesmo conteúdo: são iguais. No último, os campos com nome estão em outra ordem, e mesmo assim são iguais. (Com objetos de classes, não é assim que funciona por padrão; veja toString, == e hashCode.)

Um record não muda

Depois de criado, um record não pode ter um campo trocado (ele é imutável). Para "mudar", crie um record novo:

void main() {
  var aluna = ('Ana', 30);
  aluna = (aluna.$1, aluna.$2 + 1);
  print(aluna);
}

$ dart run novo.dart
(Ana, 31)

A variável é var, então pode receber outro record. O record antigo não foi alterado: foi substituído. Tentar aluna.$2 = 31 dá erro (veja abaixo).

Record de um campo só

Um record de um campo precisa de uma vírgula no fim. Sem ela, os parênteses são só parênteses comuns:

void main() {
  final soUm = ('Ana',);
  final semVirgula = ('Ana');
  print(soUm);
  print(semVirgula);
  print(soUm.runtimeType);
  print(semVirgula.runtimeType);
}

$ dart run umcampo.dart
(Ana)
Ana
(String)
String

Record, lista, mapa ou classe?

As quatro coisas podem guardar "o nome e o preço do café":

class Produto {
  final String nome;
  final double preco;
  Produto(this.nome, this.preco);
}

void main() {
  final r = (nome: 'café', preco: 18.9);
  final m = {'nome': 'café', 'preco': 18.9};
  final p = Produto('café', 18.9);
  print(r.nome);
  print(m['nome']);
  print(p.nome);
}

$ dart run formas.dart
café
café
café

Quando dá errado

Tentou mudar um campo 
void main() {
  final aluna = ('Ana', 30);
  aluna.$2 = 31;
  print(aluna);
}

$ dart run mudar.dart
mudar.dart:3:9: Error: The setter '$2' isn't defined for the type '(String, int)'.
Try correcting the name to the name of an existing setter, or defining a setter or field named '$2'.
  aluna.$2 = 31;
        ^^
$ echo $?
254
mudar.dart:3:9
Linha 3, coluna 9: os ^^ marcam o $2.
Error: The setter '$2' isn't defined for the type '(String, int)'.
"O setter $2 não está definido para o tipo (String, int)." Um setter é o que permite escrever num campo (veja get e set). Os campos de um record só podem ser lidos.
Try correcting the name…
"Tente corrigir o nome ou definir um setter…" É uma sugestão genérica do Dart; aqui não se aplica, porque o nome está certo: o problema é que record não muda.

Como consertar: crie um record novo: var aluna = …; aluna = (aluna.$1, 31);.

Começou a contar do zero ($0) 
void main() {
  final aluna = ('Ana', 30);
  print(aluna.$0);
}

$ dart run dolar0.dart
dolar0.dart:3:15: Error: The getter '$0' isn't defined for the type '(String, int)'.
Try correcting the name to the name of an existing getter, or defining a getter or field named '$0'.
  print(aluna.$0);
              ^^

"O getter $0 não está definido." Um getter é o que permite ler um campo. Nas listas, o primeiro item é o [0]; nos records, o primeiro campo é o $1. Como consertar: aluna.$1. (Pedir um campo que não existe, como $3 num record de dois, dá a mesma mensagem.)

Pediu um nome que o record não tem 
void main() {
  final aluna = ('Ana', 30);
  print(aluna.nome);
}

$ dart run nomeerrado.dart
nomeerrado.dart:3:15: Error: The getter 'nome' isn't defined for the type '(String, int)'.
Try correcting the name to the name of an existing getter, or defining a getter or field named 'nome'.
  print(aluna.nome);
              ^^^^

O record foi criado sem nomes: o tipo é (String, int), e o Dart não tem como saber que o primeiro campo "é o nome". Como consertar: use aluna.$1, ou crie o record com nomes: (nome: 'Ana', idade: 30).

Valores na ordem errada 
void main() {
  (String, int) aluna = (30, 'Ana');
  print(aluna);
}

$ dart run tipoerrado.dart
tipoerrado.dart:2:25: Error: A value of type '(int, String)' can't be assigned to a variable of type '(String, int)'.
  (String, int) aluna = (30, 'Ana');
                        ^

"Um valor do tipo (int, String) não pode ser guardado numa variável do tipo (String, int)." A ordem dos campos sem nome faz parte do tipo. Do mesmo jeito, faltar um campo com nome também é outro tipo: ({String nome, int idade}) aluna = (nome: 'Ana'); dá A value of type '({String nome})' can't be assigned to a variable of type '({int idade, String nome})'.

Código preso numa versão antiga do Dart

Records só existem a partir do Dart 3.0. Um arquivo pode pedir para ser lido como uma versão antiga com o comentário especial // @dart=2.19 no topo (você vai encontrá-lo em projetos antigos). Aí, o record vira erro:

// @dart=2.19
void main() {
  final aluna = ('Ana', 30);
  print(aluna);
}

$ dart run antigo.dart
antigo.dart:3:17: Error: The 'records' language feature is disabled for this library.
Try removing the `@dart=` annotation or setting the language version to 3.0 or higher.
  final aluna = ('Ana', 30);
                ^
antigo.dart:1:1: Context: This is the annotation that opts out this library from the 'records' language feature.
// @dart=2.19
^^^^^^^^^^^^^

"O recurso records está desligado para esta biblioteca. Tente remover a anotação @dart= ou usar a versão 3.0 ou maior." A segunda parte (Context:, "contexto") mostra o culpado: o comentário da linha 1. Como consertar: apague o comentário. Num projeto, a versão mínima fica no pubspec.yaml (sdk: ^3.0.0 ou maior).

Missão final: a média da turma

Missão: complete a função resumo para devolver um record com dois campos nomeados: quantidade (o número de notas) e media (a soma dividida pela quantidade). O programa deve mostrar 4 notas, média 7.5.

({int quantidade, double media}) resumo(List<double> notas) {
  var soma = 0.0;
  for (final n in notas) {
    soma += n;
  }
  // devolva o record aqui
}

void main() {
  final r = resumo([8.0, 6.5, 9.0, 6.5]);
  print('${r.quantidade} notas, média ${r.media}');
}

({int quantidade, double media}) resumo(List<double> notas) {
  var soma = 0.0;
  for (final n in notas) {
    soma += n;
  }
  return (quantidade: notas.length, media: soma / notas.length);
}

void main() {
  final r = resumo([8.0, 6.5, 9.0, 6.5]);
  print('${r.quantidade} notas, média ${r.media}');
}

Resumo

  • Um record junta poucos valores, de tipos que podem ser diferentes, entre parênteses: ('Ana', 30). Existe desde o Dart 3.0.
  • Campos sem nome se leem com $1, $2… (começa em 1); campos com nome, pelo nome: (nome: 'café').nome.
  • O tipo se escreve como o valor: (String, int) ou ({String nome, int idade}).
  • O uso mais comum: uma função que devolve dois ou mais valores.
  • Records com os mesmos campos e valores são iguais (==), e nenhum campo pode ser mudado.
  • Para desmontar um record em variáveis (final (a, b) = …), veja a próxima aula: Patterns e Desestruturação.
