Dart is, is! e as

Às vezes uma variável pode guardar valores de tipos diferentes: um número, um texto, um sim/não. É o caso das variáveis do tipo Object e dynamic (aula dynamic e Object). Antes de usar um valor assim, o programa precisa perguntar o que ele é. Para isso o Dart tem três operadores de tipo: is ("é?"), is! ("não é?") e as ("trate como").

Você vai aprender
  • O is: pergunta se um valor é de um tipo, e responde true ou false.
  • A promoção de tipo: depois de um if (x is String), o Dart deixa usar x como texto.
  • O is!: a pergunta ao contrário.
  • O as: afirma o tipo, e o que acontece quando a afirmação é falsa.
  • Como int, double, num, Object e null respondem ao is.
  • Os erros reais: usar um Object sem perguntar, o as que falha, o !is que compila e engana, e o NoSuchMethodError do dynamic.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: a caixa de achados e perdidos

Na secretaria da escola tem uma caixa de achados e perdidos. Pode ter de tudo lá dentro: um guarda-chuva, um estojo, uma garrafa. Antes de fazer qualquer coisa com o objeto, a secretária olha o que ele é: "isto é um guarda-chuva? Então posso abrir." Ninguém tenta abrir uma garrafa como se fosse guarda-chuva.

  • Perguntar "isto é um guarda-chuva?" é o is.
  • Dizer "isto é um guarda-chuva, pode confiar" e sair abrindo, sem olhar, é o as. Se a pessoa estiver enganada, dá problema.

Uma variável Object é a caixa de achados e perdidos: o Dart só sabe que tem "alguma coisa" lá dentro.

1. is: "é deste tipo?"

void main() {
  Object valor = 42;
  print(valor is int);
  print(valor is String);
  print(valor is num);
  print(valor is double);
  print(valor is Object);
  print(valor is! String);
}

$ dart run is.dart
true
false
true
false
true
true
Object valor = 42;
A variável é do tipo Object ("objeto", qualquer coisa que não seja null). Dentro dela está um int, mas o Dart, olhando a declaração, só sabe que é "alguma coisa".
valor is int → true
"O valor é um int?" Sim. O is olha o valor de verdade, na hora em que o programa roda.
valor is String → false
Não é texto.
valor is num → true
num é o tipo "número", que engloba int e double. Todo int também é num, como todo cachorro também é animal.
valor is double → false
Um int não é um double.
valor is Object → true
Todo valor (menos o null) é um Object.
valor is! String → true
O is! é a pergunta ao contrário: "não é String?" Verdade, não é. (O ! fica depois do is, grudado.)

2. A promoção de tipo: depois do is, o Dart confia

Com uma variável Object, o Dart não deixa usar nada de texto, nem de número: ele não sabe o que tem lá dentro. Mas, dentro de um if que já perguntou, ele sabe:

void main() {
  Object resposta = 'abacaxi';
  if (resposta is String) {
    print('É um texto com ${resposta.length} letras');
    print(resposta.toUpperCase());
  }
}

$ dart run promocao.dart
É um texto com 7 letras
ABACAXI

Dentro das chaves do if (resposta is String), a variável resposta é tratada como String: o .length (número de letras) e o .toUpperCase() (tudo maiúsculo) funcionam. Isso se chama promoção de tipo (em inglês, type promotion): o tipo da variável "sobe" de Object para String naquele trecho. Sem o if, o mesmo .length não compila (veja Quando dá errado). O if em si é assunto da próxima aula, if e else.

Com uma pergunta para cada tipo, dá para tratar cada valor do jeito certo:

String descrever(Object valor) {
  if (valor is int) {
    return '$valor é um número inteiro; o dobro é ${valor * 2}';
  }
  if (valor is double) {
    return '$valor é um número com vírgula; arredondado: ${valor.round()}';
  }
  if (valor is String) {
    return '"$valor" é um texto com ${valor.length} letras';
  }
  if (valor is bool) {
    return '$valor é um sim/não; o contrário é ${!valor}';
  }
  return '$valor é de outro tipo: ${valor.runtimeType}';
}

void main() {
  print(descrever(7));
  print(descrever(2.6));
  print(descrever('Ana'));
  print(descrever(true));
  print(descrever([1, 2]));
}

$ dart run descreve.dart
7 é um número inteiro; o dobro é 14
2.6 é um número com vírgula; arredondado: 3
"Ana" é um texto com 3 letras
true é um sim/não; o contrário é false
[1, 2] é de outro tipo: List<int>

A função descrever (você vai aprender a escrever as suas em Funções) recebe qualquer coisa. Em cada if, a promoção libera o que aquele tipo sabe fazer: conta com int, round() com double, length com String, ! com bool. O último caso, uma lista, caiu no return do fim, e o .runtimeType mostrou o tipo exato: List<int>, lista de inteiros.

Missão: o pedido chegou numa variável Object. Troque o int do if por String e, dentro do if, mostre o pedido em maiúsculas com pedido.toUpperCase(), para sair Texto em maiúsculas: BOLO.

void main() {
  Object pedido = 'bolo';
  if (pedido is int) {
    print('É um número: $pedido');
  }
  print('Fim');
}

void main() {
  Object pedido = 'bolo';
  if (pedido is String) {
    print('Texto em maiúsculas: ${pedido.toUpperCase()}');
  }
  print('Fim');
}

3. is!: "não é deste tipo?"

void main() {
  Object entrada = 3.5;
  if (entrada is! int) {
    print('Não é inteiro: é ${entrada.runtimeType}');
  }
}

$ dart run isnot.dart
Não é inteiro: é double

entrada is! int é o mesmo que !(entrada is int). Escreva sempre is!, com o ! depois: o !is, com o ! antes, compila e dá a resposta errada (veja Quando dá errado).

4. Números, num e null

void main() {
  Object a = 5;
  Object b = 5.0;
  print(a is int);
  print(b is int);
  print(b is double);
  print(a is num && b is num);
  print(a.runtimeType);
  print(b.runtimeType);
}

$ dart run num.dart
true
false
true
true
int
double

Para o ==, 5 == 5.0 é true (aula Comparação), mas os tipos são diferentes: 5.0 é um double, não um int. Se você só quer saber "é um número?", pergunte is num.

E o null, o "vazio" (aula Tipos Anuláveis)?

void main() {
  int? idade;
  print(idade is int);
  print(idade is int?);
  print(idade is Null);
  idade = 30;
  print(idade is int);
}

$ dart run nulo.dart
false
true
true
true

Vazio, idade não é um int (false), mas é um int? ("int ou nulo") e é do tipo Null. Depois de receber 30, passa a ser um int. Por isso if (idade is int) também serve para perguntar "tem um número aqui?".

5. as: "pode confiar, é deste tipo"

O as não pergunta: ele afirma. "Trate este valor como String." Se for verdade, funciona:

void main() {
  Object guardado = 'Padaria do Zé';
  final nome = guardado as String;
  print(nome.length);
  print((guardado as String).toUpperCase());
}

$ dart run as.dart
13
PADARIA DO ZÉ
guardado as String
"Considere guardado uma String." O resultado é guardado em nome, que é do tipo String; daí o nome.length funcionar (13 letras, contando os espaços).
(guardado as String).toUpperCase()
Para usar o as no meio de uma expressão, ponha parênteses em volta. Sem eles, o Dart lê String.toUpperCase como se fosse o nome de um tipo e não compila (no lab: Error: 'String.toUpperCase' can't be used as a type because 'String' doesn't refer to an import prefix., seguido de mais dois erros).

Mas, se a afirmação for falsa, o programa para:

void main() {
  Object guardado = 'doze';
  final quantidade = guardado as int;
  print(quantidade + 1);
}

O as não transforma o texto '12' no número 12: ele só afirma que o valor já é daquele tipo. Para converter texto em número, use int.parse('12') (aula Conversão de Tipos).

Formas diferentes de fazer

Quase sempre, perguntar com is é melhor do que afirmar com as: com o is, o programa tem um caminho para o caso "não era", em vez de parar. Use o as só quando você tem certeza do tipo e o Dart não tem como saber sozinho.

SituaçãoUse
Pode ser de vários tipos, e cada um tem um tratamentoif (x is String) { … } (com promoção)
Só interessa um tipo; os outros são ignoradosif (x is! int) { … }
Você tem certeza do tipox as String (se errar, exceção)
Saber se é um número, inteiro ou nãox is num
Ver o tipo, para estudar ou depurarx.runtimeType (não use para decidir: prefira is)
Muitos tipos diferentes, um caso para cadaa expressão switch com patterns (switch)
Transformar '12' em 12nenhum destes: int.parse

  Object resposta = 'abacaxi';
  print(resposta.length);

  print(resposta.length);

"O getter length não está definido para o tipo Object." (Um getter, "pegador", é uma propriedade que se lê, como o length.) A variável foi declarada Object, e um Object qualquer não tem tamanho. O Dart olha o tipo declarado, não o valor que está lá dentro.
- 'Object' is from 'dart:core'.
Uma nota: o tipo Object vem da biblioteca principal do Dart, a dart:core.

A dica genérica: "corrija o nome, ou crie um length". Não é o caso aqui.

Como consertar: pergunte antes: if (resposta is String) { print(resposta.length); }. Ou, se a variável só vai guardar textos, declare-a como String.

Escreveu !is em vez de is!: compila e mente 
void main() {
  Object entrada = 3.5;
  print(entrada !is int);
}

$ dart run err_notis.dart
false

Nenhum erro, e a resposta está errada: 3.5 não é int, então "não é int?" deveria dar true. O que aconteceu: o Dart leu entrada! is int. Aquele ! grudado na variável é outro operador (o "tenho certeza de que não é null", da aula late e o Operador !), e a pergunta que sobrou foi "é int?", que deu false. Como consertar: entrada is! int, com o ! depois do is.

O as com o tipo errado

Visto na seção 5: 'doze' as int compila, mas para com type 'String' is not a subtype of type 'int' in type cast e código de saída 255. Como consertar: se o valor pode ser de outro tipo, use if (x is int); se é um número escrito como texto, use int.parse.

Um nome de tipo que não existe 
$ dart run err_is_tipo.dart
err_is_tipo.dart:3:14: Error: 'inteiro' isn't a type.
  print(x is inteiro);
             ^^^^^^^

"inteiro não é um tipo." Depois do is, do is! e do as vem sempre o nome de um tipo, em inglês e com a maiúscula certa: int, double, num, String, bool, List. (string com minúscula dá o mesmo erro.)

  print(coisa.length);
  coisa = 10;

Com dynamic, o Dart desliga a conferência de tipos: deixa compilar qualquer coisa. Missão: este programa compila mas para com type 'String' is not a subtype of type 'int' in type cast. A quantidade chegou como texto ('12'). Troque o as int por uma conversão de verdade, int.parse(guardado as String), até aparecer Quantidade + 1 = 13.

void main() {
  Object guardado = '12';
  final quantidade = guardado as int;
  print('Quantidade + 1 = ${quantidade + 1}');
}

void main() {
  Object guardado = '12';
  final quantidade = int.parse(guardado as String);
  print('Quantidade + 1 = ${quantidade + 1}');
}

Resumo

  • x is T pergunta se o valor é do tipo T e devolve true ou false; x is! T pergunta o contrário (o ! vai depois do is).
  • Depois de um if (x is T), o Dart trata x como T dentro das chaves: é a promoção de tipo.
  • x as T afirma o tipo; se estiver errado, o programa para com … is not a subtype of … in type cast. O as não converte texto em número.
  • 5 is num e 5.0 is num são true; 5.0 is int é false. null é int?, mas não é int.
  • Prefira Object com is ao dynamic: o erro aparece antes de rodar.
