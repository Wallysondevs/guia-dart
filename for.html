Dart for

Mostrar a tabuada do 7, somar os 30 dias do mês, imprimir as cadeiras do cinema: tudo isso é repetir. Copiar a mesma linha dez vezes até funciona, mas e se fossem mil? Para repetir existem os laços (em inglês, loops). O for ("para") é o laço de quando você sabe quantas vezes vai repetir: "para cada número de 1 a 10, faça isto".

Você vai aprender
  • As três partes do for: início, condição e passo, separadas por ;.
  • Como contar de 1 a 5, de 0 a 2, de trás para a frente e de 5 em 5.
  • Como acumular uma soma e montar a tabuada.
  • Como percorrer uma lista pela posição (o índice) e por que se começa do 0.
  • for dentro de for.
  • Os erros reais: vírgulas no lugar de ;, o for i in range do Python, final no contador, o contador usado depois do laço, o RangeError do <=, o laço infinito e o ; depois do for.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: as voltas na pista

O professor de educação física manda: "Deem 5 voltas na pista." A Ana sabe o que fazer sem pensar:

  1. Início: começa a contar do 1.
  2. Pergunta: antes de cada volta, "já dei menos de 5 voltas, ou exatamente a 5ª?" Se sim, corre.
  3. Passo: terminou a volta, conta mais uma.
  4. Quando a pergunta der "não", para e vai beber água.

Essas são as três partes do for, escritas numa linha só: início, condição e passo.

1. O primeiro for

void main() {
  for (var i = 1; i <= 5; i++) {
    print('Volta $i');
  }
  print('Fim!');
}
for
A palavra-chave do laço: "para".
var i = 1;
O início: cria a variável contadora i e dá o valor inicial. Roda uma vez só, antes de tudo. O nome i (de "índice") é tradição; poderia ser volta.
i <= 5;
A condição, testada antes de cada volta. Enquanto for true, o bloco roda.
i++
O passo: roda depois de cada volta, e soma 1 ao contador (veja Atribuição e Incremento). Sem ; no fim, porque logo vem o ).
{ print('Volta $i'); }
O corpo do laço: o que se repete.
print('Fim!');
Depois da }: roda uma vez, quando o laço termina.

2. Outras contagens

Começando do 0

Em programação, é muito comum contar a partir do zero (você vai ver o porquê com as listas, na seção 4). Para dar 3 voltas começando do 0, a condição usa < ("menor que"), não <=:

void main() {
  for (var i = 0; i < 3; i++) {
    print('i = $i');
  }
}

$ dart run for_zero.dart
i = 0
i = 1
i = 2

Três voltas: 0, 1 e 2. O padrão for (var i = 0; i < N; i++) dá exatamente N voltas, e é o que você mais vai ver em código Dart.

De trás para a frente

void main() {
  for (var s = 5; s > 0; s--) {
    print('$s...');
  }
  print('Feliz Ano Novo!');
}

$ dart run regressiva.dart
5...
4...
3...
2...
1...
Feliz Ano Novo!

Começa do maior (5), a condição é "maior que zero" e o passo é s-- (tira 1). Quando s chega a 0, 0 > 0 é false, e o laço acaba.

De 5 em 5

void main() {
  for (var n = 0; n <= 20; n += 5) {
    print(n);
  }
}

$ dart run passo.dart
0
5
10
15
20

O passo pode ser qualquer atribuição: n += 5, n += 2 (só os pares, começando do 0), n *= 2 (dobrando).

3. Acumulando: somar e montar a tabuada

A Ana vai guardar dinheiro: 1 real no dia 1, 2 reais no dia 2, e assim por diante, até o dia 30. Quanto ela junta? Uma variável acumuladora, criada antes do laço, recebe um pouco a cada volta:

void main() {
  var total = 0;
  for (var dia = 1; dia <= 30; dia++) {
    total += dia;
  }
  print('Se a Ana guardar 1 real no dia 1, 2 no dia 2... em 30 dias: R\$ $total');
}

$ dart run soma.dart
Se a Ana guardar 1 real no dia 1, 2 no dia 2... em 30 dias: R$ 465

Por que total fica fora do laço? Se ele fosse criado dentro das chaves, nasceria valendo 0 a cada volta e sumiria no }. Fora, ele sobrevive às 30 voltas e ainda está lá para o print.

Usar o contador dentro de uma conta dá a tabuada:

void main() {
  final numero = 7;
  for (var i = 1; i <= 10; i++) {
    print('$numero x $i = ${numero * i}');
  }
}

4. Percorrendo uma lista pela posição

Uma lista guarda vários valores em ordem (aula Listas). Cada um tem uma posição, o índice, que começa em 0: em ['arroz', 'feijão', 'café'], o arroz está na posição 0 e o café na 2. O compras.length é o tamanho da lista (3). Juntando com o padrão "do 0 até menos que N":

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  for (var i = 0; i < compras.length; i++) {
    print('${i + 1}. ${compras[i]}');
  }
}

$ dart run lista_indice.dart
1. arroz
2. feijão
3. café

compras[i] pega o item da posição i. Para mostrar a numeração "de gente" (1, 2, 3), o programa soma 1: ${i + 1}. A condição é i < compras.length, com <: a última posição é 2, e não 3 (veja o que o <= faz em Quando dá errado). Quando você não precisa do número da posição, existe um jeito mais simples de percorrer a lista, o for-in, assunto da próxima aula.

5. for dentro de for

O corpo de um laço pode ter outro laço. O de fora conta as filas do cinema; para cada fila, o de dentro conta as cadeiras:

void main() {
  for (var fila = 1; fila <= 3; fila++) {
    var linha = '';
    for (var cadeira = 1; cadeira <= 4; cadeira++) {
      linha += '[$fila-$cadeira] ';
    }
    print(linha);
  }
}

$ dart run aninhado.dart
[1-1] [1-2] [1-3] [1-4]
[2-1] [2-2] [2-3] [2-4]
[3-1] [3-2] [3-3] [3-4]

O laço de dentro dá as 4 voltas inteiras a cada volta do laço de fora: 3 × 4 = 12 cadeiras. A variável linha começa vazia em cada fila, junta as quatro cadeiras com += e é mostrada no fim da fila. (Cada linha termina com um espaço, depois do último ]: o += pôs um espaço depois de cada cadeira.) Use nomes que digam o que é cada contador (fila, cadeira): com i e j, é fácil trocar um pelo outro.

Formas diferentes de fazer

Qualquer for pode ser escrito com while, separando as três partes:

var i = 1;          // início
while (i <= 5) {    // condição
  print('Volta $i');
  i++;              // passo
}

O for junta as três partes numa linha, o que deixa claro, logo de cara, de onde o laço começa, até onde vai e como anda. Se você precisa do valor do contador depois do laço, crie-o antes e deixe o início vazio: var i = 0; for (; i < 3; i++) { … } (no lab, depois desse laço, i valia 3).

SituaçãoUse
Contar um número conhecido de vezes (de 1 a 10, de 10 a 0)for (var i = 1; i <= 10; i++)
Percorrer uma lista e precisar da posiçãofor (var i = 0; i < lista.length; i++)
Percorrer uma lista só pelos itensfor-in: for (final item in lista)
Não se sabe quantas voltas (até o usuário digitar 0, até juntar a meta)while
Sair antes do fim, ou pular uma voltabreak e continue

O passo para o lado errado: laço infinito

  for (var i = 1; i <= 5; i--) {

Resumo

  • for (início; condição; passo) { … }: o início roda uma vez; a condição é testada antes de cada volta; o passo roda depois de cada volta. As partes se separam com ;.
  • for (var i = 1; i <= N; i++) conta de 1 a N; for (var i = 0; i < N; i++) dá N voltas a partir do 0, o jeito de percorrer listas (posições de 0 a length - 1).
  • O passo pode ser i--, i += 5, o que for preciso, desde que leve a condição a ficar falsa; senão, o laço é infinito.
  • O contador é var e só existe dentro do laço; acumuladores (total) são criados antes.
  • Cuidado com o <= no length (RangeError) e com o ; depois do for (…).
