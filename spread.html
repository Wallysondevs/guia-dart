Dart spread (...)

Na aula anterior, você pôs if e for dentro dos colchetes de uma lista (veja if e for Dentro de Coleções). Falta uma peça: como pôr uma lista inteira dentro de outra, item por item? Para isso existem os três pontinhos ..., o operador spread (em inglês, "espalhar"). Ele pega a coleção e "espalha" os itens dela no lugar onde está escrito.

Você vai aprender
  • Como juntar duas listas numa só com [...a, ...b].
  • A diferença entre pôr a lista com e sem os três pontos.
  • Como fazer uma cópia de uma lista com [...lista], e por que final copia = lista; não copia.
  • O ...?, para espalhar uma lista que pode ser null.
  • Spread em Map e Set, e junto com o if de coleção.
  • As outras formas (+ e addAll) e os erros reais que o Dart mostra.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: esvaziar a sacola no carrinho

A Ana chega ao caixa com o carrinho e com uma sacola de frutas que pegou na feira. Ela pode fazer duas coisas:

  • pôr a sacola fechada no carrinho: o carrinho fica com o pão, o leite e uma sacola (que tem frutas dentro);
  • esvaziar a sacola no carrinho: o carrinho fica com o pão, o leite, a maçã e a banana, cada uma solta.

Os três pontos ... são o "esvaziar a sacola". Sem eles, a lista vai inteira, fechada, como um item só.

1. Juntar duas listas

void main() {
  final frutas = ['maçã', 'banana'];
  final legumes = ['cenoura', 'abobrinha'];
  final feira = [...frutas, ...legumes];
  print(feira);
  print('Itens: ${feira.length}');
}
[ … ]
Uma lista nova, como sempre.
...frutas
"Espalhe aqui os itens de frutas": entram 'maçã' e 'banana', um de cada vez, na ordem. Os três pontos ficam colados no nome.
, ...legumes
Depois da vírgula, espalhe também os itens de legumes.
$ dart run juntar.dart
[maçã, banana, cenoura, abobrinha]
Itens: 4

A lista nova tem 4 itens soltos. As listas frutas e legumes continuam como estavam.

No meio de outros itens

O spread pode ficar em qualquer posição, junto com itens comuns:

void main() {
  final frutas = ['maçã', 'banana'];
  final feira = ['pão', ...frutas, 'leite'];
  print(feira);
}

$ dart run meio.dart
[pão, maçã, banana, leite]

E sem os três pontos?

Olhe o que acontece com a "sacola fechada":

void main() {
  final frutas = ['maçã', 'banana'];
  final feira = ['pão', frutas, 'leite'];
  print(feira);
  print('Itens: ${feira.length}');
}

$ dart run semspread.dart
[pão, [maçã, banana], leite]
Itens: 3

Os colchetes de dentro, [maçã, banana], mostram que a lista entrou inteira, como um item só: são 3 itens, não 4. O Dart aceitou porque a variável feira não tinha tipo declarado, então ele a fez uma lista de "qualquer objeto" (List<Object>). Com o tipo List<String>, ele recusaria (veja Quando dá errado).

Missão: a lista compras ficou com a sacola fechada dentro. Use o spread para que as frutas entrem soltas. O resultado deve ser [pão, leite, maçã, banana, uva].

void main() {
  final frutas = ['maçã', 'banana', 'uva'];
  final compras = ['pão', 'leite', frutas];
  print(compras);
}

void main() {
  final frutas = ['maçã', 'banana', 'uva'];
  final compras = ['pão', 'leite', ...frutas];
  print(compras);
}

2. Copiar uma lista

Este é um dos usos mais importantes do spread, e ele resolve uma surpresa que pega todo iniciante. Compare mesma e copia:

void main() {
  final original = ['pão', 'leite'];
  final mesma = original;
  final copia = [...original];

  original.add('café');

  print('original: $original');
  print('mesma:    $mesma');
  print('copia:    $copia');
}

$ dart run copia.dart
original: [pão, leite, café]
mesma:    [pão, leite, café]
copia:    [pão, leite]
final mesma = original;
Não copia. Uma variável de lista guarda o endereço da lista, e não os itens. Aqui, mesma recebeu o mesmo endereço: são dois nomes para a mesma lista. Por isso o café apareceu nas duas.
final copia = [...original];
Copia. Os colchetes criam uma lista nova, e o spread põe nela os itens que a original tinha naquele momento. Depois disso, as duas vivem separadas: o café não chegou à cópia.
Quando copiar

Copie antes de mexer numa lista que não é sua: por exemplo, a lista que uma função recebeu. Assim, quem chamou a função não leva um susto. A lista também tem o método toList(), que faz a mesma cópia: original.toList().

3. ...?: quando a lista pode ser null

Às vezes a lista pode nem existir. O pedido da padaria tem os "extras" (manteiga, geleia…), que podem ser null quando o cliente não pede nada (veja Tipos Anuláveis). O ...? espalha a lista se ela existir e não faz nada se ela for null:

void main() {
  final List<String>? extras = null;
  final pedido = ['pão', ...?extras];
  print(pedido);

  final List<String>? extras2 = ['manteiga', 'geleia'];
  final pedido2 = ['pão', ...?extras2];
  print(pedido2);
}

$ dart run nulo.dart
[pão]
[pão, manteiga, geleia]

O List<String>? quer dizer "uma lista de textos ou null". Com null, o pedido ficou só com o pão; com a lista, os dois extras entraram. Sem o ?, o Dart nem compila (você vai ver a mensagem em Quando dá errado).

4. Em mapas e conjuntos

void main() {
  final precos = {'pão': 1.0, 'leite': 5.5};
  final novos = {'café': 18.9, 'pão': 1.2};
  final tabela = {...precos, ...novos};
  print(tabela);

  final turmaA = {'Ana', 'Bia'};
  final turmaB = {'Bia', 'Caio'};
  print({...turmaA, ...turmaB});
}

$ dart run mapas.dart
{pão: 1.2, leite: 5.5, café: 18.9}
{Ana, Bia, Caio}
  • No Map, o spread copia os pares chave: valor. A chave pão estava nos dois mapas: vale o que veio por último (1.2, o preço novo). A posição continua a da primeira vez que a chave apareceu.
  • No Set, a Bia, que está nas duas turmas, aparece uma vez só, como todo conjunto.

5. Spread + if: vários itens de uma vez

O if de coleção põe um item. Para pôr vários sob a mesma condição, espalhe uma lista depois do if:

void main() {
  final temVisita = true;
  final compras = [
    'pão',
    'leite',
    if (temVisita) ...['bolo', 'refrigerante', 'guardanapo'],
  ];
  print(compras);
}

$ dart run comif.dart
[pão, leite, bolo, refrigerante, guardanapo]

Lê-se: "se tem visita, espalhe aqui o bolo, o refrigerante e o guardanapo". Com temVisita = false, nenhum dos três entra.

Missão: quando chove, a Ana leva o guarda-chuva e a capa. Acrescente à mochila, com um if e um spread, os itens de paraChuva só se chovendo for verdadeiro.

void main() {
  final chovendo = true;
  final paraChuva = ['guarda-chuva', 'capa'];
  final mochila = [
    'caderno',
    'lápis',
  ];
  print(mochila);
}

void main() {
  final chovendo = true;
  final paraChuva = ['guarda-chuva', 'capa'];
  final mochila = [
    'caderno',
    'lápis',
    if (chovendo) ...paraChuva,
  ];
  print(mochila);
}

Formas diferentes de fazer a mesma coisa

void main() {
  final frutas = ['maçã', 'banana'];
  final legumes = ['cenoura'];

  final a = [...frutas, ...legumes];

  final b = frutas + legumes;

  final c = <String>[];
  c.addAll(frutas);
  c.addAll(legumes);

  print(a);
  print(b);
  print(c);
}

$ dart run formas.dart
[maçã, banana, cenoura]
[maçã, banana, cenoura]
[maçã, banana, cenoura]
  1. Spread: a lista nasce pronta e aceita itens soltos, if e for no meio.
  2. +: soma duas listas e devolve uma nova. Curto, mas só junta listas (não dá para pôr um item solto no meio) e não existe para Map nem Set.
  3. addAll ("acrescentar todos"): acrescenta os itens numa lista que já existe, mudando-a (veja Métodos de Lista).
SituaçãoQual usar
Montar uma lista nova com partes de outras e itens soltos[...a, 'x', ...b]
Só juntar duas listas[...a, ...b] ou a + b
Acrescentar itens numa lista que já existelista.addAll(outra)
Copiar uma lista[...lista] ou lista.toList()
A lista pode ser null[...?talvez]

Quando dá errado

Espalhou uma lista que pode ser null, sem o ?

  final List<String>? extras = null;
  final pedido = ['pão', ...extras];
  print(pedido);
}

  final pedido = ['pão', ...extras];
                            ^
$ echo $?

nuloerro.dart:3:29
Arquivo, linha 3, coluna 29: o ^ aponta para o extras.

"Uma expressão que pode valer null precisa ser conferida antes de ser usada." O tipo List<String>? avisa que extras pode ser null, e não dá para espalhar "nada". O Dart barra isso antes de rodar: é a null safety trabalhando.

Como consertar: use ...?extras.

Os tipos não combinam 
void main() {
  final nomes = ['Ana', 'Bia'];
  final idades = [30, 25];
  final List<String> tudo = [...nomes, ...idades];
  print(tudo);
}

$ dart run tipo.dart
tipo.dart:4:43: Error: Can't assign spread elements of type 'int' to collection elements of type 'String'.
  final List<String> tudo = [...nomes, ...idades];
                                          ^

"Não dá para pôr itens espalhados do tipo int numa coleção de String." A lista tudo só aceita textos, e idades tem números. Como consertar: converta os números (...[for (final i in idades) '$i']) ou mude o tipo da lista.

Espalhou algo que não é uma coleção 
void main() {
  final quantidade = 3;
  final lista = ['pão', ...quantidade];
  print(lista);
}

$ dart run numero.dart
numero.dart:3:28: Error: Unexpected type 'int' of a spread.  Expected 'dynamic' or an Iterable.
  final lista = ['pão', ...quantidade];
                           ^

"Tipo inesperado int num spread. Era esperado um Iterable" (algo que se percorre item por item, como uma lista ou um conjunto). Um número não tem itens para espalhar. O mesmo acontece ao espalhar um mapa dentro de uma lista: sai Unexpected type 'Map<String, double>' of a spread.. Para levar só as chaves de um mapa para uma lista, espalhe ...precos.keys.

Esqueceu os três pontos numa lista com tipo 
void main() {
  final frutas = ['maçã', 'banana'];
  final List<String> feira = ['pão', frutas, 'leite'];
  print(feira);
}

$ dart run tipada.dart
tipada.dart:3:38: Error: A value of type 'List<String>' can't be assigned to a variable of type 'String'.
 - 'List' is from 'dart:core'.
  final List<String> feira = ['pão', frutas, 'leite'];
                                     ^

"Um valor do tipo List<String> não pode ser guardado onde se espera um String." É a sacola fechada da seção 1, agora barrada porque a lista diz que só aceita textos. Como consertar: ...frutas.

Missão: monte pedido com: os itens de bebidas e de comidas (spread), mais os de extras, que é anulável (use ...?). O resultado deve ser [café, pão de queijo, bolo, suco, manteiga]. Depois, troque extras para null e veja o programa continuar funcionando.

  final pedido = [];

void main() {
  final bebidas = ['café'];
  final comidas = ['pão de queijo', 'bolo', 'suco'];
  final List<String>? extras = ['manteiga'];
  final pedido = [...bebidas, ...comidas, ...?extras];
  print(pedido);
}

Resumo

  • Os três pontos ... espalham os itens de uma coleção dentro de outra: [...a, ...b].
  • Sem eles, a lista entra inteira, como um item só.
  • final b = a; não copia (são dois nomes para a mesma lista); [...a] copia.
  • ...? espalha uma coleção que pode ser null; se for, não põe nada.
  • Funciona em Map (a chave repetida fica com o último valor) e em Set, e combina com o if e o for de coleção.
  • Próxima aula: Records, um jeito de juntar valores diferentes num só.
