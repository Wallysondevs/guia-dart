Dart main e print

Chegou a hora de escrever o seu primeiro programa e entender cada pedaço dele. Todo programa Dart, do menor script ao maior aplicativo Flutter, começa do mesmo jeito: por uma função chamada main. E a primeira coisa que quase todo programa faz é mostrar algo na tela com o print. Nesta aula você aprende os dois, e também a ler as mensagens que o Dart mostra quando um deles está escrito errado.

Você vai aprender
  • O que é a função main e por que todo programa precisa de uma.
  • O que significam o void, os parênteses () e as chaves { }.
  • A mostrar textos com print, com aspas simples ou duplas, e textos que têm aspas dentro.
  • A mostrar números e o resultado de contas, e por que print(2 + 3) e print('2 + 3') são diferentes.
  • A mostrar várias linhas e uma linha em branco.
  • Os erros reais mais comuns: Print com P maiúsculo, aspas e parênteses sem fechar, texto sem aspas, o programa sem main e o print com dois valores.

Todos os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook), com dart run arquivo.dart (aula Rodando um Programa). As caixas "Experimente" fazem o mesmo no navegador (aula O Editor do Guia).

A ideia: a porta de entrada e o alto-falante

Pense numa loja. Ela pode ter muitas salas (estoque, cozinha, escritório), mas o cliente sempre entra pela porta da frente. Num programa Dart, a porta da frente é o main (em inglês, "principal"): quando você roda o programa, o Dart procura o main e começa por ele, sempre.

E pense no alto-falante da padaria: "Senha 42, seu pão está pronto!". Quem está no balcão diz o recado, e o alto-falante anuncia exatamente aquilo. O print é o alto-falante do programa: você entrega um valor e ele mostra esse valor na tela, numa linha.

1. O programa mínimo

void main() {
  print('Olá, Ana!');
}

$ dart run ola.dart
Olá, Ana!

São três linhas, e cada pedaço tem um papel:

void
"Vazio". Diz que o main faz o trabalho dele e não devolve nenhum resultado no fim. A palavra fica antes do nome; você vai entender o "devolver" na aula Funções.
main
O nome da função. Uma função é um bloco de instruções com nome. Esse nome é especial: é por ele que o Dart começa. Tem de ser escrito assim, tudo minúsculo.
()
Os parênteses vêm logo depois do nome de toda função. Aqui estão vazios: o main não está recebendo nada.
{ }
As chaves marcam o corpo da função: o que está entre a { da primeira linha e a } da última é o que o main faz.
print('Olá, Ana!');
A instrução que o main executa: mostrar o texto. Fica dois espaços para dentro (o recuo), para mostrar que está dentro das chaves.

E dentro do print:

print
"Imprimir", do tempo em que a saída do computador ia para uma impressora. Hoje, mostra na tela.
( … )
Os parênteses chamam (usam) a função. O que vai dentro é o que você entrega a ela: o argumento.
'Olá, Ana!'
Um texto, que em programação se chama string ("cordão": uma fileira de letras). As aspas marcam onde ele começa e termina e não aparecem na tela. Dentro delas, acento, espaço e vírgula saem do jeito que estão.
;
O ponto e vírgula termina a instrução. No Dart ele é obrigatório (aula Instruções, Ponto e Vírgula e Blocos).

Missão: faça o programa mostrar Padaria do Bairro. Mude só o que está entre as aspas.

void main() {
  print('Olá, Ana!');
}

void main() {
  print('Padaria do Bairro');
}

2. Várias linhas: um print para cada

O main pode ter quantas instruções você quiser. O Dart executa uma de cada vez, de cima para baixo, e cada print mostra uma linha:

void main() {
  print('Bom dia!');
  print('Padaria do Bairro');
  print('Pão francês saindo às 7h');
}

$ dart run varios.dart
Bom dia!
Padaria do Bairro
Pão francês saindo às 7h

Três print, três linhas, na mesma ordem do arquivo. Troque duas linhas de lugar no código e elas trocam de lugar na saída.

Uma linha em branco

Para pular uma linha, mostre um texto vazio: duas aspas sem nada entre elas.

void main() {
  print('Padaria do Bairro');
  print('');
  print('Pão francês');
}

$ dart run vazio.dart
Padaria do Bairro

Pão francês

Atenção: print(''), com as aspas, e não print() vazio. O print do Dart sempre precisa de alguma coisa dentro (veja em "Quando dá errado").

3. Aspas simples ou duplas

O Dart aceita os dois tipos de aspas: 'simples' e "duplas". A regra é fechar com a mesma que abriu. Quando o texto tem um apóstrofo, como em Padaria D'Ouro, use aspas duplas por fora, ou ponha uma barra invertida antes do apóstrofo (\'), que avisa "esta aspa é uma letra, não o fim do texto":

void main() {
  print("Olá, Ana!");
  print('Padaria D\'Ouro');
  print("Padaria D'Ouro");
  print('Ela disse: "Que pão cheiroso!"');
}

$ dart run duplas.dart
Olá, Ana!
Padaria D'Ouro
Padaria D'Ouro
Ela disse: "Que pão cheiroso!"
SituaçãoComo escrever
Texto comum'Bom dia' (o padrão do estilo oficial do Dart)
Texto com apóstrofo"Padaria D'Ouro" ou 'Padaria D\'Ouro'
Texto com aspas duplas dentro'Ela disse: "oi"'
Qual aspa usar?

O guia de estilo do Dart (Effective Dart) e o verificador de código (aula Análise e Formatação) preferem aspas simples, e este guia segue essa regra. Aspas duplas só quando o texto tem apóstrofo. Mais sobre textos em Strings.

4. Números e contas: sem aspas

O print não mostra só textos. Números se escrevem sem aspas, e uma conta dentro do print é calculada antes de ser mostrada:

void main() {
  print(42);
  print(3.5);
  print(2 + 3);
  print('2 + 3');
  print(10 / 4);
}

$ dart run numeros.dart
42
3.5
5
2 + 3
2.5
print(42)
Um número inteiro, mostrado como está.
print(3.5)
Número com casas decimais: no programa, o separador é o ponto, nunca a vírgula.
print(2 + 3)
Sem aspas é uma conta: o Dart calcula e mostra 5.
print('2 + 3')
Com aspas é um texto: sai exatamente 2 + 3, sem conta nenhuma.
print(10 / 4)
A divisão com / dá 2.5. As contas têm aula própria: Operadores Aritméticos.

Missão: a Ana comprou 5 pacotes de pão de queijo a 3 reais cada. Troque o texto por uma conta com * (vezes), sem aspas, para o Dart mostrar o total: 15.

void main() {
  print('5 * 3');
}

void main() {
  print(5 * 3);
}

5. Outras formas de escrever o main

Você vai encontrar o main escrito de jeitos um pouco diferentes em outros lugares:

main() {
  print('Olá, Ana!');
}

$ dart run sem_void.dart
Olá, Ana!
FormaFunciona?Quando usar
void main() { … }SimSempre, neste guia. É o jeito recomendado: deixa claro que não devolve nada.
main() { … }SimCódigo antigo. Funciona, mas o verificador de estilo pede o tipo de retorno.
void main(List<String> args) { … }SimQuando o programa recebe palavras digitadas depois do nome no terminal (aula Argumentos da Linha de Comando).
void main() async { … }SimProgramas que esperam coisas demoradas (aula async e await).

E um main com o corpo vazio também é um programa válido: ele roda, não mostra nada e termina com código 0. É um programa que não faz nada, mas faz certo.

Quando dá errado

As mensagens do Dart saem em inglês. Todo erro de compilação tem o mesmo formato: arquivo:linha:coluna: Error: mensagem, depois a linha do código e, embaixo, ^ apontando o lugar (veja a explicação completa em O que é Dart). Com qualquer erro de compilação, nada do programa roda.

Print com P maiúsculo 
void main() {
  Print('Olá, Ana!');
}

$ dart run maiuscula.dart
maiuscula.dart:2:3: Error: Method not found: 'Print'.
  Print('Olá, Ana!');
  ^^^^^
$ echo $?
254
maiuscula.dart:2:3:
Linha 2, coluna 3 (as colunas 1 e 2 são os espaços do recuo).
Method not found: 'Print'.
"Método não encontrado: Print". Método é outra palavra para função. O Dart procurou uma função chamada Print e não achou.
^^^^^
Cinco ^, um embaixo de cada letra de Print: a palavra inteira é o problema.

O Dart diferencia maiúsculas de minúsculas: print, Print e PRINT são três nomes diferentes, e só o primeiro existe. Como consertar: print, tudo minúsculo.

Aspa que não fecha 
void main() {
  print('Olá, Ana!);
}

$ dart run aspas.dart
aspas.dart:2:9: Error: String starting with ' must end with '.
  print('Olá, Ana!);
        ^^^^^^^^^^^^
aspas.dart:2:8: Error: Can't find ')' to match '('.
  print('Olá, Ana!);
       ^
aspas.dart:2:9: Error: Expected ';' after this.
  print('Olá, Ana!);
        ^^^^^^^^^^^^

Um erro só, três mensagens. Leia sempre a primeira: "Texto que começa com ' tem de terminar com '". O texto abriu na coluna 9 e a linha acabou sem a aspa de fechar; os ^ sublinham tudo o que o Dart engoliu como texto, inclusive o ) e o ;. As outras duas mensagens são consequência: como o ) e o ; viraram parte do texto, faltam um ) ("não acho o ) que fecha o (") e um ; ("esperava ; depois disto"). Conserte a primeira e as outras somem. Como consertar: print('Olá, Ana!');.

Parêntese que não fecha 
void main() {
  print('Olá, Ana!';
}

$ dart run parentese.dart
parentese.dart:2:8: Error: Can't find ')' to match '('.
  print('Olá, Ana!';
       ^

"Não acho o ) que combina com o (". O ^ aponta para o parêntese que abriu, na coluna 8. Todo ( precisa do seu ). Como consertar: print('Olá, Ana!');.

Chave que não fecha 
void main() {
  print('Olá, Ana!');

$ dart run chave.dart
chave.dart:1:13: Error: Can't find '}' to match '{'.
void main() {
            ^

A mesma ideia, com as chaves: o { da linha 1 (coluna 13) não tem o } que fecha o corpo do main. Como consertar: uma } sozinha na última linha.

Texto sem aspas 
void main() {
  print(Ana);
}

$ dart run sem_aspas.dart
sem_aspas.dart:2:9: Error: Undefined name 'Ana'.
  print(Ana);
        ^^^

"Nome não definido: Ana". Sem aspas, Ana não é um texto: o Dart entende que é o nome de alguma coisa (uma variável, como você vai ver em Variáveis), e ninguém criou nada com esse nome. Como consertar: print('Ana');.

print() vazio 
void main() {
  print();
}

$ dart run print_vazio.dart
print_vazio.dart:2:8: Error: Too few positional arguments: 1 required, 0 given.
  print();
       ^
org-dartlang-sdk:///sdk/lib/core/print.dart:19:6: Context: Found this candidate, but the arguments don't match.

Too few positional arguments: 1 required, 0 given.
"Argumentos de menos: 1 é obrigatório, 0 foram dados". O print exige exatamente um valor dentro dos parênteses.
org-dartlang-sdk:///sdk/lib/core/print.dart:19:6: Context:
Uma mensagem de contexto: o Dart mostra onde o print foi criado, dentro do próprio SDK, para você ver como ele é.
void print(Object? object)
A "assinatura" do print: ele recebe um valor, chamado object, que pode ser de qualquer tipo (Object?). Você vai entender cada pedaço disso ao longo do guia.

Como consertar: para uma linha em branco, print('');.

Dois valores no mesmo print 
void main() {
  print('Pães:', 12);
}

$ dart run dois_args.dart
dois_args.dart:2:8: Error: Too many positional arguments: 1 allowed, but 2 found.
Try removing the extra positional arguments.
  print('Pães:', 12);
       ^
org-dartlang-sdk:///sdk/lib/core/print.dart:19:6: Context: Found this candidate, but the arguments don't match.
void print(Object? object) {
     ^^^^^

"Argumentos demais: 1 permitido, mas 2 encontrados. Tente remover os argumentos extras". Em outras linguagens, a vírgula no print separa vários valores; no Dart, não. E juntar com + também não funciona entre texto e número:

void main() {
  print('Pães: ' + 12);
}

$ dart run mais.dart
mais.dart:2:20: Error: A value of type 'int' can't be assigned to a variable of type 'String'.
  print('Pães: ' + 12);
                   ^

"Um valor do tipo int (número inteiro) não pode ser usado onde se espera String (texto)". O + junta texto com texto, mas 12 é número. Como consertar: por enquanto, ponha tudo no texto, print('Pães: 12');. Para misturar texto com valores de verdade, o Dart tem a interpolação, 'Pães: $quantidade', que você aprende em Interpolação.

Em algumas linguagens, uma linha solta no arquivo já é um programa. No Dart, não: fora de uma função, o Dart só aceita declarações (criar funções, variáveis, classes). Ele leu print(…) como o começo da criação de uma função chamada print, esperava um nome (identifier) entre os parênteses e achou um texto; depois esperava o corpo da função, { }. As mensagens confundem, mas a causa é uma só: instruções vão dentro do main.

main com o nome errado 
void mian() {
  print('Olá, Ana!');
}

$ dart run mian.dart
Invoked Dart programs must have a 'main' function defined:
https://dart.dev/to/main-function
$ echo $?
253

"Programas Dart executados precisam ter uma função main definida", seguido de um link para a documentação. A Ana trocou duas letras: escreveu mian. O arquivo está bem escrito (por isso não há Error: com linha e coluna), mas o Dart não acha a porta de entrada. Repare no código de saída diferente: 253. Como consertar: void main().

Resumo

  • Todo programa Dart começa pelo main: void main() { … }. As instruções vão entre as chaves, com dois espaços de recuo.
  • print(valor); mostra um valor e pula de linha. Cada print é uma linha da saída, na ordem do código.
  • Textos vão entre aspas (simples, de preferência); as aspas não aparecem. Apóstrofo: aspas duplas por fora ou \'.
  • Números e contas vão sem aspas, e o Dart calcula antes de mostrar. Decimal com ponto.
  • O print recebe exatamente um valor: print('') para linha em branco; nada de vírgula separando valores.
  • Maiúsculas importam (Print não existe). Aspa, parêntese ou chave que abre tem de fechar. Instruções só dentro do main.
  • Com erro de compilação, nada roda (código 254). Leia sempre a primeira mensagem.
