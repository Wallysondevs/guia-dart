Projeto Estoque da Lojinha (JSON)

A Ana abriu uma papelaria pequena e anota o estoque num arquivo. Ela quer um programa que leia esse arquivo, registre as vendas, avise o que está acabando e grave tudo de volta, para o dia seguinte começar de onde parou. O formato do arquivo é o JSON, o mesmo que os aplicativos usam para conversar com servidores: aprender a ler e escrever JSON em Dart serve para muito mais do que esta lojinha.

Você vai praticar
  • Ler JSON com jsonDecode e escrever com JsonEncoder (veja JSON (dart:convert)).
  • Criar uma classe Produto com um construtor factory fromJson e um método toJson.
  • Converter dynamic no tipo certo com as (veja is, is! e as e dynamic e Object).
  • Procurar com firstWhere e filtrar com where (veja map, where, reduce e Outros).
  • Ler e gravar o arquivo com dart:io.

O arquivo de estoque

JSON (JavaScript Object Notation, "notação de objetos do JavaScript") é um jeito de escrever dados como texto. Ele tem só seis tipos de coisa: textos entre aspas duplas, números, true/false, null, listas entre [ ] e objetos entre { } com pares "chave": valor. O estoque da Ana é uma lista de objetos, um por produto:

[
  {"nome": "Caderno", "preco": 18.9, "quantidade": 40},
  {"nome": "Caneta azul", "preco": 2.5, "quantidade": 120},
  {"nome": "Mochila", "preco": 149.9, "quantidade": 3},
  {"nome": "Borracha", "preco": 1.75, "quantidade": 0}
]

Repare que o JSON parece muito com uma lista de mapas do Dart. É essa a ideia: o jsonDecode transforma o texto JSON em List e Map do Dart; o jsonEncode faz o caminho de volta.

Versão 1 · Decodificar o JSON

Antes de ler o arquivo, um teste com o texto JSON dentro do próprio programa. Uma string com três aspas (''') pode ocupar várias linhas, perfeita para isso.

import 'dart:convert';

const textoJson = '''
[
  {"nome": "Caderno", "preco": 18.9, "quantidade": 40},
  {"nome": "Caneta azul", "preco": 2.5, "quantidade": 120},
  {"nome": "Mochila", "preco": 149.9, "quantidade": 3},
  {"nome": "Borracha", "preco": 1.75, "quantidade": 0}
]
''';

void main() {
  final dados = jsonDecode(textoJson) as List;
  print('${dados.length} produtos');
  print(dados[0]);
  print(dados[0]['nome']);
  print(dados[0].runtimeType);
}

Versão 2 · A classe Produto

Trabalhar com dados[0]['nome'] funciona, mas é frágil: um erro de digitação em 'nmoe' só aparece quando o programa roda, e o Dart não ajuda a completar nada, porque tudo é dynamic. O jeito profissional é converter cada mapa num objeto de uma classe, uma vez só, logo depois de ler o JSON. A partir daí, o resto do programa usa produto.nome, com tipo e com a ajuda do compilador.

import 'dart:convert';

class Produto {
  final String nome;
  final double preco;
  int quantidade;

  Produto({required this.nome, required this.preco, required this.quantidade});

  factory Produto.fromJson(Map<String, dynamic> json) => Produto(
        nome: json['nome'] as String,
        preco: (json['preco'] as num).toDouble(),
        quantidade: json['quantidade'] as int,
      );

  double get valorEmEstoque => preco * quantidade;
}

const textoJson = '''
[
  {"nome": "Caderno", "preco": 18.9, "quantidade": 40},
  {"nome": "Caneta azul", "preco": 2.5, "quantidade": 120},
  {"nome": "Mochila", "preco": 149.9, "quantidade": 3},
  {"nome": "Borracha", "preco": 1.75, "quantidade": 0}
]
''';

void main() {
  final lista = jsonDecode(textoJson) as List;
  final produtos = [
    for (final item in lista) Produto.fromJson(item as Map<String, dynamic>),
  ];

  for (final p in produtos) {
    print('${p.nome.padRight(12)} ${p.quantidade.toString().padLeft(4)} un.'
        '  R\$ ${p.preco.toStringAsFixed(2).padLeft(7)}');
  }
  final total = produtos.fold(0.0, (soma, p) => soma + p.valorEmEstoque);
  print('Valor do estoque: R\$ ${total.toStringAsFixed(2)}');
}

factory Produto.fromJson(Map<String, dynamic> json)Um construtor com nome (fromJson = "a partir do JSON") e factory ("fábrica"): ele recebe o mapa e devolve um Produto pronto. É a convenção do Dart para isso.

No Dart, int e double são tipos diferentes, irmãos debaixo do num: um int não "vira" double sozinho num as. E o JSON não distingue: quem escreve o arquivo (uma pessoa, uma planilha, outro programa) pode muito bem escrever 3. Conserto: (json['preco'] as num).toDouble(), como na versão 2.

Versão 3 · Vender e avisar o que repor

Agora o programa lê o estoque.json de verdade e ganha duas funções: carregar, que transforma o arquivo numa lista de produtos, e vender, que procura o produto pelo nome e dá baixa, recusando a venda quando não há o suficiente. No fim, ele lista o que está com menos de 5 unidades. A classe Produto ganhou também o método toJson, que a versão 4 vai usar.

import 'dart:convert';
import 'dart:io';

class Produto {
  final String nome;
  final double preco;
  int quantidade;

  Produto({required this.nome, required this.preco, required this.quantidade});

  factory Produto.fromJson(Map<String, dynamic> json) => Produto(
        nome: json['nome'] as String,
        preco: (json['preco'] as num).toDouble(),
        quantidade: json['quantidade'] as int,
      );

  Map<String, dynamic> toJson() => {
        'nome': nome,
        'preco': preco,
        'quantidade': quantidade,
      };

  double get valorEmEstoque => preco * quantidade;
}

List<Produto> carregar(String caminho) {
  final lista = jsonDecode(File(caminho).readAsStringSync()) as List;
  return [for (final item in lista) Produto.fromJson(item as Map<String, dynamic>)];
}

void vender(List<Produto> produtos, String nome, int quantidade) {
  final produto = produtos.firstWhere((p) => p.nome == nome);
  if (quantidade > produto.quantidade) {
    print('Venda recusada: só há ${produto.quantidade} de $nome.');
    return;
  }
  produto.quantidade -= quantidade;
  print('Vendido: $quantidade × $nome.');
}

void main() {
  final produtos = carregar('estoque.json');

  vender(produtos, 'Caderno', 5);
  vender(produtos, 'Mochila', 4);
  vender(produtos, 'Mochila', 2);

  print('');
  print('Repor (menos de 5 unidades):');
  for (final p in produtos.where((p) => p.quantidade < 5)) {
    print('- ${p.nome}: ${p.quantidade}');
  }
}

Versão 4 · Gravar o estoque de volta

Até aqui, as vendas sumiam quando o programa terminava: o arquivo continuava igual. Para guardar, o caminho é o inverso: cada produto vira um mapa (toJson), a lista de mapas vira texto JSON, e o texto vai para o arquivo. A classe e o carregar são os da versão 3; o resto muda:

import 'dart:convert';
import 'dart:io';

class Produto {
  final String nome;
  final double preco;
  int quantidade;

  Produto({required this.nome, required this.preco, required this.quantidade});

  factory Produto.fromJson(Map<String, dynamic> json) => Produto(
        nome: json['nome'] as String,
        preco: (json['preco'] as num).toDouble(),
        quantidade: json['quantidade'] as int,
      );

  Map<String, dynamic> toJson() => {
        'nome': nome,
        'preco': preco,
        'quantidade': quantidade,
      };

  double get valorEmEstoque => preco * quantidade;
}

List<Produto> carregar(String caminho) {
  final lista = jsonDecode(File(caminho).readAsStringSync()) as List;
  return [for (final item in lista) Produto.fromJson(item as Map<String, dynamic>)];
}

void salvar(String caminho, List<Produto> produtos) {
  const codificador = JsonEncoder.withIndent('  ');
  File(caminho).writeAsStringSync(codificador.convert(produtos));
}

void main() {
  final produtos = carregar('estoque.json');

  final caderno = produtos.firstWhere((p) => p.nome == 'Caderno');
  caderno.quantidade -= 5;

  produtos.add(Produto(nome: 'Régua 30 cm', preco: 4.2, quantidade: 25));

  salvar('estoque.json', produtos);
  print('Estoque salvo: ${produtos.length} produtos.');
}
ParteO que faz
Map<String, dynamic> toJson() => {…}O caminho de volta do fromJson: o produto vira um mapa com as mesmas chaves do arquivo.
JsonEncoder.withIndent(' ')Um codificador que escreve o JSON "bonito", com quebras de linha e 2 espaços de recuo. O jsonEncode(…) simples escreveria tudo numa linha só.
codificador.convert(produtos)Transforma a lista em texto. O codificador não sabe o que é um Produto, mas, quando encontra um objeto desconhecido, chama o método toJson() dele. Por isso o nome tem de ser exatamente esse.
File(caminho).writeAsStringSync(…)Grava o texto no arquivo, apagando o conteúdo antigo.
produtos.add(Produto(…))Um produto novo, a régua, entra na lista e, portanto, no arquivo.

import 'dart:convert';
import 'dart:io';

class Produto {
  final String nome;
  final double preco;
  int quantidade;

  Produto({required this.nome, required this.preco, required this.quantidade});

  factory Produto.fromJson(Map<String, dynamic> json) => Produto(
        nome: json['nome'] as String,
        preco: (json['preco'] as num).toDouble(),
        quantidade: json['quantidade'] as int,
      );

  Map<String, dynamic> toJson() => {
        'nome': nome,
        'preco': preco,
        'quantidade': quantidade,
      };

  double get valorEmEstoque => preco * quantidade;
}

List<Produto> carregar(String caminho) {
  final lista = jsonDecode(File(caminho).readAsStringSync()) as List;
  return [for (final item in lista) Produto.fromJson(item as Map<String, dynamic>)];
}

void main() {
  final produtos = carregar('estoque.json');

  final caderno = produtos.firstWhere((p) => p.nome == 'Caderno');
  caderno.quantidade -= 5;

  produtos.add(Produto(nome: 'Régua 30 cm', preco: 4.2, quantidade: 25));

  // grave a lista em estoque.json (JsonEncoder.withIndent)
  print('Estoque salvo: ${produtos.length} produtos.');
}

  Produto({required this.nome, required this.preco, required this.quantidade});

  factory Produto.fromJson(Map<String, dynamic> json) => Produto(
        nome: json['nome'] as String,
        preco: (json['preco'] as num).toDouble(),
        quantidade: json['quantidade'] as int,
      );

  Map<String, dynamic> toJson() => {
        'nome': nome,
        'preco': preco,
        'quantidade': quantidade,
      };

  double get valorEmEstoque => preco * quantidade;

List<Produto> carregar(String caminho) {
  final lista = jsonDecode(File(caminho).readAsStringSync()) as List;
  return [for (final item in lista) Produto.fromJson(item as Map<String, dynamic>)];
}

void salvar(String caminho, List<Produto> produtos) {
  const codificador = JsonEncoder.withIndent('  ');
  File(caminho).writeAsStringSync(codificador.convert(produtos));
}

void main() {
  final produtos = carregar('estoque.json');

  final caderno = produtos.firstWhere((p) => p.nome == 'Caderno');
  caderno.quantidade -= 5;

  produtos.add(Produto(nome: 'Régua 30 cm', preco: 4.2, quantidade: 25));

  salvar('estoque.json', produtos);
  print('Estoque salvo: ${produtos.length} produtos.');
}

Resumo

  • JSON é texto; jsonDecode o transforma em List/Map<String, dynamic>, e jsonEncode/JsonEncoder.withIndent fazem o caminho de volta.
  • Converta o dynamic num objeto logo na entrada: factory Produto.fromJson(Map<String, dynamic> json); na saída, toJson().
  • as String, as int conferem o tipo; para números que podem vir com ou sem ponto, (… as num).toDouble() evita o type 'int' is not a subtype of type 'double'.
  • firstWhere procura; sem resultado, Bad state: No element. where filtra.
  • readAsStringSync lê, writeAsStringSync grava. Vírgula sobrando no JSON dá FormatException: Unexpected character, com a linha e o caractere do arquivo.
