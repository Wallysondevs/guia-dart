Dart Interpolação

Na aula Strings, você juntou textos com o +. Funciona, mas fica feio rápido: 'Olá, ' + nome + '! Você tem ' + idade.toString() + ' anos.'. O Dart tem um jeito muito mais limpo: escrever o texto inteiro de uma vez e marcar com um $ o lugar onde entra cada valor. Isso se chama interpolação (do latim, "pôr no meio").

Você vai aprender
  • Como pôr uma variável no texto: 'Olá, $nome!'.
  • Como pôr uma conta ou um método: '${paes * preco}', '${nome.length}'.
  • A armadilha do '$nome.length', e quando as chaves {} são obrigatórias.
  • Como mostrar o cifrão de verdade: 'R\$ $total'.
  • Interpolação com números, bool, null, listas e textos de várias linhas.
  • Os erros reais: o nome digitado errado, a chave que não fecha e o $ solto.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: o formulário com espaços em branco

Lembra das fichas da escola? "Nome: ______. Idade: ____ anos." O texto já vem pronto; você só preenche os espaços. A interpolação é isso: você escreve o texto pronto e, no lugar de cada espaço em branco, põe $ e o nome da variável. Na hora de rodar, o Dart troca cada $nome pelo valor que está na variável.

1. $variavel: o caso mais simples

void main() {
  var nome = 'Ana';
  var idade = 30;
  print('Olá, $nome!');
  print('$nome tem $idade anos.');
  print("Bom dia, $nome");
}

$ dart run ola.dart
Olá, Ana!
Ana tem 30 anos.
Bom dia, Ana
'Olá, $nome!'
O $ avisa: "o que vem agora é o nome de uma variável". O Dart lê o nome até onde ele pode continuar (letras, números e _), por isso o ! não entra no nome. Na saída, $nome virou Ana.
'$nome tem $idade anos.'
Quantas variáveis quiser, em qualquer lugar do texto. idade é um int, e o Dart o transformou em texto sozinho: com interpolação, não precisa de toString().
"Bom dia, $nome"
Funciona igual com aspas duplas.

Compare com o +; as duas linhas mostram a mesma coisa:

void main() {
  var nome = 'Ana';
  var idade = 30;
  print('Nome: ' + nome + ', idade: ' + idade.toString());
  print('Nome: $nome, idade: $idade');
}

$ dart run comparar.dart
Nome: Ana, idade: 30
Nome: Ana, idade: 30

A segunda é mais curta, mais fácil de ler e não esquece espaço. O guia de estilo oficial (Effective Dart) recomenda: use interpolação, não +, para montar textos.

Missão: reescreva o print sem nenhum +, usando $nome e $idade dentro de um texto só. A saída tem de continuar Olá, Ana! Você tem 30 anos.

void main() {
  var nome = 'Ana';
  var idade = 30;
  print('Olá, ' + nome + '! Você tem ' + idade.toString() + ' anos.');
}

void main() {
  var nome = 'Ana';
  var idade = 30;
  print('Olá, $nome! Você tem $idade anos.');
}

2. ${expressão}: contas e métodos dentro do texto

Quando o que vai no espaço em branco é mais que um nome (uma conta, um método, uma propriedade), ponha entre chaves: ${…}.

void main() {
  var nome = 'Ana';
  var paes = 7;
  var preco = 0.8;
  print('Daqui a 5 anos: ${30 + 5}');
  print('Total: R\$ ${paes * preco}');
  print('Total: R\$ ${(paes * preco).toStringAsFixed(2)}');
  print('Em maiúsculas: ${nome.toUpperCase()}');
  print('O nome tem ${nome.length} letras');
  print('Ele tem $nome.length letras');
}

$ dart run chaves.dart
Daqui a 5 anos: 35
Total: R$ 5.6000000000000005
Total: R$ 5.60
Em maiúsculas: ANA
O nome tem 3 letras
Ele tem Ana.length letras
${30 + 5}
O Dart faz a conta e põe o resultado no texto: 35.
${paes * preco}
7 × 0,8. Saiu 5.6000000000000005: é o errinho do double que você viu em int e double.
${(paes * preco).toStringAsFixed(2)}
A conta, e depois o método que deixa com 2 casas. Tudo dentro das chaves. É assim que se mostra dinheiro.
${nome.toUpperCase()} e ${nome.length}
Métodos e propriedades da variável: precisam das chaves.
$nome.length (sem chaves)
A armadilha da última linha: sem chaves, o $ pega só o nome nome. O .length ficou como texto comum, e saiu Ana.length. O Dart não avisa: o programa roda e mostra o texto errado.
Chaves: quando sim, quando não

Só um nome de variável? $nome, sem chaves (o Effective Dart considera ${nome} excesso). Qualquer coisa além do nome (ponto, parênteses, conta)? ${…}, com chaves.

3. O que pode ir no espaço em branco

Qualquer valor. O Dart chama o toString() dele por você:

void main() {
  var inteiro = 7;
  var decimal = 4.5;
  var aberto = true;
  String? apelido;
  var compras = ['pão', 'leite'];
  print('int: $inteiro, double: $decimal, bool: $aberto');
  print('apelido: $apelido');
  print('compras: $compras');
}

$ dart run tipos.dart
int: 7, double: 4.5, bool: true
apelido: null
compras: [pão, leite]

Números e bool aparecem como você espera. A variável apelido é um String?, um texto que pode estar vazio de vez, sem valor nenhum; aí ela vale null e o texto mostra a palavra null (isso é assunto de Null Safety). Uma lista aparece com colchetes (veja Listas).

4. O cifrão do real

A Ana trabalha com reais, e o símbolo do real tem um $. Cuidado:

void main() {
  var total = 20;
  print('Total: R$total');
  print('Total: R\$$total');
  print('Total: R\$ $total');
  print(r'Sem trocar: $total');
  print('$total' == '20');
}

$ dart run cifrao.dart
Total: R20
Total: R$20
Total: R$ 20
Sem trocar: $total
true
'R$total'
O Dart leu $total como interpolação: o cifrão sumiu, e saiu R20. Sem erro, sem aviso.
'R\$$total'
\$ é um cifrão de verdade; o $total seguinte é a interpolação. Saiu R$20.
'R\$ $total'
O mesmo, com espaço: R$ 20, o jeito brasileiro.
r'Sem trocar: $total'
Num texto cru (r), não há interpolação: o $total sai como está escrito.
'$total' == '20'
O resultado de uma interpolação é uma String comum: '$total' é o texto '20'.

5. Interpolação em textos de várias linhas

Com ''', dá para montar um recibo inteiro de uma vez:

void main() {
  var cliente = 'Bia';
  var itens = 3;
  var total = 12.4;
  var recibo = '''
Cliente: $cliente
Itens:   $itens
Total:   R\$ ${total.toStringAsFixed(2)}''';
  print(recibo);
}

$ dart run linhas.dart
Cliente: Bia
Itens:   3
Total:   R$ 12.40

Formas diferentes de fazer

A mesma frase, Ana tem 30 anos., de quatro jeitos:

print(nome + ' tem ' + idade.toString() + ' anos.');   // + e toString()
print('$nome tem $idade anos.');                        // interpolação
print('${nome} tem ${idade} anos.');                    // chaves sem necessidade
print([nome, 'tem', idade, 'anos.'].join(' '));         // juntar uma lista
SituaçãoQual usar
Pôr variáveis num texto'$nome'
Pôr contas, métodos, propriedades'${conta}', '${nome.length}'
Juntar dois textos que já são String, sem nada no meioa + b ainda serve, mas '$a$b' também
Juntar muitos pedaços com o mesmo separadorjoin (aula Métodos de Lista)
Montar um texto aos poucos, num laçoStringBuffer (aula Montando Textos)

Quando dá errado

Digitou o nome da variável errado 
void main() {
  var nome = 'Ana';
  print('Olá, $nmoe!');
}

$ dart run err_nome.dart
err_nome.dart:3:16: Error: Undefined name 'nmoe'.
  print('Olá, $nmoe!');
               ^^^^
err_nome.dart:3:16:
Arquivo, linha 3, coluna 16: bem em cima do nome depois do $.
Error: Undefined name 'nmoe'.
"Nome não definido: nmoe." Não existe variável com esse nome. O Dart confere os nomes dentro do texto também, antes de rodar.
^^^^
Sublinha o nome culpado.

Como consertar: $nome. (É uma vantagem sobre o +? Não: com + nmoe + daria o mesmo erro. A vantagem é que o Dart sempre confere.)

Método sem chaves: o texto sai errado, sem erro 
void main() {
  var nome = 'ana';
  print('Nome: $nome.toUpperCase()');
}

$ dart run err_metodo.dart
Nome: ana.toUpperCase()

Nenhuma mensagem de erro: o programa rodou e mostrou o texto errado. O $ pegou só nome; o resto virou texto. Como consertar: 'Nome: ${nome.toUpperCase()}'.

Uma chave esquecida, seis mensagens. Dentro de ${, o Dart está lendo código, não texto; então a aspa depois de preco abriu um texto novo, que nunca fecha. A pista mais útil está na quinta mensagem: Expected '}' before this. ("era esperado um } antes disto"), na coluna 24, logo depois de preco. Como consertar: 'Preço: ${preco}', ou melhor ainda, sem chaves: 'Preço: $preco'.

Um $ com espaço depois 
void main() {
  var paes = 7;
  print('Faltam $ paes pães');
}

$ dart run err_espaco.dart
err_espaco.dart:3:18: Error: A '$' has special meaning inside a string, and must be followed by an identifier or an expression in curly braces ({}).
Try adding a backslash (\) to escape the '$'.
  print('Faltam $ paes pães');
                 ^

"Um $ tem significado especial num texto e precisa vir seguido de um nome (identifier, "identificador") ou de uma expressão entre chaves." O $ e o nome têm de estar colados. Como consertar: 'Faltam $paes pães'. Se você queria mesmo um cifrão, escreva \$.

O cifrão do real sumiu

Você viu na seção 4: 'Total: R$total' mostra Total: R20, sem erro. Sempre que o texto tiver R$, escreva R\$.

Missão final: a linha do pedido

Missão: monte num print só a linha do pedido: 6 x Pão de queijo = R$ 15.00. Use $quantidade, $produto, o cifrão de verdade (R\$) e, para o total, a conta com toStringAsFixed(2) dentro de ${…}.

void main() {
  var produto = 'Pão de queijo';
  var quantidade = 6;
  var preco = 2.5;
  // escreva o print aqui
}

void main() {
  var produto = 'Pão de queijo';
  var quantidade = 6;
  var preco = 2.5;
  print('$quantidade x $produto = R\$ ${(quantidade * preco).toStringAsFixed(2)}');
}

$ dart run missao.dart
6 x Pão de queijo = R$ 15.00

Resumo

  • Interpolação põe valores dentro do texto: 'Olá, $nome!'. É o jeito recomendado de montar textos no Dart, no lugar do +.
  • Qualquer valor serve; o Dart converte para texto sozinho (sem toString()).
  • Só um nome: $nome. Conta, método ou propriedade: ${…}. Sem as chaves, '$nome.length' mostra Ana.length, sem aviso.
  • O cifrão de verdade é \$: 'R\$ $total'. Num texto cru (r'…') não há interpolação.
  • Nome errado depois do $ não compila (Undefined name); ${ sem } gera várias mensagens: procure o Expected '}'.
