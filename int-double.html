Dart int e double

Quase todo programa faz conta: o total da compra, a média da turma, quantos pães cabem em cada saco. O Dart tem dois tipos de número: o int, para números inteiros (sem vírgula: 3, 30, -4), e o double, para números com casas decimais (4.50, 1.68). Nesta aula você vai ver quando usar cada um, como eles se misturam nas contas e as surpresas que todo programador encontra um dia.

Você vai aprender
  • A diferença entre int e double, e como escrever cada um no código.
  • Por que 7 / 2 dá 3.5 e 7 ~/ 2 dá 3, e o que é o resto %.
  • Por que 0.1 + 0.2 não dá exatamente 0.3, e como mostrar dinheiro com toStringAsFixed(2).
  • Os métodos de arredondar: round, floor, ceil e truncate.
  • O tipo num, que aceita os dois.
  • Os erros reais: guardar um double numa variável int e dividir por zero com ~/.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com dart run arquivo.dart (veja Rodando um Programa).

A ideia: contar pães e pesar farinha

Na padaria do bairro, algumas coisas se contam: 7 pães, 2 clientes, 30 anos de idade. Ninguém compra 2,7 pães. Outras coisas se medem: 1,68 metro de altura, 4,50 reais, 0,5 quilo de farinha. Medidas quase sempre têm casas decimais.

O Dart separa os números do mesmo jeito:

TipoPara quêExemplos
int (de integer, "inteiro")Coisas que se contam7, 30, -4, 0
double (de "precisão dupla")Coisas que se medem, com casas decimais4.50, 1.68, -0.5, 2.0
No código, a vírgula decimal é um ponto

Em português escrevemos 4,50; no Dart (e em quase toda linguagem de programação) se escreve 4.50. A vírgula tem outro trabalho no código: separar itens de uma lista e argumentos de uma função.

1. Criando variáveis int e double

void main() {

  double altura = 1.68;

  print(estoque);
  print(preco);
  print(altura);

int idade = 30;
Cria a variável idade do tipo int com o valor 30. O tipo vem antes do nome, como em Variáveis.
int estoque = -4;

double preco = 4.50;

print(preco)
Mostra o valor. Repare na saída: o Dart mostra 4.5, sem o zero do fim. Para o computador, 4.50 e 4.5 são o mesmo número. Como mostrar sempre duas casas está na seção 4.

2. Contas com int e double

A Ana tem 7 pães para dividir entre 2 pessoas. Veja as contas:

  int pessoas = 2;
  print(paes + pessoas);
  print(paes - pessoas);
  print(paes * pessoas);
  print(paes / pessoas);

  print(paes % pessoas);

}

7 + 2, 7 - 2, 7 * 29, 5, 14Soma, subtração, multiplicação (o * é o "vezes"). int com int dá int.

3. O tipo num: "qualquer número"

int e double são primos: os dois são num (de number, "número"). Uma variável num aceita os dois:

void main() {
  num qualquer = 3;
  print(qualquer);
  qualquer = 2.5;
  print(qualquer);
  print(qualquer is int);
  print(qualquer is double);
}

$ dart run num.dart
3
2.5
false
true

O is pergunta "é deste tipo?" e responde true ou false (veja is, is! e as). Depois de receber 2.5, a variável guarda um double. Na prática, prefira int ou double: dizem mais sobre o valor. Use num só quando os dois servem de verdade.

4. Dinheiro e o 0.1 + 0.2

Agora uma surpresa que pega todo mundo:

void main() {
  double total = 0.1 + 0.2;
  print(total);
  print(total == 0.3);
  print(total.toStringAsFixed(2));
  double compra = 4.5 + 12.9 + 3.25;
  print(compra);
  print('Total: R\$ ${compra.toStringAsFixed(2)}');
}

$ dart run dinheiro.dart
0.30000000000000004
false
0.30
20.65
Total: R$ 20.65

Não é defeito do Dart. O computador guarda o double em binário (zeros e uns), e números como 0,1 não têm representação exata em binário, do mesmo jeito que 1/3 não tem representação exata em decimal (0,3333…). Fica um errinho minúsculo no fim. O total == 0.3 (o == pergunta "é igual?") deu false por causa desse errinho. Python, JavaScript, Java e C fazem igual.

total.toStringAsFixed(2)
"Para texto com casas fixas": transforma o número em texto com exatamente 2 casas decimais, arredondando. 0.30000000000000004 vira '0.30'. É o jeito de mostrar dinheiro.
'Total: R\$ ${…}'
Um texto com o valor dentro. O \$ mostra o cifrão de verdade; o ${…} encaixa o resultado da conta no texto. Os dois são assunto da aula Interpolação.
Boa prática com dinheiro

Para mostrar, use toStringAsFixed(2). Para comparar, não use == com double. Programas de banco costumam guardar dinheiro em centavos, num int (R$ 4,50 = 450): conta com inteiro nunca tem esse errinho.

5. Arredondar e outras perguntas ao número

Todo número no Dart tem métodos: ações que você chama com um ponto depois do valor, como nota.round(). A nota da Ana foi 7,6:

void main() {
  double nota = 7.6;
  print(nota.round());
  print(nota.floor());
  print(nota.ceil());
  print(nota.truncate());
  print((-7.6).truncate());
  print((-7.6).floor());
  print((-3).abs());
  print(8.isEven);
  print(7.isOdd);
  print(15.clamp(0, 10));
  print(7.toDouble());
  print(2.5.round());
  print(3.14159.toStringAsFixed(2));
}

6. Os limites: o maior int e o "infinito"

void main() {
  int maior = 9223372036854775807;
  print(maior);
  print(maior + 1);
  print(1 / 0);
  print(-1 / 0);
  print(0 / 0);
  print(double.maxFinite);
}

$ dart run limites.dart
9223372036854775807
-9223372036854775808
Infinity
-Infinity
NaN
1.7976931348623157e+308
  • Um int do Dart (num programa de terminal) cabe em 64 bits: vai até 9.223.372.036.854.775.807 (9 quintilhões). Passou disso, ele dá a volta para o menor número negativo, sem aviso nenhum. Ninguém conta pães até lá, mas é bom saber. (Para números ainda maiores existe o BigInt.)
  • Dividir um número por zero com / não dá erro: dá Infinity ("infinito") ou -Infinity.
  • 0 / 0 dá NaN: Not a Number, "não é um número". Um double que avisa que a conta não faz sentido.
  • double.maxFinite é o maior double que não é infinito: cerca de 1,8 × 10308.

Resumo

  • int guarda inteiros (o que se conta); double guarda números com casas decimais (o que se mede). Os dois são num.
  • No código, a vírgula decimal é um ponto: 4.50.
  • / sempre dá double; ~/ é a divisão inteira; % é o resto. int misturado com double dá double.
  • 0.1 + 0.2 dá 0.30000000000000004: mostre dinheiro com toStringAsFixed(2) e não compare double com ==.
  • round, floor, ceil e truncate transformam double em int, cada um do seu jeito.
  • Um double numa variável int não compila (código 254); ~/ por zero é uma exceção em tempo de execução (código 255).
