Dart Instalar

Para rodar programas Dart no seu computador, você precisa do Dart SDK: o kit que traz o comando dart. Ele é gratuito e oficial, feito pelo time do Dart no Google. Nesta aula você vê como instalá-lo no Windows, no macOS e no Linux, como conferir se deu certo e o que fazer quando o terminal responde que não conhece o dart.

Você vai aprender
  • O que é o Dart SDK e o que vem dentro dele.
  • A instalar no Windows (winget ou Chocolatey), no macOS (Homebrew) e no Linux (o apt com o repositório do Google).
  • O jeito que funciona em qualquer sistema: o arquivo zip.
  • Por que, se você já tem o Flutter, já tem o Dart.
  • A conferir a instalação com dart --version.
  • O que quer dizer Comando 'dart' não encontrado e como resolver.
Não quer instalar nada agora?

Pode pular esta aula por enquanto. As caixas "Experimente" deste guia rodam no navegador, sem instalação (aula O Editor do Guia). Volte aqui quando quiser rodar programas no seu computador.

Os comandos de instalação abaixo são os da página oficial dart.dev/get-dart (conferidos em outubro de 2026). As saídas de terminal foram colhidas na máquina fictícia da Ana (usuária ana, computador notebook, Ubuntu), que tem o Dart SDK 3.13.5. O que não deu para rodar lá (Windows, macOS e o próprio processo de instalação) está marcado como ilustrativo.

A ideia: a caixa de ferramentas

Um marceneiro não faz uma mesa só com a vontade: ele precisa da caixa de ferramentas. O SDK (Software Development Kit, "kit de desenvolvimento de software") é a caixa de ferramentas do programador Dart. Tudo nela é usado pelo mesmo comando, o dart, seguido do nome da ferramenta:

dart createCriar um projeto novoCriando um Projeto
dart pubBaixar pacotes de outras pessoasPacotes do pub.dev
dart compileTransformar o programa num executávelCompilando

Comando 'dart' não encontrado
O terminal procurou um programa chamado dart nas pastas de programas do sistema e não achou. Quer dizer: o Dart não está instalado (ou está, mas numa pasta que o terminal não conhece; veja a seção 6).

O Ubuntu sugere programas com nome parecido (dar, darts, tart…). Nenhum deles é o Dart. Não instale nada dessa lista: o Dart SDK não vem dos pacotes comuns do Ubuntu, e sim do repositório do Google (seção 4).

No Windows, o PowerShell responde com uma mensagem parecida (ilustrativo): dart : O termo 'dart' não é reconhecido como nome de cmdlet, função, arquivo de script ou programa operável. No macOS, o terminal diz zsh: command not found: dart (ilustrativo). As três querem dizer a mesma coisa.

2. Windows

O Dart roda no Windows 10 e no Windows 11 (processadores x64 ou Arm64). Escolha um dos dois jeitos abaixo, no PowerShell.

Com o winget (já vem no Windows)

O winget é o instalador de programas da própria Microsoft. Ilustrativo:

winget install --id=Google.DartSDK -e
winget install
"Instale um programa".
--id=Google.DartSDK
O nome exato do pacote do Dart SDK no catálogo do winget.
-e
De exact, "exato": instale esse id e nenhum de nome parecido.

Com o Chocolatey

Se você já usa o Chocolatey (outro instalador de programas, que precisa ser instalado antes), abra o PowerShell como administrador e digite (ilustrativo):

choco install dart-sdk

Depois de qualquer um dos dois, feche e abra o PowerShell de novo (o terminal só enxerga programas novos quando é aberto de novo) e confira com dart --version (seção 7).

3. macOS

No macOS, o jeito oficial é o Homebrew, o instalador de programas mais usado no Mac (instale-o antes, em brew.sh). No Terminal (ilustrativo):

brew tap dart-lang/dart
brew trust dart-lang/dart
brew install dart
brew tap dart-lang/dart
Acrescenta ao Homebrew a "prateleira" (tap) mantida pelo time do Dart, onde fica o pacote.
brew trust dart-lang/dart
Diz ao Homebrew que você confia nessa prateleira (passo pedido pela página oficial).
brew install dart
Baixa e instala o Dart SDK.

4. Linux (Ubuntu, Debian): o apt com o repositório do Google

O Dart SDK não está nos pacotes normais do Ubuntu e do Debian. O time do Dart mantém um repositório (um "armazém" de pacotes) próprio, e você precisa avisar o apt que ele existe. Os passos 1 a 3 são feitos só uma vez; o passo 4 instala. Ilustrativo (a máquina da Ana já veio com o Dart):

sudo apt-get update && sudo apt-get install apt-transport-https gpg
wget -qO- https://dl-ssl.google.com/linux/linux_signing_key.pub \
  | sudo gpg --dearmor -o /usr/share/keyrings/dart.gpg
echo 'deb [signed-by=/usr/share/keyrings/dart.gpg arch=amd64] https://storage.googleapis.com/download.dartlang.org/linux/debian stable main' \
  | sudo tee /etc/apt/sources.list.d/dart_stable.list
sudo apt-get update && sudo apt-get install dart
  1. Prepara o apt: atualiza a lista de pacotes e instala duas ferramentas que os próximos passos usam (gpg confere assinaturas digitais).
  2. Baixa a chave do Google: o wget baixa a chave pública de assinatura e o gpg --dearmor a guarda em /usr/share/keyrings/dart.gpg. Com ela, o apt confere que os pacotes vieram mesmo do Google e não foram trocados no caminho.
  3. Cadastra o repositório: cria o arquivo /etc/apt/sources.list.d/dart_stable.list com o endereço do armazém do Dart, canal stable (estável). O arch=amd64 é o tipo de processador: troque por arm64, armhf ou riscv64 se o seu for outro.
  4. Instala: atualiza a lista de novo (agora com o repositório do Dart) e instala o pacote dart.

O pacote coloca o SDK em /usr/lib/dart e cria o atalho /usr/bin/dart. Na máquina da Ana, o Dart está exatamente nesses lugares:

$ which dart
/usr/bin/dart
$ readlink -f /usr/bin/dart
/usr/lib/dart/bin/dart
$ cat /usr/lib/dart/version
3.13.5
which dart
"Qual dart?": mostra onde está o programa que o terminal roda quando você digita dart.
readlink -f /usr/bin/dart
O /usr/bin/dart é um atalho (link); o readlink -f mostra para onde ele aponta: o programa de verdade, dentro de /usr/lib/dart/bin.
/usr/lib/dart/version
Um arquivo de texto com a versão do SDK instalado.

Para atualizar o Dart mais tarde, basta o passo 4 de novo: sudo apt-get update && sudo apt-get install dart.

5. O jeito que funciona em qualquer sistema: o arquivo zip

Sem instalador nenhum: você baixa o SDK compactado da página oficial do arquivo de versões (dart.dev/get-dart/archive), escolhendo o sistema e o processador, e descompacta numa pasta sua. Ele vem numa pasta chamada dart-sdk, com os programas dentro de dart-sdk/bin. É também o jeito de ter versões de teste (beta e dev) ou várias versões lado a lado.

O único trabalho extra é avisar o terminal onde está o dart, colocando a pasta bin no PATH: a lista de pastas onde o terminal procura programas. No Linux, se você descompactou em /home/ana/dart-sdk, acrescente esta linha ao fim do arquivo ~/.bashrc e abra um terminal novo (ilustrativo):

export PATH="$PATH:$HOME/dart-sdk/bin"

No Windows, o caminho é parecido: descompacte, por exemplo, em C:\dart-sdk e acrescente C:\dart-sdk\bin à variável Path em "Editar as variáveis de ambiente do sistema" (ilustrativo).

6. Já tem o Flutter? Então já tem o Dart

O Flutter SDK traz o Dart SDK completo dentro dele: o comando dart fica na pasta bin do Flutter, ao lado do comando flutter. Se você instalou o Flutter e o flutter --version funciona, o dart --version também funciona e você não precisa instalar o Dart separado.

O contrário não vale: instalar o Dart não instala o Flutter. A máquina da Ana tem só o Dart SDK:

$ flutter --version
Comando 'flutter' não encontrado, você quis dizer:
  comando 'fluster' do deb fluster (1.0.1+really0.6.0-2)
Experimente: sudo apt install <deb name>

Mais sobre a dupla em Dart e Flutter.

Dois Darts no mesmo computador

Se você instalar o Dart sozinho e o Flutter, vai ter dois Darts, possivelmente de versões diferentes. O terminal usa o que achar primeiro no PATH. Na dúvida, which dart (Linux e macOS) ou where.exe dart (Windows) mostra qual está sendo usado.

Quando dá errado

"Comando 'dart' não encontrado" depois de instalar

Você instalou, mas o terminal continua sem achar o dart. As causas, da mais comum para a menos comum:

  1. O terminal estava aberto durante a instalação. Feche e abra de novo.
  2. Instalou pelo zip e não pôs a pasta bin no PATH (seção 5), ou pôs a pasta errada: tem de ser a dart-sdk/bin, não a dart-sdk.
  3. O apt não instalou porque faltou um dos passos 1 a 3 (aí o apt-get install dart responde que não encontrou o pacote).
Dart com D maiúsculo 
$ Dart --version
Comando 'Dart' não encontrado, você quis dizer:
  comando 'tart' do deb tart (3.10-3build1)
  comando 'art' do deb artemis (18.2.0+dfsg-5)
  comando 'zart' do deb gmic-zart (2.9.4-4.2)
  comando 'bart' do deb bart (0.9.00-3build1)
Experimente: sudo apt install <deb name>

No Linux e no macOS, maiúsculas e minúsculas fazem diferença nos nomes de comandos: Dart e dart são nomes diferentes, e só o segundo existe. Aqui o Dart está instalado; o erro é só de digitação. Como consertar: tudo minúsculo, dart --version.

Opção escrita errado 
$ dart --verson
Could not find an option named "--verson".

Usage: dart <command|dart-file> [arguments]
…
$ echo $?
64

"Não encontrei uma opção chamada --verson". Desta vez o dart foi achado (então está instalado), mas ele não conhece a opção, que tem uma letra faltando. Depois da mensagem ele mostra a mesma ajuda do dart sozinho (cortada aqui com …), para você achar a opção certa. O código de saída 64 é o jeito de o dart dizer "você usou o comando errado". Como consertar: dart --version.

Resumo

  • O Dart SDK é a caixa de ferramentas do Dart; todas as ferramentas se usam pelo comando dart.
  • Windows: winget install --id=Google.DartSDK -e ou choco install dart-sdk.
  • macOS: brew tap dart-lang/dart, brew trust dart-lang/dart e brew install dart.
  • Linux: cadastre o repositório do Google uma vez e instale com sudo apt-get install dart; ele fica em /usr/lib/dart, com o atalho /usr/bin/dart.
  • Zip: funciona em qualquer sistema; ponha a pasta dart-sdk/bin no PATH.
  • Quem tem o Flutter já tem o Dart.
  • Confira com dart --version num terminal novo. Comando 'dart' não encontrado = não instalado, terminal antigo ou fora do PATH.
