Dart late e o Operador !

Nas aulas anteriores, o Dart conferiu tudo por você: se uma variável podia ser null, ele não deixava usar sem tratar. Mas às vezes você sabe mais do que o Dart consegue enxergar: "esta chave está no mapa, eu acabei de conferir", "esta variável vai ser preenchida antes de alguém ler". Para esses casos existem duas ferramentas que dizem ao Dart "confie em mim": o operador ! e a palavra late. Elas são úteis, e perigosas: se você estiver errado, o erro volta a aparecer durante a execução.

Você vai aprender
  • O operador !: transforma um String? em String na marra.
  • O que acontece quando o ! encontra null: a exceção real Null check operator used on a null value.
  • late: uma variável sem ? que só vai receber valor depois.
  • O LateInitializationError, quando o "depois" não chegou.
  • late com valor (preguiçoso) e late final (preenchido uma vez só).
  • Quando usar cada um, e quando preferir if, ?? ou um tipo com ?.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a promessa

O Dart é o gerente cuidadoso da lojinha: antes de abrir qualquer caixa, ele pergunta "tem certeza de que tem algo aí dentro?". O ! e o late são promessas que você faz para ele:

  • x! — "Pode abrir, eu garanto que esta caixa não está vazia."
  • late — "Esta prateleira está vazia agora, mas eu garanto que vou abastecê-la antes de alguém pegar algo."

O gerente aceita a promessa e para de conferir. Se você cumprir, tudo bem. Se não cumprir, o programa para no meio, com uma exceção: o mesmo tipo de quebra que o null safety existe para evitar.

1. O operador !

void main() {
  var precos = {'pão': 1, 'bolo': 25};
  if (precos.containsKey('bolo')) {
    int preco = precos['bolo']!;
    print('Bolo: R\$ $preco');
  }
  String? apelido = buscar();
  print(apelido!.length);
}

String? buscar() => 'Aninha';

$ dart run exclamacao.dart
Bolo: R$ 25
6
precos.containsKey('bolo')
"O mapa contém a chave bolo?" Você conferiu: tem. Mas o Dart não liga essa pergunta à próxima linha: para ele, precos['bolo'] continua sendo int?.
precos['bolo']!
O ! colado depois do valor diz: "não é null, confie". O tipo vira int, e cabe na variável int preco. Sem o !, seria o erro A value of type 'int?' can't be assigned to a variable of type 'int'. (aula Null Safety).
apelido!.length
O mesmo antes de um ponto: "apelido não é null, pode pegar o length". Deu 6.
String? buscar() => 'Aninha';
Uma função de uma linha que devolve String? (veja Funções de Uma Linha). Ela devolveu um texto, então a promessa foi cumprida.

O nome técnico do ! é operador de asserção de não nulo (null assertion operator; muita gente diz "bang", o nome do ! em inglês). Não confunda com o ! que vem antes de um bool (!aberta, "não aberta", da aula Booleanos): mesmo sinal, outro trabalho.

2. late: "vou preencher depois"

Às vezes uma variável comum (sem ?) não tem valor no momento em que é criada, mas vai ter antes de ser usada. Aqui, a saudação depende da hora:

late String saudacao;

void main() {
  var hora = 9;
  if (hora < 12) {
    saudacao = 'Bom dia';
  } else {
    saudacao = 'Boa tarde';
  }
  print('$saudacao, Ana!');
}

$ dart run tardia.dart
Bom dia, Ana!
late String saudacao;
late quer dizer "atrasado", "tardio". A variável é String (nunca null), mas começa sem valor, com a promessa de receber um antes de ser lida. Ela foi criada fora do main, no "topo" do arquivo: uma variável assim se chama global, e o Dart não consegue acompanhar o caminho dela como faz com as variáveis de dentro de uma função. Sem o late, seria o erro Field 'saudacao' should be initialized because its type 'String' doesn't allow null. (o mesmo do campo de classe, na aula Null Safety).
saudacao = 'Bom dia';
A promessa sendo cumprida, num dos dois caminhos do if.

Onde o late aparece de verdade é em classes: campos que só são preenchidos depois que o objeto é criado (você vai ver em Classes):

class Pedido {
  late String cliente;
}

void main() {
  var p = Pedido();
  p.cliente = 'Ana';
  print(p.cliente);
  var q = Pedido();
  print(q.cliente);
}

3. Dois usos especiais: late com valor e late final

late com valor: só calcula se precisar

Um late com valor inicial é "preguiçoso": o valor só é calculado na primeira vez que alguém lê a variável. Repare na ordem das linhas na saída:

int contarEstoque() {
  print('(contando o estoque...)');
  return 42;
}

void main() {
  late int estoque = contarEstoque();
  print('Programa começou');
  print('Estoque: $estoque');
  print('Estoque de novo: $estoque');
}

$ dart run preguica.dart
Programa começou
(contando o estoque...)
Estoque: 42
Estoque de novo: 42

A contagem aconteceu depois do Programa começou, só quando o $estoque foi usado, e uma vez só: na segunda leitura, o valor já estava guardado. Útil quando o cálculo é demorado e talvez nem seja necessário.

late final: preenchido uma vez, nunca mais

final quer dizer "não muda mais" (aula final e const). Com late final, a variável começa vazia e pode receber valor uma única vez:

late final String codigo;

void main() {
  codigo = 'A1';
  print(codigo);
  codigo = 'B2';
  print(codigo);
}

Quando dá errado

! num valor que era null

Seção 1: Null check operator used on a null value, em tempo de execução, código 255. É de longe o erro mais comum de quem usa !: num aplicativo Flutter, é a tela vermelha. Como consertar: troque o ! por ?? padrao, ou por um if (x != null).

late local lido antes de receber valor 
void main() {
  late String saudacao;
  var hora = 15;
  if (hora < 12) {
    saudacao = 'Bom dia';
  }
  print('$saudacao, Ana!');
}

Missão final: o caixa que quebrava

Missão: o caixa soma os preços do pedido usando precos[item]!. Mas a torta não está na tabela, e o programa para com Null check operator used on a null value. Troque o ! por ?? 0 (com parênteses: (precos[item] ?? 0)) para itens desconhecidos valerem zero. A saída deve ser Total: R$ 26.

void main() {
  var precos = {'pão': 1, 'bolo': 25};
  var pedido = ['bolo', 'torta', 'pão'];
  var total = 0;
  for (var item in pedido) {
    total = total + precos[item]!;
  }
  print('Total: R\$ $total');
}

void main() {
  var precos = {'pão': 1, 'bolo': 25};
  var pedido = ['bolo', 'torta', 'pão'];
  var total = 0;
  for (var item in pedido) {
    total = total + (precos[item] ?? 0);
  }
  print('Total: R\$ $total');
}

Resumo

  • x! promete que x não é null e o transforma de T? em T. Se a promessa falhar: Null check operator used on a null value, durante a execução.
  • late cria uma variável sem ? que só recebe valor depois. Ler antes: LateInitializationError … has not been initialized.
  • late com valor só calcula na primeira leitura; late final aceita um valor só.
  • Os dois trocam um erro de compilação (seguro) por um possível erro de execução (perigoso). Use só com certeza; na dúvida, ?, if e ??.
  • O ! depois de um valor (asserção de não nulo) não é o ! antes de um bool (negação).
