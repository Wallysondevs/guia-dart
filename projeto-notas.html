Projeto Notas da Turma

A Ana é professora. No fim do bimestre, ela tem três notas de prova para cada aluno e precisa responder sempre as mesmas perguntas: qual a média de cada um, quem passou, quem ficou de recuperação e qual a média da turma. Neste projeto você vai escrever, aos poucos, o programa que faz isso por ela: primeiro com as notas escritas no próprio código, depois lendo o arquivo que a planilha da escola exporta.

Você vai praticar
  • Guardar a turma num Map de nome para lista de notas.
  • Percorrer o mapa com for-in e entries (veja Percorrendo Mapas).
  • Escrever funções que devolvem um valor: media e situacao.
  • Juntar os dados de cada aluno num record e ordenar com sort (veja Métodos de Lista).
  • Alinhar colunas com padLeft, padRight e toStringAsFixed (veja Métodos de String).
  • Ler e gravar arquivos com dart:io.

O que vamos construir

O programa pronto, no terminal da Ana, mostra um relatório com os alunos da maior para a menor média e grava um arquivo novo, o relatorio.csv, que a planilha abre de volta:

Versão 1 · A turma num Map

Pense na caderneta da Ana: cada linha tem o nome do aluno e, ao lado, as notas dele. Em Dart, "um nome que leva a uma coisa" é um Map (mapa). A chave é o nome (String) e o valor é a lista de notas (List<double>).

void main() {
  final turma = <String, List<double>>{
    'Ana Clara': [8.5, 7.0, 9.0],
    'Bruno': [5.0, 6.5, 4.0],
    'Carla': [7.0, 7.0, 7.5],
    'Diego': [3.5, 5.0, 6.0],
    'Elisa': [10, 9.5, 9.0],
  };

  print('${turma.length} alunos na turma.');
  for (final entrada in turma.entries) {
    print('${entrada.key}: ${entrada.value.join(' ')}');
  }
}

Versão 2 · Média e situação

Agora as contas. Duas perguntas, duas funções: "qual a média destas notas?" e "com essa média, qual a situação?". Cada uma recebe um valor e devolve outro com return.

double media(List<double> notas) {
  var soma = 0.0;
  for (final nota in notas) {
    soma += nota;
  }
  return soma / notas.length;
}

String situacao(double m) {
  if (m >= 7) return 'aprovado(a)';
  if (m >= 5) return 'recuperação';
  return 'reprovado(a)';
}

void main() {
  final turma = <String, List<double>>{
    'Ana Clara': [8.5, 7.0, 9.0],
    'Bruno': [5.0, 6.5, 4.0],
    'Carla': [7.0, 7.0, 7.5],
    'Diego': [3.5, 5.0, 6.0],
    'Elisa': [10, 9.5, 9.0],
  };

  for (final entrada in turma.entries) {
    final m = media(entrada.value);
    print('${entrada.key}: média ${m.toStringAsFixed(2)}, ${situacao(m)}');
  }
}

var soma = 0.0;O acumulador: começa em zero e cada nota é somada a ele. O .0 é importante (veja o erro logo abaixo).
soma += nota;O mesmo que soma = soma + nota; (veja Atribuição).
soma / notas.lengthA média: a soma dividida pela quantidade. A barra / sempre dá double.
if (m >= 7) return …;Se a condição vale, a função devolve e termina ali. Por isso o segundo if não precisa de else: só chega nele quem tem menos de 7.
m.toStringAsFixed(2)Transforma o número em texto com 2 casas decimais, arredondando: 8.1666… vira 8.17.

Outras formas de escrever as duas funções

As mesmas funções, mais curtas: a média com reduce ("reduzir": soma os itens dois a dois, veja map, where, reduce e Outros) e a situação com uma expressão switch com padrões relacionais (>= 7):

double media(List<double> notas) =>
    notas.reduce((a, b) => a + b) / notas.length;

String situacao(double m) => switch (m) {
      >= 7 => 'aprovado(a)',
      >= 5 => 'recuperação',
      _ => 'reprovado(a)',
    };

void main() {
  print(media([8.5, 7.0, 9.0]).toStringAsFixed(2));
  print(situacao(5.17));
  print(media([]));
}

Versão 3 · O relatório

A Ana quer uma tabela bonita, da maior para a menor média, com a média da turma e quantos passaram. Para ordenar, cada aluno precisa carregar junto o nome, as notas e a média. Um record faz isso sem precisar criar uma classe: (nome: …, notas: …, media: …). As funções media e situacao continuam as mesmas; o main muda:

void main() {
  final turma = <String, List<double>>{
    'Ana Clara': [8.5, 7.0, 9.0],
    'Bruno': [5.0, 6.5, 4.0],
    'Carla': [7.0, 7.0, 7.5],
    'Diego': [3.5, 5.0, 6.0],
    'Elisa': [10, 9.5, 9.0],
  };

  // Um record por aluno: nome, notas e média.
  final alunos = [
    for (final entrada in turma.entries)
      (nome: entrada.key, notas: entrada.value, media: media(entrada.value)),
  ];

  // Da maior média para a menor.
  alunos.sort((a, b) => b.media.compareTo(a.media));

  print('Aluno         P1    P2    P3   Média  Situação');
  print('-' * 48);
  for (final aluno in alunos) {
    final colunas = aluno.notas.map((n) => n.toStringAsFixed(1).padLeft(6));
    print('${aluno.nome.padRight(10)}${colunas.join()}'
        '${aluno.media.toStringAsFixed(2).padLeft(8)}  ${situacao(aluno.media)}');
  }
  print('-' * 48);

  final somaDasMedias = alunos.fold(0.0, (soma, a) => soma + a.media);
  final aprovados = alunos.where((a) => a.media >= 7).length;
  print('Média da turma: ${(somaDasMedias / alunos.length).toStringAsFixed(2)}');
  print('Aprovados: $aprovados de ${alunos.length}');
}
[ for (…) (nome: …, notas: …, media: …), ]
Um for dentro da lista: para cada entrada do mapa, a lista ganha um record. O tipo da lista é deduzido: List<({String nome, List<double> notas, double media})>.
alunos.sort((a, b) => b.media.compareTo(a.media))
sort = "ordenar", e muda a própria lista. A função recebe dois alunos e diz qual vem antes: compareTo dá negativo, zero ou positivo. Com b na frente, a ordem fica decrescente (para crescente, a.media.compareTo(b.media)).
'-' * 48
Um texto multiplicado por um número se repete: 48 tracinhos.
padRight(10) e padLeft(6)
"Encher à direita/à esquerda": completa o texto com espaços até ter aquele tamanho. Nome à esquerda da coluna, números alinhados à direita.
'…' '…' em duas linhas
Dois textos lado a lado, sem nada no meio, viram um só. Serve para quebrar uma linha comprida.
fold(0.0, (soma, a) => soma + a.media)
Começa com 0.0 e vai somando a média de cada aluno.
where((a) => a.media >= 7).length
where = "onde": fica só com os aprovados; .length conta quantos.

Versão 4 · Lendo o CSV e gravando o relatório

Escrever as notas no código serve para testar, mas todo bimestre elas mudam. A secretaria da escola exporta a planilha como CSV (comma-separated values, "valores separados por vírgula"): cada linha da planilha vira uma linha de texto, e as vírgulas separam as colunas. A primeira linha é o cabeçalho, com os nomes das colunas. As notas usam ponto (8.5), porque a vírgula já separa as colunas.

Bruno,5.0,6.5,4.0
Carla,7.0,7.0,7.5
Diego,3.5,5.0,6.0
Elisa,10,9.5,9.0

O programa final troca o mapa escrito à mão pela leitura do arquivo e, no fim, grava o relatorio.csv. As funções media e situacao e o trecho que mostra o relatório são os mesmos da versão 3:

import 'dart:io';

double media(List<double> notas) {
  var soma = 0.0;
  for (final nota in notas) {
    soma += nota;
  }
  return soma / notas.length;
}

String situacao(double m) {
  if (m >= 7) return 'aprovado(a)';
  if (m >= 5) return 'recuperação';
  return 'reprovado(a)';
}

void main() {
  final linhas = File('notas.csv').readAsLinesSync();

  final alunos = <({String nome, List<double> notas, double media})>[];
  for (final linha in linhas.skip(1)) {
    final campos = linha.split(',');
    final notas = [for (final campo in campos.skip(1)) double.parse(campo)];
    alunos.add((nome: campos[0], notas: notas, media: media(notas)));
  }

  alunos.sort((a, b) => b.media.compareTo(a.media));

  print('Aluno         P1    P2    P3   Média  Situação');
  print('-' * 48);
  for (final aluno in alunos) {
    final colunas = aluno.notas.map((n) => n.toStringAsFixed(1).padLeft(6));
    print('${aluno.nome.padRight(10)}${colunas.join()}'
        '${aluno.media.toStringAsFixed(2).padLeft(8)}  ${situacao(aluno.media)}');
  }
  print('-' * 48);

  final somaDasMedias = alunos.fold(0.0, (soma, a) => soma + a.media);
  final aprovados = alunos.where((a) => a.media >= 7).length;
  print('Média da turma: ${(somaDasMedias / alunos.length).toStringAsFixed(2)}');
  print('Aprovados: $aprovados de ${alunos.length}');

  // Grava o relatório num CSV novo.
  final saida = StringBuffer('nome,media,situacao\n');
  for (final aluno in alunos) {
    saida.writeln(
        '${aluno.nome},${aluno.media.toStringAsFixed(2)},${situacao(aluno.media)}');
  }
  File('relatorio.csv').writeAsStringSync(saida.toString());
  print('Relatório gravado em relatorio.csv.');
}
Peça novaO que faz
import 'dart:io';Traz a biblioteca de entrada e saída, onde mora a classe File ("arquivo").
File('notas.csv').readAsLinesSync()Lê o arquivo inteiro e devolve uma List<String>, uma linha por item, já sem a quebra de linha. O Sync quer dizer que o programa espera a leitura terminar (veja Lendo e Escrevendo Arquivos).
linhas.skip(1)"Pular 1": percorre as linhas a partir da segunda, deixando o cabeçalho de fora.
linha.split(',')"Dividir": corta o texto em cada vírgula. 'Bruno,5.0,6.5,4.0' vira ['Bruno', '5.0', '6.5', '4.0'].
double.parse(campo)Transforma o texto '8.5' no número 8.5 (veja Conversão de Tipos).
<({String nome, …})>[]Uma lista vazia de records. Aqui o tipo precisa ser escrito, porque a lista começa vazia e o Dart não teria de onde deduzir.
StringBuffer e writelnMonta o texto do arquivo aos poucos, uma linha por aluno (veja StringBuffer).

Conserto: use double.tryParse, que devolve null em vez de lançar exceção, e decida o que fazer com a linha ruim. Este trecho avisa e pula o aluno:

import 'dart:io';

double media(List<double> notas) {
  var soma = 0.0;
  for (final nota in notas) {
    soma += nota;
  }
  return soma / notas.length;
}

void main() {
  final linhas = File('notas.csv').readAsLinesSync();
  for (final (i, linha) in linhas.indexed.skip(1)) {
    if (linha.trim().isEmpty) continue; // linha em branco: pula
    final campos = linha.split(',');
    final notas = <double>[];
    for (final campo in campos.skip(1)) {
      final nota = double.tryParse(campo.trim());
      if (nota == null) {
        print('Linha ${i + 1}: nota inválida "$campo" (${campos[0]} ficou de fora)');
        notas.clear();
        break;
      }
      notas.add(nota);
    }
    if (notas.isEmpty) continue;
    print('${campos[0]}: ${media(notas).toStringAsFixed(2)}');
  }
}

}

Resumo

  • Um Map<String, List<double>> guarda "nome → notas"; entries percorre os pares com .key e .value.
  • Funções pequenas com nome (media, situacao) deixam o main fácil de ler.
  • O acumulador de double começa em 0.0; com 0, o Dart recusa: A value of type 'double' can't be assigned to a variable of type 'int'.
  • Um record junta nome, notas e média; sort precisa de uma função de comparação (b.media.compareTo(a.media) = decrescente).
  • padLeft, padRight e toStringAsFixed alinham colunas.
  • File(…).readAsLinesSync(), split(',') e double.parse leem o CSV; writeAsStringSync grava. Arquivo ausente: PathNotFoundException; campo vazio: FormatException, que o double.tryParse evita.
