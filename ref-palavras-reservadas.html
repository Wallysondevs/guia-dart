Dart Palavras Reservadas

Esta é a página de consulta das palavras-chave (em inglês, keywords) do Dart: as palavras que fazem parte da própria linguagem, como if, class e return. O Dart as divide em três grupos, e a diferença importa na hora de escolher nomes: algumas nunca podem ser nome de variável; outras só não podem ser nome de classe; e outras podem ser usadas à vontade.

Como ler esta página
  • A lista e a classificação vêm da página oficial Keywords (dart.dev/language/keywords).
  • Os resultados e as mensagens de erro foram colhidos no computador da Ana, com o Dart SDK 3.13.5.
  • O Dart diferencia maiúsculas de minúsculas: class é reservada; Class é um nome comum (conferido no lab: var Class = 2; compila).

Para ter os resultados da tabela, a Ana escreveu um programa que usa todas elas. Cada linha da saída começa com o nome da palavra testada:

enum Cor { verde, azul }

class Animal {
  final String nome;
  Animal(this.nome);
  String som() => '...';
}

mixin Nadador {
  String nadar() => 'nadando';
}

class Pato extends Animal with Nadador {
  Pato() : super('Pato');
  @override
  String som() => 'quack';
  String quemSou() => this.nome;
}

int dobro(int n) {
  return n * 2;
}

void main() {
  // break
  for (var i = 1; i <= 10; i++) {
    if (i > 3) break;
    print('break: $i');
  }
  // continue
  for (var i = 1; i <= 4; i++) {
    if (i.isEven) continue;
    print('continue: $i');
  }
  // switch case default
  final nota = 'B';
  switch (nota) {
    case 'A':
      print('switch: ótimo');
    case 'B':
      print('switch: bom');
    default:
      print('switch: outro');
  }
  // do while
  var n = 0;
  do {
    n++;
  } while (n < 3);
  print('do-while: $n');
  // if else
  if (2 > 3) {
    print('maior');
  } else {
    print('else: não é maior');
  }
  // for in
  for (final fruta in ['maçã', 'uva']) {
    print('for-in: $fruta');
  }
  // try catch finally throw
  try {
    throw FormatException('nota inválida');
  } catch (e) {
    print('catch: $e');
  } finally {
    print('finally: sempre roda');
  }
  // rethrow
  try {
    try {
      int.parse('dez');
    } catch (e) {
      print('rethrow: repassando');
      rethrow;
    }
  } on FormatException {
    print('rethrow: pego lá fora');
  }
  // is, true, false, null
  Object x = 42;
  print('is: ${x is int} ${x is String}');
  print('true/false: ${true && false}');
  String? apelido;
  print('null: $apelido ${apelido == null}');
  // var final const
  var idade = 30;
  idade++;
  final nome = 'Ana';
  const pi = 3.14;
  print('var/final/const: $idade $nome $pi');
  // class extends with super this new
  final p = Pato();
  print('classe: ${p.som()} ${p.nadar()} ${p.quemSou()}');
  final p2 = new Pato();
  print('new: ${p2.nome}');
  // enum
  print('enum: ${Cor.azul} ${Cor.values.length}');
  // return void
  print('return: ${dobro(21)}');
  // assert
  assert(1 + 1 == 2);
  print('assert: passou');
  // in
  print('in: ${[1, 2].contains(2)}');
}

"class não pode ser usado como identificador porque é uma palavra-chave. Tente renomear para um identificador que não seja palavra-chave." Identificador é o nome que você dá a uma variável, função ou classe. O Dart avisa nas duas linhas em que a palavra aparece. Com final new = 1;, a mensagem é a mesma, trocando 'class' por 'new'. Troque por turma, classe ou Class (com maiúscula funciona, mas foge da convenção lowerCamelCase).

Identificadores embutidos

Estas palavras têm sentido especial em certos lugares, mas foram deixadas livres como nome de variável e de função, para não quebrar programas antigos. Elas não podem ser nome de classe, de tipo, de extensão nem prefixo de import.

Palavras de contexto

Estas só têm sentido especial em certos lugares, e fora deles são nomes comuns, inclusive de classe: async, base, hide, of, on, sealed, show, sync e when. Duas delas, await e yield, têm uma restrição: não podem ser nome dentro de uma função async, async* ou sync*.

"await não pode ser identificador em métodos async, async* ou sync*." O segundo erro é consequência do primeiro: na linha 3, o Dart leu await como a palavra "espere" e esperava alguma coisa para esperar antes do ). Sem o async (num void main() comum), var await = 1; var yield = 2; print(await + yield); compila e mostra 3, conferido no lab.

Resumo

  • 33 reservadas nunca são nome: assert break case catch class const continue default do else enum extends false final finally for if in is new null rethrow return super switch this throw true try var void while with. O erro: 'class' can't be used as an identifier because it's a keyword.
  • Identificadores embutidos (abstract, required, late, get…) podem ser nome de variável, mas não de classe: Can't use 'required' as a name here.
  • Palavras de contexto (async, on, sealed, when…) são livres; await e yield só não podem ser nome dentro de funções async/async*/sync*.
  • Maiúsculas importam: Class é um nome comum.
  • assert só funciona com dart run --enable-asserts.
