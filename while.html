Dart while e do-while

O for é ótimo quando você sabe quantas voltas o laço vai dar: de 1 a 10, um aluno por vez. Mas muitas repetições do dia a dia não têm número certo: juntar dinheiro até chegar à meta, perguntar até a resposta prestar. Para isso existe o while, que em inglês quer dizer "enquanto": enquanto a condição for verdadeira, repita. E o seu irmão, o do-while ("faça … enquanto"), que roda o bloco pelo menos uma vez antes de perguntar.

Você vai aprender
  • Como se escreve um while: a condição entre parênteses e o bloco entre chaves.
  • Como contar para a frente e para trás com uma variável contadora.
  • Como repetir quando você não sabe quantas voltas vão ser, e por que um while pode dar zero voltas.
  • O do { … } while (…);, que testa a condição no fim, e quando ele é a escolha certa.
  • O laço infinito: como ele acontece e como pará-lo (Ctrl+C).
  • Os erros reais do Dart: parênteses esquecidos, o ; do do-while, condição que não é bool e variável que não existe.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: "enquanto tiver pão no cesto, atenda o próximo"

A padaria do bairro abre com um cesto de pães. O dono deixa um bilhete: "Enquanto tiver pão no cesto, atenda o próximo cliente." O bilhete não diz quantos clientes serão. Mesmo assim, funciona:

  1. O funcionário olha o cesto: tem pão? Sim → atende um cliente.
  2. Olha de novo: tem pão? Sim → atende mais um.
  3. … e assim por diante …
  4. Olha de novo: tem pão? Não → para de atender e vai fazer outra coisa.

Três detalhes valem para todo while:

  • A pergunta vem antes de cada atendimento. Se o cesto começar vazio, ninguém é atendido.
  • Cada volta muda alguma coisa (sai pão do cesto). Sem isso, a resposta seria sempre a mesma e o funcionário atenderia para sempre.
  • Quando a resposta vira não, ele sai da repetição e continua o resto do dia.

No Dart, a "pergunta" é uma condição do tipo bool, a mesma do if: uma expressão como contador <= 5 (veja Comparação). A diferença é que o if roda o bloco uma vez; o while roda de novo e de novo, enquanto a condição continuar true.

1. O primeiro while: contar de 1 a 5

void main() {
  var contador = 1;
  while (contador <= 5) {
    print('Volta $contador');
    contador++;
  }
  print('Fim! contador agora vale $contador');
}
var contador = 1;
A variável contadora, criada antes do laço, com o valor inicial. Ela é var (e não final) porque vai mudar a cada volta. Poderia se chamar volta ou i (de "índice", nome tradicional de contador).
while
A palavra-chave do laço: "enquanto".
(contador <= 5)
A condição, testada antes de cada volta: "enquanto o contador for menor ou igual a 5". No Dart os parênteses são obrigatórios, como no if.
{ … }
O corpo do laço: as linhas que se repetem. Os 2 espaços a mais mostram que elas estão dentro dele.
print('Volta $contador');
Mostra o valor atual do contador dentro do texto (veja Strings).
contador++;
"Some 1 ao contador" (o mesmo que contador = contador + 1 ou contador += 1; veja Atribuição e Incremento). É esta linha que faz o laço andar: sem ela, o contador seria 1 para sempre.
}
Fecha o bloco. Quando o Dart chega aqui, ele volta lá para cima e testa a condição de novo.
print('Fim! …');
Depois do bloco, fora do laço: roda uma vez só, quando o laço termina.
$ dart run contador.dart

Volta 2
Volta 3
Volta 4
Volta 5
Fim! contador agora vale 6

Cada execução do corpo se chama uma volta (ou iteração). Aqui foram 5.

As três peças de todo laço com contador

1) o início: var contador = 1; · 2) a condição: contador <= 5 · 3) o passo: contador++;. O for junta as três numa linha só; no while, quem cuida delas é você.

2. Contar para trás

O passo não precisa ser "mais 1". Para uma contagem regressiva, comece do maior número, diminua com -- e troque a condição para "maior que zero":

void main() {
  var segundos = 5;
  while (segundos > 0) {
    print('$segundos...');
    segundos--;
  }
  print('Já!');
}

$ dart run regressiva.dart
5...
4...
3...
2...
1...
Já!

Quando segundos chega a 0, a pergunta 0 > 0 dá false e o laço termina. O passo também pode ser de 2 em 2 (contador += 2) ou uma multiplicação (valor *= 2), como na missão final.

3. Quando você não sabe quantas voltas vão ser

A Ana quer juntar R$ 1000 para um notebook novo. Ela guarda R$ 150 por mês. Quantos meses vai levar? Ninguém disse; o programa descobre:

void main() {
  var saldo = 0;
  var meses = 0;
  while (saldo < 1000) {
    saldo += 150;
    meses++;
    print('Mês $meses: R\$ $saldo');
  }
  print('A Ana juntou R\$ $saldo em $meses meses.');
}

$ dart run poupanca.dart
Mês 1: R$ 150
Mês 2: R$ 300
Mês 3: R$ 450
Mês 4: R$ 600
Mês 5: R$ 750
Mês 6: R$ 900
Mês 7: R$ 1050
A Ana juntou R$ 1050 em 7 meses.
  • saldo é um acumulador: começa em 0 e, a cada volta, recebe mais um pouco (saldo += 150). É ele que a condição olha.
  • meses é um contador: conta as voltas.
  • O R\$ tem uma barra porque, num texto do Dart, o $ sozinho anuncia uma variável. \$ quer dizer "o cifrão mesmo" (veja Strings).

No mês 6 o saldo era 900, ainda menor que 1000: mais uma volta. No mês 7 virou 1050, a condição 1050 < 1000 deu false, e o laço parou.

Zero voltas também é possível

Como a pergunta vem antes da primeira volta, o corpo pode não rodar nenhuma vez. Se a Ana já tivesse R$ 1200:

$ dart run nunca.dart

Logo no primeiro teste, 1200 < 1000 deu false: o Dart pulou o bloco inteiro. Isso não é erro; é o cesto que já começou vazio.

4. O do-while: primeiro faz, depois pergunta

Às vezes o bloco tem de rodar pelo menos uma vez, antes de qualquer pergunta. Pense no provador da loja: você prova a roupa e só depois pergunta "serviu?"; se não serviu, prova outra. Para isso o Dart tem o do-while ("faça … enquanto"), que testa a condição no fim de cada volta.

Exemplo: contar quantos dígitos tem um número. A cada volta, o programa conta um dígito e "corta" o último com a divisão inteira por 10 (~/, veja Operadores Aritméticos): 4096 → 409 → 40 → 4 → 0.

void main() {
  var numero = 4096;
  var digitos = 0;
  do {
    digitos++;
    numero ~/= 10;
  } while (numero > 0);
  print('O número tem $digitos dígito(s).');
}
do {
"Faça": o bloco começa direto, sem condição nenhuma antes.
digitos++; numero ~/= 10;
O corpo: conta um dígito e tira o último do número.
} while (numero > 0);
Só aqui, depois da volta, vem a pergunta: "ainda sobrou número?". Se sim, volta para o do. Repare no ; no fim: no do-while ele é obrigatório (no while comum, não tem).
$ dart run digitos.dart
O número tem 4 dígito(s).

Por que não um while comum?

Com 4096 os dois dariam 4. A diferença aparece no número 0, que tem 1 dígito. Este programa conta os dígitos do 0 dos dois jeitos:

void main() {
  var numero = 0;
  var comWhile = 0;
  var n = numero;
  while (n > 0) {
    comWhile++;
    n ~/= 10;
  }
  var comDo = 0;
  n = numero;
  do {
    comDo++;
    n ~/= 10;
  } while (n > 0);
  print('while contou $comWhile dígito(s) no 0');
  print('do-while contou $comDo dígito(s) no 0');
}

$ dart run digitos_zero.dart
while contou 0 dígito(s) no 0
do-while contou 1 dígito(s) no 0

O while perguntou primeiro (0 > 0? não) e não rodou nenhuma vez: resposta errada. O do-while rodou a primeira volta sem perguntar e acertou. Esse é o critério: se a primeira volta tem de acontecer sempre, use do-while. O uso mais comum dele é pedir uma resposta ao usuário e repetir se ela for inválida; você vai ver isso na aula Lendo o Teclado.

5. O laço infinito, e como pará-lo

Um laço cuja condição nunca fica falsa não termina nunca: é um laço infinito. O jeito mais comum de criar um sem querer é esquecer o passo. Olhe o contador da seção 1 sem o contador++:

void main() {
  var contador = 1;
  while (contador <= 5) {
    print('Volta $contador');
  }
  print('Fim!');
}

O contador fica em 1 para sempre, e o programa mostra Volta 1 sem parar. A Ana deixou ele rodar só 2 segundos (com o comando timeout 2) e contou as linhas com o wc -l:

$ timeout 1 dart run infinito.dart | head -3
Volta 1
Volta 1
Volta 1
$ timeout 2 dart run infinito.dart | wc -l
1262286

Mais de um milhão de linhas em 2 segundos (o número muda de um computador para outro). O Fim! nunca chega.

No terminal: Ctrl+C

Para interromper um programa que não termina, segure Ctrl e aperte C. Um laço infinito também pode ser silencioso; aqui a Ana esqueceu de somar o dinheiro no saldo e o programa ficou parado, "pensando":

void main() {
  var saldo = 0;
  var meses = 0;
  while (saldo < 1000) {
    meses++;
  }
  print('A Ana juntou R\$ $saldo em $meses meses.');
}

$ dart run esqueceu.dart
^C
$ echo $?
130
^C
O terminal mostrando que você apertou Ctrl+C. O Dart não escreve mensagem nenhuma: o programa simplesmente para.
echo $? → 130
O código de saída do último programa. 0 seria "terminou bem"; 130 é o código que o terminal usa para "interrompido pelo Ctrl+C". Não é defeito do seu código: foi você que mandou parar.

No editor do guia

A caixa "Experimente" também roda o programa de verdade, então um laço infinito lá também não termina sozinho: enquanto ele roda, o botão ▶ Rodar vira ■ Parar, que faz o papel do Ctrl+C. Os detalhes (e o limite de tempo do editor) estão em O Editor do Guia.

Experimente: este é o programa da Ana que esqueceu de somar no saldo. Clique em Rodar e depois em ■ Parar. Depois, conserte: acrescente saldo += 150; dentro do laço e rode de novo.

void main() {

  var meses = 0;
  while (saldo < 1000) {
    meses++;
  }
  print('A Ana juntou R\$ $saldo em $meses meses.');
}

Quando o infinito é de propósito: while (true)

Às vezes o laço infinito é proposital: um programa que fica esperando pedidos até alguém mandar parar. Escreve-se while (true), uma condição sempre verdadeira, e a saída fica no meio do bloco, com o break ("quebrar"). É o assunto da próxima aula: break e continue.

Formas diferentes de fazer a mesma coisa

Contar de 1 a 5 pode ser escrito com os três laços. Todos mostram Volta 1 a Volta 5:

void main() {
  // 1) while: as três peças espalhadas
  var i = 1;
  while (i <= 5) {
    print('Volta $i');
    i++;
  }

  // 2) do-while: testa no fim
  var j = 1;
  do {
    print('Volta $j');
    j++;
  } while (j <= 5);

  // 3) for: as três peças numa linha só
  for (var k = 1; k <= 5; k++) {
    print('Volta $k');
  }
}
SituaçãoQual usar
Contar um número conhecido de voltas (de 1 a 10, de 10 a 0…)for (aula for): fica tudo numa linha e é difícil esquecer o passo
Passar por todos os itens de uma listafor-in (aula for-in)
Não se sabe quantas voltas vão ser (até a meta, até a resposta ser válida)while (condição) { … }
O bloco tem de rodar pelo menos uma vezdo { … } while (condição);

Como consertar: while (contador <= 5) {. Quem vem do Python ou do Lua estranha, mas no Dart a condição do while, do if e do do-while vai sempre entre parênteses.

A condição não é bool 
void main() {
  var n = 3;
  while (n) {
    print(n);
    n--;
  }
}

"Um valor do tipo int não pode ser atribuído a uma variável do tipo bool." Em C ou JavaScript, while (n) quer dizer "enquanto n não for zero". O Dart não aceita: a condição tem de ser um true ou false de verdade. Como consertar: escreva a comparação inteira: while (n > 0).

O passo ficou fora do laço: laço infinito

Este é traiçoeiro, porque o Dart não reclama de nada:

void main() {
  var contador = 1;
  while (contador <= 5) {
    print('Volta $contador');
  }
  contador++;
}

O contador++ está depois do }: só rodaria quando o laço terminasse, e o laço nunca termina. O resultado é o da seção 5: Volta 1 sem parar, até o Ctrl+C. Como consertar: ponha o passo dentro das chaves.

}

  var valor = 1;
  var dias = 0;
  while (valor <= 1000) {
    valor *= 2;
    dias++;

Resumo

  • while (condição) { … } repete o bloco enquanto a condição for true. Ela é testada antes de cada volta; se for falsa logo de cara, o bloco não roda nenhuma vez.
  • do { … } while (condição); testa no fim: o bloco roda pelo menos uma vez. Não esqueça o ;.
  • Laço com contador tem três peças: início (antes), condição e passo (dentro do bloco: contador++, saldo += 150).
  • A condição vai entre parênteses e tem de ser bool: while (n > 0), nunca while (n).
  • Sem o passo, o laço é infinito. No terminal, Ctrl+C o interrompe (código 130); no editor, o botão ■ Parar.
  • Use for quando souber o número de voltas; while quando não souber; do-while quando a primeira volta tiver de acontecer sempre.
