Dart Métodos de List, Set e Map

Esta é a página de consulta das três coleções do Dart: a List (lista em ordem, com repetição), o Set (conjunto, sem repetição) e o Map (mapa de chave para valor). Também estão aqui os métodos que toda coleção tem, por ser um Iterable ("percorrível"): map, where, fold e companhia. As aulas com a explicação completa são Listas, Métodos de Lista, Set, Map, Percorrendo Mapas e map, where, reduce e Outros.

Como ler as tabelas
  • Cada tabela segue a história de uma variável: os exemplos são executados em ordem, e cada um parte de como a coleção ficou no anterior.
  • Resultado é o que o Dart SDK 3.13.5 mostrou com print no computador da Ana. O programa inteiro está no fim da página.
  • Métodos marcados com (muda) alteram a própria coleção; os outros devolvem algo novo.

Para qualquer coleção (Iterable)

Com final precos = [4.5, 12.0, 7.25, 30.0];. Nenhum destes muda a lista. Vários devolvem um Iterable "preguiçoso", que só é calculado quando usado; o .toList() o transforma em lista (o print de um Iterable usa parênteses, como em I8).

void main() {
  final compras = ['pão', 'leite', 'café'];

"Operação não suportada: não dá para acrescentar a uma lista que não pode ser modificada." Compila, mas quebra ao rodar. Com final, a variável não muda, mas a lista sim; com const, nem a lista (veja final e const).

Valor do mapa pode ser nulo 
void main() {
  final estoque = {'pão': 30};
  final mais = estoque['pão'] + 10;
  print(mais);
}

$ dart run mapa.dart
mapa.dart:3:31: Error: Operator '+' cannot be called on 'int?' because it is potentially null.
  final mais = estoque['pão'] + 10;
                              ^

Para o Dart, estoque['pão'] é int?: a chave podia não existir. Use (estoque['pão'] ?? 0) + 10 (veja ?. , ?? e ??=).

Item do tipo errado

Em final notas = <int>[7, 8]; só cabem int: "o argumento do tipo String não pode ser passado para um parâmetro int" (veja Genéricos).

Missão: conte quantas vezes cada fruta aparece na lista de vendas e mostre o mapa: {maçã: 2, pera: 1, uva: 3}. Use o padrão contagem[f] = (contagem[f] ?? 0) + 1; ou o update com ifAbsent.

void main() {
  final vendas = ['maçã', 'pera', 'uva', 'maçã', 'uva', 'uva'];
  final contagem = <String, int>{};
  // conte aqui
  print(contagem);
}

void main() {
  final vendas = ['maçã', 'pera', 'uva', 'maçã', 'uva', 'uva'];
  final contagem = <String, int>{};
  for (final f in vendas) {
    contagem[f] = (contagem[f] ?? 0) + 1;
  }
  print(contagem);
}

Resumo

  • List: add, insert, remove/removeAt, sort, sublist; posições de 0 a length - 1.
  • Todo Iterable: map, where, fold, any/every, firstWhere, take/skip, join, toList.
  • Set: sem repetição; union, intersection, difference. {} vazio é Map.
  • Map: mapa[chave] é anulável; ??, putIfAbsent, update, entries, removeWhere.
  • Não remova itens dentro de um for-in da mesma coleção: use removeWhere.
