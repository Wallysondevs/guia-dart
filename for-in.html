Dart for-in

Na aula for, para mostrar uma lista de compras, você precisou de um contador, da posição [i] e do cuidado com o < no length. Na maioria das vezes, porém, você não quer saber a posição: quer só passar por cada item. Para isso existe o for-in: "para cada item em (in) esta lista, faça isto". Sem contador, sem índice, sem RangeError.

Você vai aprender
  • Como escrever for (final item in lista) { … }, e por que final.
  • Como somar, contar e achar o maior valor passando pela lista.
  • Que o for-in funciona com listas, conjuntos (Set) e as chaves de um mapa (Map).
  • Como passar pelas letras de um texto, e como ter a posição junto com o item (.indexed).
  • Os erros reais: texto e número que não são "percorríveis", of no lugar de in, mudar o item, mexer na lista durante o laço e a lista que pode ser null.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: conferir a sacola

Quando a Ana volta do mercado, ela tira as compras da sacola uma por uma e guarda cada uma no lugar. Ela não numera nada ("item 0, item 1…"): só pega o próximo, até a sacola ficar vazia. Se a sacola vier vazia, ela não guarda nada, e tudo bem. Esse é o for-in: pega cada item, na ordem, e para sozinho quando acabam.

1. O primeiro for-in

void main() {
  final compras = ['arroz', 'feijão', 'café', 'pão'];
  for (final item in compras) {
    print('Comprar: $item');
  }
  print('Lista conferida!');
}
final compras = [ … ];
Uma lista com 4 textos (veja Listas).
for ( … in compras)
"Para cada … em compras". Depois do in vem a coleção que vai ser percorrida.
final item
A variável que recebe um item por volta: na 1ª volta vale 'arroz', na 2ª 'feijão', e assim por diante. É final porque, dentro de uma volta, ela não muda (a cada volta nasce uma nova). O nome é você que escolhe: o costume é o singular do nome da lista (compras → item, notas → nota).

O corpo: roda uma vez para cada item.

2. Somar, contar, achar o maior

As três tarefas mais comuns com um laço usam o mesmo truque: uma variável criada antes do laço, que vai sendo atualizada a cada item.

Somar

void main() {
  final precos = [4.50, 12.90, 3.25, 7.00];
  var total = 0.0;
  for (final preco in precos) {
    total += preco;
  }
  print('Itens: ${precos.length}');
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

$ dart run soma.dart
Itens: 4
Total: R$ 27.65

O total começa em 0.0 (um double, porque os preços têm centavos; veja Atribuição) e recebe cada preço com +=.

Achar o maior e contar

void main() {
  final notas = [7.5, 9.0, 6.0, 8.5];
  var maior = notas[0];
  var aprovadas = 0;
  for (final nota in notas) {
    if (nota > maior) {
      maior = nota;
    }
    if (nota >= 7) {
      aprovadas++;
    }
  }
  print('Maior nota: $maior');
  print('Notas de 7 para cima: $aprovadas');
}

$ dart run maior.dart
Maior nota: 9.0
Notas de 7 para cima: 3
var maior = notas[0];
O "campeão" começa sendo a primeira nota. A cada volta, se aparecer uma nota maior, ela vira a campeã.
var aprovadas = 0; … aprovadas++;
Um contador: começa em 0 e ganha 1 cada vez que uma nota passa no if.

(As listas também têm atalhos prontos para isso, como reduce e where, na aula map, where, reduce e Outros. Mas o laço mostra o que eles fazem por dentro.)

3. Não é só lista: Set e Map

O for-in funciona com qualquer coisa que seja um Iterable (um "percorrível": uma coleção que sabe entregar os itens um por um). Listas são, conjuntos (Set) também, e as chaves e os valores de um mapa (Map) também:

void main() {
  final sabores = {'calabresa', 'mussarela', 'portuguesa'};
  for (final sabor in sabores) {
    print('Pizza de $sabor');
  }
  final estoque = {'pão': 30, 'bolo': 4, 'sonho': 12};
  for (final produto in estoque.keys) {
    print('$produto: ${estoque[produto]} unidades');
  }
}

$ dart run conjunto.dart
Pizza de calabresa
Pizza de mussarela
Pizza de portuguesa
pão: 30 unidades
bolo: 4 unidades
sonho: 12 unidades

O estoque.keys são as chaves do mapa ('pão', 'bolo', 'sonho'), e estoque[produto] busca o valor de cada uma. O Set e o Map escritos assim, com chaves, mantêm a ordem em que os itens foram colocados. Outras formas de percorrer mapas estão em Percorrendo Mapas.

4. Letras de um texto, e a posição junto

As letras: split('')

Um texto (String) não é um Iterable: for (final letra in 'Dart') não compila (veja Quando dá errado). Para passar pelas letras, primeiro quebre o texto numa lista de letras com split('') ("dividir" sem separador):

void main() {
  final palavra = 'Dart';
  for (final letra in palavra.split('')) {
    print(letra);
  }
}

$ dart run texto.dart
D
a
r
t

A posição e o item: .indexed Dart 3.0

E se você quer o item e a posição? Em vez de voltar para o for com contador, use o .indexed ("com índice"), que entrega pares (posição, item):

void main() {
  final fila = ['Ana', 'Bia', 'Caio'];
  for (final (posicao, nome) in fila.indexed) {
    print('${posicao + 1}º da fila: $nome');
  }
}

$ dart run indexed.dart
1º da fila: Ana
2º da fila: Bia
3º da fila: Caio

O (posicao, nome) desmonta cada par em duas variáveis: a posição (começando em 0, por isso o + 1) e o item. Esse jeito de desmontar valores é um pattern, assunto de Records e Patterns e Desestruturação. O indexed chegou no Dart 3.0.

Formas diferentes de fazer

Esqueceu o final (ou o var)

Em for (item in compras), o Dart procura uma variável item que já exista para guardar cada valor (Setter not found, "não achei onde guardar") e não acha. Como consertar: crie a variável ali mesmo: for (final item in compras).

Tentou mudar o item 
void main() {
  final precos = [10, 20, 30];
  for (final preco in precos) {
    preco = preco * 2;
  }
  print(precos);
}

$ dart run err_muda_item.dart
err_muda_item.dart:4:5: Error: Can't assign to the final variable 'preco'.
    preco = preco * 2;
    ^^^^^

"Não dá para atribuir à variável final preco." E trocar final por var faz compilar, mas não adianta: no lab, com for (var preco in precos), a lista continuou [10, 20, 30]. A variável do laço é uma cópia do item, não o lugar dele na lista; mudar a cópia não muda a lista. É por isso que o final é o recomendado: ele avisa do engano. Como consertar: para mudar os itens, use o for clássico com precos[i] = precos[i] * 2;.

O tipo do item não bate 
$ dart run err_tipo.dart
err_tipo.dart:3:18: Error: A value of type 'double' can't be assigned to a variable of type 'int'.
Try changing the type of the variable.
  for (final int preco in precos) {
                 ^

Com precos = [4.5, 12.9], cada item é um double, e a variável do laço foi declarada int. A dica do Dart resolve: "tente mudar o tipo da variável". Como consertar: for (final double preco in precos), ou só final preco, e o Dart descobre o tipo sozinho.

A lista pode ser null 
void main() {
  List<String>? compras;
  for (final item in compras) {
    print(item);
  }
}

Repare no ? em 'List<String>?': a variável pode ser uma lista ou null (aula Tipos Anuláveis), e não dá para percorrer o nada. Como consertar: use uma lista vazia como padrão, for (final item in compras ?? []) (o ?? é da aula ?. , ?? e ??=), ou teste antes com if (compras != null).

void main() {
  final notas = [8.0, 6.5, 9.0, 7.5];
  var soma = 0.0;
  var abaixo = 0;
  for (final nota in notas) {
    soma += nota;
    if (nota < 7) {
      abaixo++;
    }
  }
  print('Média: ${soma / notas.length}');
  print('Abaixo de 7: $abaixo');
}

Resumo

  • for (final item in colecao) { … } passa por cada item, na ordem, e para sozinho no fim. Sem contador, sem índice, sem RangeError; com a coleção vazia, roda zero vezes.
  • Funciona com tudo que é Iterable: listas, Set, mapa.keys, mapa.values, texto.split(''). Texto e número direto não.
  • A variável do laço é final e é uma cópia: mudar ela não muda a lista. Para mudar itens, for clássico com lista[i].
  • Não acrescente nem remova itens da lista dentro do for-in (Concurrent modification during iteration): use removeWhere ou uma lista nova.
  • Precisa da posição? for (final (i, item) in lista.indexed) Dart 3.0.
