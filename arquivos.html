Dart Arquivos

Tudo o que seus programas guardaram até agora em variáveis some quando o programa termina. Para a lista de compras da Ana estar lá amanhã, ela precisa ir para um arquivo no disco. No Dart, quem cuida disso é a classe File ("arquivo"), da biblioteca dart:io (io = input/output, "entrada e saída").

Você vai aprender
  • Como escrever um texto num arquivo e ler de volta (writeAsStringSync e readAsStringSync).
  • Como ler um arquivo linha por linha e como acrescentar no fim sem apagar o que já estava lá.
  • A diferença entre as versões …Sync e as versões com await.
  • Como saber se um arquivo existe, apagar, criar pastas e listar o que tem nelas.
  • Como escrever aos pouquinhos com openWrite.
  • Os erros reais: arquivo que não existe, sem permissão, import esquecido e await esquecido.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), na pasta pessoal dela (/home/ana), com dart run arquivo.dart. O comando cat, que aparece algumas vezes, é do terminal do Linux: ele mostra o conteúdo de um arquivo.

A ideia: o caderno da padaria

A memória do programa é como um quadro-negro: rápido de escrever, mas alguém apaga tudo no fim do dia. Um arquivo é o caderno: o que está escrito fica lá até alguém rasgar a página. Com um caderno você faz quatro coisas:

No cadernoNo Dart
escrever numa página nova (ou passar a borracha e reescrever)writeAsStringSync(texto)
ler a página inteirareadAsStringSync()
ler linha por linhareadAsLinesSync()
escrever mais uma linha no fimwriteAsStringSync(texto, mode: FileMode.append)

Antes de qualquer uma delas, você cria um objeto File com o caminho do arquivo: File('compras.txt'). Isso não cria nem abre nada; é só um "endereço". O nome sem pasta quer dizer "na pasta onde o programa foi rodado" (aqui, /home/ana).

1. Escrever e ler um arquivo

import 'dart:io';

void main() {
  final arquivo = File('compras.txt');
  arquivo.writeAsStringSync('pão\nleite\ncafé\n');
  print('Lista salva em ${arquivo.path}');
}
import 'dart:io';
Traz File, Directory e companhia. Sem ele, o Dart não conhece File (veja Quando dá errado).
File('compras.txt')
O endereço do arquivo. Guardado em arquivo, para usar várias vezes.
writeAsStringSync(…)
"Escrever como texto, de forma síncrona": cria o arquivo (ou apaga o conteúdo antigo, se já existia) e escreve o texto. O \n é a quebra de linha. Sync quer dizer que o programa espera terminar antes de ir para a próxima linha.
arquivo.path
O caminho que você deu, como texto.

$ cat compras.txt

O arquivo existe de verdade: o cat mostrou o conteúdo, e ele continua lá depois que o programa acabou. Agora, outro programa lê esse arquivo:

import 'dart:io';

void main() {
  final arquivo = File('compras.txt');
  final conteudo = arquivo.readAsStringSync();
  print('O arquivo tem ${conteudo.length} caracteres:');
  print(conteudo);
}

$ dart run ler.dart
O arquivo tem 15 caracteres:
pão
leite
café

readAsStringSync() devolve o arquivo inteiro numa única String, com as quebras de linha dentro (os três \n contam nos 15 caracteres). A linha em branco no fim é a última quebra do arquivo somada à do print.

2. Linha por linha

Quase sempre é mais útil ter cada linha separada. readAsLinesSync() devolve uma List<String>, sem os \n:

import 'dart:io';

void main() {
  final linhas = File('compras.txt').readAsLinesSync();
  print('São ${linhas.length} itens.');
  for (var i = 0; i < linhas.length; i++) {
    print('${i + 1}. ${linhas[i]}');
  }
}

$ dart run linhas.dart
São 3 itens.
1. pão
2. leite
3. café

Como é uma lista comum, valem todos os métodos de Métodos de Lista: length, contains, where…

3. Acrescentar × sobrescrever

Para pôr mais um item na lista sem perder os outros, passe mode: FileMode.append ("modo: acrescentar"):

import 'dart:io';

void main() {
  final arquivo = File('compras.txt');
  arquivo.writeAsStringSync('manteiga\n', mode: FileMode.append);
  print(arquivo.readAsLinesSync());
}

$ dart run acrescentar.dart
[pão, leite, café, manteiga]

Sem o mode, o padrão é sobrescrever: tudo o que havia some.

import 'dart:io';

void main() {
  final arquivo = File('compras.txt');
  arquivo.writeAsStringSync('ovos\n');
  print(arquivo.readAsLinesSync());
}

$ dart run sobrescrever.dart
[ovos]
O Dart não pergunta "tem certeza?"

writeAsStringSync sem FileMode.append apaga o conteúdo anterior sem aviso e sem lixeira. Sempre que for escrever num arquivo que já tem dados importantes, pense: quero trocar ou acrescentar?

Missão: o programa deveria guardar as três tarefas, mas só a última sobra. Conserte as duas últimas gravações para acrescentarem em vez de sobrescrever.

import 'dart:io';

void main() {

  arquivo.writeAsStringSync('lavar a louça\n');
  arquivo.writeAsStringSync('regar as plantas\n');
  arquivo.writeAsStringSync('pagar a luz\n');
  final linhas = arquivo.readAsLinesSync();
  for (var i = 0; i < linhas.length; i++) {
    print('${i + 1}. ${linhas[i]}');
  }
}

4. As versões assíncronas (com await)

Cada método …Sync tem um irmão sem o Sync que devolve um Future: writeAsString, readAsString, readAsLines, exists, delete. Com await, o resultado é o mesmo, mas o programa fica livre enquanto o disco trabalha. Aqui, as notas da turma, separadas por ;:

import 'dart:io';

Future<void> main() async {
  final arquivo = File('notas.txt');
  await arquivo.writeAsString('Ana;9.5\nBia;7.0\nCaio;8.25\n');
  final linhas = await arquivo.readAsLines();
  for (final linha in linhas) {
    final partes = linha.split(';');
    final nota = double.parse(partes[1]);
    print('${partes[0]} tirou $nota');
  }
}

$ dart run assincrono.dart
Ana tirou 9.5
Bia tirou 7.0
Caio tirou 8.25
$ cat notas.txt
Ana;9.5
Bia;7.0
Caio;8.25

split(';') corta a linha em pedaços (veja Métodos de String) e double.parse transforma o texto em número (veja Conversão de Tipos). Para guardar dados com mais estrutura que "nome;nota", a próxima aula usa JSON.

VersãoExemploQuando usar
síncronafinal t = f.readAsStringSync();scripts pequenos de terminal, que não fazem mais nada enquanto leem
assíncronafinal t = await f.readAsString();programas que fazem várias coisas ao mesmo tempo (servidores, aplicativos com tela); é a recomendada no Flutter

5. Existe? Apagar. Pastas.

import 'dart:io';

void main() {
  final arquivo = File('recados.txt');
  if (arquivo.existsSync()) {
    print('Recados: ${arquivo.readAsStringSync()}');
  } else {
    print('Ainda não há recados.');
  }
  arquivo.writeAsStringSync('Comprar fermento');
  print('Existe agora? ${arquivo.existsSync()}');
  arquivo.deleteSync();
  print('E depois de apagar? ${arquivo.existsSync()}');
}

$ dart run existe.dart
Ainda não há recados.
Existe agora? true
E depois de apagar? false

existsSync() ("existe?") devolve true ou false; deleteSync() apaga o arquivo (de vez, sem lixeira). Para pastas, a classe é Directory ("diretório", outro nome para pasta):

import 'dart:io';

void main() {
  final pasta = Directory('receitas');
  pasta.createSync();
  File('receitas/bolo.txt').writeAsStringSync('farinha, ovos, açúcar');
  File('receitas/pao.txt').writeAsStringSync('farinha, água, fermento');
  final nomes = pasta.listSync().map((item) => item.path).toList()..sort();
  for (final nome in nomes) {
    print(nome);
  }
}

$ dart run pastas.dart
receitas/bolo.txt
receitas/pao.txt
$ ls receitas
bolo.txt
pao.txt
Directory('receitas').createSync()
Cria a pasta. Se ela já existe, não faz nada (e não dá erro).
'receitas/bolo.txt'
Caminho com pasta: no Linux e no macOS, as pastas se separam com /.
pasta.listSync()
A lista do que tem dentro da pasta (arquivos e subpastas). Cada item tem o .path.
..sort()
Põe em ordem alfabética. O sistema não garante em que ordem devolve os itens; ordenar deixa a saída sempre igual.

6. Escrevendo aos poucos: openWrite

Quando o texto é montado em muitas partes (um relatório, um registro), em vez de juntar tudo numa String você pode abrir o arquivo uma vez e ir escrevendo, como no print:

import 'dart:io';

Future<void> main() async {
  final saida = File('relatorio.txt').openWrite();
  saida.writeln('Vendas da semana');
  for (var dia = 1; dia <= 3; dia++) {
    saida.writeln('Dia $dia: ${dia * 10} pães');
  }
  await saida.close();
  print(File('relatorio.txt').readAsStringSync());
}

$ dart run sink.dart
Vendas da semana
Dia 1: 10 pães
Dia 2: 20 pães
Dia 3: 30 pães

openWrite() devolve um IOSink ("escoadouro"): write escreve, writeln escreve e pula linha. O await saida.close() é obrigatório: é ele que garante que tudo foi parar no disco e fecha o arquivo.

Qual usar

Você quer…Use
gravar um texto inteiro de uma vezwriteAsStringSync / await writeAsString
acrescentar no fimo mesmo, com mode: FileMode.append
ler tudo num texto sóreadAsStringSync / await readAsString
ler uma lista de linhasreadAsLinesSync / await readAsLines
escrever em muitas partesopenWrite() + writeln + await close()
conferir antes de lerexistsSync() (ou tente ler e trate o erro com try)

import 'dart:io';

void main() {
  final arquivo = File('vendas.txt');
  arquivo.writeAsStringSync('pão: 15\nbolo: 12\nsonho: 3\n');

  var total = 0;
  for (final linha in arquivo.readAsLinesSync()) {
    final partes = linha.split(': ');
    total += int.parse(partes[1]);
  }

  print('Total: $total');
}

Resumo

  • Arquivos guardam dados depois que o programa termina. A classe File vem de import 'dart:io';.
  • writeAsStringSync cria ou sobrescreve; com mode: FileMode.append, acrescenta no fim.
  • readAsStringSync lê tudo num texto; readAsLinesSync lê uma lista de linhas.
  • Os métodos sem Sync devolvem Future e pedem await.
  • existsSync, deleteSync, Directory (createSync, listSync) cuidam de existência e pastas.
  • Os erros de arquivo são FileSystemException (PathNotFoundException, PathAccessException…), com a explicação do sistema no OS Error. Trate com on FileSystemException catch (e).
