Dart if e for Dentro de Coleções

Você já sabe criar uma lista escrevendo os itens entre colchetes: ['pão', 'leite'] (veja Listas). Mas muitas vezes a lista depende de alguma coisa: o bolo só entra na lista de compras se vier visita; a lista de aprovados só tem as notas boas. O Dart deixa você escrever um if e um for dentro dos colchetes, no meio dos itens. Os nomes oficiais são collection if e collection for ("if de coleção" e "for de coleção").

Você vai aprender
  • Como pôr um item na lista só se uma condição for verdadeira: if (temVisita) 'bolo'.
  • Como escolher entre dois itens com if … else dentro da lista.
  • Como gerar vários itens com um for dentro da lista: [for (final p in precos) p * 2].
  • Como juntar os dois para filtrar: [for (final n in notas) if (n >= 7) n].
  • Como usar os dois em mapas (Map) e conjuntos (Set).
  • As outras formas de fazer a mesma coisa e os erros reais que o Dart mostra.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com dart run arquivo.dart (veja Rodando um Programa).

A ideia: a lista de compras com observações

A Ana escreve a lista do mercado num papel. Às vezes ela anota assim:

  • pão
  • leite
  • bolo (só se vier visita)
  • uma fruta de cada tipo que estiver na promoção

A terceira linha é um if: o bolo só vai para o carrinho se a condição for verdadeira. A quarta linha é um for: ela vira várias compras, uma para cada fruta da promoção. O papel continua sendo uma lista só; a decisão e a repetição estão escritas no meio dela. É exatamente isso que o collection if e o collection for fazem no Dart.

1. O if dentro da lista

void main() {
  final temVisita = true;
  final compras = [
    'pão',
    'leite',
    if (temVisita) 'bolo',
  ];
  print(compras);
}
final temVisita = true;
Uma variável bool (verdadeiro ou falso; veja Booleanos). Ela decide se o bolo entra.
final compras = [
Começa a lista, como sempre. Cada item fica numa linha, separado por vírgula.
if (temVisita) 'bolo',
O collection if. Lê-se: "se tem visita, põe 'bolo' aqui". A condição vai entre parênteses, como no if comum, mas sem chaves: logo depois do parêntese vem o item. Se a condição for falsa, é como se a linha não existisse.
,
A vírgula depois do último item é opcional. O estilo oficial do Dart recomenda colocá-la em listas de várias linhas: assim, para acrescentar um item, você só escreve uma linha nova.
$ dart run compras.dart
[pão, leite, bolo]

Agora a mesma lista com temVisita = false (e uma linha a mais, para contar os itens):

void main() {
  final temVisita = false;
  final compras = [
    'pão',
    'leite',
    if (temVisita) 'bolo',
  ];
  print(compras);
  print('Itens: ${compras.length}');
}

$ dart run compras2.dart
[pão, leite]
Itens: 2

Repare: a lista não ficou com um "buraco" nem com um null no lugar do bolo. Ela tem 2 itens, e não 3. O if decide se o item existe na lista.

if … else: um item ou outro

Com else ("senão"), sempre entra um item: o primeiro se a condição for verdadeira, o segundo se for falsa.

void main() {
  final chovendo = true;
  final lanche = [
    'sanduíche',
    if (chovendo) 'chocolate quente' else 'suco gelado',
  ];
  print(lanche);
}

$ dart run lanche.dart
[sanduíche, chocolate quente]

Com chovendo = false, a lista seria [sanduíche, suco gelado]. O tamanho é sempre 2.

Missão: a lista abaixo sempre leva o bolo. Faça o bolo entrar só se temVisita for verdadeiro (use um if dentro da lista). Depois, troque para false e veja o bolo sumir.

2. O for dentro da lista

O collection for gera itens: para cada elemento de outra coleção, ele põe um item novo na lista. A Ana tem os preços de três produtos e quer saber quanto custam dois de cada:

void main() {
  final precos = [4, 10, 7];
  final dobro = [for (final p in precos) p * 2];
  print(precos);
  print(dobro);
}
[ … ]
Os colchetes de sempre: o resultado é uma lista nova.
for (final p in precos)
O mesmo cabeçalho do for-in: "para cada p em precos". De novo, sem chaves.
p * 2
O item que entra na lista nova a cada volta. Na 1ª volta p vale 4 e entra 8; depois 10 vira 20; depois 7 vira 14.
$ dart run dobro.dart
[4, 10, 7]
[8, 20, 14]

A lista original, precos, não mudou: o for criou uma lista nova.

Misturando itens fixos e gerados

O for pode ficar no meio de outros itens. A Ana monta as etiquetas da feira: um título, uma linha por fruta e o total no fim.

void main() {
  final frutas = ['maçã', 'banana', 'uva'];
  final etiquetas = [
    'Feira da Ana',
    for (final f in frutas) '- $f',
    'Total: ${frutas.length} frutas',
  ];
  for (final linha in etiquetas) {
    print(linha);
  }
}

$ dart run etiquetas.dart
Feira da Ana
- maçã
- banana
- uva
Total: 3 frutas

A lista etiquetas tem 5 itens: 1 fixo, 3 gerados pelo for e mais 1 fixo. O segundo for, fora dos colchetes, é um for comum, que só mostra as linhas.

O for com contador também vale

Além do for-in, o for clássico de três partes (veja for) também funciona dentro da lista:

void main() {
  final numeros = [for (var i = 1; i <= 5; i++) i * 10];
  print(numeros);
}

$ dart run contagem.dart
[10, 20, 30, 40, 50]

3. for + if: filtrar

O item de um for pode ser um if. Assim, só entram na lista nova os elementos que passam no teste. A professora quer as notas a partir de 7:

void main() {
  final notas = [8.5, 6.0, 9.0, 4.5, 7.0];
  final boas = [
    for (final n in notas)
      if (n >= 7) n,
  ];
  print('Todas: $notas');
  print('A partir de 7: $boas');
}

$ dart run aprovados.dart
Todas: [8.5, 6.0, 9.0, 4.5, 7.0]
A partir de 7: [8.5, 9.0, 7.0]

Leia de fora para dentro: "para cada nota n, se n >= 7, põe n". As notas 6.0 e 4.5 não passaram no if e ficaram de fora. A ordem das que passaram é a mesma da lista original.

Missão: a padaria vende pacotes com estes números de pães. Monte a lista grandes com um for e um if dentro dos colchetes, deixando só os pacotes com 10 pães ou mais. O resultado deve ser [10, 15, 20].

void main() {
  final pacotes = [6, 10, 4, 15, 20, 8];
  final grandes = [];
  print(grandes);
}

void main() {
  final pacotes = [6, 10, 4, 15, 20, 8];
  final grandes = [
    for (final p in pacotes)
      if (p >= 10) p,
  ];
  print(grandes);
}

4. Em mapas e conjuntos

O if e o for funcionam também dentro das chaves { } de um Map (pares chave: valor) e de um Set (itens sem repetição):

void main() {
  final produtos = ['pão', 'leite', 'café'];
  final tamanhos = {for (final p in produtos) p: p.length};
  print(tamanhos);

  final temDesconto = true;
  final pedido = {
    'cliente': 'Ana',
    'total': '25.00',
    if (temDesconto) 'cupom': 'PADARIA10',
  };
  print(pedido);

  final turmas = ['A', 'B', 'A', 'C', 'B'];
  final semRepetir = {for (final t in turmas) 'Turma $t'};
  print(semRepetir);
}

$ dart run mapa.dart
{pão: 3, leite: 5, café: 4}
{cliente: Ana, total: 25.00, cupom: PADARIA10}
{Turma A, Turma B, Turma C}
TrechoO que faz
{for (final p in produtos) p: p.length}Gera um par por produto: a chave é o nome, o valor é o número de letras. Como tem chave: valor, o Dart sabe que é um Map.
if (temDesconto) 'cupom': 'PADARIA10'O par do cupom só entra no mapa se houver desconto.
{for (final t in turmas) 'Turma $t'}Sem dois-pontos, é um Set: as turmas repetidas (A e B) entram uma vez só.

Formas diferentes de fazer a mesma coisa

Filtrar as notas a partir de 7 pode ser escrito de três jeitos. Os três dão o mesmo resultado:

void main() {
  final notas = [8.5, 6.0, 9.0, 4.5, 7.0];

  // 1) laço comum + add
  final a = <double>[];
  for (final n in notas) {
    if (n >= 7) {
      a.add(n);
    }
  }

  // 2) where (filtrar) + toList
  final b = notas.where((n) => n >= 7).toList();

  // 3) collection for + if
  final c = [for (final n in notas) if (n >= 7) n];

  print(a);
  print(b);
  print(c);
}

$ dart run formas.dart
[8.5, 9.0, 7.0]
[8.5, 9.0, 7.0]
[8.5, 9.0, 7.0]
  1. Laço + add: cria uma lista vazia (<double>[], "lista de double vazia") e vai acrescentando. Funciona, mas são 6 linhas, e a lista precisa ser montada aos poucos.
  2. where + toList: where ("onde") filtra com uma função de uma linha, e o toList() transforma o resultado em lista (veja map, where, reduce e Outros).
  3. collection for + if: uma linha, e a lista nasce pronta. Funciona bem quando a lista tem também itens fixos (como as etiquetas da feira).
SituaçãoQual usar
Um item que às vezes entra, às vezes não, no meio de itens fixoscollection if
Gerar itens a partir de outra coleção, misturados com itens fixoscollection for
Só filtrar ou só transformar uma coleção inteiracollection for (+ if) ou where/map: os dois são comuns
Muita lógica por item (várias linhas, print, contas intermediárias)laço comum com add
Já existe no Dart 3: o if-case dentro da lista Dart 3.0

Desde o Dart 3.0, o if de coleção também aceita um pattern: if (desconto case int d when d > 0) 'Desconto: R\$ $d' só põe o item se desconto for um int maior que zero (no lab, saiu [Pão: R$ 8, Desconto: R$ 10]). Patterns têm aula própria: Patterns e Desestruturação.

Quando dá errado

Pôs chaves depois do if

No if comum, o bloco vai entre chaves. Dentro da lista, não:

void main() {
  final temVisita = true;
  final List<String> compras = [
    'pão',
    if (temVisita) {'bolo'},
  ];
  print(compras);
}

$ dart run chaves.dart

 - 'Set' is from 'dart:core'.
    if (temVisita) {'bolo'},
                   ^
$ echo $?
254

Linha por linha:

chaves.dart:5:20
Arquivo, linha 5, coluna 20: o lugar do problema. O ^ embaixo aponta a coluna, bem na chave {.
Error: A value of type 'Set<String>' can't be assigned to a variable of type 'String'.
"Um valor do tipo Set<String> não pode ser guardado onde se espera um String." Dentro da lista, {'bolo'} não é um bloco: é um conjunto com um item. A lista é de String, e um conjunto não é um texto.
- 'Set' is from 'dart:core'.
Só uma informação extra: o tipo Set vem da biblioteca básica do Dart.
echo $? → 254
O código de saída de um erro de compilação: o programa nem começou.

Como consertar: tire as chaves: if (temVisita) 'bolo',. (Sem o tipo List<String>, seria pior: o Dart aceitaria e você teria uma lista misturando textos e um conjunto.)

Escreveu como um ternário (? :) 
void main() {
  final chovendo = true;
  final lanche = [
    'sanduíche',
    if (chovendo) 'chocolate quente' : 'suco gelado',
  ];
  print(lanche);
}

$ dart run ternario.dart
ternario.dart:5:38: Error: Expected ']' before this.
    if (chovendo) 'chocolate quente' : 'suco gelado',
                                     ^

"Era esperado um ] antes disto." Depois de 'chocolate quente', o Dart esperava uma vírgula, o else ou o fim da lista; os dois-pontos não fazem sentido ali. Como consertar: use else: if (chovendo) 'chocolate quente' else 'suco gelado'. (Ou use o ternário inteiro, sem if: chovendo ? 'chocolate quente' : 'suco gelado'.)

A condição não é bool 
void main() {
  final visitas = 2;
  final compras = ['pão', if (visitas) 'bolo'];
  print(compras);
}

$ dart run naobool.dart
naobool.dart:3:31: Error: A value of type 'int' can't be assigned to a variable of type 'bool'.
  final compras = ['pão', if (visitas) 'bolo'];
                              ^

"Um valor do tipo int não pode ser usado onde se espera um bool." Em algumas linguagens, um número diferente de zero vale como "verdadeiro"; no Dart, não: a condição do if tem de ser true ou false. Como consertar: escreva a pergunta inteira: if (visitas > 0) 'bolo'.

Um print no lugar do item: sem erro, mas lista de null 
void main() {
  final nomes = ['Ana', 'Bia'];
  final x = [for (final n in nomes) print(n)];
  print(x);
}

$ dart run printdentro.dart
Ana
Bia
[null, null]

O Dart não reclamou. O print(n) rodou duas vezes (mostrou Ana e Bia), mas o print não devolve nada, então a lista ficou com dois "nada" (null). O item de um collection for é um valor, não um comando. Como consertar: para só mostrar, use um for comum, fora dos colchetes: for (final n in nomes) { print(n); }.

Resumo

  • Dentro de [ ] e { }, o Dart aceita if e for no meio dos itens: o collection if e o collection for.
  • if (cond) item põe o item só se a condição for verdadeira; com else, sempre entra um dos dois. Sem chaves e sem dois-pontos.
  • for (final x in lista) expr gera um item para cada elemento; o for de três partes também vale.
  • for + if filtra: [for (final n in notas) if (n >= 7) n].
  • Funciona em Map (chave: valor) e em Set.
  • O item é um valor: um print ali dentro enche a lista de null.
  • Na próxima aula, outra forma de juntar coleções dentro dos colchetes: o spread (...).
