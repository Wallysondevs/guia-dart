Dart Montando Textos (StringBuffer)

Muitas vezes o texto que o programa vai mostrar não existe pronto: ele é montado aos poucos. O cupom da padaria ganha uma linha por item; uma lista de compras ganha um nome por volta do laço. Dá para fazer isso com texto += '…', mas o Dart tem uma ferramenta feita para esse trabalho: o StringBuffer (em inglês, buffer é uma "área de rascunho", um lugar onde as coisas se acumulam antes de serem usadas).

Você vai aprender
  • Criar um StringBuffer e escrever nele com write, writeln e writeAll.
  • Transformar o rascunho em String com toString(), e quando o print faz isso sozinho.
  • length, isEmpty e clear().
  • Montar textos dentro de laços: o cupom e a tabuada.
  • Por que += num laço muito grande é lento, com a medição real do lab.
  • Os erros reais: tratar o StringBuffer como se fosse uma String.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook), com dart run arquivo.dart.

A ideia: o bloquinho do garçom

O garçom não escreve a conta final de uma vez. Ele tem um bloquinho: a cada pedido, anota mais uma linha. No fim, destaca a folha e entrega. Com texto += '…', seria como passar a limpo uma folha nova inteira a cada pedido, copiando tudo o que já estava escrito, só para acrescentar uma linha. Para 3 pedidos, tanto faz. Para 200 mil, o garçom passaria o dia copiando.

No bloquinhoNo Dart
Pegar um bloquinho em brancofinal cupom = StringBuffer();

Anotar e pular para a linha de baixocupom.writeln('Pão');

1. O primeiro StringBuffer

void main() {
  final texto = StringBuffer();
  texto.write('Pão');
  texto.write(', ');
  texto.write('leite');
  texto.write(' e ');
  texto.write('café');
  print(texto.toString());
  print(texto.length);
}
final texto = StringBuffer();
Cria um rascunho vazio. Os parênteses são obrigatórios: é assim que se cria um objeto de uma classe (veja Classes). A variável é final porque ela vai apontar sempre para o mesmo rascunho; quem muda é o conteúdo dele.
texto.write('Pão');
"Escreva": acrescenta Pão no fim do que já existe, sem pular linha.
texto.toString()
"Para texto": devolve tudo o que foi escrito, como uma String de verdade.
texto.length → 17
Quantos caracteres já foram escritos, como no length de uma String.
$ dart run primeiro.dart
Pão, leite e café
17

2. writeln: uma linha por vez (o cupom)

writeln (write line, "escreva a linha") acrescenta o texto e uma quebra de linha no fim. O cupom da padaria:

void main() {
  final cupom = StringBuffer();
  cupom.writeln('PADARIA DO BAIRRO');
  cupom.writeln('-' * 20);
  cupom.writeln('Pão francês  R\$ 0,75');
  cupom.writeln('Leite        R\$ 5,49');
  cupom.writeln('-' * 20);
  cupom.write('Obrigado!');
  print(cupom);
}

$ dart run cupom.dart
PADARIA DO BAIRRO
--------------------
Pão francês  R$ 0,75
Leite        R$ 5,49
--------------------
Obrigado!
  • '-' * 20 repete o tracinho 20 vezes (veja Métodos de String).
  • A última linha usa write, sem quebra: assim o cupom não termina com uma linha vazia sobrando (o print já pula uma linha no fim).
  • print(cupom), sem o .toString(): o print chama o toString() sozinho, para qualquer objeto. Já para guardar o texto numa variável String, o toString() é obrigatório (veja Quando dá errado).

3. Montar dentro de um laço

O lugar natural do StringBuffer é dentro de um laço (veja for). Uma linha com os números de 1 a 5, separados por traço:

void main() {
  final linha = StringBuffer();
  for (var i = 1; i <= 5; i++) {
    linha.write(i);
    if (i < 5) linha.write(' - ');
  }
  print(linha);
}

$ dart run laco.dart
1 - 2 - 3 - 4 - 5

O write aceita qualquer valor, não só textos: o i é um int, e o StringBuffer o transforma em texto. O if (i < 5) evita um ' - ' sobrando depois do último número.

E a tabuada do 7, guardada numa String para usar depois:

void main() {
  final tabuada = StringBuffer();
  for (var i = 1; i <= 5; i++) {
    tabuada.writeln('7 x $i = ${7 * i}');
  }
  final texto = tabuada.toString();
  print(texto.trim());
  print('O texto tem ${texto.length} caracteres.');
}

$ dart run tabuada.dart
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
O texto tem 54 caracteres.

Depois do toString(), texto é uma String comum, e todos os métodos de texto funcionam nela. O trim() tirou a quebra de linha que o último writeln deixou no fim.

4. writeAll, valor inicial e clear

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  final texto = StringBuffer('Lista: ');
  texto.writeAll(compras, ', ');
  print(texto);
  texto.clear();
  print('Depois do clear: [${texto.toString()}] ${texto.isEmpty}');
}

$ dart run writeall.dart
Lista: arroz, feijão, café
Depois do clear: [] true
StringBuffer('Lista: ')
Um rascunho que já começa com um texto.
writeAll(compras, ', ')
"Escreva todos": escreve cada item da lista, com ', ' entre eles (o separador é opcional). Faz num comando só o que o laço da seção 3 fazia.
clear()
"Limpar": apaga tudo. O rascunho fica vazio, e o isEmpty passa a dar true.

5. Por que não só +=?

Lembra da aula Métodos de String: uma String nunca muda. Então texto += 'x' não acrescenta nada no texto antigo: ele cria um texto novo, copiando o antigo inteiro e mais o x. Num laço, a cópia fica maior a cada volta. O StringBuffer só acumula as peças e junta tudo uma vez, no toString(). A Ana mediu os dois jeitos montando um texto de 200 mil letras, com um cronômetro (Stopwatch):

void main() {
  const n = 200000;
  final relogio = Stopwatch()..start();
  var texto = '';
  for (var i = 0; i < n; i++) {
    texto += 'x';
  }
  print('Com +=: ${relogio.elapsedMilliseconds} ms (${texto.length} letras)');

  relogio.reset();
  final buffer = StringBuffer();
  for (var i = 0; i < n; i++) {
    buffer.write('x');
  }
  final texto2 = buffer.toString();
  print('Com StringBuffer: ${relogio.elapsedMilliseconds} ms (${texto2.length} letras)');
}

$ dart run tempo.dart
Com +=: 2876 ms (200000 letras)
Com StringBuffer: 9 ms (200000 letras)
$ dart run tempo.dart
Com +=: 2870 ms (200000 letras)
Com StringBuffer: 8 ms (200000 letras)

Quase 3 segundos contra menos de 10 milésimos: o mesmo texto, cerca de 300 vezes mais rápido. Os números mudam de um computador para outro (e de uma execução para outra), mas a diferença enorme se repete. (ms = milissegundos; o ..start() liga o cronômetro logo ao criá-lo.)

Então nunca usar += em textos?

Não é isso. Para juntar algumas peças, += e a interpolação ('Olá, $nome!') são ótimos e mais simples. O StringBuffer vale a pena quando o texto é montado num laço, principalmente se o laço pode ser grande (um relatório, um arquivo, uma lista com milhares de itens).

Formas diferentes de fazer a mesma coisa

A linha arroz, feijão, café pode sair de quatro jeitos:

void main() {
  final compras = ['arroz', 'feijão', 'café'];

  // 1) += num laço
  var a = '';
  for (final item in compras) {
    if (a.isNotEmpty) a += ', ';
    a += item;
  }

  // 2) StringBuffer + write
  final b = StringBuffer();
  for (final item in compras) {
    if (b.isNotEmpty) b.write(', ');
    b.write(item);
  }

  // 3) StringBuffer + writeAll
  final c = StringBuffer()..writeAll(compras, ', ');

  // 4) join da lista
  final d = compras.join(', ');

  print(a);
  print(b);
  print(c);
  print(d);
}

$ dart run formas.dart
arroz, feijão, café
arroz, feijão, café
arroz, feijão, café
arroz, feijão, café
SituaçãoQual usar
Juntar os itens de uma lista com um separadorlista.join(', '): uma linha, sem laço
Montar um texto em várias etapas, com ifs e laços no meio (cupom, relatório)StringBuffer com write/writeln
Juntar duas ou três peçasInterpolação: '$nome mora em $cidade'
Acrescentar pouca coisa, poucas vezes+= serve

O .. do jeito 3 é a cascata: "crie o StringBuffer e, nele, chame writeAll", devolvendo o próprio buffer. Ele aparece de novo em Classes.

Quando dá errado

Guardou o StringBuffer numa String 
void main() {
  final cupom = StringBuffer();
  cupom.write('Pão');
  String texto = cupom;
  print(texto);
}

$ dart run err1.dart
err1.dart:4:18: Error: A value of type 'StringBuffer' can't be assigned to a variable of type 'String'.
 - 'StringBuffer' is from 'dart:core'.
  String texto = cupom;
                 ^
A value of type 'StringBuffer' can't be assigned to a variable of type 'String'.
"Um valor do tipo StringBuffer não pode ser guardado numa variável do tipo String." O rascunho não é o texto: é o bloquinho.
- 'StringBuffer' is from 'dart:core'.
Um lembrete de onde vem o tipo citado: da biblioteca principal do Dart (dart:core), que todo programa já tem.

Como consertar: String texto = cupom.toString(); (ou final texto = cupom.toString();).

Usou + ou um método de String no StringBuffer 
void main() {
  final cupom = StringBuffer();
  cupom + 'Pão';
  print(cupom);
}

$ dart run err2.dart
err2.dart:3:9: Error: The operator '+' isn't defined for the type 'StringBuffer'.
 - 'StringBuffer' is from 'dart:core'.
Try correcting the operator to an existing operator, or defining a '+' operator.
  cupom + 'Pão';
        ^

"O operador + não existe para StringBuffer": para acrescentar, é cupom.write('Pão'). Com os métodos de texto acontece o mesmo; cupom.toUpperCase() dá Error: The method 'toUpperCase' isn't defined for the type 'StringBuffer'. Como consertar: converta primeiro, cupom.toString().toUpperCase().

Passou vários textos para o write/writeln 
void main() {
  final cupom = StringBuffer();
  cupom.writeln('Pão', 'Leite');
  print(cupom);
}

$ dart run err4.dart
err4.dart:3:16: Error: Too many positional arguments: 1 allowed, but 2 found.
Try removing the extra positional arguments.
  cupom.writeln('Pão', 'Leite');
               ^

"Argumentos demais: 1 permitido, 2 encontrados." O write e o writeln recebem um valor. Como consertar: um writeln por linha, ou cupom.writeAll(['Pão', 'Leite'], '\n').

As palavras saíram grudadas 
$ dart run err5.dart
PãoLeite

Dois write seguidos (cupom.write('Pão'); cupom.write('Leite');) não põem nada entre os textos. O Dart não acusa erro: ele escreveu exatamente o que você mandou. Como consertar: use writeln (uma linha cada), escreva o separador (cupom.write(', ')) ou use writeAll(lista, ', ').

Resumo

  • StringBuffer é um rascunho para montar textos aos poucos: write (sem quebra), writeln (com quebra), writeAll (uma lista com separador).
  • No fim, toString() devolve a String pronta. O print faz isso sozinho; uma variável String, não.
  • O StringBuffer não é uma String: nada de + nem de métodos de texto nele.
  • Num laço grande, += é lento (no lab, quase 3 s contra 9 ms para 200 mil letras), porque cada += copia o texto inteiro.
  • Para só juntar uma lista, lista.join(', ') é o mais curto.
