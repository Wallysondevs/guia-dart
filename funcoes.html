Dart Funções

Desde o primeiro programa você escreve uma função: o main. E usa outras o tempo todo: print, int.tryParse. Agora é a sua vez de criar funções. Uma função é um pedaço de código com um nome: você escreve uma vez e, sempre que precisar, chama pelo nome. Ela também pode receber valores e devolver um resultado, como uma pequena máquina.

Você vai aprender
  • Por que criar funções: escrever uma vez, usar muitas.
  • Como criar (declarar) e chamar uma função, e o que é void.
  • O caminho que o programa faz quando chama uma função, e volta.
  • Como uma função devolve um valor com return, e o tipo de retorno.
  • O return antecipado, que sai da função no meio.
  • Por que as variáveis de dentro da função não existem fora dela.
  • Os erros reais: return esquecido, tipo errado, usar o "nada" de uma função void, acento no nome.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook), com dart run arquivo.dart.

A ideia: a receita de bolo

Na cozinha da padaria há um caderno de receitas. A receita "massa de pão" está escrita uma vez, com um nome no topo. Quando o padeiro precisa de massa, ele não reescreve a receita: ele diz "faz a massa de pão" e segue os passos. Às vezes a receita pede ingredientes ("quantos quilos de farinha?") e entrega um resultado (a massa pronta).

Na cozinhaNo Dart
Escrever a receita no caderno, com um nomeDeclarar a função: void mostrarCabecalho() { … }
"Faz a massa de pão"Chamar a função: mostrarCabecalho();
Os ingredientes que a receita pedeOs parâmetros: dobro(int numero)
A massa pronta que ela entregaO valor de retorno: return numero * 2;

1. O problema: código repetido

A Ana quer imprimir o cabeçalho da padaria antes de cada produto:

void main() {
  print('=====================');
  print(' PADARIA DO BAIRRO');
  print('=====================');
  print('Pão francês: R\$ 0,75');
  print('=====================');
  print(' PADARIA DO BAIRRO');
  print('=====================');
  print('Leite: R\$ 5,49');
}

Funciona, mas as três linhas do cabeçalho estão escritas duas vezes. Se o nome da padaria mudar, a Ana tem de lembrar de trocar em todos os lugares; se esquecer um, o cupom sai com dois nomes diferentes. Com uma função, o cabeçalho fica escrito em um lugar só.

2. A primeira função

void mostrarCabecalho() {
  print('=====================');
  print(' PADARIA DO BAIRRO');
  print('=====================');
}

void main() {
  mostrarCabecalho();
  print('Pão francês: R\$ 0,75');
  mostrarCabecalho();
  print('Leite: R\$ 5,49');
}
void
O tipo de retorno: o que a função devolve. void ("vazio") quer dizer "não devolve nada": ela só faz alguma coisa (aqui, mostrar linhas). É o mesmo void do void main().
mostrarCabecalho
O nome da função. Use um verbo que diga o que ela faz, em lowerCamelCase (primeira palavra minúscula, as outras com maiúscula), como as variáveis. Sem acento e sem espaço.
()
Os parênteses dos parâmetros. Aqui estão vazios: a função não precisa de nenhum valor para trabalhar.
{ … }
O corpo: as instruções que rodam cada vez que a função é chamada.
mostrarCabecalho();
A chamada: o nome, os parênteses (obrigatórios, mesmo vazios) e o ;. "Execute o corpo de mostrarCabecalho agora."
$ dart run cabecalho.dart
=====================
 PADARIA DO BAIRRO
=====================
Pão francês: R$ 0,75
=====================
 PADARIA DO BAIRRO
=====================
Leite: R$ 5,49

A saída é idêntica à do programa repetido, mas agora o cabeçalho existe uma vez só. Declarar a função não roda nada: ela só roda quando alguém a chama. O programa sempre começa pelo main.

O caminho do programa

Quando o Dart encontra uma chamada, ele pula para dentro da função, roda o corpo inteiro e volta para a linha seguinte à chamada. Os números no texto mostram a ordem:

void main() {
  print('1. main começou');
  cumprimentar();
  print('3. main voltou e terminou');
}

void cumprimentar() {
  print('2. dentro de cumprimentar');
}

$ dart run ordem.dart
1. main começou
2. dentro de cumprimentar
3. main voltou e terminou

Repare que cumprimentar está escrita depois do main, e funcionou. No Dart, as funções do arquivo podem ficar em qualquer ordem: o Dart lê o arquivo inteiro antes de começar. (Muita gente põe o main no topo, para quem abre o arquivo ver logo por onde o programa começa.)

3. Devolver um valor: return

Funções como mostrarCabecalho fazem algo. Outras calculam algo e entregam o resultado para quem chamou. Para isso: um tipo no lugar do void, e a palavra return ("devolver").

int dobro(int numero) {
  return numero * 2;
}

void main() {
  final resultado = dobro(21);
  print(resultado);
  print(dobro(5) + dobro(10));
  print('O dobro de 7 é ${dobro(7)}');
}
int dobro
O tipo de retorno agora é int: a função promete devolver um número inteiro.
(int numero)
Um parâmetro: um valor que a função recebe, aqui chamado numero, do tipo int. Dentro da função, ele funciona como uma variável. Os parâmetros têm aula própria: Parâmetros Posicionais.
return numero * 2;
Calcula o dobro e o devolve para quem chamou. O return também encerra a função na hora.
dobro(21)
Chama a função com 21 no lugar de numero. A chamada inteira "vira" o valor devolvido, 42, que vai para a variável resultado.
dobro(5) + dobro(10)
Como cada chamada vira um número, dá para usar em contas: 10 + 20.
$ dart run dobro.dart
42
30
O dobro de 7 é 14

Um exemplo da padaria, com dois parâmetros e uma variável de apoio dentro da função:

double totalDaCompra(double preco, int quantidade) {
  final total = preco * quantidade;
  return total;
}

void main() {
  final paes = totalDaCompra(0.75, 10);
  final leites = totalDaCompra(5.49, 2);
  print('Pães: R\$ ${paes.toStringAsFixed(2)}');
  print('Leites: R\$ ${leites.toStringAsFixed(2)}');
  print('Total: R\$ ${(paes + leites).toStringAsFixed(2)}');
}

$ dart run total.dart
Pães: R$ 7.50
Leites: R$ 10.98
Total: R$ 18.48

A conta preco * quantidade foi escrita uma vez e usada duas. Se amanhã a padaria der desconto, só a função muda.

4. Vários return, e o return antecipado

Uma função pode ter vários return, em caminhos diferentes. O primeiro que for alcançado encerra a função:

String situacao(double media) {
  if (media >= 7) {
    return 'aprovada';
  }
  if (media >= 5) {
    return 'recuperação';
  }
  return 'reprovada';
}

void main() {
  print(situacao(8.5));
  print(situacao(6.0));
  print(situacao(3.2));
}

$ dart run situacao.dart
aprovada
recuperação
reprovada

Com 8.5, o primeiro return já devolve 'aprovada' e a função acaba: os outros ifs nem são testados. Por isso não precisa de else. E o último return garante que a função sempre devolve alguma coisa, qualquer que seja a média.

Numa função void, um return; sozinho (sem valor) serve para sair mais cedo, quando não dá para continuar:

void dividir(int a, int b) {
  if (b == 0) {
    print('Não dá para dividir por zero.');
    return;
  }
  print('$a / $b = ${a ~/ b}');
}

void main() {
  dividir(10, 2);
  dividir(7, 0);
  print('Fim do programa.');
}

$ dart run retorno_cedo.dart
10 / 2 = 5
Não dá para dividir por zero.
Fim do programa.

O return; saiu só da função dividir; o main continuou normalmente. Esse estilo (testar o problema no começo e sair) é a mesma cláusula de guarda que você viu com o continue em break e continue.

5. O que nasce na função, fica na função

Uma variável criada dentro de uma função é local: só existe ali dentro, enquanto a função roda.

void calcular() {
  final segredo = 42;
  print('Dentro: $segredo');
}

void main() {
  calcular();
  print('Fora: $segredo');
}

$ dart run escopo.dart
escopo.dart:8:17: Error: Undefined name 'segredo'.
  print('Fora: $segredo');
                ^^^^^^^

"Nome não definido: segredo". Para o main, essa variável não existe. Isso é bom: cada função tem as suas próprias variáveis, e duas funções podem ter uma variável total cada uma, sem uma atrapalhar a outra. Para levar um valor para fora, use return; para levar um valor para dentro, use um parâmetro.

Função dentro de função

Também dá para declarar uma função dentro do main (ou de outra função). Ela é local, como uma variável: só pode ser chamada ali dentro.

void main() {
  void linha() {
    print('-' * 20);
  }

  linha();
  print('Cupom');
  linha();
}

$ dart run dentro_main.dart
--------------------
Cupom
--------------------

Formas diferentes de fazer a mesma coisa

A função dobro pode ser escrita de três jeitos que dão o mesmo resultado:

// 1) corpo com chaves e return
int dobro1(int numero) {
  return numero * 2;
}

// 2) com uma variável de apoio (bom quando a conta é longa)
int dobro2(int numero) {
  final resultado = numero * 2;
  return resultado;
}

// 3) numa linha só, com => (aula "Funções de Uma Linha")
int dobro3(int numero) => numero * 2;
SituaçãoQual usar
A função só faz algo (mostrar, gravar)void nome() { … }
A função calcula e entrega um resultadoTipo nome(…) { … return valor; }
O corpo é uma única expressãoTipo nome(…) => expressão; (veja Funções de Uma Linha)
A função só serve dentro de outraFunção local, declarada dentro dela
Boa prática: uma função, uma tarefa

Uma função boa faz uma coisa, e o nome diz qual: calcularTotal, mostrarCabecalho, situacao. Prefira devolver o valor (return) a mostrá-lo com print lá dentro: quem chamou decide o que fazer com ele (mostrar, somar, guardar). E escreva sempre o tipo de retorno: o Effective Dart recomenda, e o Dart avisa você quando a função não cumpre a promessa.

Quando dá errado

Esqueceu o return 
int dobro(int numero) {
  numero * 2;
}

void main() {
  print(dobro(21));
}

$ dart run semreturn.dart
semreturn.dart:1:5: Error: A non-null value must be returned since the return type 'int' doesn't allow null.
int dobro(int numero) {
    ^
semreturn.dart:1:5
Linha 1, coluna 5: o nome da função.
A non-null value must be returned since the return type 'int' doesn't allow null.
"Um valor não nulo tem de ser devolvido, já que o tipo de retorno int não aceita null." A função calcula numero * 2 e joga fora: chega ao } sem devolver nada. Uma função que termina sem return devolve null, e o int prometeu que isso nunca aconteceria (veja Null Safety).

Como consertar: return numero * 2;. O mesmo erro aparece quando só alguns caminhos têm return (um if com return e nenhum no fim).

Devolveu um valor do tipo errado 
int dobro(int numero) {
  return 'o dobro é ${numero * 2}';
}

void main() {
  print(dobro(21));
}

$ dart run tipoerrado.dart
tipoerrado.dart:2:10: Error: A value of type 'String' can't be returned from a function with return type 'int'.
  return 'o dobro é ${numero * 2}';
         ^

"Um valor do tipo String não pode ser devolvido por uma função com tipo de retorno int." Como consertar: devolva o número (return numero * 2;) e monte o texto em quem chamou, ou mude o tipo de retorno para String.

Usou o resultado de uma função void 
void mostrarCabecalho() {
  print('PADARIA DO BAIRRO');
}

void main() {
  final texto = mostrarCabecalho();
  print(texto);
}

$ dart run usavoid.dart
usavoid.dart:7:9: Error: This expression has type 'void' and can't be used.
  print(texto);
        ^

"Esta expressão tem tipo void e não pode ser usada." A função não devolve nada, então não há o que guardar nem mostrar. Como consertar: chame a função sozinha (mostrarCabecalho();), ou, se você precisa do texto, faça ela devolver uma String com return.

Resumo

  • Uma função é um pedaço de código com nome: declare uma vez (void nome() { … }), chame quantas vezes quiser (nome();).
  • Ao chamar, o programa pula para dentro da função, roda o corpo e volta para a linha seguinte.
  • O tipo antes do nome é o tipo de retorno: void não devolve nada; int, double, String… obrigam a função a devolver um valor desse tipo com return.
  • return devolve o valor e encerra a função; numa void, return; sai mais cedo.
  • Variáveis criadas dentro da função são locais: não existem fora dela.
  • Os valores que a função recebe são os parâmetros: próxima aula, Parâmetros Posicionais.
