Dart Classes

Até aqui, você usou os tipos que já vêm com o Dart: int, String, List, Map… Mas o programa da lojinha da Ana fala de produtos, o da escola fala de alunos, o do banco fala de contas. Uma classe (em inglês, class) é como você cria o seu próprio tipo: você diz quais informações um produto tem e o que ele sabe fazer, e depois cria quantos produtos quiser.

Você vai aprender
  • O que é uma classe e o que é um objeto (a forma e o bolo).
  • Como escrever uma classe com campos (as informações) e criar objetos com Produto().
  • Como ler e mudar os campos com o ponto: cafe.preco = 18.9.
  • Como escrever métodos (o que o objeto sabe fazer): cafe.mostrar().
  • Por que o print mostra Instance of 'Produto', e como mudar isso.
  • Os erros reais mais comuns ao usar classes.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a forma de bolo

A padaria tem uma forma de bolo. A forma não é um bolo: ninguém come a forma. Ela diz o formato que todo bolo feito nela vai ter. Com a mesma forma, a padaria faz o bolo de cenoura de hoje, o de chocolate de amanhã, quantos quiser. Cada bolo é um bolo, com o seu sabor e a sua cobertura.

  • A classe é a forma: o desenho, a descrição. "Todo produto tem um nome e um preço."
  • O objeto é o bolo: uma coisa feita a partir da forma, com valores próprios. "Este produto é o café, de R$ 18,90." Também se diz instância da classe.

Você escreve a classe uma vez e cria quantos objetos precisar.

1. A primeira classe

class Produto {
  String nome = '';
  double preco = 0;
}

void main() {
  final cafe = Produto();
  cafe.nome = 'café';
  cafe.preco = 18.9;
  print(cafe.nome);
  print(cafe.preco);
}
class Produto { … }
Cria a classe (a forma) chamada Produto. A palavra class vem primeiro; o nome começa com letra maiúscula e, se tiver várias palavras, cada uma começa com maiúscula (ContaBancaria): é o padrão UpperCamelCase do Dart, que ajuda a ver de longe o que é classe. A classe fica fora do main.
String nome = '';
Um campo (ou atributo): uma variável que todo produto vai ter. O = '' é o valor inicial, um texto vazio. Os campos se escrevem como variáveis comuns, só que dentro da classe.
double preco = 0;
Outro campo, o preço, começando em 0.
final cafe = Produto();
Cria um objeto da classe: o nome da classe com parênteses. A variável cafe guarda esse objeto, e o tipo dela é Produto. (Em código antigo você pode ver new Produto(): o new é opcional desde o Dart 2, e o estilo atual é não escrever.)
cafe.nome = 'café';
O ponto entra no objeto: "o nome do cafe passa a ser 'café'". É o mesmo ponto que você já usa em lista.length.
print(cafe.nome);
Lê o campo.
$ dart run primeira.dart
café
18.9

A variável cafe é final, e mesmo assim os campos mudaram. O final diz que cafe vai apontar sempre para o mesmo objeto; ele não impede que esse objeto mude por dentro. (Para campos que não mudam, veja Construtores.)

Cada objeto tem os seus valores

class Produto {
  String nome = '';
  double preco = 0;
}

void main() {
  final cafe = Produto();
  cafe.nome = 'café';
  cafe.preco = 18.9;

  final pao = Produto();
  pao.nome = 'pão';
  pao.preco = 1.0;

  print('${cafe.nome}: R\$ ${cafe.preco}');
  print('${pao.nome}: R\$ ${pao.preco}');
}

$ dart run dois.dart
café: R$ 18.9
pão: R$ 1.0

Dois bolos da mesma forma: cafe e pao têm os mesmos campos, mas cada um com os seus valores. Mudar o preço do pão não mexe no café.

2. Métodos: o que o objeto sabe fazer

Uma classe também pode ter funções dentro dela. Uma função de classe se chama método. Ela pode usar os campos do objeto direto, pelo nome:

class Produto {
  String nome = '';
  double preco = 0;
  int estoque = 0;

  void mostrar() {
    print('$nome: R\$ ${preco.toStringAsFixed(2)} ($estoque no estoque)');
  }

  double totalPara(int quantidade) {
    return preco * quantidade;
  }

  void vender(int quantidade) {
    estoque = estoque - quantidade;
  }
}

void main() {
  final cafe = Produto();
  cafe.nome = 'café';
  cafe.preco = 18.9;
  cafe.estoque = 10;

  cafe.mostrar();
  print('3 pacotes: R\$ ${cafe.totalPara(3).toStringAsFixed(2)}');
  cafe.vender(3);
  cafe.mostrar();
}
void mostrar() { … }
Um método que não recebe nada e não devolve nada (void, "vazio"): só mostra o produto. Dentro dele, nome, preco e estoque são os campos deste objeto.
double totalPara(int quantidade)
Um método que recebe um parâmetro e devolve um double: o preço vezes a quantidade.
void vender(int quantidade)
Um método que muda o objeto: tira do estoque.
cafe.mostrar();
Chama o método no objeto cafe: o ponto, o nome do método e os parênteses. Quem "faz" a ação é o café.
$ dart run metodos.dart
café: R$ 18.90 (10 no estoque)
3 pacotes: R$ 56.70
café: R$ 18.90 (7 no estoque)

Depois do cafe.vender(3), o mesmo cafe.mostrar() mostrou 7 no estoque: o método mudou o campo, e o objeto "lembrou". É isso que torna as classes úteis: os dados (campos) e as ações sobre eles (métodos) ficam juntos.

Campo × método

Campo é uma informação, e se usa sem parênteses: cafe.preco. Método é uma ação, e se chama com parênteses: cafe.mostrar(). Pense em substantivo (preço, nome, estoque) e verbo (mostrar, vender, calcular).

3. print de um objeto: Instance of 'Produto'

class Produto {
  String nome = '';
  double preco = 0;
}

void main() {
  final cafe = Produto();
  cafe.nome = 'café';
  print(cafe);
  print(cafe.runtimeType);
}

$ dart run imprimir.dart
Instance of 'Produto'
Produto

"Instância de Produto". O Dart não sabe quais campos você quer ver, então diz só de que classe o objeto é. Para escolher o texto, escreva na classe um método especial chamado toString ("para texto"):

class Produto {
  String nome = '';
  double preco = 0;

  @override
  String toString() => 'Produto($nome, R\$ $preco)';
}

void main() {
  final cafe = Produto();
  cafe.nome = 'café';
  cafe.preco = 18.9;
  print(cafe);
  print('No carrinho: $cafe');
}

$ dart run tostring.dart
Produto(café, R$ 18.9)
No carrinho: Produto(café, R$ 18.9)

O print e a interpolação ($cafe) chamam o toString sozinhos. O @override ("sobrescrever") avisa que você está trocando um método que toda classe já tem; ele é explicado em Sobrescrevendo e o toString em detalhe em toString, == e hashCode. O => é a função de uma linha.

4. Duas variáveis, o mesmo objeto

Como nas listas (veja Espalhando Coleções), uma variável guarda o endereço do objeto, e não uma cópia dele:

class Produto {
  String nome = '';
  double preco = 0;
}

void main() {
  final a = Produto();
  a.nome = 'café';
  final b = a;
  b.nome = 'chá';
  print(a.nome);

  final c = Produto();
  c.nome = 'chá';
  print(a == b);
  print(a == c);
}

$ dart run mesmo.dart
chá
true
false
  • final b = a; não criou um produto novo: a e b são dois nomes para o mesmo objeto. Mudar b.nome mudou o que a.nome mostra.
  • a == b deu true (é o mesmo objeto). a == c deu false, mesmo com o mesmo nome: são dois objetos. Por padrão, o == de uma classe compara "é o mesmo objeto?", e não "tem os mesmos valores?" (ao contrário dos records).

5. Muitos objetos: uma lista de produtos

Objetos podem ir para listas, mapas, ser parâmetros e retorno de funções, como qualquer valor. A função criar monta um produto pronto:

class Produto {
  String nome = '';
  double preco = 0;
}

Produto criar(String nome, double preco) {
  final p = Produto();
  p.nome = nome;
  p.preco = preco;
  return p;
}

void main() {
  final carrinho = [
    criar('pão', 1.0),
    criar('leite', 5.5),
    criar('café', 18.9),
  ];
  var total = 0.0;
  for (final p in carrinho) {
    total += p.preco;
  }
  print('${carrinho.length} produtos, total R\$ ${total.toStringAsFixed(2)}');
}

$ dart run lista.dart
3 produtos, total R$ 25.40

O tipo de carrinho é List<Produto>: uma lista de produtos. No for, cada p é um Produto, e o Dart deixa usar p.preco.

Formas diferentes: o construtor

A função criar resolveu um problema real: criar o objeto e preencher os campos em várias linhas é cansativo, e é fácil esquecer um campo. As classes têm uma solução própria para isso, o construtor, um "método" especial que roda na hora de criar o objeto:

class Produto {
  final String nome;
  final double preco;

  Produto(this.nome, this.preco);
}

void main() {
  final cafe = Produto('café', 18.9);
  print('${cafe.nome}: R\$ ${cafe.preco}');
}

$ dart run construtor.dart
café: R$ 18.9

Agora o produto nasce pronto, numa linha, e os campos podem ser final. Os detalhes estão na próxima aula, Construtores.

Usou a classe no lugar do objeto

$ dart run classe.dart

  Produto.nome = 'café';

"Setter não encontrado: nome." É como querer pôr cobertura na forma em vez de no bolo: o nome é de cada objeto, e não da classe. Como consertar: crie o objeto primeiro (final cafe = Produto();) e use cafe.nome. (Existem, sim, campos da própria classe; são os membros static.)

Nome da classe com letra minúscula 
class Produto {
  String nome = '';
}

void main() {
  final cafe = produto();
  print(cafe.nome);
}

$ dart run minuscula.dart
minuscula.dart:6:16: Error: Method not found: 'produto'.
  final cafe = produto();
               ^^^^^^^

"Método não encontrado: produto." O Dart diferencia maiúsculas de minúsculas: produto e Produto são nomes diferentes, e como não existe nada chamado produto, ele achou que era uma função. Como consertar: Produto().

Campo late que ninguém preencheu

void main() {
  final cafe = Produto();

  print('Preço: ${cafe.preco}');
  print('Nome: ${cafe.nome}');

Missão final: o cofrinho

Missão: a classe Cofrinho tem o campo saldo. Escreva dentro dela o método void guardar(double valor), que soma o valor ao saldo. O main já guarda 20 e 15; o resultado deve ser Saldo: R$ 35.0.

class Cofrinho {
  double saldo = 0;

  // escreva o método guardar aqui

  void mostrar() {
    print('Saldo: R\$ $saldo');
  }
}

void main() {
  final cofre = Cofrinho();
  // cofre.guardar(20);
  // cofre.guardar(15);
  cofre.mostrar();
}

class Cofrinho {
  double saldo = 0;

  void guardar(double valor) {
    saldo = saldo + valor;
  }

  void mostrar() {
    print('Saldo: R\$ $saldo');
  }
}

void main() {
  final cofre = Cofrinho();
  cofre.guardar(20);
  cofre.guardar(15);
  cofre.mostrar();
}

Resumo

  • Uma classe é o molde de um tipo novo; um objeto (instância) é uma coisa criada com ele: final cafe = Produto();.
  • Campos são as informações de cada objeto; métodos são as ações. Os dois se usam com o ponto: cafe.preco, cafe.mostrar().
  • Cada objeto tem os seus valores; uma variável guarda o endereço do objeto, então final b = a; não copia.
  • Campo de tipo que não aceita null precisa de valor inicial (ou de um construtor).
  • print(objeto) mostra Instance of 'Classe' até você escrever um toString.
  • Próxima aula: Construtores, para o objeto já nascer com os valores certos.
