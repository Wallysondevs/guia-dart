Projeto: Lista de Tarefas

A Ana vive esquecendo coisas da padaria: comprar farinha, ligar para o fornecedor, pagar a luz. Neste projeto ela vai escrever a própria lista de tarefas no terminal: adicionar, marcar como feita, limpar as feitas, e (o mais importante) não perder nada quando fechar o programa. São quatro versões, e cada uma usa uma parte do Dart que você já estudou: listas, laços, switch, classes e arquivos.

Você vai usar
  • List, add, removeAt, removeWhere (aulas Listas e Métodos de Lista).
  • Um menu com while (true) e switch (aulas while e switch).
  • Uma classe com campo que muda e toString (aulas Classes e toString).
  • File do dart:io: ler e gravar um arquivo de texto (aula Arquivos).

As sessões rodaram no Dart SDK 3.13.5 da máquina da Ana (usuária ana, computador notebook), numa pasta tarefas; o que ela digitou aparece depois de cada pergunta. No editor do guia, as respostas "digitadas" vêm prontas na caixa.

O plano

  1. Versão 1: uma lista de textos: adicionar, mostrar numerada, remover.
  2. Versão 2: um menu que repete até a pessoa sair.
  3. Versão 3: uma classe Tarefa que sabe se está feita: [x] ou [ ].
  4. Versão 4: salvar num arquivo e carregar de volta ao abrir.

Versão 1: uma lista de textos

void main() {
  final tarefas = <String>[];
  tarefas.add('Comprar farinha');
  tarefas.add('Ligar para o fornecedor');
  tarefas.add('Pagar a conta de luz');

  print('Tarefas da Ana:');
  for (var i = 0; i < tarefas.length; i++) {
    print('${i + 1}. ${tarefas[i]}');
  }

  final feita = tarefas.removeAt(1);
  print('Feita: $feita');
  print('Faltam ${tarefas.length}:');
  for (var i = 0; i < tarefas.length; i++) {
    print('${i + 1}. ${tarefas[i]}');
  }
}

Põe um item no fim da lista.

Percorre as posições 0, 1, 2. Precisamos do número i para mostrar a numeração.

tarefas.removeAt(1)
Remove o item da posição 1 (o segundo!) e o devolve, por isso dá para guardar em feita. Os itens seguintes "sobem" uma posição.

Versão 2: o menu

Tarefas escritas no código não servem para a Ana: ela quer digitá-las. A versão 2 mostra um menu, lê a escolha e repete até a pessoa digitar 0. A parte de mostrar a lista virou uma função, porque é usada em dois lugares.

import 'dart:io';

void mostrar(List<String> tarefas) {
  if (tarefas.isEmpty) {
    print('Nenhuma tarefa.');
    return;
  }
  for (var i = 0; i < tarefas.length; i++) {
    print('${i + 1}. ${tarefas[i]}');
  }
}

void main() {
  final tarefas = <String>[];
  while (true) {
    print('');
    print('[1] listar  [2] adicionar  [3] remover  [0] sair');
    stdout.write('Escolha: ');
    final opcao = stdin.readLineSync();
    switch (opcao) {
      case '1':
        mostrar(tarefas);
      case '2':
        stdout.write('Nova tarefa: ');
        final titulo = stdin.readLineSync()?.trim() ?? '';
        if (titulo.isEmpty) {
          print('Tarefa vazia, nada adicionado.');
        } else {
          tarefas.add(titulo);
          print('Adicionada: $titulo');
        }
      case '3':
        mostrar(tarefas);
        stdout.write('Número da tarefa: ');
        final n = int.tryParse(stdin.readLineSync() ?? '');
        if (n == null || n < 1 || n > tarefas.length) {
          print('Número inválido.');
        } else {
          final removida = tarefas.removeAt(n - 1);
          print('Removida: $removida');
        }
      case '0':
      case null:
        print('Até logo!');
        return;
      default:
        print('Opção inválida: $opcao');
    }
  }
}
while (true)
O menu volta "para sempre"; quem encerra é o return do caso '0', que sai do main.
switch (opcao)
Compara a escolha com cada case. A opção fica como texto ('1'), sem converter: assim, se a pessoa digitar abc, cai no default em vez de quebrar.
stdin.readLineSync()?.trim() ?? ''
Lê a linha; se vier null (entrada acabou), o ?. não chama o trim e o ?? troca por '' (veja ?. , ?? e ??=).
n < 1 || n > tarefas.length
O número tem de estar entre 1 e o tamanho da lista. É essa conferência que evita o RangeError (veja Quando dá errado).
removeAt(n - 1)
A pessoa digita 1 para a primeira tarefa, que está na posição 0.
case '0': case null:
Um case vazio "cai" no seguinte: tanto 0 quanto o fim da entrada (null) encerram o programa.

Versão 3: a classe Tarefa

Na versão 2, "fazer" uma tarefa era apagá-la. Mas a Ana gosta de ver o que já fez no dia, riscado. Para isso, cada tarefa precisa guardar duas informações: o título e se está feita. É o trabalho de uma classe:

import 'dart:io';

class Tarefa {
  final String titulo;
  bool feita;

  Tarefa(this.titulo, {this.feita = false});

  @override
  String toString() => '[${feita ? 'x' : ' '}] $titulo';
}

void mostrar(List<Tarefa> tarefas) {
  if (tarefas.isEmpty) {
    print('Nenhuma tarefa.');
    return;
  }
  for (var i = 0; i < tarefas.length; i++) {
    print('${i + 1}. ${tarefas[i]}');
  }
}

int? lerNumero(List<Tarefa> tarefas) {
  stdout.write('Número da tarefa: ');
  final n = int.tryParse(stdin.readLineSync() ?? '');
  if (n == null || n < 1 || n > tarefas.length) {
    print('Número inválido.');
    return null;
  }
  return n - 1;
}

void main() {
  final tarefas = <Tarefa>[];
  while (true) {
    print('');
    print('[1] listar  [2] adicionar  [3] marcar/desmarcar  [4] limpar feitas  [0] sair');
    stdout.write('Escolha: ');
    final opcao = stdin.readLineSync();
    switch (opcao) {
      case '1':
        mostrar(tarefas);
      case '2':
        stdout.write('Nova tarefa: ');
        final titulo = stdin.readLineSync()?.trim() ?? '';
        if (titulo.isNotEmpty) {
          tarefas.add(Tarefa(titulo));
        }
      case '3':
        mostrar(tarefas);
        final i = lerNumero(tarefas);
        if (i != null) {
          tarefas[i].feita = !tarefas[i].feita;
          print(tarefas[i]);
        }
      case '4':
        final antes = tarefas.length;
        tarefas.removeWhere((t) => t.feita);
        print('Removidas: ${antes - tarefas.length}');
      case '0':
      case null:
        print('Até logo!');
        return;
      default:
        print('Opção inválida: $opcao');
    }
  }
}
final String titulo; bool feita;
O título nunca muda (final); o feita muda quando a Ana marca (por isso não é final).
Tarefa(this.titulo, {this.feita = false})
O construtor: o título é obrigatório; o feita é um parâmetro nomeado opcional que começa false (veja Parâmetros Opcionais). A versão 4 vai precisar dele.
toString() => '[${feita ? 'x' : ' '}] $titulo'
Diz como a tarefa aparece num print ou numa interpolação: [x] Ligar… se feita, [ ] Ligar… se não.
int? lerNumero(…)
Uma função que devolve a posição escolhida, ou null se o número for inválido. O ? no tipo avisa quem chama: "confira o null".
tarefas[i].feita = !tarefas[i].feita;
Inverte: o que era false vira true e vice-versa. Marcar duas vezes desmarca.
tarefas.removeWhere((t) => t.feita)
"Remova onde": apaga todas as tarefas para as quais a função devolve true, de uma vez e com segurança (veja por que em Quando dá errado).

Versão 4: salvar num arquivo

Até aqui, fechar o programa apagava tudo: a lista morava só na memória. A versão 4 grava as tarefas num arquivo de texto, tarefas.txt, a cada mudança, e lê esse arquivo quando o programa abre. Cada linha do arquivo é uma tarefa: x na frente se está feita, - se não.

import 'dart:io';

const nomeArquivo = 'tarefas.txt';

class Tarefa {
  final String titulo;
  bool feita;

  Tarefa(this.titulo, {this.feita = false});

  @override
  String toString() => '[${feita ? 'x' : ' '}] $titulo';
}

List<Tarefa> carregar() {
  final arquivo = File(nomeArquivo);
  if (!arquivo.existsSync()) {
    return [];
  }
  return [
    for (final linha in arquivo.readAsLinesSync())
      if (linha.length > 2)
        Tarefa(linha.substring(2), feita: linha.startsWith('x')),
  ];
}

void salvar(List<Tarefa> tarefas) {
  final texto = StringBuffer();
  for (final t in tarefas) {
    texto.writeln('${t.feita ? 'x' : '-'} ${t.titulo}');
  }
  File(nomeArquivo).writeAsStringSync(texto.toString());
}

void mostrar(List<Tarefa> tarefas) {
  if (tarefas.isEmpty) {
    print('Nenhuma tarefa.');
    return;
  }
  for (var i = 0; i < tarefas.length; i++) {
    print('${i + 1}. ${tarefas[i]}');
  }
}

void main() {
  final tarefas = carregar();
  print('${tarefas.length} tarefa(s) carregada(s) de $nomeArquivo.');
  while (true) {
    print('');
    print('[1] listar  [2] adicionar  [3] marcar/desmarcar  [4] limpar feitas  [0] sair');
    stdout.write('Escolha: ');
    final opcao = stdin.readLineSync();
    switch (opcao) {
      case '1':
        mostrar(tarefas);
      case '2':
        stdout.write('Nova tarefa: ');
        final titulo = stdin.readLineSync()?.trim() ?? '';
        if (titulo.isNotEmpty) {
          tarefas.add(Tarefa(titulo));
          salvar(tarefas);
        }
      case '3':
        mostrar(tarefas);
        stdout.write('Número da tarefa: ');
        final n = int.tryParse(stdin.readLineSync() ?? '');
        if (n == null || n < 1 || n > tarefas.length) {
          print('Número inválido.');
        } else {
          tarefas[n - 1].feita = !tarefas[n - 1].feita;
          salvar(tarefas);
          print(tarefas[n - 1]);
        }
      case '4':
        tarefas.removeWhere((t) => t.feita);
        salvar(tarefas);
        mostrar(tarefas);
      case '0':
      case null:
        print('Até logo!');
        return;
      default:
        print('Opção inválida: $opcao');
    }
  }
}
File(nomeArquivo)
Um objeto que representa o arquivo tarefas.txt na pasta de onde o programa roda. Criar o File não cria o arquivo no disco.
arquivo.existsSync()
"O arquivo existe?". Na primeira vez, não existe, e a lista começa vazia.
readAsLinesSync()
Lê o arquivo inteiro e devolve uma lista com uma linha em cada posição.
[ for (…) if (…) Tarefa(…), ]
Monta a lista com for e if dentro dela (veja if e for Dentro de Coleções): uma Tarefa para cada linha com mais de 2 caracteres (pula linhas vazias).
linha.substring(2)
O título é a linha a partir da posição 2, pulando o x ou o - .
StringBuffer + writeln
Junta todas as linhas num texto só (veja Montando Textos).
writeAsStringSync(…)
Grava o texto no arquivo, criando-o se não existir e substituindo o conteúdo antigo. É chamado depois de cada mudança.

import 'dart:io';

const nomeArquivo = 'tarefas.txt';

class Tarefa {
  final String titulo;
  bool feita;

  Tarefa(this.titulo, {this.feita = false});
}

void salvar(List<Tarefa> tarefas) {
  final texto = StringBuffer();
  for (final t in tarefas) {
    texto.writeln('${t.feita ? 'x' : '-'} ${t.titulo}');
  }
  File(nomeArquivo).writeAsStringSync(texto.toString());
}

void main() {
  final tarefas = <Tarefa>[];
  while (true) {
    stdout.write('Escolha: ');
    final opcao = stdin.readLineSync();
    switch (opcao) {
      case '2':
        stdout.write('Nova tarefa: ');
        final titulo = stdin.readLineSync()?.trim() ?? '';
        if (titulo.isNotEmpty) {
          tarefas.add(Tarefa(titulo));
          salvar(tarefas);
        }
      case '0':
      case null:
        print('Até logo!');
        return;
    }
  }
}

Resumo

  • Uma lista guarda as tarefas; add põe, removeAt(n - 1) tira pela posição (que começa em 0), sempre conferindo a faixa antes.
  • Um menu é um while (true) com switch na opção lida como texto; o return (ou break) encerra.
  • Quando cada item tem mais de uma informação, crie uma classe (Tarefa com titulo e feita) e um toString para mostrá-la.
  • removeWhere apaga vários itens com segurança; apagar dentro do for que percorre a lista dá Concurrent modification during iteration.
  • Para não perder nada: existsSync + readAsLinesSync ao abrir, writeAsStringSync a cada mudança.
