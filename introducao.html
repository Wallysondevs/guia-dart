Dart O que é

O Dart é uma linguagem de programação: um jeito de escrever instruções que o computador consegue seguir. Foi criado pelo Google e hoje é mais conhecido por ser a linguagem do Flutter, a ferramenta usada para fazer aplicativos de celular, de computador e de navegador com um código só. Mas o Dart também serve, sozinho, para programas de terminal, scripts e servidores. É esse Dart "puro" que este guia ensina, do zero.

Você vai aprender
  • O que é uma linguagem de programação e o que é um programa.
  • De onde veio o Dart e para que ele é usado hoje.
  • Como é a cara de um programa Dart de verdade, e a saída que ele mostra.
  • O que o comando dart faz com o seu arquivo antes de rodá-lo.
  • Por que o Dart reclama de alguns erros antes de o programa começar (e o que é um erro em tempo de execução).
  • Como este guia está organizado e o que você precisa para acompanhar.

Todos os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook, com Ubuntu), na pasta pessoal dela, com o comando dart run arquivo.dart. Você vai aprender esse comando na aula Rodando um Programa.

A ideia: uma receita escrita para o computador

Pense numa receita de bolo. Ela é uma lista de passos, na ordem certa: "misture os ovos com o açúcar", "acrescente a farinha", "asse por 40 minutos". Quem segue a receita não precisa pensar, só obedecer, um passo de cada vez.

Um programa é uma receita para o computador. E uma linguagem de programação é o idioma em que a receita é escrita. O computador é um cozinheiro muito rápido e muito literal: ele faz exatamente o que está escrito, nem mais nem menos. Por isso a linguagem tem regras rígidas de escrita, e boa parte de aprender a programar é aprender essas regras.

Na cozinhaNo Dart

SDK é a sigla de Software Development Kit, "kit de desenvolvimento de software": a caixa de ferramentas que você instala para escrever e rodar programas Dart. A aula Instalar o Dart mostra como colocá-la no seu computador.

1. Um programa Dart de verdade

Este é um programa Dart completo. Ele mostra uma frase na tela:

void main() {
  print('Olá, Ana!');
}

$ dart run ola.dart
Olá, Ana!

Ainda não precisa entender cada pedaço: a aula Seu Primeiro Programa explica tudo com calma. Por enquanto, repare em três coisas:

void main() { ... }
O ponto de partida do programa. Todo programa Dart começa a rodar pelo que está entre as chaves { } do main (em inglês, "principal").
print('Olá, Ana!')
A instrução que mostra um texto na tela (print = "imprimir"). O texto vai entre aspas, e as aspas não aparecem na saída.
;
O ponto e vírgula fecha a instrução, como o ponto final fecha uma frase. A aula Instruções, Ponto e Vírgula e Blocos conta por que ele é obrigatório.

Um pouco mais: a lista de compras

Programas de verdade guardam informações e repetem tarefas. Este aqui guarda a lista de compras da Ana, mostra cada item e conta quantos são:

void main() {
  final itens = ['pão', 'leite', 'café'];
  print('Lista de compras da Ana:');
  for (final item in itens) {
    print('- $item');
  }
  print('Total de itens: ${itens.length}');
}

$ dart run compras.dart
Lista de compras da Ana:
- pão
- leite
- café
Total de itens: 3

Leia em voz alta, quase como português: "os itens são pão, leite e café; mostre o título; para cada (for) item dos itens, mostre um tracinho e o item; mostre o total". Cada novidade deste programa tem a sua aula: final, listas, for-in e o $ dentro do texto. Você vai chegar lá.

2. De onde veio o Dart

O Dart foi apresentado pelo Google em 2011, e a versão 1.0 saiu em 2013. A ideia original era ser uma linguagem para páginas da web. Com o tempo, o grande uso dele passou a ser o Flutter (lançado em 2018), e a linguagem foi ficando mais rigorosa e mais segura. Os marcos que importam para você:

VersãoAnoO que trouxe
Dart 12013A primeira versão estável.
Dart 22018Tipos conferidos com rigor (o "sistema de tipos forte" que você vai ver na seção 4).
Dart 2.122021Null safety: o Dart passa a avisar quando algo pode estar "vazio" (aula Null Safety).
Dart 32023Null safety obrigatório para todos, records, patterns e mais. É o Dart que este guia ensina.

A história completa, versão por versão, está em Versões do Dart.

Por que aprender o Dart pelo terminal, e não direto no Flutter?

Porque o Flutter é muita coisa ao mesmo tempo: telas, botões, celular, emulador. Se você não sabe o que é uma variável, uma lista ou uma classe, cada erro vira um mistério. No terminal, só existe a linguagem: você escreve, roda e vê a resposta na hora. Quando chegar ao Flutter, o Dart já vai ser velho conhecido.

4. O que o dart faz com o seu arquivo

Quando a Ana digita dart run ola.dart, o dart não sai executando a primeira linha às cegas. Ele faz duas coisas, nesta ordem:

  1. Lê e confere o arquivo inteiro e o compila: traduz o texto que você escreveu para uma forma que a máquina executa rápido. Nessa conferência, ele procura erros de escrita e de tipo (um número onde devia ir um texto, por exemplo). Se achar um, para aqui: nada do programa roda.
  2. Roda o programa, começando pelo main. Aqui ainda pode acontecer um problema que só aparece na hora, como uma divisão por zero.

Essa conferência de tipos antes de rodar é uma das marcas do Dart. Cada valor tem um tipo: int para números inteiros, String para textos, e assim por diante (aula Os Tipos Básicos). Se você diz que uma coisa é número e tenta guardar um texto nela, o Dart percebe antes de rodar.

Quando dá errado antes de rodar: erro de compilação

Um texto onde devia ir um número 
void main() {
  int quantidade = 'três';
  print(quantidade);
}

$ dart run quantidade.dart
quantidade.dart:2:20: Error: A value of type 'String' can't be assigned to a variable of type 'int'.
  int quantidade = 'três';
                   ^
$ echo $?
254

É a primeira mensagem de erro do guia, então vamos ler parte por parte. As mensagens do Dart saem em inglês:

quantidade.dart:2:20:
Onde está o problema: arquivo quantidade.dart, linha 2, coluna 20 (a 20.ª letra da linha, contando os espaços). É a parte mais útil da mensagem.
Error:
"Erro". É um erro de compilação: o Dart achou durante a conferência, antes de rodar.
A value of type 'String' can't be assigned to a variable of type 'int'.
"Um valor do tipo String (texto) não pode ser guardado numa variável do tipo int (número inteiro)." A Ana disse que quantidade é um número e tentou guardar o texto 'três'.
a linha do código e o ^
O Dart repete a linha com problema e aponta com o ^ ("acento circunflexo", aqui uma setinha) o lugar exato: o começo de 'três'.
echo $? → 254
O código de saída: um número que todo programa devolve ao terminar (o $? do terminal mostra o do último comando). 0 é "deu tudo certo"; o dart run devolve 254 quando o código nem compilou.

Repare que o print da linha 3 não rodou: com erro de compilação, nenhuma linha do programa é executada. Como consertar: guarde um número, int quantidade = 3;.

Quando dá errado durante a execução: exceção

Uma divisão por zero 
void main() {
  final pessoas = 0;
  print('Começando a conta...');
  print(12 ~/ pessoas);
}

$ dart run divisao.dart
Começando a conta...
Unhandled exception:
IntegerDivisionByZeroException
#0      int.~/ (dart:core-patch/integers.dart:27:7)
#1      main (file:///home/ana/divisao.dart:4:12)
#2      _delayEntrypointInvocation.<anonymous closure> (dart:isolate-patch/isolate_patch.dart:313:19)
#3      _RawReceivePort._handleMessage (dart:isolate-patch/isolate_patch.dart:192:12)
$ echo $?
255

A Ana quer dividir 12 pães entre as pessoas (o ~/ é a divisão inteira, aula Operadores Aritméticos), mas o número de pessoas é zero. Desta vez o arquivo estava bem escrito: o Dart compilou e começou a rodar, tanto que Começando a conta... apareceu. O problema só surgiu na linha 4, na hora da conta:

Unhandled exception:
"Exceção não tratada". Uma exceção é um problema que acontece com o programa já rodando; "não tratada" quer dizer que o programa não tinha um plano para ela (aula Exceções), então ele para ali.
IntegerDivisionByZeroException
O nome do problema: "exceção de divisão inteira por zero".
#0, #1, #2, #3
O stack trace ("rastro da pilha"): o caminho até o erro, do ponto mais fundo para fora. Procure a linha que fala do seu arquivo: #1 main (file:///home/ana/divisao.dart:4:12), ou seja, função main, linha 4, coluna 12. As linhas com dart: são peças internas do Dart; pode ignorá-las.
echo $? → 255
O código de saída de um programa que parou por exceção não tratada.

5. Como este guia funciona

  • Níveis: o menu tem cinco abas. O Iniciante vai do primeiro programa até decisões, repetições e o teclado; o Intermediário traz funções, coleções e classes; o Avançado, assíncrono, arquivos e pacotes; e há uma aba de Projetos completos e outra de Referência.
  • Uma aula, um assunto: cada página ensina uma coisa só, com exemplos, a saída real, os erros mais comuns e exercícios.
  • Saídas reais: todo terminal mostrado (as caixas escuras com $) foi rodado de verdade no Dart da Ana. O $ é o "prompt": o sinal de que o terminal espera um comando. Você não digita o $.
  • Experimente: as caixas com o botão Rodar deixam você mudar o código e ver o resultado no navegador, sem instalar nada (aula O Editor do Guia).

Resumo

  • Um programa é uma receita para o computador; o Dart é o idioma em que ela é escrita.
  • O Dart foi criado pelo Google (2011). O Dart 3 (2023) é o que este guia ensina, com null safety obrigatório.
  • É a linguagem do Flutter, mas roda sozinho: programas de terminal, scripts, servidores e web.
  • Todo programa começa pelo main; o print mostra textos na tela.
  • O dart run confere e compila o arquivo inteiro antes de rodar: erros de escrita e de tipo aparecem antes (Error:, código 254) e nada roda.
  • Problemas que só aparecem na hora viram uma exceção (Unhandled exception:, código 255), e o programa para ali.
