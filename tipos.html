Dart Os Tipos Básicos

Na aula Variáveis, você viu que toda variável tem um tipo, e que o Dart não deixa guardar um texto num pote de números. Esta aula apresenta os tipos que você vai usar o tempo todo: números inteiros, números com vírgula, textos e verdadeiro/falso. Cada um deles tem uma aula própria mais adiante; aqui é o mapa geral, para você reconhecer cada tipo e saber escolher.

Você vai aprender
  • O que é um tipo e por que o Dart se importa tanto com eles.
  • Os quatro tipos básicos: int, double, String e bool, e o num, que junta os dois números.
  • Um primeiro olhar em List, Map e no Null.
  • A descobrir o tipo de um valor com runtimeType e a perguntar com is.
  • Por que '5' e 5 são coisas diferentes.
  • Os erros reais de tipo errado, de tipo escrito errado e de usar algo que o tipo não tem.

Os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook), na pasta pessoal dela, com dart run arquivo.dart.

A ideia: cada coisa na sua forma

Na cozinha da padaria, cada forma serve para uma coisa: a forma de pão de forma, a de bolo redondo, a de pudim com furo no meio. Ninguém assa pudim na forma de pão. E dá para saber o que vai sair só de olhar para a forma.

Os tipos são as formas dos valores. Um número inteiro, um preço com centavos, um nome, um "sim ou não": cada um tem o seu tipo, e cada tipo sabe fazer coisas diferentes (dá para somar números; dá para pôr um texto em maiúsculas). Como o Dart confere os tipos antes de rodar o programa, um valor na forma errada é descoberto na hora, e não quando a cliente já está no caixa.

2. Descobrindo o tipo: runtimeType e is

Quando você cria a variável com var, o Dart descobre o tipo pelo valor. Para ver qual foi, todo valor tem o .runtimeType ("tipo durante a execução"):

void main() {
  var paes = 30;
  var preco = 0.9;
  var padaria = 'Padaria do Bairro';
  var aberta = true;
  print(paes.runtimeType);
  print(preco.runtimeType);
  print(padaria.runtimeType);
  print(aberta.runtimeType);
}

$ dart run runtime.dart
int
double
String
bool

E para perguntar se um valor é de um tipo, use is ("é"). A resposta é um bool:

void main() {
  var troco = 2.5;
  print(troco is double);
  print(troco is int);
  print(troco is num);
}

$ dart run is.dart
true
false
true

2.5 é double, não é int, e é num (todo double é um num). O runtimeType serve para estudar e investigar; para decidir coisas no programa, o certo é o is, que tem aula própria: is, is! e as.

3. '5' não é 5

Aspas fazem toda a diferença. Na tela, os dois parecem iguais; para o Dart, um é texto e o outro é número:

void main() {
  var a = '5';
  var b = 5;
  print(a);
  print(b);
  print(a.runtimeType);
  print(b.runtimeType);
  print(a == b);
}

$ dart run texto_numero.dart
5
5
String
int
false

As duas primeiras linhas saem iguais, mas a é String e b é int, e a comparação a == b ("a é igual a b?") responde false. Não dá para fazer conta com '5': primeiro é preciso converter o texto em número, com int.parse('5') (aula Conversão de Tipos). Isso vai importar muito quando o programa ler o que a pessoa digita, porque o teclado sempre entrega texto (aula Lendo o Teclado).

4. Outros tipos que você vai encontrar

Os quatro básicos guardam um valor. Logo você vai querer guardar vários de uma vez: a lista de compras inteira, a tabela de preços. Um primeiro olhar:

void main() {
  var compras = ['pão', 'leite'];
  var precos = {'pão': 0.9, 'leite': 5.5};
  print(compras.runtimeType);
  print(precos.runtimeType);
  print(null.runtimeType);
}

$ dart run colecoes.dart
List<String>
_Map<String, double>
Null
List<String>
Uma lista de textos. O que está entre < > é o tipo de cada item. Aula Listas.
_Map<String, double>
Um mapa: cada nome (String) aponta para um preço (double). No seu código, o tipo se escreve Map<String, double>; o _Map com sublinhado é o nome interno que o Dart usa por baixo. Aula Mapas.
Null
O tipo do null, o "nada": a ausência de valor. Ele tem um grupo de aulas inteiro, começando por Null Safety.

Há ainda Set (conjuntos), dynamic e Object (dynamic e Object) e os tipos que você mesmo cria com classes.

Escrever o tipo ou usar var?

Os dois produzem o mesmo programa. O guia de estilo oficial (Effective Dart) sugere deixar o Dart descobrir o tipo nas variáveis de dentro das funções, quando o valor deixa o tipo óbvio (var paes = 30;), e escrever o tipo quando ele não é óbvio. Neste começo, escrever o tipo ajuda você a pensar nele: use os dois e veja qual fica mais claro.

Quando dá errado

Decimal num int 
void main() {
  int paes = 2.5;
  print(paes);
}

$ dart run int_decimal.dart
int_decimal.dart:2:14: Error: A value of type 'double' can't be assigned to a variable of type 'int'.
  int paes = 2.5;
             ^
$ echo $?
254

"Um valor do tipo double não pode ser atribuído a uma variável do tipo int." O Dart não corta as casas decimais sozinho, porque isso perderia o meio pão sem avisar. Como consertar: se o valor pode ter decimais, double paes = 2.5;. Se queria um inteiro, escreva um inteiro.

Texto onde vai número ou bool 
void main() {
  int quantidade = '5';
  print(quantidade);
}

$ dart run int_texto.dart
int_texto.dart:2:20: Error: A value of type 'String' can't be assigned to a variable of type 'int'.
  int quantidade = '5';
                   ^
$ dart run bool_texto.dart
bool_texto.dart:2:17: Error: A value of type 'String' can't be assigned to a variable of type 'bool'.
  bool aberta = 'sim';
                ^

As aspas fazem do '5' um texto (seção 3). E bool só aceita true ou false: 'sim' é texto. Como consertar: int quantidade = 5; e bool aberta = true;.

Tipo escrito com a letra errada 
void main() {
  string nome = 'Ana';
  Int idade = 30;
  print(nome);
}

$ dart run maiuscula.dart
maiuscula.dart:2:3: Error: 'string' isn't a type.
  string nome = 'Ana';
  ^^^^^^
maiuscula.dart:3:3: Error: 'Int' isn't a type.
  Int idade = 30;
  ^^^

"string não é um tipo" e "Int não é um tipo". Quem vem de outras linguagens erra muito isto: em Dart é String (maiúsculo) e int (minúsculo). O mesmo com os valores do bool:

$ dart run bool_maiusc.dart
bool_maiusc.dart:2:17: Error: Undefined name 'True'.
  bool aberta = True;
                ^^^^

True com T maiúsculo é, para o Dart, o nome de uma variável que não existe. Como consertar: String, int, double, bool, true, false.

Pedir a um tipo o que ele não tem 
void main() {
  var nome = 'Ana';
  var paes = 30;
  print(nome.length);
  print(paes.length);
}

$ dart run length.dart
length.dart:5:14: Error: The getter 'length' isn't defined for the type 'int'.
Try correcting the name to the name of an existing getter, or defining a getter or field named 'length'.
  print(paes.length);
             ^^^^^^

Cada tipo sabe fazer coisas diferentes. Um texto tem .length (o comprimento, quantas letras tem), mas um número não. A mensagem diz: "o getter length não está definido para o tipo int" (um getter é uma informação que se pede a um valor com o ponto, como .length e .runtimeType; aula get e set). A segunda linha sugere corrigir o nome ou criar esse getter. Repare: o erro está na linha 5, e mesmo assim a linha 4, que estava certa, não rodou. Aqui o tipo protegeu você: o Dart sabe que paes é int e avisa antes de rodar. Como consertar: use .length só com textos (e listas).

Missão: cada linha de declaração tem um erro de tipo. Conserte trocando o tipo ou o valor, para a saída ser Bia, 10, 2.5 e true.

Resumo

  • Todo valor tem um tipo, e o Dart confere os tipos antes de rodar.
  • int para inteiros, double para decimais (com ponto), num para os dois, String para textos, bool para true/false.
  • String com maiúscula; int, double, bool, true e false com minúscula.
  • A divisão / sempre dá double. Um int cabe num double, mas não o contrário.
  • '5' é texto e 5 é número: não são iguais.
  • .runtimeType mostra o tipo; is pergunta se é de um tipo.
  • Vêm aí: List, Map, Set e o Null da null safety.
