Dart Comandos dart

Tudo o que você faz com o Dart no terminal passa por um único programa, o dart, seguido de um subcomando: dart run roda, dart create cria um projeto, dart format arruma o código, e assim por diante. Esta página é a consulta rápida desses comandos, com a saída que cada um deu no computador da Ana (Dart SDK 3.13.5). A explicação passo a passo está nas aulas Rodando um Programa, dart create, Pacotes, Análise e Formatação, Testes e Compilando.

O editor do guia só faz dart run

As caixas "Experimente" rodam o seu main.dart, como um dart run main.dart. Os outros comandos desta página (criar projeto, baixar pacotes, compilar) precisam do Dart instalado no seu computador (veja Instalar o Dart).

A ajuda está em inglês: "Uso: dart <comando|arquivo-dart> [argumentos]". exe gera um executável nativo, que roda com ./padaria sem o Dart instalado (mas só no mesmo sistema: um executável de Linux não roda no Windows). js gera JavaScript para o navegador, mais o mapa (.js.map) e a lista de arquivos usados (.js.deps). Quando dá errado

Pacote que não existe 
$ dart pub add pacote_que_nao_existe_xyz
Because padaria depends on pacote_que_nao_existe_xyz any which doesn't exist (could not find package pacote_que_nao_existe_xyz at https://pub.dev), version solving failed.
$ echo $?
65

"Como padaria depende de pacote_que_nao_existe_xyz, que não existe (não encontrado no pub.dev), a resolução de versões falhou." Confira o nome em pub.dev; os nomes de pacote usam snake_case.

dart pub fora do projeto 
$ dart pub get
Found no `pubspec.yaml` file in `/home/ana` or parent directories
$ echo $?
66

"Não achei um pubspec.yaml em /home/ana nem nas pastas acima." Os comandos pub precisam rodar dentro da pasta do projeto: cd padaria antes.

Experimente

Missão: esta caixa roda o programa como dart run main.dart Ana Souza. Faça-o mostrar também quantos argumentos chegaram: Olá, Ana Souza! (2 palavras).

void main(List<String> args) {
  print('Olá, ${args.join(' ')}!');
}

void main(List<String> args) {
  print('Olá, ${args.join(' ')}! (${args.length} palavras)');
}

Livre: um programa que termina com um código de saída escolhido. Troque o número do exit e veja o código que o editor mostra.

import 'dart:io';

void main() {
  print('Encerrando com código 3');
  exit(3);
}

Resumo

  • dart run arquivo.dart roda; dart create nome cria um projeto; dentro dele, dart run roda o bin/.
  • dart pub add/get/outdated cuidam dos pacotes e só funcionam dentro do projeto.
  • dart analyze (erros, avisos e dicas), dart format (estilo) e dart fix --apply (correções automáticas) deixam o código limpo.
  • dart test roda os testes; dart compile exe gera um executável.
  • Códigos de saída: 0 ok, 254 erro de compilação, 255 exceção ou arquivo inexistente.
