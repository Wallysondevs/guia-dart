Dart Operadores

Esta é a página de consulta dos operadores do Dart: os símbolos que fazem contas (+, ~/), comparam (==, <), combinam condições (&&), lidam com null (??, ?.) e mais alguns que só o Dart tem, como a cascata ... Cada tabela tem um exemplo e o resultado que o Dart deu no computador da Ana; no fim da página está o programa que gerou todos eles.

Como ler as tabelas
  • Resultado é o que o Dart SDK 3.13.5 mostrou com print.
  • Quando o exemplo usa uma variável, ela foi criada antes (por exemplo, var a = 5;).
  • Os nomes em inglês ficam entre parênteses, para você reconhecer na documentação.

Quando dá errado

Texto + número 
void main() {
  final total = 5;
  print('Total: ' + total);
}

$ dart run soma.dart
soma.dart:3:21: Error: A value of type 'int' can't be assigned to a variable of type 'String'.
  print('Total: ' + total);
                    ^

O + de um texto só aceita outro texto: "um valor do tipo int não pode ser atribuído a String". Use interpolação: 'Total: $total' (veja Interpolação).

Divisão por zero: / não reclama, ~/ sim 
void main() {
  print(5 / 0);
  print(-5 / 0);
  print(0 / 0);
  print(5 ~/ 0);
}

$ dart run divisao.dart
Infinity
-Infinity
NaN
Unhandled exception:
IntegerDivisionByZeroException
#0      int.~/ (dart:core-patch/integers.dart:27:7)
#1      main (file:///home/ana/divisao.dart:5:11)
#2      _delayEntrypointInvocation.<anonymous closure> (dart:isolate-patch/isolate_patch.dart:313:19)
#3      _RawReceivePort._handleMessage (dart:isolate-patch/isolate_patch.dart:192:12)

A / trabalha com double, que tem valores especiais: Infinity (infinito) e NaN (not a number, "não é um número"). A ~/ dá int, que não tem infinito: "exceção de divisão inteira por zero", na linha 5.

= no lugar de == 
void main() {
  var x = 3;
  if (x = 4) {
    print('quatro');
  }
}

$ dart run igual.dart
igual.dart:3:7: Error: A value of type 'int' can't be assigned to a variable of type 'bool'.
  if (x = 4) {
      ^

O if precisa de um bool, e x = 4 é uma atribuição, que vale 4 (um int). O Dart recusa, o que evita um erro clássico de outras linguagens. Para comparar: x == 4.

Ponto num valor que pode ser nulo 
void main() {
  String? apelido;
  print(apelido.length);
}

$ dart run nulo.dart
nulo.dart:3:17: Error: Property 'length' cannot be accessed on 'String?' because it is potentially null.
Try accessing using ?. instead.
  print(apelido.length);
                ^^^^^^

"A propriedade length não pode ser acessada em String? porque pode ser nula. Tente ?.." Com apelido!.length compila, mas, como o valor é mesmo nulo, quebra ao rodar:

$ dart run exclama.dart

"Operador de checagem de nulo usado num valor nulo." Use ! só quando tiver certeza; senão, ?. ou ??.

Experimente

Missão: a padaria tem 26 pães e os pacotes levam 6. Troque os dois 0 pelas contas certas: quantos pacotes cheios (~/) e quantos pães sobram (%).

void main() {
  final paes = 26;
  final porPacote = 6;
  print('Pacotes cheios: ${0}');
  print('Sobram: ${0}');
}

void main() {
  final paes = 26;
  final porPacote = 6;
  print('Pacotes cheios: ${paes ~/ porPacote}');
  print('Sobram: ${paes % porPacote}');
}

Livre: o programa que gerou os resultados das tabelas. Mude os valores e rode.

void main() {
  // aritméticos
  print('7 + 2 = ${7 + 2}');
  print('7 - 2 = ${7 - 2}');
  print('7 * 2 = ${7 * 2}');
  print('7 / 2 = ${7 / 2}');
  print('7 ~/ 2 = ${7 ~/ 2}');
  print('7 % 2 = ${7 % 2}');
  print('-7 % 2 = ${-7 % 2}');
  print('-7 ~/ 2 = ${-7 ~/ 2}');
  print('6 / 2 = ${6 / 2}');
  print('-(3) = ${-(3)}');
  print("'ab' + 'cd' = ${'ab' + 'cd'}");
  print("'ab' * 3 = ${'ab' * 3}");
  // incremento
  var a = 5;
  print('a++ = ${a++}, depois a = $a');
  var b = 5;
  print('++b = ${++b}, depois b = $b');
  var c = 5;
  print('c-- = ${c--}, depois c = $c');
  // comparação
  print('3 == 3.0: ${3 == 3.0}');
  print("'a' == 'a': ${'a' == 'a'}");
  print('3 != 4: ${3 != 4}');
  print('3 < 4: ${3 < 4}, 3 <= 3: ${3 <= 3}, 3 > 4: ${3 > 4}, 4 >= 5: ${4 >= 5}');
  // lógicos
  print('true && false: ${true && false}');
  print('true || false: ${true || false}');
  print('!true: ${!true}');
  // tipo
  Object x = 'Ana';
  print("x is String: ${x is String}, x is! int: ${x is! int}");
  print('(x as String).length: ${(x as String).length}');
  // null
  String? nome;
  print('nome ?? "visitante": ${nome ?? 'visitante'}');
  print('nome?.length: ${nome?.length}');
  nome ??= 'Bia';
  print('nome ??= "Bia": $nome');
  String? outro = 'Caio';
  print('outro!.length: ${outro!.length}');
  List<int>? notas;
  print('notas?[0]: ${notas?[0]}');
  // ternário
  final idade = 17;
  print("idade >= 18 ? 'adulto' : 'menor': ${idade >= 18 ? 'adulto' : 'menor'}");
  // atribuição composta
  var t = 10;
  t += 5;
  print('t += 5: $t');
  t -= 3;
  print('t -= 3: $t');
  t *= 2;
  print('t *= 2: $t');
  t ~/= 5;
  print('t ~/= 5: $t');
  t %= 3;
  print('t %= 3: $t');
  var d = 10.0;
  d /= 4;
  print('d /= 4: $d');
  // bits
  print('6 & 3 = ${6 & 3}, 6 | 3 = ${6 | 3}, 6 ^ 3 = ${6 ^ 3}, ~6 = ${~6}');
  print('1 << 3 = ${1 << 3}, 16 >> 2 = ${16 >> 2}, -16 >> 2 = ${-16 >> 2}, -16 >>> 60 = ${-16 >>> 60}');
  // cascata
  final lista = <int>[]
    ..add(3)
    ..add(1)
    ..sort();
  print('cascata: $lista');
  StringBuffer? sb;
  sb?..write('x')..write('y');
  print('?.. com null: $sb');
  // spread
  final base = [1, 2];
  List<int>? vazia;
  print('[...base, 3]: ${[...base, 3]}');
  print('[0, ...?vazia]: ${[0, ...?vazia]}');
  // índice e chamada
  print("'Dart'[0]: ${'Dart'[0]}");
  // precedência
  print('2 + 3 * 4 = ${2 + 3 * 4}');
  print('(2 + 3) * 4 = ${(2 + 3) * 4}');
  print('10 - 4 - 3 = ${10 - 4 - 3}');
  print('-2 * -2 = ${-2 * -2}');
  print('true || false && false = ${true || false && false}');
}

Resumo

  • / sempre dá double; ~/ dá a parte inteira; % dá o resto.
  • x++ vale o valor de antes; ++x, o de depois.
  • == compara; = guarda. && vem antes de ||.
  • Null: ?? (valor padrão), ??= (guarda se nulo), ?. e ?[] (acesso seguro), ! (garantia, com risco).
  • is/is! perguntam o tipo; as confere e lança exceção se estiver errado.
  • .. encadeia operações no mesmo objeto; ... espalha uma coleção em outra.
  • Na dúvida sobre a precedência, use parênteses.
