Dart break e continue

Os laços que você já conhece (for, for-in, while e do-while) só param quando a condição fica falsa ou quando os itens acabam. Às vezes você quer mais controle: parar no meio, porque já achou o que procurava, ou pular uma volta, porque aquele item não interessa. Para isso existem duas palavras: break ("quebrar": sai do laço agora) e continue ("continuar": pula o resto desta volta e vai para a próxima).

Você vai aprender
  • O break: sair do laço assim que achar o que procurava.
  • O while (true) com break: o laço com a saída no meio.
  • O continue: pular as voltas que não interessam.
  • A armadilha do continue dentro do while, que cria um laço infinito.
  • Laços dentro de laços: o break só sai do laço de dentro, e os rótulos (break procura;) resolvem isso.
  • Os erros reais: break fora de laço e rótulo que não existe.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook), com dart run arquivo.dart.

A ideia: procurar o café na prateleira

A Ana está no mercado procurando o café. Ela olha a prateleira produto por produto, da esquerda para a direita. Quando acha o café, ela para de olhar: não faz sentido conferir o resto da prateleira. Isso é o break.

Agora outra cena: a professora soma as notas da turma, mas quem faltou à prova está marcado com -1. Quando ela chega num -1, ela pula aquele aluno e segue para o próximo. Ela não para de somar; só ignora aquele. Isso é o continue.

1. break: parar quando achar

void main() {
  final prateleira = ['arroz', 'feijão', 'café', 'açúcar', 'leite'];
  for (final produto in prateleira) {
    print('Olhando: $produto');
    if (produto == 'café') {
      print('Achei o café!');
      break;
    }
  }
  print('Fim da procura.');
}

2. while (true) com break: a saída no meio

Na aula while e do-while, você viu que while (true) é um laço que nunca para sozinho, porque a condição é sempre verdadeira. Com um break lá dentro, ele vira um laço com a saída onde você quiser. A Ana enche uma caixa de 6 ovos:

void main() {
  var ovos = 0;
  while (true) {
    ovos++;
    print('Coloquei o ovo $ovos na caixa');
    if (ovos == 6) {
      break;
    }
  }
  print('Caixa cheia: $ovos ovos.');
}

$ dart run ovos.dart
Coloquei o ovo 1 na caixa
Coloquei o ovo 2 na caixa
Coloquei o ovo 3 na caixa
Coloquei o ovo 4 na caixa
Coloquei o ovo 5 na caixa
Coloquei o ovo 6 na caixa
Caixa cheia: 6 ovos.

Aqui daria para escrever while (ovos < 6), sem break. O while (true) brilha quando a decisão de sair depende de algo que só se sabe no meio da volta, como a resposta que a pessoa digitou. Você vai usar muito esse formato na próxima aula, Lendo o Teclado: "pergunte; se a resposta for sair, break; senão, trate a resposta e pergunte de novo".

3. continue: pular uma volta

As notas da turma, com -1 para quem faltou. A média só deve contar quem fez a prova:

void main() {
  final notas = [8, -1, 6, 9, -1, 7];
  var soma = 0;
  var quantas = 0;
  for (final nota in notas) {
    if (nota < 0) {
      print('Faltou: pulando');
      continue;
    }
    soma += nota;
    quantas++;
    print('Somei a nota $nota');
  }
  print('Média de $quantas provas: ${soma / quantas}');
}
if (nota < 0) { … continue; }
Se a nota é de quem faltou, mostra o aviso e dá continue: "esquece o resto desta volta, vai para a próxima nota".
soma += nota; quantas++;
Só chegam aqui as notas que não foram puladas.
${soma / quantas}
A média: a soma dividida pela quantidade. O / sempre dá um double (veja Operadores Aritméticos).
$ dart run notas.dart
Somei a nota 8
Faltou: pulando
Somei a nota 6
Somei a nota 9
Faltou: pulando
Somei a nota 7
Média de 4 provas: 7.5

Repare que o laço não parou no primeiro -1: ele pulou aquela volta e continuou até o fim. Com break no lugar do continue, o programa pararia de somar na segunda nota.

O continue numa linha só

Quando o if só tem o continue, muita gente escreve tudo numa linha. Este programa mostra só os números pares de 1 a 10, pulando os ímpares (i % 2 != 0: "o resto da divisão por 2 não é zero"):

void main() {
  for (var i = 1; i <= 10; i++) {
    if (i % 2 != 0) continue;
    print(i);
  }
}

$ dart run pares.dart
2
4
6
8
10

Esse estilo se chama cláusula de guarda: as linhas do começo "barram" o que não interessa, e o resto do bloco fica sem um if em volta, mais fácil de ler.

Missão: a professora decidiu que nota zero também é falta (o aluno entregou a prova em branco porque chegou atrasado). Mude a condição do continue para pular as notas menores ou iguais a zero.

4. A armadilha: continue no while

No for, o passo (i++) fica no cabeçalho e roda mesmo depois de um continue. No while, o passo é uma linha do bloco, e o continue pode pular por cima dele:

void main() {
  var i = 0;
  while (i < 5) {
    if (i == 2) {
      continue;
    }
    print('i = $i');
    i++;
  }
  print('Fim!');
}

$ timeout 3 dart run continue_while.dart
i = 0
i = 1
$ echo $?
124

O programa mostrou i = 0 e i = 1 e travou. Quando i vale 2, o continue volta para a condição sem passar pelo i++; i continua 2, o continue acontece de novo, e assim para sempre. Quem parou o programa foi o timeout 3, depois de 3 segundos (o código 124 é o aviso do timeout: "precisei parar"). Como consertar: faça o passo antes do continue, ou use um for, que cuida do passo sozinho:

void main() {
  for (var i = 0; i < 5; i++) {
    if (i == 2) continue;
    print('i = $i');
  }
  print('Fim!');
}

5. Laço dentro de laço: o break só sai de um

O break e o continue agem sobre o laço mais de dentro, aquele em que eles estão. Veja o que acontece com um break no laço das cadeiras, que está dentro do laço das mesas:

void main() {
  for (var mesa = 1; mesa <= 3; mesa++) {
    for (var cadeira = 1; cadeira <= 3; cadeira++) {
      if (cadeira == 2) break;
      print('Mesa $mesa, cadeira $cadeira');
    }
  }
}

$ dart run aninhado.dart
Mesa 1, cadeira 1
Mesa 2, cadeira 1
Mesa 3, cadeira 1

O break saiu só do laço das cadeiras. O laço das mesas continuou: mesa 2, mesa 3. Em cada mesa, a cadeira 2 interrompeu as cadeiras daquela mesa.

Rótulos: sair dos dois laços de uma vez

No cinema, a Ana quer a primeira cadeira livre. Achou, acabou: não deve olhar mais nenhuma fila. Para o break sair do laço de fora, dê um rótulo (um nome seguido de :) a esse laço e escreva break nomeDoRotulo;:

void main() {
  final cinema = [
    ['ocupada', 'ocupada', 'livre'],
    ['livre', 'ocupada', 'livre'],
  ];
  var fila = 0;
  procura:
  for (final linha in cinema) {
    fila++;
    var cadeira = 0;
    for (final lugar in linha) {
      cadeira++;
      if (lugar == 'livre') {
        print('Primeira cadeira livre: fila $fila, cadeira $cadeira');
        break procura;
      }
    }
  }
  print('Fim.');
}
final cinema = [[…], […]];
Uma lista de filas; cada fila é uma lista de lugares (listas dentro de lista; veja Listas).
procura:
O rótulo: um nome qualquer seguido de dois-pontos, logo antes do laço de fora. Ele não faz nada sozinho; só dá um nome ao laço.
break procura;
"Sai do laço chamado procura": abandona os dois laços de uma vez e vai para o print('Fim.'). Também existe continue procura;: pula para a próxima volta do laço de fora.
$ dart run rotulo.dart
Primeira cadeira livre: fila 1, cadeira 3
Fim.

A fila 2 também tem cadeiras livres, mas ninguém olhou: o break procura; saiu de tudo. Sem o rótulo, o break sairia só das cadeiras da fila 1, e o programa mostraria também a fila 2.

Missão: este programa mostra uma cadeira livre de cada fila, porque o break só sai do laço de dentro. Dê o rótulo procura: ao laço de fora e troque o break; por break procura;, para mostrar só a primeira.

E o break no switch?

Quem vem de outras linguagens escreve break no fim de cada case de um switch. No Dart 3 ele não é necessário: cada case termina sozinho (veja switch e Expressões switch). Um break lá dentro é permitido, mas não muda nada.

Formas diferentes de fazer a mesma coisa

A procura do café também pode ser escrita sem break, com um while e uma variável que diz se já achou:

void main() {
  final prateleira = ['arroz', 'feijão', 'café', 'açúcar', 'leite'];
  var i = 0;
  var achou = false;
  while (i < prateleira.length && !achou) {
    print('Olhando: ${prateleira[i]}');
    if (prateleira[i] == 'café') {
      achou = true;
    }
    i++;
  }
  print('Fim da procura.');
}

Funciona, mas tem mais peças para cuidar (o índice i, a variável achou, a condição dupla). E, para só saber se existe, as listas têm um método pronto: prateleira.contains('café') devolve true ou false sem laço nenhum (veja Métodos de Lista).

Rótulo que não existe 
void main() {
  for (var i = 0; i < 3; i++) {
    for (var j = 0; j < 3; j++) {
      break externo;

  }

"Não dá para sair para externo": nenhum laço em volta tem esse rótulo. Como consertar: escreva externo: antes do laço de fora (externo: for (var i = 0; …)), ou corrija o nome se ele foi digitado diferente.

O continue que trava o while

Revise a seção 4: no while, um continue antes do passo (i++) deixa a variável parada e o laço não termina. O Dart não acusa nada; o programa só fica "pensando". Pare com Ctrl+C (ou o ■ Parar do editor) e mova o passo para antes do continue.

Missão: a Ana queria pular só o 2, mas usou break, e o laço parou de vez (rode e veja: só 0 e 1). Troque o break por continue. Cuidado: se você só trocar a palavra, o laço trava no 2 (pare com ■ Parar); o i++ tem de acontecer antes do continue. O resultado certo mostra 0, 1, 3, 4 e Fim!.

void main() {
  var i = 0;
  while (i < 5) {
    if (i == 2) {
      break;
    }
    print('i = $i');
    i++;
  }
  print('Fim!');
}

void main() {
  var i = 0;
  while (i < 5) {
    if (i == 2) {
      i++;
      continue;
    }
    print('i = $i');
    i++;
  }
  print('Fim!');
}

Missão final: o primeiro múltiplo de 7

Missão: descubra o primeiro múltiplo de 7 maior que 50. Do jeito que está, o break sai na primeira volta, sem fazer nada. Antes dele, some 1 em n, e ponha o break dentro de um if: só saia quando n % 7 == 0 ("o resto da divisão por 7 é zero").

void main() {
  var n = 50;
  while (true) {
    // some 1 em n aqui
    break; // saia só se n for múltiplo de 7
  }
  print('Primeiro múltiplo de 7 depois de 50: $n');
}

void main() {
  var n = 50;
  while (true) {
    n++;
    if (n % 7 == 0) break;
  }
  print('Primeiro múltiplo de 7 depois de 50: $n');
}

Resumo

  • break; sai do laço agora; o programa segue na linha depois dele.
  • continue; abandona só a volta atual e vai para a próxima.
  • while (true) + break é o laço com a saída no meio, ótimo para "repita até a pessoa mandar parar".
  • No while, cuidado: um continue antes do passo trava o laço.
  • Os dois agem no laço mais de dentro. Para sair do de fora, use um rótulo: procura: for (…) e break procura;.
  • Fora de um laço (ou switch), break e continue são erro de compilação.
