Dart Métodos de Lista

Na aula Listas, você criou listas, leu itens pela posição e acrescentou com add. Mas a vida real pede mais: o cliente que fura a fila, o item riscado da lista de compras, "tem café na lista?", "põe as notas em ordem". Para tudo isso, a List traz métodos prontos. Esta aula mostra os mais usados, agrupados pelo que fazem.

Você vai aprender
  • Acrescentar: add, addAll e insert (no meio da fila).
  • Remover: remove, removeAt, removeLast, removeWhere e clear, e o que cada um devolve.
  • Procurar: contains, indexOf (e o famoso -1) e indexWhere.
  • Ordenar: sort, do menor para o maior, ao contrário e por qualquer critério.
  • Pedaços e textos: sublist, reversed e join.
  • Os erros reais: remover durante o for, o -1 usado como posição, o sort que não devolve nada e o reversed que não aceita [0].

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a fila do caixa

Pense na fila do caixa da padaria. Chega gente no fim (acrescentar); a Dona Rosa, que tem prioridade, vai para a frente (inserir numa posição); alguém desiste e sai (remover); a moça do caixa pergunta "a Bia está na fila?" (procurar); e, no fim do dia, o dono quer a lista dos clientes em ordem alfabética (ordenar). Cada uma dessas ações é um método da lista, chamado com um ponto: fila.add(…), fila.insert(…)…

Uma regra vale para quase todos: eles mudam a própria lista (não criam outra). Os que criam uma lista ou um valor novo estão avisados na tabela do fim.

1. Acrescentar: add, addAll e insert

void main() {
  final fila = ['Ana', 'Bia'];
  fila.add('Caio');
  print(fila);
  fila.addAll(['Davi', 'Edu']);
  print(fila);
  fila.insert(0, 'Dona Rosa');
  print(fila);
  fila.insert(2, 'Fabi');
  print(fila);
}

Um item, no fim.

"Acrescentar todos": vários itens de uma vez, no fim, na ordem em que vieram.

"Inserir" na posição 0, a primeira. Quem estava lá e todos depois andam uma casa para trás: a Ana, que era a 0, vira a 1.

Fabi entra na posição 2, entre a Ana e a Bia. O primeiro argumento é sempre a posição; o segundo, o item.

2. Remover

void main() {
  final compras = ['arroz', 'feijão', 'café', 'leite', 'pão'];
  final tirou = compras.remove('café');
  print('$tirou $compras');
  final naoTinha = compras.remove('bolo');
  print('$naoTinha $compras');
  final segundo = compras.removeAt(1);
  print('$segundo $compras');
  final ultimo = compras.removeLast();
  print('$ultimo $compras');
  compras.clear();
  print(compras);
}

$ dart run remover.dart

false [arroz, feijão, leite, pão]
feijão [arroz, leite, pão]
pão [arroz, leite]
[]
compras.remove('café') → true
Remove o item pelo valor (a primeira vez que ele aparece) e devolve true: "achei e tirei".
compras.remove('bolo') → false
Não havia bolo: devolve false e a lista fica igual. Não dá erro; se quiser saber, olhe o que ele devolveu.
compras.removeAt(1) → feijão
Remove pela posição e devolve o item que tirou. Quem vinha depois anda uma casa para a frente.
compras.removeLast() → pão
Remove o último e devolve-o.
compras.clear()
"Limpar": tira tudo. A lista continua existindo, vazia: [].

Remover todos que obedecem a uma regra: removeWhere

A Ana quer tirar da lista tudo o que custa mais de R$ 30. O removeWhere ("remover onde") recebe uma função que responde, para cada item, "tira este?" (veja Funções Anônimas):

void main() {
  final precos = [4.5, 32.0, 12.9, 55.0, 3.25];
  precos.removeWhere((p) => p > 30);
  print(precos);
}

$ dart run removewhere.dart
[4.5, 12.9, 3.25]

O contrário também existe: retainWhere ("manter onde") fica só com os que obedecem à regra.

4. Ordenar: sort

void main() {
  final nomes = ['Bia', 'ana', 'Caio', 'Álvaro'];
  nomes.sort();
  print(nomes);
  final notas = [7.5, 10.0, 6.0, 8.5];
  notas.sort();
  print(notas);
  notas.sort((a, b) => b.compareTo(a));
  print(notas);
  final palavras = ['pão', 'banana', 'kiwi', 'abacaxi'];
  palavras.sort((a, b) => a.length.compareTo(b.length));
  print(palavras);
}

$ dart run ordenar.dart
[Bia, Caio, ana, Álvaro]
[6.0, 7.5, 8.5, 10.0]
[10.0, 8.5, 7.5, 6.0]
[pão, kiwi, banana, abacaxi]
nomes.sort() → [Bia, Caio, ana, Álvaro]
Sem argumento, o sort ("ordenar") usa a ordem natural. Para textos, isso é a ordem dos códigos dos caracteres, e não a do dicionário: todas as maiúsculas vêm antes das minúsculas, e as letras com acento vêm depois de tudo. Por isso ana e Álvaro ficaram no fim.
notas.sort() → do menor para o maior
Para números, a ordem natural é a esperada.
sort((a, b) => b.compareTo(a))
Com uma função, você decide a ordem. a.compareTo(b) dá um número negativo se a vem antes, zero se empatam, positivo se vem depois. Trocando para b.compareTo(a), a ordem se inverte: do maior para o menor.
sort((a, b) => a.length.compareTo(b.length))
Qualquer critério: aqui, o tamanho da palavra.
Ordem alfabética sem bagunça de maiúsculas

Compare as versões em minúsculas: nomes.sort((a, b) => a.toLowerCase().compareTo(b.toLowerCase()));. Assim ana vai para perto de Bia. As letras acentuadas continuam indo para o fim; para a ordem perfeita do português é preciso um pacote de idioma (como o intl; veja Pacotes).

Missão: ponha as notas do maior para o menor antes de mostrar.

  print(notas);
}

void main() {

  notas.sort((a, b) => b.compareTo(a));

5. Pedaços e textos: sublist, reversed e join

Estes três não mudam a lista original: eles criam algo novo.

void main() {
  final ranking = ['Ana', 'Bia', 'Caio', 'Davi', 'Edu'];
  print(ranking.sublist(0, 3));
  print(ranking.sublist(3));
  print(ranking.reversed);
  print(ranking.reversed.toList());
  print(ranking.join(', '));
  print(ranking.join(' > '));
  print(ranking);
}

$ dart run pedacos.dart
[Ana, Bia, Caio]
[Davi, Edu]
(Edu, Davi, Caio, Bia, Ana)
[Edu, Davi, Caio, Bia, Ana]
Ana, Bia, Caio, Davi, Edu
Ana > Bia > Caio > Davi > Edu
[Ana, Bia, Caio, Davi, Edu]
sublist(0, 3)
Uma lista nova com as posições de 0 até antes de 3 (0, 1 e 2): o pódio. O segundo número não entra.
sublist(3)
Sem o segundo número: da posição 3 até o fim.
reversed → (Edu, …, Ana)
"Invertida". Repare nos parênteses no lugar dos colchetes: o reversed não devolve uma List, e sim um Iterable (uma sequência que dá para percorrer, mas não tem [0]). O assunto é explicado em map, where, reduce e Outros.
reversed.toList()
Transforma a sequência numa lista de verdade, com colchetes.
join(', ')
"Juntar": cria um texto só, com os itens separados pelo que você passar.
print(ranking)
A lista original continua igual: nenhum dos três mexeu nela.

  final compras = ['arroz', 'feijão', 'café'];
  for (final item in compras) {
    if (item == 'feijão') {
      compras.remove(item);
    }
  }
  print(compras);
}

"Modificação simultânea durante a iteração": a lista mudou de tamanho enquanto o for a percorria. É como tirar uma pessoa da fila enquanto alguém conta a fila: a contagem se perde, e o Dart prefere parar.

"Esta expressão tem o tipo void e não pode ser usada." O sort ordena a própria lista e não devolve nada (void, "vazio"). Como consertar: chame notas.sort(); numa linha e use notas depois. Se precisa manter a original, copie antes: final ordenadas = [...notas]..sort(); (o .. chama o método e devolve a própria lista; veja Espalhando Coleções).

Missão final: a lista de compras arrumada

Missão: a lista tem o 'feijão' repetido, que já foi comprado. Remova todos os 'feijão', ordene a lista e mostre-a como texto separado por vírgula e espaço: arroz, café, leite, pão.

void main() {
  final compras = ['pão', 'feijão', 'arroz', 'leite', 'feijão', 'café'];
  print(compras);
}

void main() {
  final compras = ['pão', 'feijão', 'arroz', 'leite', 'feijão', 'café'];
  compras.removeWhere((item) => item == 'feijão');
  compras.sort();
  print(compras.join(', '));
}

Resumo

  • Acrescentar: add (fim), addAll (vários), insert(posição, item) (no meio).
  • Remover: remove(valor) devolve true/false; removeAt(posição) e removeLast() devolvem o item; removeWhere(regra) tira vários; clear() esvazia.
  • Procurar: contains (sim/não), indexOf (posição ou -1), indexWhere (por regra).
  • sort() ordena a própria lista e não devolve nada; com (a, b) => b.compareTo(a), ao contrário.
  • sublist, reversed e join não mexem na lista; o reversed é um Iterable (parênteses no print, sem [i]).
  • Nunca mude a lista dentro do for-in que a percorre.
