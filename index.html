Tutorial Dart

Você não precisa instalar nada para começar, em qualquer sistema: Windows, macOS, Linux ou até um Chromebook.

Experimente agora

A caixa abaixo é o editor Experimente do guia. Em cima fica o programa; clique em ▶ Rodar e o que ele escreve aparece embaixo, num terminal. Na primeira vez, o editor baixa o Dart do guia (uns 180 KB, menos que uma foto); depois, é na hora. Pode mexer à vontade: nada que você fizer aqui estraga o guia.

Missão: rode o programa como está e veja a lista de compras da Ana. Depois, ela lembrou que acabou a manteiga: acrescente 'manteiga' na lista da segunda linha (depois de 'café', com uma vírgula antes) e rode de novo.

void main() {
  var compras = ['pão', 'leite', 'café'];
  for (var item in compras) {
    print('Comprar: $item');
  }
  print('Total de itens: ${compras.length}');
}

void main() {
  var compras = ['pão', 'leite', 'café', 'manteiga'];
  for (var item in compras) {
    print('Comprar: $item');
  }
  print('Total de itens: ${compras.length}');
}

O que aconteceu: você escreveu um programa, uma lista de instruções que o computador segue na ordem. Lido em voz alta, ele diz: "a lista de compras é pão, leite, café e manteiga; para cada item da lista, escreva 'Comprar: ' e o item; no fim, escreva quantos itens a lista tem". O Dart seguiu as instruções e escreveu uma linha por item. Você não precisou mudar o resto do programa: ele se adaptou sozinho à lista maior. Essa língua de instruções é o Dart, e é isso que este guia ensina.

Se você esqueceu de fechar as aspas ('manteiga]), viu uma mensagem em vermelho, em inglês: main.dart:2:42: Error: String starting with ' must end with '. ("o texto que começa com ' tem de terminar com '", na linha 2, coluna 42). E se esqueceu a vírgula? Aí não houve erro nenhum, e sim uma surpresa: Comprar: cafémanteiga e Total de itens: 3. Em Dart, dois textos colados um no outro viram um texto só. O computador não adivinha o que você quis dizer: ele faz exatamente o que está escrito. Errar e ler o que ele responde é metade do aprendizado: todas as aulas mostram os erros mais comuns, com a mensagem real e o jeito de consertar.

Um programa que conversa

Programas também podem perguntar. Rode a caixa, digite o seu nome no terminal dela (no campo que aparece depois da pergunta) e tecle Enter:

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  var nome = stdin.readLineSync();
  print('Olá, $nome! Bem-vinda ao Dart.');
}

O que é este guia

Um programa é uma receita que o computador segue. O Dart é uma língua para escrever essas receitas, criada pelo Google e apresentada em 2011. Ela é a linguagem do Flutter, a ferramenta do Google para fazer aplicativos de celular (Android e iPhone), de computador e da web com um código só. Mas o Dart também roda sozinho, em programas de terminal, e é assim que este guia o ensina: sem telas, só você, o código e o que ele responde. A aula O que é Dart conta essa história.

Quem aprende Dart consegue:

  • fazer o computador repetir tarefas e tomar decisões: "se a nota for 7 ou mais, aprovada; senão, recuperação";
  • guardar e organizar informações em listas, conjuntos e mapas: o estoque da lojinha, a agenda de contatos;
  • escrever programas que não quebram por causa de um valor "vazio", graças ao null safety, a marca registrada do Dart;
  • organizar programas grandes em funções, classes e pacotes, ler e gravar arquivos e JSON, e esperar respostas lentas com async e await;
  • dar o próximo passo para o Flutter e criar os seus próprios aplicativos (aula Dart e Flutter).

O guia é para quem nunca programou. Ele começa do zero absoluto (o que é um programa? como se roda um?) e vai até classes, genéricos, records, patterns, código assíncrono, pacotes do pub.dev e testes. Cada aula ensina um assunto só, com calma. O Dart das aulas é o Dart 3; o que chegou numa versão recente ganha um selo com o número da versão.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, você entende o problema que ele resolve, com uma comparação do dia a dia: uma receita de bolo, uma caixa com etiqueta, uma lista de compras.
  2. Anatomia. Cada parte de um comando novo é separada e explicada.
  3. A saída real. Depois de cada exemplo, o que o Dart respondeu de verdade, no terminal. Nenhuma saída foi inventada.
  4. Experimente. Pelo menos duas caixas por aula para você mudar o código e rodar, muitas com uma missão que confere sozinha se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um jeito de escrever a mesma coisa, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro e a mensagem real do Dart (main.dart:3:9: Error: …, ou o Unhandled exception: com o rastro #0 …), traduzida e explicada linha por linha.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de um programa

Veja como as aulas desmontam um programa. Primeiro o código, num arquivo chamado compras.dart:

void main() {
  var compras = ['pão', 'leite', 'café'];
  for (var item in compras) {
    print('Comprar: $item');
  }
  print('Total de itens: ${compras.length}');
}

Agora cada parte:

void main() { … }
A função principal: todo programa Dart começa a rodar por ela. As chaves { } marcam onde ela começa e termina (aula Seu Primeiro Programa).
var compras = ['pão', 'leite', 'café'];
Uma variável: um nome (compras) que guarda um valor. Aqui o valor é uma lista com três textos, entre colchetes. O ; encerra a instrução (aulas Variáveis, Listas e Instruções, Ponto e Vírgula e Blocos).
for (var item in compras) {
"Para cada item de compras, faça": repete o bloco de baixo uma vez para cada elemento da lista (aula for-in).
print('Comprar: $item');
O bloco que se repete. O $item põe o valor do item dentro do texto (aula Interpolação). Os 2 espaços no começo são para você enxergar que a linha está "dentro" do for.
}
Fecha o bloco do for.
print('Total de itens: ${compras.length}');
Depois do }: roda uma vez só. O compras.length é o tamanho da lista; o ${…} põe o resultado dentro do texto.

Exemplo: o terminal

Além do editor, as aulas mostram o terminal da máquina das aulas: um computador chamado notebook, da usuária ana, com o Dart SDK oficial instalado. Lá, o programa fica no arquivo compras.dart, e quem o roda é o comando dart run:

$ dart run compras.dart
Comprar: pão
Comprar: leite
Comprar: café
Total de itens: 3

E o programa que conversa (salvo como conversa.dart), com a Ana digitando o nome dela:

$ dart run conversa.dart
Qual é o seu nome? Ana
Olá, Ana! Bem-vinda ao Dart.

A resposta é a mesma do editor. A aula O Editor do Guia mostra tudo o que as caixas Experimente sabem fazer e o que muda no terminal, e Instalar o Dart ensina a pôr o Dart no seu computador.

Como estudar

Programar se aprende programando, como quem aprende a cozinhar cozinhando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte "Quando dá errado": quem entende a mensagem de erro conserta o problema em segundos.
  2. Mexa nos exemplos. Em toda caixa Experimente, mude um número, troque um texto, apague um pedaço de propósito e veja o que o Dart responde. Não tem como estragar nada: cada Rodar começa do zero.
  3. Faça as missões. As caixas com Missão conferem sozinhas se você acertou. Tente de verdade antes de abrir a solução; se abrir, digite a solução você mesmo em vez de só olhar.
  4. Repita no seu computador. Quando chegar à aula Instalar o Dart, instale-o e refaça os programas no terminal. Algumas coisas (criar projetos, baixar pacotes do pub.dev, rodar testes, compilar um executável, guardar arquivos de verdade) só existem lá.
A regra de ouro

Ler não basta: digite cada programa. Copiar e colar ensina pouco; digitar faz você reparar em cada aspa, cada ; e cada chave. Comece pela aula O que é Dart e, antes de ir longe, dê uma olhada em O Editor do Guia.

Versão de referência: Dart 3

O guia ensina o Dart 3. Todas as saídas de terminal foram colhidas no Dart SDK 3.13.5 oficial (o mesmo que você baixa em dart.dev), num Ubuntu 26.04 em português do Brasil. As mensagens do Dart saem em inglês, exatamente como ele as escreve, e as aulas as explicam em português.

O editor das caixas Experimente é outra coisa: o Dart do guia, um tradutor de Dart para JavaScript feito para estas aulas, que roda no seu navegador e imita o dart run. Ele dá as mesmas respostas nos programas das aulas, mas não é o SDK oficial: às vezes mostra menos mensagens de erro de uma vez, e não tem pacotes nem outros programas. A aula O Editor do Guia conta as diferenças.
