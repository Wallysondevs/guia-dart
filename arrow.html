Dart Funções de Uma Linha (=>)

Muitas funções são só um cálculo: { return numero * 2; }. Para esses casos, o Dart tem um atalho: a seta => (em inglês, arrow; também chamada de "fat arrow", a seta gorda). int dobro(int numero) => numero * 2; quer dizer exatamente o mesmo que a versão com chaves e return, numa linha só. Você vai ver essa seta por todo lado, principalmente nas funções sem nome das próximas aulas.

Você vai aprender
  • Que => expressão; é um atalho para { return expressão; }.
  • Funções void de uma linha: void saudar(String nome) => print(…);.
  • A diferença entre expressão (tem valor) e instrução (faz algo), e por que só a primeira cabe depois da seta.
  • O ternário (? :) no lugar do if, numa função de seta.
  • A armadilha: chaves depois da seta não são um bloco, são um Set.
  • Os erros reais: return depois da seta, if depois da seta, ponto e vírgula esquecido.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook), com dart run arquivo.dart.

A ideia: "é só isso"

Algumas receitas do caderno da padaria têm várias etapas ("misture, sove, deixe crescer, asse"). Outras cabem numa frase: "dobro da receita = tudo vezes dois". Para a receita de uma frase, não precisa de folha inteira. A seta é isso: a função cujo corpo inteiro é "devolva isto".

Forma com corpoForma com seta
int dobro(int numero) {
  return numero * 2;
}		int dobro(int numero) => numero * 2;

Leia => como "devolve": "dobro de numero devolve numero * 2".

1. A primeira função de seta

int dobroLongo(int numero) {
  return numero * 2;
}

int dobro(int numero) => numero * 2;

void main() {
  print(dobroLongo(21));
  print(dobro(21));
}
int dobro(int numero)
O começo é igual ao de qualquer função (veja Funções): tipo de retorno, nome, parâmetros.
=>
A seta: um sinal de igual e um sinal de maior, juntos, sem espaço entre eles. Substitui o { return.
numero * 2
A expressão cujo valor a função devolve. Uma só.
;
O ponto e vírgula fecha a função (no lugar do ; }).
$ dart run dobro.dart

As duas funções são idênticas para o Dart: mesmo resultado, mesma velocidade. A seta é só uma forma mais curta de escrever.

2. Uma lojinha de funções de uma linha

Funções de seta combinam com cálculos curtos, perguntas de sim ou não e formatação. Um pouco de tudo, na padaria:

double totalDaCompra(double preco, int quantidade) => preco * quantidade;

String formatarPreco(double valor) => 'R\$ ${valor.toStringAsFixed(2)}';

bool estaAberta(int hora) => hora >= 6 && hora < 20;

String situacao(double media) => media >= 7 ? 'aprovada' : 'reprovada';

void saudar(String nome) => print('Bom dia, $nome!');

void main() {
  saudar('Ana');
  print(formatarPreco(totalDaCompra(0.75, 10)));
  print(estaAberta(7));
  print(estaAberta(22));
  print(situacao(8.5));
}

Não cabe um if depois da seta (seção 3), mas cabe o ternário, que é o "if de expressão" (veja O Operador Ternário).

Funciona com void também: a função só executa o print e não devolve nada. É comum em funções de uma ação só.

Funções de seta se chamam e se combinam como quaisquer outras.

3. Só cabe uma expressão

Depois da seta vem uma expressão: algo que tem um valor. Não cabem instruções, que são ordens que fazem algo mas não "valem" nada.

Expressão (cabe depois da =>)Instrução (não cabe)
numero * 2 · 'R\$ $valor' · hora >= 6final taxa = valor * 0.1; (criar variável)
media >= 7 ? 'aprovada' : 'reprovada' (ternário)if (…) … else …
print('oi') · dobro(5) (chamadas)for, while
nome ?? 'visitante'return … (a seta já é o return)

Se a função precisa de uma variável de apoio, de um if com várias linhas ou de um laço, use o corpo com chaves. A seta não é "melhor": ela é para quando a função inteira é "devolva isto".

4. A armadilha: chaves depois da seta

Quem está aprendendo às vezes junta as duas formas: => { … }. Parece um bloco, mas não é. Depois da seta, {numero * 2} é uma expressão: um Set, um conjunto com um elemento (veja Conjuntos). Com tipo de retorno, o Dart pega:

int dobro(int numero) => {numero * 2};

void main() {
  print(dobro(21));
}

$ dart run err_chaves.dart
err_chaves.dart:1:26: Error: A value of type 'Set<int>' can't be returned from a function with return type 'int'.
 - 'Set' is from 'dart:core'.
int dobro(int numero) => {numero * 2};
                         ^

"Um valor do tipo Set<int> não pode ser devolvido por uma função com tipo de retorno int." O Dart viu as chaves como um conjunto de inteiros. Com void, é pior: não dá erro.

void saudar(String nome) => {
  print('Bom dia, $nome!')
};

void main() {
  saudar('Ana');
}

$ dart run err_chaves_void.dart
Bom dia, Ana!
$ dart analyze err_chaves_void.dart
Analyzing err_chaves_void.dart...

warning - err_chaves_void.dart:1:29 - Braces unnecessarily wrap this expression in a set literal. Try removing the set literal around the expression. - unnecessary_set_literal

1 issue found.

Rodou "por acaso": o Dart montou um conjunto com o resultado do print e jogou fora (a função é void). Só o dart analyze avisou: "as chaves embrulham a expressão num set literal sem necessidade" (veja Análise e Formatação). Repare também que não cabe um ; depois do print ali dentro, sinal de que aquilo não é um bloco de instruções. A regra: ou => expressão;, ou { … }. Nunca os dois.

Formas diferentes de fazer a mesma coisa

A função situacao de três jeitos:

// 1) corpo com if e dois return
String situacao1(double media) {
  if (media >= 7) {
    return 'aprovada';
  }
  return 'reprovada';
}

// 2) corpo com o ternário
String situacao2(double media) {
  return media >= 7 ? 'aprovada' : 'reprovada';
}

// 3) seta com o ternário
String situacao3(double media) => media >= 7 ? 'aprovada' : 'reprovada';

void main() {
  print(situacao1(6.5));
  print(situacao2(6.5));
  print(situacao3(6.5));
}

Quando dá errado

Escreveu return depois da seta 
int dobro(int numero) => return numero * 2;

void main() {
  print(dobro(21));
}

$ dart run err_return.dart
err_return.dart:1:26: Error: Unexpected token 'return'.
int dobro(int numero) => return numero * 2;
                         ^^^^^^

"Símbolo inesperado: return." A seta já quer dizer "devolva". Como consertar: apague o return: => numero * 2;.

Pôs um if depois da seta 
String situacao(double media) => if (media >= 7) 'aprovada' else 'reprovada';

void main() {
  print(situacao(8.5));
}

O Dart respondeu com 11 erros para essa única linha. Os três primeiros:

"Esperava um identificador (um nome), mas veio if" e "if não pode ser usado como nome, porque é uma palavra-chave". Depois da seta, o Dart esperava uma expressão, e if é instrução. Daí em diante ele se perde e reclama de tudo (else, as aspas, o ;…): quando aparecem muitos erros de uma vez, leia só o primeiro. Como consertar: use o ternário, => media >= 7 ? 'aprovada' : 'reprovada';, ou volte para o corpo com chaves.

Tentou criar uma variável depois da seta

double totalComTaxa(double valor) => final taxa = valor * 0.1; valor + taxa; também dá uma cascata de erros, começando por Error: Expected an identifier, but got 'final'. Criar variável é instrução. Como consertar: faça a conta inteira numa expressão (=> valor + valor * 0.1;) ou use chaves:

double totalComTaxa(double valor) {
  final taxa = valor * 0.1;
  return valor + taxa;
}
Esqueceu o ; no fim 
int dobro(int numero) => numero * 2

void main() {
  print(dobro(21));
}

$ dart run err_ponto.dart
err_ponto.dart:1:35: Error: Expected ';' after this.
int dobro(int numero) => numero * 2
                                  ^
err_ponto.dart:3:1: Error: Unexpected token 'void'.

"Era esperado ; depois disto." Na forma com chaves, o } fecha a função; na forma de seta, quem fecha é o ;. Sem ele, o Dart emenda a função com o void main da linha 3 e se confunde ("símbolo inesperado: void"). Como consertar: => numero * 2;.

A expressão tem o tipo errado 
int metade(int numero) => numero / 2;

void main() {
  print(metade(10));
}

$ dart run err_tipo.dart
err_tipo.dart:1:34: Error: A value of type 'double' can't be returned from a function with return type 'int'.
int metade(int numero) => numero / 2;
                                 ^

A seta não muda as regras de tipo: o / sempre dá double, e a função prometeu int. Como consertar: use a divisão inteira, => numero ~/ 2;, ou mude o tipo de retorno para double.

Resumo

  • => expressão; é um atalho para { return expressão; }. Leia a seta como "devolve".
  • Funciona com qualquer tipo de retorno, inclusive void (void saudar(String n) => print(n);).
  • Depois da seta cabe uma expressão: contas, comparações, chamadas, o ternário. Não cabem if, laços, variáveis nem return.
  • => { … } não é um bloco: é um Set. Ou seta, ou chaves.
  • A função de seta termina com ;.
  • Use a seta quando a função couber, clara, numa linha. A seguir: funções sem nome, onde a seta aparece o tempo todo (Funções Anônimas).
