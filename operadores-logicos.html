Dart Operadores Lógicos

Na aula Comparação, cada pergunta tinha uma condição só: "a idade é maior ou igual a 18?". Mas as regras da vida real costumam juntar várias: "maior de idade e com ingresso", "sábado ou domingo", "não está chovendo". Para juntar perguntas de sim ou não existem os operadores lógicos: && (e), || (ou) e ! (não).

Você vai aprender
  • O && ("e"): verdadeiro só quando as duas partes são verdadeiras.
  • O || ("ou"): verdadeiro quando pelo menos uma parte é verdadeira.
  • O ! ("não"): inverte true e false.
  • As tabelas da verdade, com a saída real do Dart.
  • O curto-circuito: por que alunos > 0 && pontos ~/ alunos >= 5 não quebra com zero alunos.
  • A ordem: && vem antes de ||, e os parênteses resolvem.
  • Os erros reais: and/or por extenso, um número no lugar de um bool, e o dia == 'sábado' || 'domingo'.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: as regras da portaria

O porteiro do show tem duas regras e um aviso:

  • "Só entra quem é maior de idade E tem ingresso." Se faltar qualquer uma das duas coisas, não entra. Isso é o &&.
  • "Paga meia quem é criança OU idoso." Basta uma das duas. Isso é o ||.
  • "Quem NÃO tem pulseira volta para a fila." Inverte a pergunta "tem pulseira?". Isso é o !.

Cada parte (maior de idade? tem ingresso?) é uma comparação que dá true ou false. O operador lógico junta essas respostas numa resposta só, também true ou false.

1. &&: "e"

void main() {
  final idade = 30;
  final temIngresso = true;
  print(idade >= 18 && temIngresso);
  print(idade >= 18 && idade <= 60);
  final idade2 = 70;
  print(idade2 >= 18 && idade2 <= 60);
}

$ dart run e.dart
true
true
false
idade >= 18 && temIngresso
"Tem 18 anos ou mais e tem ingresso?" As duas partes são true, então o resultado é true. A segunda parte já é um bool (a variável temIngresso), e não precisa de == true.
idade >= 18 && idade <= 60
O jeito de dizer "entre 18 e 60" no Dart: duas comparações ligadas por &&. Com 30, as duas são verdade.
idade2 … → false
Com 70, a primeira parte é verdade (70 ≥ 18), mas a segunda não (70 ≤ 60 é falso). Basta uma parte falsa para o && dar false.

O && se escreve com dois "e comercial" (&), grudados. Lê-se "e".

2. ||: "ou"

void main() {
  final dia = 'sábado';
  final fimDeSemana = dia == 'sábado' || dia == 'domingo';
  print('É fim de semana? $fimDeSemana');
  final idade = 8;
  final meiaEntrada = idade < 12 || idade >= 65;
  print('Meia-entrada? $meiaEntrada');
}

$ dart run ou.dart
É fim de semana? true
Meia-entrada? true

O || são duas barras verticais (a tecla fica perto do Enter, com Shift). Basta uma das partes ser verdade: a criança de 8 anos não é idosa, mas é menor de 12, e isso já garante a meia-entrada. Repare que cada lado do || é uma comparação completa: dia == 'sábado' || dia == 'domingo', com o dia == repetido (escrever só || 'domingo' dá erro; veja Quando dá errado).

3. !: "não"

void main() {
  final chovendo = false;
  print('Está chovendo? $chovendo');
  print('Dá para estender a roupa? ${!chovendo}');
  final idade = 15;
  print(!(idade >= 18));
  print(idade < 18);
}

$ dart run nao.dart
Está chovendo? false
Dá para estender a roupa? true
true
true

O ! vai antes do valor e inverte: !false é true. Para inverter uma comparação inteira, use parênteses: !(idade >= 18), "não é maior de idade". Muitas vezes existe uma comparação que já diz o contrário (idade < 18), e ela costuma ser mais fácil de ler. O ! brilha com variáveis bool de nome claro: !chovendo, !temIngresso, !lista.isEmpty.

4. As tabelas da verdade

Com duas partes, só existem quatro combinações. O Dart mostra todas:

void main() {
  print('true  && true  → ${true && true}');
  print('true  && false → ${true && false}');
  print('false && true  → ${false && true}');
  print('false && false → ${false && false}');
  print('true  || true  → ${true || true}');
  print('true  || false → ${true || false}');
  print('false || true  → ${false || true}');
  print('false || false → ${false || false}');
  print('!true          → ${!true}');
  print('!false         → ${!false}');
}

5. O curto-circuito: o Dart para de olhar assim que sabe

O Dart lê da esquerda para a direita e é preguiçoso de um jeito esperto:

  • no a && b, se a já é false, o resultado só pode ser false: o b nem é calculado;
  • no a || b, se a já é true, o resultado só pode ser true: o b nem é calculado.

Isso se chama curto-circuito, e serve de proteção. A professora quer saber se a turma fez, em média, 5 pontos ou mais; mas hoje não veio ninguém:

void main() {
  final alunos = 0;
  final pontos = 30;
  final passou = alunos > 0 && pontos ~/ alunos >= 5;
  print('Passou? $passou');
}

$ dart run curto.dart
Passou? false

Como alunos > 0 deu false, a divisão pontos ~/ alunos nunca foi feita. Agora a mesma pergunta com as partes na ordem trocada:

void main() {
  final alunos = 0;
  final pontos = 30;
  final passou = pontos ~/ alunos >= 5 && alunos > 0;
  print('Passou? $passou');
}

$ dart run curto_err.dart
Unhandled exception:
IntegerDivisionByZeroException
#0      int.~/ (dart:core-patch/integers.dart:27:7)
#1      main (file:///home/ana/curto_err.dart:4:25)
#2      _delayEntrypointInvocation.<anonymous closure> (dart:isolate-patch/isolate_patch.dart:313:19)
#3      _RawReceivePort._handleMessage (dart:isolate-patch/isolate_patch.dart:192:12)

Agora a divisão vem primeiro, e o programa para com a exceção de divisão inteira por zero (a mesma de Operadores Aritméticos), apontando a linha 4, coluna 25: o ~/. A lógica do "e" é a mesma; o que muda é a ordem. Regra prática: ponha a verificação de segurança à esquerda.

O mesmo truque protege contra variáveis vazias (null, veja Tipos Anuláveis):

void main() {
  String? nome;
  final valido = nome != null && nome.length >= 3;
  print('Nome válido? $valido');
  nome = 'Ana';
  print('Nome válido? ${nome != null && nome.length >= 3}');
}

$ dart run curto_null.dart
Nome válido? false
Nome válido? true

O Dart entende o curto-circuito: depois de nome != null &&, ele sabe que nome não é null e deixa usar o nome.length (o número de letras) sem reclamar.

6. A ordem: && antes de ||

Como o * vem antes do +, o && vem antes do ||. E o ! vem antes dos dois. Isso pode mudar a resposta:

void main() {
  final temCupom = false;
  final valor = 30;
  final clienteVip = true;
  print(temCupom && valor > 50 || clienteVip);
  print(temCupom && (valor > 50 || clienteVip));
}

$ dart run precedencia.dart
true
false
temCupom && valor > 50 || clienteVip → true
O Dart faz (temCupom && valor > 50) || clienteVip: "(tem cupom e comprou mais de 50) ou é VIP". O VIP ganha desconto mesmo sem cupom.
temCupom && (valor > 50 || clienteVip) → false
Com os parênteses: "tem cupom e (comprou mais de 50 ou é VIP)". Sem cupom, nada feito.

Duas regras diferentes, só pela posição dos parênteses. Sempre que misturar && e ||, ponha parênteses, mesmo quando a ordem natural já dá o que você quer: quem lê (inclusive você, daqui a um mês) não precisa decorar a tabela.

Formas diferentes de fazer

Uma condição comprida fica mais fácil de ler quando cada parte ganha um nome:

final maiorDeIdade = idade >= 18;
final podeEntrar = maiorDeIdade && temIngresso;

E toda negação de um "e" ou de um "ou" pode ser reescrita (são as chamadas leis de De Morgan): "não (chuva ou frio)" é o mesmo que "não chuva e não frio".

EscritaÉ o mesmo que
!(a || b)!a && !b
!(a && b)!a || !b
!(idade >= 18)idade < 18
!(x == y)x != y
pronto == true / pronto == falsepronto / !pronto (prefira estes)
E o & e o | sozinhos?

Com bool, o Dart também aceita &, | e ^ (um sinal só): no lab, true & false deu false, true | false deu true e true ^ false ("ou exclusivo": um ou outro, mas não os dois) deu true. A diferença é que & e | não fazem curto-circuito: calculam sempre os dois lados. No dia a dia, use && e ||.

Com or, a mensagem é a mesma, sugerindo || (Binary operator 'or' is written as '||' instead of the written out word.). Já o not o Dart nem reconhece como engano: print(not chovendo); dá Error: Undefined name 'not'. ("nome não definido") e mais três erros de quebra; o "não" do Dart é o !.

"Sábado ou domingo" pela metade 
void main() {
  final dia = 'domingo';
  print(dia == 'sábado' || 'domingo');
}

$ dart run err_ou.dart

"Um valor do tipo String não pode ser usado onde se espera um bool." Em português, "o dia é sábado ou domingo" funciona; no Dart, cada lado do || tem de ser uma pergunta de sim ou não, e 'domingo' sozinho é só um texto. Como consertar: repita a comparação: dia == 'sábado' || dia == 'domingo'.

Um número onde o Dart espera true ou false 
void main() {

  if (pessoas && pessoas < 10) {
    print('Mesa pequena');
  }
}

$ dart run err_int.dart

Em linguagens como C, JavaScript e Python, um número diferente de zero "vale" verdadeiro. No Dart, não: &&, || e ! só aceitam bool. O mesmo erro sai com !estoque num int (err_not.dart:3:10: Error: A value of type 'int' can't be assigned to a variable of type 'bool'.). Como consertar: escreva a comparação inteira: pessoas > 0 && pessoas < 10, ou estoque == 0.

A verificação de segurança do lado errado

Já visto na seção 5: pontos ~/ alunos >= 5 && alunos > 0 compila, mas com alunos = 0 para com IntegerDivisionByZeroException. O Dart não reclama da ordem, porque a lógica está certa; quem quebra é a conta. Como consertar: o teste que protege vem primeiro: alunos > 0 && pontos ~/ alunos >= 5.

Missão final: a promoção da padaria

Missão: a padaria dá um brinde para quem compra mais de 50 reais, ou para quem compra mais de 20 reais e tem o cartão fidelidade. Escreva a regra dentro da função ganhaBrinde, no lugar do false, usando &&, || e parênteses.

bool ganhaBrinde(double valor, bool temCartao) {
  return false; // escreva a regra aqui
}

void main() {
  print('Cliente 1 ganha brinde? ${ganhaBrinde(60, false)}');
  print('Cliente 2 ganha brinde? ${ganhaBrinde(30, false)}');
  print('Cliente 3 ganha brinde? ${ganhaBrinde(30, true)}');
}

bool ganhaBrinde(double valor, bool temCartao) {
  return valor > 50 || (valor > 20 && temCartao);
}

void main() {
  print('Cliente 1 ganha brinde? ${ganhaBrinde(60, false)}');
  print('Cliente 2 ganha brinde? ${ganhaBrinde(30, false)}');
  print('Cliente 3 ganha brinde? ${ganhaBrinde(30, true)}');
}

A função (bool ganhaBrinde(…) { return …; }) só serve para testar três clientes de uma vez; você vai aprender a escrever as suas em Funções. Por enquanto, mexa só no que vem depois do return. No lab, a solução mostrou true, false e true.

Resumo

  • && ("e") é true só quando os dois lados são; || ("ou") é true quando pelo menos um é; ! ("não") inverte.
  • Cada lado precisa ser um bool de verdade: no Dart, número e texto não "valem" verdadeiro. dia == 'sáb' || dia == 'dom', com a comparação repetida.
  • Curto-circuito: o Dart para de calcular assim que sabe a resposta. Ponha a verificação de segurança (x != 0, nome != null) à esquerda.
  • A ordem é !, &&, ||; ao misturar && e ||, use parênteses.
  • and, or e not por extenso não existem no Dart: o próprio erro sugere &&, || e !.
