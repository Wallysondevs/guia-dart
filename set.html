Dart Conjuntos (Set)

Uma lista aceita o mesmo valor quantas vezes você quiser: ['Ana', 'Ana', 'Ana'] é uma lista válida. Às vezes, porém, repetir não faz sentido: o álbum de figurinhas não precisa da mesma figurinha duas vezes, e a lista de pessoas que visitaram a loja hoje não deveria contar a Ana três vezes. Para isso existe o conjunto, o tipo Set: uma coleção em que cada valor aparece uma vez só.

Você vai aprender
  • Como criar um Set com chaves { } e o que acontece quando você tenta pôr um repetido.
  • add (que devolve true ou false), contains, remove e length.
  • Como tirar os repetidos de uma lista com toSet().
  • Como criar um conjunto vazio, e por que {} sozinho não é um conjunto.
  • As operações de conjunto: juntar (union), o que tem em comum (intersection) e a diferença (difference).
  • Os erros reais: o [0] que não existe num Set, o {} que virou Map, o const com repetido.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: o álbum de figurinhas

No álbum da Copa, cada figurinha tem o seu lugar. Quando o Caio tira do pacotinho uma figurinha que ele já tem, ela não entra no álbum: vai para o monte das repetidas. O álbum responde rápido a duas perguntas: "essa eu já tenho?" e "quantas eu tenho?". O que o álbum não tem é "a figurinha número 3 que eu colei": o que importa é ter ou não ter.

Um Set é esse álbum: sem repetidos, ótimo para perguntar "tem?", e sem posições numeradas.

1. Criando um conjunto

void main() {
  final album = {'Pelé', 'Marta', 'Garrincha'};
  print(album);
  print(album.length);
  print(album.runtimeType);
  final entrou = album.add('Marta');
  print(entrou);
  print(album.add('Zico'));
  print(album);
  print(album.contains('Pelé'));
  album.remove('Garrincha');
  print(album);
}

Um conjunto literal: os itens entre chaves (a lista usa colchetes). O tipo é Set<String>.
_Set<String>
O runtimeType mostra o nome da classe interna que o Dart usa por baixo (o _ na frente quer dizer "privada"; veja Privacidade). Para você, é um Set<String>.
album.add('Marta') → false
A Marta já estava lá: o add não a coloca de novo e devolve false ("não entrou"). Não é erro: é o conjunto fazendo o trabalho dele.
album.add('Zico') → true
O Zico era novo: entrou, e o add devolve true.
album.contains('Pelé') → true
"Contém?" É a pergunta em que o Set é craque: mesmo com milhares de itens, ele responde sem precisar olhar um por um (a lista precisa).
album.remove('Garrincha')
Tira o item (e devolve true se ele estava lá).
E a ordem?

O Set que você cria com chaves (ou com Set()/toSet()) mostra os itens na ordem em que entraram, como nas saídas acima. Mas ele não tem posições: não dá para pedir "o item número 2" com colchetes (veja Quando dá errado).

Missão: o Caio tirou do pacotinho a Marta (de novo) e o Zico. Faça os dois add mostrando o que cada um devolve, e mostre o álbum no fim.

void main() {
  final album = {'Pelé', 'Marta'};
  // tente pôr a Marta e o Zico, mostrando o que o add devolve
  print(album);
}

void main() {
  final album = {'Pelé', 'Marta'};
  print(album.add('Marta'));
  print(album.add('Zico'));
  print(album);
}

2. Tirando os repetidos de uma lista

O caderno de visitas da loja tem um nome por visita. Quantas pessoas diferentes vieram?

void main() {
  final visitas = ['Ana', 'Bia', 'Ana', 'Caio', 'Bia', 'Ana'];
  final pessoas = visitas.toSet();
  print(pessoas);
  print('${visitas.length} visitas de ${pessoas.length} pessoas');
  final semRepetir = visitas.toSet().toList();
  print(semRepetir);
}

$ dart run repetidos.dart
{Ana, Bia, Caio}
6 visitas de 3 pessoas
[Ana, Bia, Caio]

toSet() cria um conjunto com os itens da lista, e os repetidos somem sozinhos (fica a primeira vez que cada um apareceu). Se você precisa de uma lista de novo (para usar [0] ou sort), toSet().toList(). É o jeito mais curto de "tirar os repetidos" no Dart.

3. O conjunto vazio: cuidado com o {}

void main() {
  final tags = <String>{};
  tags.add('promoção');
  tags.addAll(['pão', 'promoção', 'doce']);
  print(tags);
  final oQueE = {};
  print(oQueE.runtimeType);
}

$ dart run vazio.dart
{promoção, pão, doce}
_Map<dynamic, dynamic>
<String>{}
O jeito certo de criar um conjunto vazio: o tipo entre < > antes das chaves.
addAll([…])
Acrescenta vários de uma vez; o 'promoção' repetido foi ignorado.
{} → _Map<dynamic, dynamic>
A pegadinha: chaves vazias, sem tipo, criam um mapa (Map), e não um conjunto. Mapas também usam chaves (veja Mapas), e o Dart escolheu que {} é mapa. Com itens dentro ({'a', 'b'}), não há dúvida: é conjunto.

4. Operações de conjunto: juntar, comum e diferença

A Ana e a Bia vão dividir a pizza da festa e anotaram do que cada uma gosta:

void main() {
  final ana = {'pizza', 'sorvete', 'pastel', 'açaí'};
  final bia = {'açaí', 'coxinha', 'pizza'};
  print(ana.union(bia));
  print(ana.intersection(bia));
  print(ana.difference(bia));
  print(bia.difference(ana));
  print({'pizza'}.difference(ana).isEmpty);
  print(ana.containsAll({'pizza', 'açaí'}));
}

5. Percorrendo um conjunto

void main() {
  final cores = {'azul', 'verde', 'rosa'};
  for (final cor in cores) {
    print('Cor: $cor');
  }
  print(cores.first);
  print(cores.elementAt(1));
}

$ dart run percorrer.dart
Cor: azul
Cor: verde
Cor: rosa
azul
verde

O for-in funciona como na lista (veja for-in). first e last também existem. Se você precisar mesmo do "segundo item", há o elementAt(1), mas ele anda pelo conjunto item por item até chegar lá: se você usa muito, o que você queria era uma lista.

Lista ou conjunto? Formas de guardar vários valores

SituaçãoQual usar
A ordem e as posições importam (ranking, fila, histórico); repetidos são normaisList: ['Ana', 'Ana', 'Bia']
Cada valor só pode aparecer uma vez (tags, figurinhas, quem já votou)Set: {'Ana', 'Bia'}
A pergunta principal é "tem?" e a coleção é grandeSet (o contains é muito mais rápido)
Comparar dois grupos (em comum, só de um, todos)Set com intersection, difference, union
Tirar repetidos de uma listalista.toSet() (e .toList() se precisar de lista de novo)
Associar um valor a outro (produto → preço)Map (aula Mapas)

Para criar um conjunto, há também Set.of(lista) e Set<String>() (vazio), que fazem o mesmo que lista.toSet() e <String>{}. O guia de estilo do Dart prefere as formas literais, com chaves.

Missão final: quem ainda não votou

Missão: a turma tem 5 alunos. A lista de votos tem nomes repetidos (gente que votou duas vezes!). Transforme os votos num conjunto e descubra quem ainda não votou: deve aparecer {Caio, Edu}.

void main() {
  final turma = {'Ana', 'Bia', 'Caio', 'Davi', 'Edu'};
  final votos = ['Bia', 'Ana', 'Bia', 'Davi', 'Ana'];
  print(votos);
}

void main() {
  final turma = {'Ana', 'Bia', 'Caio', 'Davi', 'Edu'};
  final votos = ['Bia', 'Ana', 'Bia', 'Davi', 'Ana'];
  final votaram = votos.toSet();
  print(turma.difference(votaram));
}

Resumo

  • Um Set guarda valores sem repetição: {'Pelé', 'Marta'}. Pôr um repetido não dá erro; o add só devolve false.
  • A especialidade do conjunto é responder rápido a contains, e comparar grupos com union, intersection e difference.
  • lista.toSet() tira os repetidos de uma lista.
  • Conjunto vazio: <String>{}. O {} sozinho é um Map.
  • Conjunto não tem posição: nada de [0]; use first, elementAt ou toList().
