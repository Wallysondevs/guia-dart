Dart Recursão

Uma função pode chamar outra função. E pode também chamar a si mesma. Isso se chama recursão. Parece um truque estranho (como uma função que ainda não terminou pode se usar?), mas é um jeito muito natural de resolver problemas que contêm uma versão menor deles mesmos: pastas dentro de pastas, a contagem de 3 que é "3 e depois a contagem de 2", o fatorial de 4 que é "4 vezes o fatorial de 3".

Você vai aprender
  • As duas partes de toda função recursiva: o caso base (quando parar) e o passo recursivo (chamar a si mesma com um problema menor).
  • A contagem regressiva e o fatorial, com o passo a passo de cada chamada na tela.
  • Como somar uma lista e mostrar pastas dentro de pastas com recursão.
  • Quando é melhor usar um laço (for) em vez de recursão.
  • Os erros reais: o Stack Overflow (a recursão sem fim), o return esquecido e o int que estoura.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a fila do pão

A Ana está no fim de uma fila enorme na padaria e quer saber em que lugar está. Ela não consegue contar as pessoas lá da frente. Então pergunta para a pessoa da frente: "em que lugar você está?". Essa pessoa também não sabe, e pergunta para a da frente dela… e assim por diante, até chegar à primeira da fila, que sabe a resposta sem perguntar para ninguém: "estou em 1º".

Aí a resposta volta: a segunda pessoa diz "então estou em 2º", a terceira "3º"… até chegar à Ana. Repare nas duas peças:

  • Caso base: a primeira da fila responde direto, sem perguntar. É o que faz a pergunta parar de ser repassada.
  • Passo recursivo: cada uma das outras faz a mesma pergunta para alguém mais perto do começo (um problema um pouco menor) e soma 1 à resposta.

Sem o caso base, a pergunta seria repassada para sempre. Com programas é igual.

1. A primeira função recursiva: contagem regressiva

void contar(int n) {
  if (n == 0) {
    print('Já!');
    return;
  }
  print('$n...');
  contar(n - 1);
}

void main() {
  contar(3);
}

$ dart run regressiva.dart
3...
2...
1...
Já!
if (n == 0) { print('Já!'); return; }
O caso base: quando chega a zero, mostra Já! e o return encerra esta chamada sem chamar mais ninguém. Ele vem primeiro, antes de qualquer outra coisa.
print('$n...');
O trabalho desta chamada: mostrar o seu número.
contar(n - 1);
O passo recursivo: a função chama a si mesma com um número menor. "Para contar a partir de 3, mostre 3 e depois conte a partir de 2."

As chamadas foram: contar(3) → contar(2) → contar(1) → contar(0), e esta última parou. Cada chamada tem o seu próprio n: são quatro chamadas da mesma função, cada uma com o seu valor, como quatro pessoas na fila.

2. Recursão que devolve um valor: o fatorial

O fatorial de um número é a multiplicação dele por todos os números menores até 1. O fatorial de 4 é 4 × 3 × 2 × 1 = 24. (Serve para contar de quantas formas dá para arrumar coisas: 4 pães numa vitrine podem ser arrumados de 24 jeitos.) Repare que 4 × 3 × 2 × 1 é "4 vezes o fatorial de 3": o problema contém uma versão menor dele mesmo.

int fatorial(int n) {
  if (n <= 1) {
    return 1;
  }
  return n * fatorial(n - 1);
}

void main() {
  print(fatorial(1));
  print(fatorial(4));
  print(fatorial(10));
}

$ dart run fatorial.dart
1
24
3628800
if (n <= 1) return 1;
Caso base: o fatorial de 1 (e de 0) é 1. Responde direto.
return n * fatorial(n - 1);
Passo recursivo: "o fatorial de n é n vezes o fatorial de n - 1". Para fazer a multiplicação, esta chamada precisa esperar a resposta da chamada de baixo.

Passo a passo: as chamadas na tela

Para ver a "fila" de chamadas, a Ana acrescentou prints e um recuo que cresce a cada nível (o parâmetro opcional recuo; veja Parâmetros Opcionais):

int fatorial(int n, [String recuo = '']) {
  print('${recuo}fatorial($n) começou');
  if (n <= 1) {
    print('${recuo}fatorial($n) devolve 1');
    return 1;
  }
  final resultado = n * fatorial(n - 1, '$recuo  ');
  print('${recuo}fatorial($n) devolve $resultado');
  return resultado;
}

void main() {
  print(fatorial(4));
}

$ dart run rastro.dart
fatorial(4) começou
  fatorial(3) começou
    fatorial(2) começou
      fatorial(1) começou
      fatorial(1) devolve 1
    fatorial(2) devolve 2
  fatorial(3) devolve 6
fatorial(4) devolve 24
24

Leia de cima para baixo. As chamadas descem (4, 3, 2, 1), cada uma esperando a de baixo. Quando o caso base responde, as respostas sobem: 1, depois 2 × 1 = 2, depois 3 × 2 = 6, depois 4 × 6 = 24. O Dart guarda as chamadas que estão esperando numa estrutura chamada pilha de chamadas (call stack), a mesma que aparece nos stack traces (os #0, #1…).

3. Recursão com listas: somar as compras

"A soma de uma lista é o primeiro item mais a soma do resto." E a soma de uma lista vazia é 0 (caso base):

double somar(List<double> precos) {
  if (precos.isEmpty) {
    return 0;
  }
  return precos.first + somar(precos.sublist(1));
}

void main() {
  print(somar([4.5, 12.9, 3.25]));
  print(somar([]));
}

$ dart run soma.dart
20.65
0.0

precos.first é o primeiro item; precos.sublist(1) é uma lista nova com todos os itens a partir da posição 1 (o "resto"). A cada chamada, a lista diminui um item, até ficar vazia. (Os métodos de lista estão em Métodos de Lista. Para somar de verdade no dia a dia, um for é mais simples; aqui o objetivo é ver o padrão "primeiro + resto".)

Missão: complete a função contarItens no mesmo padrão: uma lista vazia tem 0 itens; senão, são 1 + os itens do resto (lista.sublist(1)). Não vale usar .length!

4. Onde a recursão brilha: pastas dentro de pastas

Até aqui, um laço também resolveria. Mas há problemas em que a recursão é o jeito natural: estruturas que têm pedaços do mesmo tipo dentro. Uma pasta pode ter arquivos e outras pastas, que têm arquivos e outras pastas… sem limite de níveis. A Ana representou a pasta pessoal dela com mapas dentro de mapas (veja Mapas): cada pasta é um mapa; cada arquivo é um nome com o valor 1:

void mostrar(Map<String, dynamic> pasta, int nivel) {
  for (final nome in pasta.keys) {
    final recuo = '  ' * nivel;
    final conteudo = pasta[nome];
    if (conteudo is Map<String, dynamic>) {
      print('$recuo$nome/');
      mostrar(conteudo, nivel + 1);
    } else {
      print('$recuo$nome');
    }
  }
}

void main() {
  final home = <String, dynamic>{
    'Documentos': <String, dynamic>{
      'escola': <String, dynamic>{
        'notas.txt': 1,
      },
      'receitas.txt': 1,
    },
    'Imagens': <String, dynamic>{
      'gato.png': 1,
    },
    'lista.txt': 1,
  };
  mostrar(home, 0);
}

$ dart run pastas.dart
Documentos/
  escola/
    notas.txt
  receitas.txt
Imagens/
  gato.png
lista.txt

A função mostrar não sabe quantos níveis de pastas existem, e não precisa saber: quando encontra uma pasta (conteudo is Map…, veja is, is! e as), ela chama a si mesma para mostrar o que tem dentro, com um nível de recuo a mais. O caso base aqui é escondido: uma pasta sem subpastas não chama ninguém, e o for simplesmente termina. (' ' * nivel repete o texto de 2 espaços nivel vezes.)

5. Fibonacci: duas chamadas de uma vez

Na sequência de Fibonacci, cada número é a soma dos dois anteriores: 0, 1, 1, 2, 3, 5, 8… A definição já é recursiva, e cabe numa linha com a seta e o ternário (veja O Operador Ternário):

int fib(int n) => n < 2 ? n : fib(n - 1) + fib(n - 2);

void main() {
  for (var i = 0; i <= 10; i++) {
    print('fib($i) = ${fib(i)}');
  }
}

Cada fib chama duas outras, que chamam duas cada uma… O fib(40) faz centenas de milhões de chamadas, refazendo as mesmas contas muitas vezes. Recursão é elegante, mas nem sempre é o caminho mais rápido.

Formas diferentes de fazer a mesma coisa

Todo problema resolvido com recursão também pode ser resolvido com um laço. O fatorial com for (veja for):

int fatorial(int n) {
  var resultado = 1;
  for (var i = 2; i <= n; i++) {
    resultado = resultado * i;
  }
  return resultado;
}

void main() {
  print(fatorial(4));
  print(fatorial(10));
}

Missão final: a potência

Missão: complete a função recursiva potencia. Qualquer número elevado a 0 é 1 (caso base); senão, base elevado a expoente é base * potencia(base, expoente - 1).

int potencia(int base, int expoente) {
  // caso base aqui
  // passo recursivo aqui
  return 0;
}

void main() {
  print('2^10 = ${potencia(2, 10)}');
  print('3^4 = ${potencia(3, 4)}');
}

int potencia(int base, int expoente) {
  if (expoente == 0) {
    return 1;
  }
  return base * potencia(base, expoente - 1);
}

void main() {
  print('2^10 = ${potencia(2, 10)}');
  print('3^4 = ${potencia(3, 4)}');
}

Resumo

  • Uma função recursiva chama a si mesma. Toda recursão precisa de um caso base (responde direto e para) e de um passo recursivo (chama a si mesma com um problema menor).
  • As chamadas descem até o caso base, esperando umas pelas outras na pilha de chamadas; depois as respostas sobem.
  • Padrões comuns: n * f(n - 1), "primeiro + resto" (lista.first + f(lista.sublist(1))) e entrar em estruturas aninhadas (pastas dentro de pastas).
  • Sem caso base, ou com um caso base que nunca é alcançado, o Dart para com Stack Overflow.
  • Para repetições simples, prefira um laço; a recursão brilha em estruturas com "o mesmo tipo dentro".
