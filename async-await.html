Dart async e await

Na aula Future, para usar o valor de um Future você escrevia o resto do código dentro de um then, e cada passo a mais virava um then dentro do outro. Funciona, mas fica difícil de ler. O Dart tem duas palavras que resolvem isso: await ("aguarde") espera o Future ficar pronto e entrega o valor, e async ("assíncrono") marca a função onde se pode usar o await. Com elas, o código assíncrono se lê de cima para baixo, como qualquer outro.

Você vai aprender
  • Como usar await para pegar o valor de um Future, e por que a função precisa de async.
  • Como escrever o main assíncrono: Future<void> main() async.
  • Como escrever as suas funções async, que sempre devolvem um Future.
  • A ordem real: o que roda antes e o que roda depois de um await.
  • A diferença de tempo entre esperar um depois do outro e esperar tudo junto (Future.wait).

Todos os programas desta aula rodaram no Dart SDK 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart. As esperas são simuladas com Future.delayed.

A ideia: esperar a senha sentado

Lembra da senha da lanchonete? Com o then, a Ana deixava um bilhete: "quando chamarem a senha, pegue o sanduíche e depois pague e depois…". Com o await, ela simplesmente espera a senha ser chamada e depois segue a vida, um passo de cada vez:

  1. Pede o sanduíche (recebe a senha).
  2. Aguarda a senha ser chamada (await) e pega o sanduíche.
  3. Paga e vai embora.

Uma diferença importante: enquanto a Ana espera, a lanchonete não para. Outros clientes continuam sendo atendidos. O await pausa só a função onde ele está; o resto do programa (outros Futures, outras tarefas) continua andando.

1. O primeiro await

Future<String> assarPao() {
  return Future.delayed(Duration(seconds: 2), () => 'pão quentinho');
}

Future<void> main() async {
  print('1. Ana pede um pão');
  final pao = await assarPao();
  print('2. Ficou pronto: $pao');
  print('3. Ela paga e vai embora');
}
Future<void> main() async
O main marcado com async. Toda função async devolve um Future; como o main não devolve valor nenhum, é Future<void> ("futuro de nada": só avisa quando terminou).
async
Vem depois dos parênteses e antes da {. Avisa: "dentro desta função vai ter await".
await assarPao()
"Aguarde o Future de assarPao() ficar pronto". O resultado do await é o valor de dentro do Future: a String, não a senha.
final pao = …
Por isso pao é uma String de verdade ('pão quentinho').
$ dart run a1.dart
1. Ana pede um pão
2. Ficou pronto: pão quentinho
3. Ela paga e vai embora

Compare com a aula anterior: lá, o "3" aparecia antes do pão ficar pronto, porque o main não esperava. Aqui o await pausou o main por 2 segundos na linha do pedido, e as linhas seguem na ordem em que estão escritas.

Missão: o programa mostra Pronto: Instance of 'Future<String>' (a senha, não o pão). O main já é async: só falta uma palavra antes do assarPao().

Future<String> assarPao() =>
    Future.delayed(Duration(seconds: 1), () => 'pão quentinho');

Future<void> main() async {
  final pao = assarPao();
  print('Pronto: $pao');
}

No lab: sem o await, saiu Pronto: Instance of 'Future<String>'; com ele, Pronto: pão quentinho.

2. As suas funções async

Qualquer função pode ser async. Dentro dela, você usa await e devolve um valor normal com return; o Dart embrulha esse valor num Future automaticamente:

Future<int> contarPaes() =>
    Future.delayed(Duration(seconds: 1), () => 24);

Future<String> planejarAmanha() async {
  final hoje = await contarPaes();
  final amanha = hoje * 2;
  return 'Amanhã: $amanha pães';
}

Future<void> main() async {
  final plano = await planejarAmanha();
  print(plano);
  print(planejarAmanha());
}

$ dart run a2.dart
Amanhã: 48 pães
Instance of 'Future<String>'
Future<String> planejarAmanha() async
O tipo de retorno é Future<String>, mesmo o return sendo de uma String. Quem chama recebe uma senha.
final hoje = await contarPaes();
Pausa esta função até a contagem chegar; hoje é um int.
return 'Amanhã: $amanha pães';
Devolve uma String; o Dart a entrega dentro do Future.
print(planejarAmanha())
Sem await, de propósito: mostra a senha (Instance of 'Future<String>'). Uma função async sempre devolve um Future: quem quer o valor precisa de await (ou then).

Também dá para usar await dentro de um laço. Cada volta espera a anterior:

Future<int> lerEstoque(String produto) async {
  await Future.delayed(Duration(seconds: 1));
  return produto.length * 10;
}

Future<void> main() async {
  var total = 0;
  for (final p in ['pão', 'bolo', 'broa']) {
    final n = await lerEstoque(p);
    print('$p: $n');
    total += n;
  }
  print('Total: $total');
}

$ dart run a5.dart
pão: 30
bolo: 40
broa: 40
Total: 110

(O await Future.delayed(Duration(seconds: 1));, sem função dentro, só espera 1 segundo. O "estoque" é inventado: 10 vezes o número de letras do nome.)

3. A ordem real: o que roda antes do await

Uma função async chamada sem await não é pulada inteira: ela roda normalmente até o primeiro await. Ali ela pausa e devolve a senha, e quem chamou continua. O resto dela roda mais tarde:

Future<void> preparar(String item) async {
  print('  começa a preparar $item');
  await Future.delayed(Duration(seconds: 1));
  print('  $item pronto');
}

void main() {
  print('1. main começa');
  preparar('café');
  print('2. main continua');
}

$ dart run a3.dart
1. main começa
  começa a preparar café
2. main continua
  café pronto
  1. 1. main começa: linha normal.
  2. preparar('café') começa a rodar na hora e mostra começa a preparar café.
  3. No await, a preparar pausa e devolve um Future. O main (que não é async e não esperou) segue: 2. main continua.
  4. Um segundo depois, a preparar continua de onde parou: café pronto.

4. Um depois do outro, ou todos juntos?

Dois await seguidos esperam um depois do outro. Se as tarefas não dependem uma da outra, dá para começar todas e esperar juntas com Future.wait. A Ana mediu as duas formas com um Stopwatch (cronômetro):

Future<String> assar(String item, int segundos) async {
  await Future.delayed(Duration(seconds: segundos));
  return item;
}

Future<void> main() async {
  final relogio = Stopwatch()..start();
  final a = await assar('pão', 2);
  final b = await assar('bolo', 3);
  print('Um depois do outro: $a, $b em ${relogio.elapsed.inSeconds} s');

  relogio.reset();
  final [c, d] = await Future.wait([assar('pão', 2), assar('bolo', 3)]);
  print('Ao mesmo tempo: $c, $d em ${relogio.elapsed.inSeconds} s');
}

$ dart run a4.dart
Um depois do outro: pão, bolo em 5 s
Ao mesmo tempo: pão, bolo em 3 s

Um depois do outro: 2 + 3 = 5 segundos, porque o bolo só começou depois que o pão ficou pronto. Juntos: 3 segundos, o tempo do mais demorado. O final [c, d] = … desmonta a lista de resultados em duas variáveis (veja Patterns). Os segundos podem variar um pouco de um computador para outro.

Quando usar cada um

Se o segundo passo precisa do resultado do primeiro (contar os pães para depois planejar), use await um depois do outro. Se são independentes (assar pão e bolo), comece todos e use await Future.wait([…]).

Formas diferentes de fazer a mesma coisa

O mesmo programa com then (aula anterior) e com async/await. Os dois mostraram Total: 8 no lab:

void main() {
  precoDe('café').then((cafe) {
    precoDe('pão').then((pao) {
      print('Total: ${cafe + pao}');
    });
  });
}

Future<void> main() async {
  final cafe = await precoDe('café');
  final pao = await precoDe('pão');
  print('Total: ${cafe + pao}');
}
SituaçãoQual usar
Quase sempre: passos em sequência, com valores intermediáriosasync/await: lê-se de cima para baixo

Quando dá errado

await numa função sem async 
Future<String> assarPao() =>
    Future.delayed(Duration(seconds: 1), () => 'pão quentinho');

void main() {
  final pao = await assarPao();
  print(pao);
}

$ dart run e1.dart
e1.dart:5:15: Error: 'await' can only be used in 'async' or 'async*' methods.
  final pao = await assarPao();
              ^^^^^

"O await só pode ser usado em funções async ou async*". O async* é dos geradores. Como consertar: Future<void> main() async {. (Só void main() async também compila, mas o costume é deixar claro, com Future<void>, que a função devolve um Future.)

Função async com tipo de retorno que não é Future 
String saudar() async {
  return 'Olá';
}

void main() {
  print(saudar());
}

$ dart run e2.dart
e2.dart:1:1: Error: Functions marked 'async' must have a return type assignable to 'Future'.
String saudar() async {
^^^^^^

"Funções marcadas com async precisam ter um tipo de retorno compatível com Future". Uma função async sempre devolve uma senha. Como consertar: Future<String> saudar() async.

O return não combina com o Future 
Future<int> contar() async {
  return 'doze';
}

void main() {}

$ dart run e4.dart
e4.dart:2:10: Error: A value of type 'String' can't be returned from an async function with return type 'Future<int>'.
 - 'Future' is from 'dart:async'.
  return 'doze';
         ^

"Um valor String não pode ser devolvido por uma função async do tipo Future<int>". Dentro da função, o return é do tipo de dentro do Future (int). Como consertar: return 12;.

Esqueceu o await

Não dá erro nenhum, e por isso é o mais traiçoeiro: a variável fica com o Future, e o print mostra Instance of 'Future<String>' (é a primeira missão desta aula). Se a função chamada sem await tiver efeitos (mostrar algo, gravar um arquivo), eles acontecem depois do que você esperava, como na seção 3. Como consertar: ponha o await antes da chamada. A ferramenta dart analyze com as regras certas ajuda a achar esses casos (veja Análise e Formatação).

Missão final: do then para o await

Missão: o programa funciona, mas está com um then dentro do outro. Reescreva o main com async e await: Future<void> main() async, final cafe = await precoDe('café');, o mesmo para o pão, e o print do total.

Future<int> precoDe(String item) async {
  await Future.delayed(Duration(seconds: 1));
  return item == 'café' ? 5 : 3;
}

void main() {
  precoDe('café').then((cafe) {
    precoDe('pão').then((pao) {
      print('Total: ${cafe + pao}');
    });
  });
}

Future<int> precoDe(String item) async {
  await Future.delayed(Duration(seconds: 1));
  return item == 'café' ? 5 : 3;
}

Future<void> main() async {
  final cafe = await precoDe('café');
  final pao = await precoDe('pão');
  print('Total: ${cafe + pao}');
}

Resumo

  • await espera um Future e entrega o valor de dentro dele. Só pode ser usado numa função async.
  • Uma função async sempre devolve um Future: Future<T>, ou Future<void> se não devolve nada. O return é do tipo T.
  • O await pausa só a função onde está; o resto do programa continua. Sem await, a função chamada roda até o primeiro await dela e o resto fica para depois.
  • await seguidos somam os tempos; await Future.wait([…]) espera tudo junto.
  • Esquecer o await não dá erro: aparece Instance of 'Future<…>' ou as coisas acontecem fora de ordem.
