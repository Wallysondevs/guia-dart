Dart Comparação

"A Ana tem 18 anos ou mais?" "A senha está certa?" "Ainda tem pão no estoque?" Todo programa que toma decisões começa com uma pergunta assim, de sim ou não. No Dart, essas perguntas se fazem com os operadores de comparação: ==, !=, <, >, <= e >=. A resposta é sempre um bool: true (verdadeiro) ou false (falso).

Você vai aprender
  • Os seis operadores de comparação e como ler cada um em voz alta.
  • Que o resultado de uma comparação é um valor bool, que dá para guardar numa variável.
  • Como comparar textos: == diferencia maiúsculas, e a ordem alfabética usa compareTo.
  • As pegadinhas dos números: 5 == 5.0 é true, mas 0.1 + 0.2 == 0.3 é false; e '5' == 5 é false, sem aviso.
  • Os erros reais: 18 <= idade <= 60, =< invertido, = no lugar de ==, === e < entre textos.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: a placa da montanha-russa

Na entrada da montanha-russa tem uma placa: "altura mínima 1,40 m". O funcionário mede a criança e faz uma pergunta só: a altura é maior ou igual a 1,40? A resposta não é "1,35" nem "quase": é sim ou não. Uma comparação é isso: pega dois valores, compara, e responde sim (true) ou não (false). Quem decide o que fazer com a resposta (deixar entrar ou não) é o if, na próxima parte do guia.

1. Os seis operadores

void main() {
  final idade = 17;
  print('idade == 18 → ${idade == 18}');
  print('idade != 18 → ${idade != 18}');
  print('idade < 18  → ${idade < 18}');
  print('idade > 18  → ${idade > 18}');
  print('idade <= 17 → ${idade <= 17}');
  print('idade >= 18 → ${idade >= 18}');
}

Três detalhes de escrita:

  • O "igual" de comparar tem dois sinais: ==. Um sinal só (=) é a atribuição, que guarda (veja Atribuição).
  • O "diferente" é !=: o ! quer dizer "não" no Dart (você vai vê-lo em Operadores Lógicos).
  • Em <= e >=, o = vem depois, do jeito que se fala: "menor ou igual". =< dá erro.

2. O resultado é um bool

Uma comparação é uma expressão, como uma conta: ela produz um valor. Só que, em vez de um número, produz um bool (veja Booleanos). E um valor pode ser guardado numa variável:

void main() {
  final nota = 7.5;
  final aprovado = nota >= 6;
  print('Nota: $nota');
  print('Aprovado? $aprovado');
  print(aprovado.runtimeType);
}

$ dart run guardar.dart

Aprovado? true
bool
nota >= 6
A pergunta: "a nota é maior ou igual a 6?". Com 7.5, a resposta é true. Repare que dá para comparar um double (7.5) com um int (6) sem problema.
final aprovado = …
Guarda a resposta. A variável aprovado é do tipo bool, como o .runtimeType confirma. Dar nome à pergunta deixa o código mais fácil de ler: mais adiante, if (aprovado) se lê sozinho.

3. Comparando textos

O == também compara textos (String): dois textos são iguais quando têm exatamente as mesmas letras, na mesma ordem.

void main() {
  final senha = 'abacate';
  print(senha == 'abacate');
  print(senha == 'Abacate');
  print(senha != 'banana');
  print('Ana' == 'Ana ');
}

$ dart run textos.dart
true
false
true
false

Maiúscula e minúscula são letras diferentes para o computador: 'abacate' == 'Abacate' dá false. E um espaço a mais no fim também conta: 'Ana' == 'Ana ' dá false. Quando o texto vem do teclado, é comum limpar antes de comparar, com trim() (tira os espaços das pontas) e toLowerCase() (tudo minúsculo): veja Métodos de String.

Ordem alfabética: compareTo

Os operadores < e > não funcionam com textos no Dart (veja o erro em Quando dá errado). Para saber quem vem antes no alfabeto, use o método compareTo ("comparar com"), que responde com um número:

void main() {
  print('Ana'.compareTo('Bia'));
  print('Bia'.compareTo('Ana'));
  print('Ana'.compareTo('Ana'));
  print('Ana'.compareTo('Bia') < 0);
  print('abacate'.compareTo('Banana'));
  print('abacate'.toLowerCase().compareTo('Banana'.toLowerCase()));
}

4. Pegadinhas com números

void main() {
  print(5 == 5.0);
  print(10 / 2 == 5);
  print(0.1 + 0.2 == 0.3);
  print(0.1 + 0.2);
  print((0.1 + 0.2 - 0.3).abs() < 0.000001);
}

$ dart run numeros.dart
true
true
false
0.30000000000000004
true
5 == 5.0 → true
Um int e um double com o mesmo valor são iguais. Por isso 10 / 2 == 5 também dá true, mesmo o 10 / 2 sendo 5.0.
0.1 + 0.2 == 0.3 → false
A conta dá 0.30000000000000004 (o double não guarda 0.1 exato; veja Operadores Aritméticos), e esse número não é igual a 0.3.
(… - 0.3).abs() < 0.000001 → true
O jeito seguro de comparar double que vieram de contas: perguntar se a diferença entre eles é minúscula. O abs() tira o sinal da diferença (o "valor absoluto").
Dinheiro e ==

Evite == com double que saíram de contas, como totais de compra. Para dinheiro, um truque comum é trabalhar em centavos, com int: 4,50 vira 450, e aí o == é exato.

Formas diferentes de fazer

Toda pergunta pode ser escrita de mais de um jeito. "Menor de idade" pode ser idade < 18 ou idade <= 17 (para números inteiros, as duas dão o mesmo); "não é 18" pode ser idade != 18 ou !(idade == 18). Prefira a forma que se lê mais perto do jeito que você falaria a regra: se a placa diz "mínimo 18", escreva idade >= 18.

Na matemática, 18 ≤ idade ≤ 60 é normal. No Dart, não. O primeiro erro diz: "uma comparação não pode ser parte de outra comparação". O segundo explica o porquê: o Dart faria 18 <= idade primeiro, que dá true, e depois true <= 60, e "o operador <= não está definido para o tipo bool". (A dica de pôr parênteses não resolve: (18 <= idade) <= 60 cai no segundo erro.) Como consertar: duas comparações ligadas por && ("e"): idade >= 18 && idade <= 60 (aula Operadores Lógicos).

Uma troca de dois caracteres, sete mensagens! O Dart leu o = como atribuição ("guarde em idade…") e o < como o começo de um tipo genérico (como em List<int>), e cada tentativa de entender o resto gerou mais um erro. "Um valor do tipo int não pode ser atribuído a um bool." O idade = 18 guarda 18 e devolve 18, um int; e o if exige um bool. É um erro que, em outras linguagens, passa despercebido; o Dart pega na hora. Como consertar: if (idade == 18).

Este é traiçoeiro, porque compila e roda: o texto '5' e o número 5 são coisas diferentes, e o == responde false. Acontece muito com o que se lê do teclado, que sempre chega como texto (veja Lendo o Teclado). Como consertar: converta antes, com int.parse (aula Conversão de Tipos).

void main() {

Missão: a conta da Ana tem saldo = 250. Um saque só é permitido se o valor for menor ou igual ao saldo. O programa tem um erro e uma comparação errada (no lab, o =< rendeu quatro mensagens de erro; o editor do guia mostra só uma delas). void main() {
  final saldo = 250;
  final saque1 = 300;
  final saque2 = 250;
  print('Saque de $saque1 permitido? ${saque1 =< saldo}');
  print('Saque de $saque2 permitido? ${saque2 < saldo}');
}

void main() {
  final saldo = 250;
  final saque1 = 300;
  final saque2 = 250;
  print('Saque de $saque1 permitido? ${saque1 <= saldo}');
  print('Saque de $saque2 permitido? ${saque2 <= saldo}');
}

Resumo

  • Os operadores de comparação são ==, !=, <, >, <= e >=; o resultado é sempre um bool, true ou false, que dá para guardar numa variável.
  • == (dois sinais) pergunta; = (um sinal) guarda. No <= e no >=, o = vem por último.
  • Textos são iguais só se forem idênticos, maiúsculas e espaços incluídos. Ordem alfabética: compareTo (o < não existe para String).
  • 5 == 5.0 é true; 0.1 + 0.2 == 0.3 é false; '5' == 5 é false, sem erro nenhum.
  • "Entre dois valores" não se escreve a <= x <= b: são duas comparações ligadas por &&, assunto da próxima aula.
