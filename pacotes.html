Dart Pacotes do pub.dev

Ninguém escreve tudo do zero. Mostrar R$ 1.234,50 no formato brasileiro, escrever a data "sábado, 14 de março de 2026", ler um arquivo CSV, baixar uma página da internet: para cada uma dessas tarefas, alguém já escreveu e publicou um pacote. Os pacotes do Dart (e do Flutter) ficam no site pub.dev, e entram no seu projeto com um comando: dart pub add.

Você vai aprender
  • O que é um pacote e como escolher um no pub.dev.
  • Como acrescentar um pacote com dart pub add (e um de desenvolvimento com --dev), e o que o comando muda no pubspec.yaml.
  • Um exemplo de verdade: o pacote intl, para dinheiro, números e datas em português.
  • Como escolher a versão e como tirar um pacote (dart pub remove).
  • Onde os pacotes ficam guardados no computador.
  • Os erros reais: usar o pacote sem acrescentar, pacote que não existe, nome digitado errado e dart pub fora do projeto.

Tudo nesta aula rodou no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com internet, num projeto criado com dart create cardapio (veja Criando um Projeto). As versões dos pacotes (intl 0.20.3, checks 0.3.2…) eram as mais novas no dia; no seu computador o dart pub add pode escolher versões mais novas, e as linhas com + podem mudar.

O editor do guia não baixa pacotes

O editor desta página só tem as bibliotecas que vêm com o Dart (dart:core, dart:math, dart:convert…). Um import 'package:intl/intl.dart'; não funciona nele. Os exemplos com pacotes são para o terminal do seu computador; as caixas "Experimente" mostram o trabalho que o pacote poupa.

A ideia: o fornecedor da padaria

A padaria da Ana não planta trigo nem cria vacas. Ela compra farinha e leite de fornecedores, e cada saco vem com marca, lote e validade. Se um fornecedor muda a receita da farinha, a padaria quer saber antes. Um pacote é esse ingrediente pronto:

  • pub.dev é o "mercado atacadista": o site oficial onde os pacotes são publicados.
  • dart pub add é fazer o pedido: o Dart escolhe uma versão, anota no pubspec.yaml (a lista de fornecedores, veja O pubspec.yaml) e baixa.
  • a versão é o lote: ^0.20.3 diz quais lotes servem.

1. Usar um pacote sem acrescentar: o erro

Para entender o que o dart pub add faz, a Ana primeiro tenta usar o intl sem acrescentá-lo. Ela troca o bin/cardapio.dart por:

import 'package:intl/intl.dart';

void main() {
  final real = NumberFormat.currency(locale: 'pt_BR', symbol: 'R\$');
  print(real.format(1234.5));
}

$ dart run
Failed to build cardapio:cardapio:
Error: Couldn't resolve the package 'intl' in 'package:intl/intl.dart'.
bin/cardapio.dart:1:8: Error: Not found: 'package:intl/intl.dart'
import 'package:intl/intl.dart';
       ^
bin/cardapio.dart:4:16: Error: Undefined name 'NumberFormat'.
  final real = NumberFormat.currency(locale: 'pt_BR', symbol: 'R\$');
               ^^^^^^^^^^^^
$ echo $?
255
  • Failed to build cardapio:cardapio: — "falhou ao montar o programa cardapio do pacote cardapio".
  • Couldn't resolve the package 'intl' — "não consegui encontrar o pacote intl": ele não está no pubspec.yaml, então o Dart não sabe onde procurar.
  • Undefined name 'NumberFormat' — consequência: sem o pacote, a classe NumberFormat não existe.

2. dart pub add

$ dart pub add intl
Resolving dependencies...
Downloading packages...
+ clock 1.1.3
+ intl 0.20.3
Changed 2 dependencies!
$ echo $?
0
$ grep -A3 '^dependencies' pubspec.yaml
dependencies:
  intl: ^0.20.3
  path: ^1.9.0
  • Resolving dependencies... — escolhendo a versão mais nova do intl que combina com o seu Dart e com os outros pacotes.
  • + intl 0.20.3 — o + quer dizer "entrou no projeto". Entrou também o clock, porque o intl depende dele (uma dependência transitiva).
  • O grep mostra que o comando escreveu intl: ^0.20.3 em dependencies, em ordem alfabética. Você não precisou editar nada.

Agora o mesmo programa funciona:

$ dart run
R$ 1.234,50

NumberFormat.currency ("formato de número: moeda") com locale: 'pt_BR' ("regras do Brasil") pôs o ponto no milhar, a vírgula nos centavos e as duas casas.

3. O intl na padaria

import 'package:intl/intl.dart';

void main() {
  final real = NumberFormat.currency(locale: 'pt_BR', symbol: 'R\$');
  final cardapio = {'pão de queijo': 4.5, 'café com leite': 7.0, 'bolo inteiro': 58.9};
  cardapio.forEach((item, preco) {
    print('${item.padRight(15)} ${real.format(preco)}');
  });
  final milhar = NumberFormat.decimalPattern('pt_BR');
  print('Pães vendidos no ano: ${milhar.format(48250)}');
}

$ dart run
pão de queijo   R$ 4,50
café com leite  R$ 7,00
bolo inteiro    R$ 58,90
Pães vendidos no ano: 48.250

padRight(15) (do próprio Dart, veja Métodos de String) completa o nome com espaços para alinhar a coluna. NumberFormat.decimalPattern('pt_BR') formata números comuns com o ponto do milhar.

Datas em português

Para nomes de dias e meses em português, o intl precisa carregar os dados do idioma antes, com initializeDateFormatting, que vem de outro arquivo do mesmo pacote:

import 'package:intl/date_symbol_data_local.dart';
import 'package:intl/intl.dart';

Future<void> main() async {
  await initializeDateFormatting('pt_BR');
  final inauguracao = DateTime(2026, 3, 14);
  print(DateFormat('EEEE, d \'de\' MMMM \'de\' y', 'pt_BR').format(inauguracao));
  print(DateFormat('dd/MM/yyyy', 'pt_BR').format(inauguracao));
}

$ dart run bin/data.dart
sábado, 14 de março de 2026
14/03/2026
import 'package:intl/date_symbol_data_local.dart';
Um pacote pode ter vários arquivos; este traz os nomes dos dias e meses de cada idioma.
await initializeDateFormatting('pt_BR');
Carrega os dados do português do Brasil. Devolve um Future, por isso o await e o main async.
'EEEE, d \'de\' MMMM \'de\' y'
O "molde" da data: EEEE = dia da semana por extenso, d = dia, MMMM = mês por extenso, y = ano. O texto fixo (de) vai entre aspas simples, escapadas com \' dentro da String do Dart.
'dd/MM/yyyy'
O formato brasileiro curto, com dois dígitos no dia e no mês.

Missão: no editor não há intl. Faça um formatador simples à mão: na função emReais, troque o ponto por vírgula no texto com .replaceAll('.', ','). (Ele não põe o ponto do milhar, e é aí que o pacote faz falta.)

String emReais(double valor) {
  final texto = valor.toStringAsFixed(2);
  return 'R\$ $texto';
}

void main() {
  print(emReais(1234.5));
  print(emReais(4.5));
}

String emReais(double valor) {
  final texto = valor.toStringAsFixed(2).replaceAll('.', ',');
  return 'R\$ $texto';
}

void main() {
  print(emReais(1234.5));
  print(emReais(4.5));
}

4. Pacotes de desenvolvimento: --dev

Pacotes que só servem para quem escreve o programa (testes, verificadores) vão para dev_dependencies. Basta o --dev. Aqui, o checks, da equipe do Dart, que ajuda a escrever testes:

$ dart pub add --dev checks
Resolving dependencies...
Downloading packages...
+ checks 0.3.2
Changed 1 dependency!
$ grep -A4 "^dev_dependencies" pubspec.yaml
dev_dependencies:
  checks: ^0.3.2
  lints: ^6.0.0
  test: ^1.33.0

Escolhendo a versão

Sem versão, o pub add escolhe a mais nova possível. Para pedir uma restrição sua, escreva nome:restrição (com aspas, para o terminal não estranhar o ^):

$ dart pub add 'collection:^1.19.0'
Resolving dependencies...
Downloading packages...
  collection 1.19.1 (from transitive dependency to direct dependency)
Changed 1 dependency!
$ grep -A4 '^dependencies' pubspec.yaml
dependencies:
  collection: ^1.19.0
  intl: ^0.20.3
  path: ^1.9.0

Desta vez não houve +: o collection já estava baixado como dependência de outro pacote. A linha diz que ele passou "de dependência transitiva para direta": agora o projeto pede por ele com o próprio nome.

Tirando um pacote: dart pub remove

$ dart pub remove collection
Resolving dependencies...
Downloading packages...
  collection 1.19.1 (from direct dependency to transitive dependency)
Changed 1 dependency!
$ dart pub remove checks
Resolving dependencies...
Downloading packages...
These packages are no longer being depended on:
- checks 0.3.2
Changed 1 dependency!

O remove apaga a linha do pubspec.yaml. O collection continua baixado (outro pacote precisa dele); o checks saiu de vez: "estes pacotes não são mais usados".

5. Onde os pacotes ficam

Os pacotes baixados não ficam dentro do projeto: ficam num cache ("depósito") na pasta pessoal, ~/.pub-cache, e são usados por todos os projetos do computador. Por isso o segundo dart create é bem mais rápido que o primeiro.

$ ls ~/.pub-cache/hosted/pub.dev | grep -E '^(intl|path|test)-'
intl-0.20.3
path-1.9.1
test-1.33.0

Cada versão fica numa pasta própria (intl-0.20.3). O pubspec.lock do projeto diz qual delas usar (veja O pubspec.yaml).

Quando dá errado

Usou o pacote sem acrescentá-lo

É o erro da seção 1: Couldn't resolve the package 'intl' in 'package:intl/intl.dart'. Como consertar: dart pub add intl dentro da pasta do projeto.

Pacote que não existe (ou nome digitado errado) 
$ dart pub add itnl
Because cardapio depends on itnl any which doesn't exist (could not find package itnl at https://pub.dev), version solving failed.
$ echo $?
65

"Como cardapio depende de itnl (qualquer versão), que não existe (não encontrei o pacote itnl em https://pub.dev), a resolução de versões falhou." A Ana trocou as letras de intl. O pubspec.yaml não foi alterado. Como consertar: copie o nome exato da página do pacote no pub.dev.

dart pub add fora da pasta do projeto 
$ cd ..
$ dart pub add intl
Found no `pubspec.yaml` file in `/home/ana` or parent directories
$ echo $?
66

"Não encontrei nenhum pubspec.yaml em /home/ana nem nas pastas acima." Pacotes pertencem a um projeto; um arquivo .dart solto não tem onde anotá-los. Como consertar: entre na pasta do projeto (cd cardapio) ou crie um com dart create.

Pacote que já estava lá 
$ dart pub add --dev test
"test" is already in "dev_dependencies". Will try to update the constraint.
Resolving dependencies...
Downloading packages...
Got dependencies!

Não é erro: "test já está em dev_dependencies. Vou tentar atualizar a restrição." O dart create já tinha posto o test; o comando só ajustou a restrição para a versão mais nova (no lab, ^1.25.6 virou ^1.33.0).

Missão final: a lista com total

Missão: some os preços do cardápio (com for ou fold) e mostre Total: R$ 70,40 usando o formatador emReais. Num projeto, você usaria o NumberFormat do intl; aqui, o formatador feito à mão.

String emReais(double valor) => 'R\$ ${valor.toStringAsFixed(2).replaceAll('.', ',')}';

void main() {
  final cardapio = {'pão de queijo': 4.5, 'café com leite': 7.0, 'bolo inteiro': 58.9};
  var total = 0.0;
  // some os preços aqui

  print('Total: ${emReais(total)}');
}

String emReais(double valor) => 'R\$ ${valor.toStringAsFixed(2).replaceAll('.', ',')}';

void main() {
  final cardapio = {'pão de queijo': 4.5, 'café com leite': 7.0, 'bolo inteiro': 58.9};
  var total = 0.0;
  for (final preco in cardapio.values) {
    total += preco;
  }
  print('Total: ${emReais(total)}');
}

Resumo

  • Pacotes são código pronto publicado no pub.dev. Escolha pelos selos, likes, pontos e data da última versão.
  • dart pub add nome (dentro do projeto) escolhe a versão, escreve no pubspec.yaml e baixa; --dev põe em dev_dependencies; dart pub remove tira.
  • No código: import 'package:nome/arquivo.dart';. Sem o pub add, o erro é Couldn't resolve the package.
  • Os pacotes ficam em ~/.pub-cache, compartilhados entre projetos.
  • O intl formata dinheiro, números e datas em português (R$ 1.234,50, sábado, 14 de março de 2026).
