Dart Operadores Aritméticos

Computador é, antes de tudo, uma calculadora muito rápida. Somar o total da compra, dividir a conta da pizza, descobrir quantas horas tem um filme de 135 minutos: tudo isso se faz com os operadores aritméticos, os sinais de conta do Dart. Quatro deles você já conhece da escola (+, -, *, /). Os outros dois, ~/ e %, são novidade e muito úteis: a divisão inteira e o resto.

Você vai aprender
  • Os seis operadores de conta do Dart: +, -, *, /, ~/ e %.
  • Por que / sempre dá um double (até 10 / 2 dá 5.0) e ~/ sempre dá um int.
  • Como usar ~/ e % juntos: 135 minutos viram 2 h e 15 min.
  • A ordem em que o Dart faz as contas e como mudar essa ordem com parênteses.
  • Contas com números negativos, com int e double misturados, e a potência com pow.
  • Os erros reais: double numa variável int, divisão por zero, 'Total: ' + 5 e o ** que o Dart não tem.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com dart run arquivo.dart (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: dividir a pizza

A Ana e o irmão pediram uma pizza de 7 fatias. Como dividir entre os dois? Depende da pergunta:

  • "Quanto dá para cada um, se a gente cortar a última fatia ao meio?" → 3,5 fatias. É a divisão comum, com vírgula.
  • "Quantas fatias inteiras cada um pega?" → 3. É a divisão inteira: joga fora o que vem depois da vírgula.
  • "E quantas fatias sobram na caixa?" → 1. É o resto da divisão.

São três perguntas diferentes sobre a mesma divisão, e o Dart tem um operador para cada uma: /, ~/ e %.

1. Os seis operadores

void main() {
  final a = 17;
  final b = 5;
  print('17 + 5 = ${a + b}');
  print('17 - 5 = ${a - b}');
  print('17 * 5 = ${a * b}');
  print('17 / 5 = ${a / b}');
  print('17 ~/ 5 = ${a ~/ b}');
  print('17 % 5 = ${a % b}');
}

$ dart run contas.dart
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3.4
17 ~/ 5 = 3
17 % 5 = 2

O ${ … } dentro do texto faz a conta e põe o resultado no lugar (é a interpolação, da aula Strings). O texto antes do = é só um rótulo: o Dart não faz conta nenhuma ali.

Confira com a conta armada da escola: 17 dividido por 5 dá 3 e sobra 2 (porque 3 × 5 = 15, e 17 − 15 = 2). O ~/ responde o 3; o % responde o 2. Repare também que o Dart escreve números com ponto, não vírgula: 3.4 é "três vírgula quatro".

2. A pizza no Dart: /, ~/ e %

void main() {
  final fatias = 7;
  final pessoas = 2;
  print('Divisão comum: ${fatias / pessoas} fatias para cada um');
  print('Fatias inteiras: ${fatias ~/ pessoas} para cada um');
  print('Sobra: ${fatias % pessoas} fatia');
}

3. ~/ e % juntos: horas e minutos

O par ~/ e % aparece toda hora quando é preciso "quebrar" uma quantidade em unidades maiores. O filme que a Ana quer ver tem 135 minutos. Quantas horas e minutos são?

void main() {
  final minutosDoFilme = 135;
  final horas = minutosDoFilme ~/ 60;
  final minutos = minutosDoFilme % 60;
  print('O filme tem $horas h e $minutos min.');
}

$ dart run tempo.dart
O filme tem 2 h e 15 min.

135 ~/ 60 dá 2 (cabem 2 horas inteiras em 135 minutos) e 135 % 60 dá 15 (os minutos que sobram). O mesmo truque serve para centavos em reais (~/ 100 e % 100), dias em semanas (~/ 7 e % 7) e ovos em dúzias (~/ 12 e % 12).

Par ou ímpar? Pergunte ao %

Um número é par quando a divisão por 2 não deixa resto: n % 2 dá 0 para os pares e 1 para os ímpares (positivos). Você vai usar isso com o if e else: if (n % 2 == 0).

4. int ou double? O tipo do resultado

Em Dart, todo valor tem um tipo, e o resultado de uma conta também. A regra é curta:

  • / devolve sempre um double, mesmo quando a divisão é exata.
  • ~/ devolve sempre um int.
  • +, -, * e % com dois int dão int; se um dos lados for double, o resultado é double.
void main() {
  print(10 / 2);
  print((10 / 2).runtimeType);
  print(10 ~/ 2);
  print((10 ~/ 2).runtimeType);
  print(3 + 2.0);
  print(2 * 1.5);
  print(0.1 + 0.2);
}

A divisão é exata, mas o resultado é 5.0, com o .0: é um double. O .runtimeType ("tipo em tempo de execução") pergunta o tipo de um valor e confirma: double.
10 ~/ 2 → 5
Mesma conta, sem o .0: um int.
3 + 2.0 → 5.0
Um int com um double: o resultado é double.
0.1 + 0.2 → 0.30000000000000004
Não é defeito do Dart: o computador guarda o double em binário, e alguns números com vírgula não cabem exatos, como 1/3 não cabe exato em decimal (0,333…). Para mostrar dinheiro, arredonde na hora de imprimir, com toStringAsFixed(2) (abaixo).

Por que isso importa? Porque uma variável do tipo int não aceita um double. Se você escrever int metade = 7 / 2;, o programa nem compila (veja em Quando dá errado).

Dinheiro: a conta e o jeito de mostrar

Na padaria, a Ana compra 8 pães de R$ 0,75:

void main() {
  final precoPao = 0.75;
  final quantidade = 8;
  final total = precoPao * quantidade;
  print('Total: R\$ $total');
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

$ dart run compras.dart

Total: R$ 6.00

Dois detalhes: o \$ é um $ de verdade dentro do texto (sem a barra, o Dart acharia que $ começa uma interpolação); e o toStringAsFixed(2) ("como texto, com 2 casas fixas") mostra o double com duas casas, do jeito que se escreve dinheiro. A conta em si continua sendo 0.75 * 8.

5. A ordem das contas e os parênteses

Como na escola, multiplicação e divisão vêm antes de soma e subtração. No Dart, *, /, ~/ e % estão no mesmo nível, acima de + e -. No mesmo nível, a conta é feita da esquerda para a direita. E os parênteses mandam em tudo:

void main() {
  print(2 + 3 * 4);
  print((2 + 3) * 4);
  print(7 + 8 + 9 / 3);
  print((7 + 8 + 9) / 3);
  print(10 - 4 - 3);
  print(20 ~/ 3 * 3 + 20 % 3);
}

$ dart run ordem.dart

Quem esquece os parênteses na média recebe 18.0 em vez de 8.0, e o Dart não reclama: para ele, 7 + 8 + 9 / 3 é uma conta perfeitamente válida. Na dúvida, ponha parênteses. Eles não custam nada e deixam a intenção clara para quem lê.

6. Números negativos

O sinal de menos na frente de um valor (o menos unário, de um lado só) troca o sinal. Com negativos, o ~/ e o % têm detalhes que pegam muita gente:

void main() {
  final saldo = -7;
  print(-saldo);
  print(saldo ~/ 2);
  print(saldo % 2);
  print(saldo.remainder(2));
  print(-7 % 2);
}

$ dart run negativos.dart
7
-3
1
-1
1
-saldo → 7
O contrário de −7.
saldo ~/ 2 → -3
−7 ÷ 2 = −3,5; o ~/ corta a parte decimal, em direção ao zero: −3 (e não −4).
saldo % 2 → 1
No Dart, o % nunca dá negativo quando o divisor é positivo. Por isso n % 2 é 0 ou 1 para qualquer inteiro, positivo ou negativo, e o teste de par funciona sempre.
saldo.remainder(2) → -1
Se você precisa do resto "com sinal" (o de outras linguagens, como C e Java), existe o método remainder ("resto"). Ele combina com o ~/: −3 × 2 + (−1) = −7.
-7 % 2 → 1
O menos unário vale antes do %: é (-7) % 2.

Formas diferentes de fazer

Potência: pow ou multiplicar

O Dart não tem operador de potência (o ** de outras linguagens dá erro; veja abaixo). Para "2 elevado a 10", use a função pow, da biblioteca dart:math, ou, para expoentes pequenos, multiplique:

import 'dart:math';

void main() {
  print(pow(2, 10));
  print(pow(2.5, 2));
  print(3 * 3);
}

$ dart run pow.dart
1024
6.25
9

O import 'dart:math'; na primeira linha traz as funções de matemática para o seu programa (veja import, export e Bibliotecas). O pow devolve um num (o tipo "número", que pode ser int ou double).

Resumo

  • Os operadores de conta do Dart são +, -, *, /, ~/ e %. O "vezes" é o *.
  • / devolve sempre double (10 / 2 é 5.0); ~/ devolve sempre int, cortando a parte decimal.
  • % dá o resto. ~/ e % juntos quebram quantidades: minutos em horas, ovos em dúzias.
  • *, /, ~/ e % vêm antes de + e -; no mesmo nível, da esquerda para a direita; parênteses mandam em tudo.
  • Um double não cabe numa variável int (erro de compilação). ~/ 0 e % 0 param o programa com IntegerDivisionByZeroException; / 0 dá Infinity.
  • Não existe **: potência é pow, do dart:math.
