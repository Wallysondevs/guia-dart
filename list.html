Dart Listas (List)

Até agora, cada variável guardava um valor: um nome, um preço, uma nota. Mas a lista de compras da Ana tem 10 itens, a turma tem 30 notas, o estoque tem 50 produtos. Criar 30 variáveis (nota1, nota2…) seria um pesadelo. Para guardar vários valores em ordem, numa variável só, o Dart tem a lista, o tipo List. É a coleção mais usada da linguagem.

Você vai aprender
  • Como criar uma lista com colchetes [ ] e qual é o tipo dela (List<String>).
  • Que as posições começam do 0, e como ler e trocar um item: compras[0].
  • length (tamanho), first e last, isEmpty, e como acrescentar com add.
  • Como criar uma lista vazia do jeito certo: <int>[].
  • Como percorrer a lista com for-in e com o índice.
  • A diferença entre final e const numa lista, e o que b = a faz.
  • Os erros reais: RangeError, Bad state: No element, o tipo errado e a lista que não aceita mudanças.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a fileira de armários

Imagine uma fileira de armários numerados no vestiário da escola. Cada armário guarda uma coisa, e você encontra qualquer uma pelo número do armário. Uma lista é isso:

  • os armários ficam em ordem, um ao lado do outro;
  • cada um tem um número, chamado índice (ou posição);
  • no Dart, a numeração começa do 0, e não do 1 (como no prédio em que o térreo é o andar 0);
  • dá para trocar o conteúdo de um armário e acrescentar armários no fim da fileira.

1. Criando uma lista e lendo os itens

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  print(compras);
  print(compras[0]);
  print(compras[2]);
  print(compras.length);
  print(compras.runtimeType);
}

2. Trocando e acrescentando itens

void main() {
  final compras = ['arroz', 'feijão', 'café'];
  compras[1] = 'lentilha';
  compras.add('açúcar');
  print(compras);
  print('Itens: ${compras.length}');
  print('Primeiro: ${compras.first}, último: ${compras.last}');
}

$ dart run mudar.dart
[arroz, lentilha, café, açúcar]
Itens: 4
Primeiro: arroz, último: açúcar
compras[1] = 'lentilha';
Troca o conteúdo da posição 1. O feijão some, e a lentilha fica no lugar dele.
compras.add('açúcar');
add = "acrescentar": põe um item novo no fim da lista. A lista cresce, e o length passa de 3 para 4.
compras.first / compras.last
O primeiro e o último item. O mesmo que compras[0] e compras[compras.length - 1], só que mais fácil de ler.
Mas a lista não era final?

Era, e continua sendo. O final quer dizer que a variável compras vai apontar sempre para a mesma lista (a mesma fileira de armários). O conteúdo dos armários pode mudar à vontade. O que não pode é trocar a fileira inteira: compras = ['pão']; dá erro (veja Quando dá errado). Para uma lista que nunca muda, nem por dentro, use const (seção 5).

Há muitos outros métodos para mexer na lista (inserir no meio, remover, procurar, ordenar…). Eles têm uma aula só para eles: Métodos de Lista.

3. O tipo dos itens e a lista vazia

void main() {
  List<double> precos = [4.5, 12.9, 3.25];
  final notas = <int>[];
  print(notas);
  print(notas.isEmpty);
  notas.add(8);
  notas.add(10);
  print(notas);
  print(notas.isNotEmpty);
  final misturada = [1, 'dois', 3.0];
  print(misturada.runtimeType);
  print(precos.runtimeType);
}

$ dart run tipos.dart

O tipo escrito por extenso. Funciona igual a final precos = […]; escreva quando ajudar a ler.
<int>[]
Uma lista vazia de inteiros. Como não há itens para o Dart olhar, você diz o tipo antes dos colchetes. [] mostra uma lista vazia.
isEmpty / isNotEmpty
"Está vazia?" e "não está vazia?", sempre true ou false. Mais claros que length == 0.
List<Object>
Misturando número e texto, o Dart escolhe o tipo que serve para todos: Object ("qualquer objeto"; veja dynamic e Object). Funciona, mas quase nunca é uma boa ideia: o Dart deixa de ajudar a conferir os itens.
Cuidado com o [] sem tipo

final precos = []; cria uma List<dynamic>: uma lista que aceita qualquer coisa e em que o Dart não confere nada. Prefira sempre <double>[]. O último erro de Quando dá errado mostra o que pode acontecer.

4. Percorrendo a lista

Para fazer algo com cada item, use um laço. O for-in ("para cada item em") entrega um item por volta (veja for-in); o for com contador entrega a posição (veja for):

void main() {
  final notas = [8.5, 6.0, 9.5, 7.0];
  var soma = 0.0;
  for (final nota in notas) {
    soma = soma + nota;
  }
  print('Média: ${soma / notas.length}');
  for (var i = 0; i < notas.length; i++) {
    print('Aluno ${i + 1}: ${notas[i]}');
  }
}

$ dart run percorrer.dart
Média: 7.75
Aluno 1: 8.5
Aluno 2: 6.0
Aluno 3: 9.5
Aluno 4: 7.0

No segundo laço, a condição é i < notas.length (menor, não menor ou igual): com 4 notas, i vai de 0 a 3, exatamente as posições que existem. O i + 1 só serve para mostrar "Aluno 1" em vez de "Aluno 0".

Missão: some os preços da lista com um for-in e mostre o total. Deve aparecer Total: R$ 20.65.

void main() {
  final precos = [4.5, 12.9, 3.25];
  var total = 0.0;
  // some os preços aqui
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

void main() {
  final precos = [4.5, 12.9, 3.25];
  var total = 0.0;
  for (final preco in precos) {
    total = total + preco;
  }
  print('Total: R\$ ${total.toStringAsFixed(2)}');

5. Lista que não muda: const

Os dias úteis da semana nunca mudam. Para uma lista assim, use const (veja final e const): ela fica congelada, por dentro e por fora.

void main() {
  const diasUteis = ['seg', 'ter', 'qua', 'qui', 'sex'];
  print(diasUteis);
  diasUteis.add('sáb');
}

$ dart run constlist.dart

Unhandled exception:

#2      _delayEntrypointInvocation.<anonymous closure> (dart:isolate-patch/isolate_patch.dart:313:19)
#3      _RawReceivePort._handleMessage (dart:isolate-patch/isolate_patch.dart:192:12)

"Operação não suportada: não dá para acrescentar a uma lista que não pode ser modificada." Repare que o programa compilou e rodou (a lista foi mostrada): o Dart só percebe na hora do add, linha 4 (a #1 main). Isso é bom quando é de propósito: ninguém consegue estragar a lista dos dias úteis sem querer.

6. Duas variáveis, a mesma lista

void main() {
  final a = [1, 2, 3];
  final b = a;
  b.add(4);
  print(a);
  final c = [1, 2, 3, 4];
  print(a == c);
  print(a == b);
}

$ dart run igual.dart
[1, 2, 3, 4]
false
true

Surpresa: o add foi feito em b, e a lista a também ganhou o 4. É que final b = a; não copia a lista: as duas variáveis passam a apontar para a mesma fileira de armários. E o == entre listas pergunta "é a mesma lista?", e não "têm os mesmos itens?": a e c têm os mesmos itens, mas são listas diferentes, então dá false. (Para copiar, use [...a] ou List.of(a); veja Espalhando Coleções.)

Formas diferentes de criar uma lista

void main() {
  final zeros = List.filled(4, 0);
  print(zeros);
  final tabuada = List.generate(5, (i) => (i + 1) * 3);
  print(tabuada);
  final turma = [
    ['Ana', 'Bia'],
    ['Caio', 'Davi', 'Edu'],
  ];
  print(turma[1][2]);
  print(turma.length);
}

$ dart run gerar.dart
[0, 0, 0, 0]
[3, 6, 9, 12, 15]
Edu
2
  • List.filled(4, 0): 4 posições, todas com 0. Atenção: essa lista tem tamanho fixo (o add dá Unsupported operation: Cannot add to a fixed-length list), a não ser que você peça List.filled(4, 0, growable: true).
  • List.generate(5, (i) => …): 5 itens, cada um calculado por uma função anônima que recebe a posição (veja Funções Anônimas).
  • Uma lista pode ter listas dentro: turma[1] é a segunda turma, e turma[1][2] é o terceiro aluno dela. A vírgula depois do último item (],) é a "vírgula do fim" recomendada pelo estilo do Dart em listas longas: o dart format põe um item por linha.

Item do tipo errado 
void main() {
  final compras = ['arroz', 'feijão'];
  compras.add(5);
}

$ dart run err_tipo.dart
err_tipo.dart:3:15: Error: The argument type 'int' can't be assigned to the parameter type 'String'.
  compras.add(5);

"O tipo do argumento, int, não pode ser atribuído ao tipo do parâmetro, String." A lista é List<String> e só aceita textos. O Dart pega isso antes de rodar (código de saída 254). Como consertar: compras.add('5 ovos');, ou, se a lista é de números, crie-a como lista de números.

Trocar a lista inteira de uma variável final 
void main() {
  final compras = ['arroz'];
  compras = ['pão'];
}

$ dart run err_final.dart
err_final.dart:3:3: Error: Can't assign to the final variable 'compras'.
  compras = ['pão'];
  ^^^^^^^

"Não dá para atribuir à variável final compras." Como consertar: se você quer mudar o conteúdo, mude os itens (compras[0] = 'pão';, ou compras.clear() e depois add). Se precisa mesmo trocar a lista inteira, use var.

A lista sem tipo aceitou um texto, e a conta quebrou 
void main() {
  final precos = [];
  precos.add(4.5);
  precos.add('doze');
  var total = 0.0;
  for (final p in precos) {
    total = total + p;
  }
  print(total);
}

$ dart run err_dynamic.dart
Unhandled exception:
type 'String' is not a subtype of type 'num'
#0      main (file:///home/ana/err_dynamic.dart:7:21)
#1      _delayEntrypointInvocation.<anonymous closure> (dart:isolate-patch/isolate_patch.dart:313:19)
#2      _RawReceivePort._handleMessage (dart:isolate-patch/isolate_patch.dart:192:12)

"O tipo String não é um subtipo do tipo num": na linha 7, o Dart tentou somar 'doze' a um número. O [] sem tipo virou List<dynamic> e aceitou o texto calado; o erro só apareceu lá na frente, rodando. Como consertar: final precos = <double>[];. Aí o precos.add('doze') vira erro de compilação, apontado na linha certa, antes de rodar.

Missão final: a maior nota

Missão: descubra a maior nota da turma com um laço. Comece com maior = notas.first e, para cada nota, se ela for maior que maior, guarde-a em maior.

void main() {
  final notas = [7.5, 9.5, 6.0, 8.0];
  var maior = notas.first;
  // percorra as notas aqui
  print('Maior nota: $maior');
}

void main() {
  final notas = [7.5, 9.5, 6.0, 8.0];
  var maior = notas.first;
  for (final nota in notas) {
    if (nota > maior) {
      maior = nota;
    }
  }
  print('Maior nota: $maior');
}

Resumo

  • Uma List guarda vários valores em ordem: ['arroz', 'feijão'], do tipo List<String>.
  • As posições começam do 0: lista[0] é o primeiro; o último é lista[lista.length - 1] ou lista.last.
  • lista[i] = valor troca um item; add acrescenta no fim; isEmpty diz se está vazia.
  • Lista vazia sempre com tipo: <int>[]. Sem tipo, ela vira List<dynamic> e aceita qualquer coisa.
  • final impede trocar a lista inteira, mas deixa mudar os itens; const congela tudo.
  • b = a não copia: as duas variáveis apontam para a mesma lista.
