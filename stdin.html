Dart Lendo o Teclado (stdin.readLineSync)

Até aqui, todos os seus programas faziam sempre a mesma coisa: os valores estavam escritos no código. Um programa de verdade conversa com quem usa: pergunta o nome, a idade, o preço do item. Nesta aula você aprende a ler o que a pessoa digita no terminal com stdin.readLineSync(), e a lidar com as duas surpresas que vêm junto: o texto pode não existir (null) e pode não ser um número.

Você vai aprender
  • O import 'dart:io';, o stdout.write (perguntar sem pular linha) e o stdin.readLineSync() (ler uma linha).
  • Por que o readLineSync() devolve String?, e não String, com o erro real do Dart.
  • Quando o null aparece de verdade (Ctrl+D), e como tratá-lo com ??, if ou !.
  • Como transformar o texto digitado em número: int.tryParse, double.tryParse, e a exceção do int.parse.
  • Como ler vários valores num laço e pedir de novo até a resposta ser válida.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (ana@notebook). Nos terminais abaixo, o que vem depois de cada pergunta (Ana, 30, 4.50…) foi digitado por ela, seguido de Enter.

A ideia: o balcão da padaria

No balcão da padaria, a atendente pergunta "o que vai ser?" e espera. Só depois que o cliente responde ela continua. O programa faz igual:

  1. escreve a pergunta na tela (stdout.write);
  2. para e espera a pessoa digitar e apertar Enter (stdin.readLineSync());
  3. guarda o que ela digitou numa variável e segue.

Os nomes vêm do inglês: stdin é a entrada padrão (standard input, o teclado), stdout é a saída padrão (standard output, a tela). readLineSync = "ler uma linha, esperando" (sync, de síncrono: o programa fica parado até a linha chegar).

1. O primeiro programa que pergunta

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  final nome = stdin.readLineSync();
  print('Olá, $nome!');
}
import 'dart:io';
"Importe a biblioteca dart:io" (io = entrada e saída). O print vem de graça, mas o stdin e o stdout moram nessa biblioteca, e o programa precisa pedir por ela na primeira linha. Sem isso, o Dart não sabe o que é stdin (veja Quando dá errado).
stdout.write('Qual é o seu nome? ');
Escreve a pergunta sem pular linha no fim, para a resposta ser digitada ao lado dela. O espaço depois do ? separa a pergunta da resposta. (Com print, a resposta iria para a linha de baixo.)
stdin.readLineSync()
Para o programa e espera a pessoa digitar uma linha e apertar Enter. Devolve o texto digitado, sem o Enter do fim.
final nome = …;
Guarda a resposta. É final porque não vai mudar depois.
$ dart run ola_nome.dart

Olá, Ana!

Rode de novo e digite outro nome: o programa é o mesmo, a saída muda. É isso que torna o programa útil.

2. Por que String? e não String?

O tipo que o readLineSync() devolve é String?, com interrogação: um tipo anulável (veja Tipos Anuláveis): pode ser um texto ou null ("nada"). Para ver na prática, a Ana tentou dizer que o nome é uma String comum:

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  String nome = stdin.readLineSync();
  print('Olá, $nome!');
}

$ dart run tipo.dart

"Um valor do tipo String? não pode ser guardado numa variável do tipo String." O readLineSync() pode devolver null, e uma String sem interrogação promete que nunca será null. O Dart não deixa você fazer uma promessa que pode ser quebrada.

O mesmo acontece se você tentar usar o texto direto, como em nome.length (quantas letras):

Try accessing using ?. instead.

"A propriedade length não pode ser acessada num String?, porque ele talvez seja null. Tente usar ?.." Isso é a null safety trabalhando: o erro aparece antes de rodar, e não no meio do programa, na frente do usuário.

Quando o null acontece de verdade

Se a pessoa só aperta Enter, o readLineSync() devolve um texto vazio (''), não null. O null aparece quando a entrada acabou e não há linha nenhuma para ler. No terminal, isso se faz com Ctrl+D ("fim da entrada"). A Ana rodou o primeiro programa e, na pergunta, apertou Ctrl+D:

$ dart run ola_nome.dart
Qual é o seu nome? Olá, null!

O Ctrl+D não aparece na tela e não pula linha, por isso o Olá saiu grudado na pergunta. O programa não quebrou, mas mostrou Olá, null!: o print transforma o null no texto null. A entrada também acaba quando ela vem de um arquivo ou de outro programa, em vez do teclado. Com < /dev/null (um "arquivo vazio" do Linux) e com echo Bia | (o echo "digita" Bia pelo programa):

$ dart run ola_nome.dart < /dev/null
Qual é o seu nome? Olá, null!
$ echo Bia | dart run ola_nome.dart
Qual é o seu nome? Olá, Bia!

(Aqui a resposta também não aparece na tela, porque ninguém digitou: ela veio pronta. Por isso o Olá ficou na mesma linha da pergunta, como no Ctrl+D.)

3. Três jeitos de lidar com o null

a) ??: um valor de reserva

O operador ?? ("se for nulo, use este", veja ?. , ?? e ??=) troca o null por um valor seu. O resultado é uma String comum, e o .length passa a funcionar:

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  final nome = stdin.readLineSync() ?? 'visitante';
  print('Olá, $nome! Seu nome tem ${nome.length} letras.');
}

$ dart run seguro.dart
Qual é o seu nome? Ana
Olá, Ana! Seu nome tem 3 letras.
$ dart run seguro.dart
Qual é o seu nome? Olá, visitante! Seu nome tem 9 letras.

Na segunda vez a Ana apertou Ctrl+D: o null virou 'visitante'. Esse é o jeito mais usado, e o que este guia vai usar: stdin.readLineSync() ?? '' (texto vazio como reserva).

b) if (… == null): tratar o caso à parte

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  final nome = stdin.readLineSync();
  if (nome == null) {
    print('Você não digitou nada.');
  } else {
    print('Seu nome tem ${nome.length} letras.');
  }
}

Dentro do else, o Dart já sabe que nome não é null (ele acabou de testar) e deixa usar o .length. Isso se chama promoção de tipo.

c) !: "confie em mim, não é null"

O ! no fim diz ao Dart: "eu garanto que não é null" (veja late e o Operador !). Compila, mas, se a garantia falhar, o programa quebra. A Ana apertou Ctrl+D neste aqui:

import 'dart:io';

void main() {
  stdout.write('Qual é o seu nome? ');
  final nome = stdin.readLineSync()!;
  print('Olá, $nome!');
}

4. O que se digita é sempre texto

O readLineSync() devolve texto, mesmo que a pessoa digite 2. Veja o que acontece numa "soma":

import 'dart:io';

void main() {
  stdout.write('Primeiro número: ');
  final a = stdin.readLineSync() ?? '';
  stdout.write('Segundo número: ');
  final b = stdin.readLineSync() ?? '';
  print('A soma é ${a + b}');
}

$ dart run soma_texto.dart
Primeiro número: 2
Segundo número: 3
A soma é 23

'2' + '3' é '23': o + de dois textos junta, não soma (veja Strings). Para fazer conta, é preciso converter o texto em número (veja também Conversão de Tipos).

int.parse: converte, ou quebra

import 'dart:io';

void main() {
  stdout.write('Quantos anos você tem? ');
  final texto = stdin.readLineSync() ?? '';
  final idade = int.parse(texto);
  print('Daqui a 10 anos você terá ${idade + 10}.');
}

int.tryParse: converte, ou devolve null

O tryParse ("tentar converter") não quebra: se o texto não é um número, ele devolve null. O resultado é um int?, e um if separa os dois casos:

import 'dart:io';

void main() {
  stdout.write('Quantos anos você tem? ');
  final texto = stdin.readLineSync() ?? '';
  final idade = int.tryParse(texto);
  if (idade == null) {
    print('"$texto" não é um número inteiro.');
  } else {
    print('Daqui a 10 anos você terá ${idade + 10}.');
  }
}

$ dart run idade.dart

$ dart run idade.dart

Números com vírgula: double.tryParse

Para preços e notas quebradas, use double.tryParse. Cuidado: o Dart escreve números com ponto, como em inglês. A vírgula do português não é entendida:

import 'dart:io';

void main() {
  stdout.write('Preço: ');
  final texto = (stdin.readLineSync() ?? '').trim();
  final preco = double.tryParse(texto);
  print('Texto lido: "$texto"  →  número: $preco');
}

$ dart run preco.dart
Preço: 4,50
Texto lido: "4,50"  →  número: null
$ dart run preco.dart
Preço:   4.50
Texto lido: "4.50"  →  número: 4.5

Na segunda vez a Ana digitou espaços antes e depois do 4.50. O .trim() ("aparar") tirou esses espaços das pontas (veja Métodos de String). É um bom hábito aparar toda resposta digitada. Para aceitar a vírgula, troque-a por ponto antes de converter: texto.replaceAll(',', '.'), como no próximo exemplo.

5. Ler vários valores num laço

No caixa da padaria, a Ana digita o preço de cada item. Ninguém sabe quantos itens serão; quando acabar, ela aperta Enter numa linha vazia. Um while (true) com break (veja break e continue) resolve:

import 'dart:io';

void main() {
  var total = 0.0;
  var itens = 0;
  while (true) {
    stdout.write('Preço do item (Enter vazio para terminar): ');
    final texto = (stdin.readLineSync() ?? '').trim();
    if (texto.isEmpty) break;
    final preco = double.tryParse(texto.replaceAll(',', '.'));
    if (preco == null) {
      print('  "$texto" não é um preço. Tente de novo.');
      continue;
    }
    total += preco;
    itens++;
  }
  print('$itens itens. Total: R\$ ${total.toStringAsFixed(2)}');
}
var total = 0.0;
O acumulador começa em 0.0, com ponto, para ser um double (preços têm centavos).
(stdin.readLineSync() ?? '').trim()
Lê, troca o null por vazio e apara os espaços: tudo numa linha.
if (texto.isEmpty) break;
Linha vazia (isEmpty = "está vazio") encerra o laço. O Ctrl+D também, graças ao ?? ''.
texto.replaceAll(',', '.')
Troca vírgula por ponto, para o 12,90 funcionar.
if (preco == null) { …; continue; }
Resposta que não é preço: avisa e pula para a próxima pergunta, sem somar nada.
total.toStringAsFixed(2)
Mostra o total com 2 casas decimais (o jeito de escrever dinheiro; veja Números).

Pedir de novo até a resposta ser válida

A professora lança uma nota de 0 a 10. Se ela digitar 15 ou oito, o programa pergunta de novo. Como a pergunta tem de ser feita pelo menos uma vez, o do-while (veja while e do-while) cai como uma luva:

import 'dart:io';

void main() {
  int? nota;
  do {
    stdout.write('Digite a nota (0 a 10): ');
    nota = int.tryParse(stdin.readLineSync() ?? '');
  } while (nota == null || nota < 0 || nota > 10);
  print('Nota aceita: $nota');
}

$ dart run nota.dart
Digite a nota (0 a 10): 15
Digite a nota (0 a 10): oito
Digite a nota (0 a 10): 8
Nota aceita: 8

A variável int? nota; é criada antes do laço (para existir na condição e no print final) e começa null. A condição diz "repita enquanto a nota for inválida": null (não era número) ou menor que 0 ou maior que 10. A ordem importa: o nota == null || vem primeiro, e o || para de avaliar assim que acha um true; por isso o nota < 0 nunca roda com null.

Quando dá errado

Esqueceu o import 'dart:io'; 
void main() {
  stdout.write('Qual é o seu nome? ');
  final nome = stdin.readLineSync();
  print('Olá, $nome!');
}

$ dart run sem_import.dart
sem_import.dart:2:3: Error: Undefined name 'stdout'.
  stdout.write('Qual é o seu nome? ');
  ^^^^^^
sem_import.dart:3:16: Error: Undefined name 'stdin'.
  final nome = stdin.readLineSync();
               ^^^^^

"Nome não definido: stdout" e "… stdin". Sem o import, esses nomes não existem para o Dart. Como consertar: ponha import 'dart:io'; na primeira linha do arquivo, antes do main.

Guardou o resultado numa String sem ?

É o erro da seção 2: A value of type 'String?' can't be assigned to a variable of type 'String'. Como consertar: final nome = stdin.readLineSync() ?? ''; (ou declare String? nome e teste o null antes de usar).

Usou .length (ou outro método) direto no resultado

Property 'length' cannot be accessed on 'String?' because it is potentially null. O mesmo motivo: trate o null primeiro, com ?? ou if.

FormatException ao converter

int.parse com um texto que não é número (trinta, 4.5, '') quebra o programa com FormatException (com trinta e 4.5, a mensagem é Invalid radix-10 number; com o texto vazio, Invalid number) e código de saída 255 (seção 4). Como consertar: use int.tryParse e trate o null.

A "soma" juntou os números

2 e 3 deram 23: você somou dois textos. O Dart não reclama, porque juntar textos com + é permitido. Como consertar: converta antes com int.tryParse.

Usou ! e a entrada acabou

Null check operator used on a null value, código 255 (seção 3c). Como consertar: troque o ! por ?? ''.

Resumo

  • Para ler o teclado: import 'dart:io'; no topo, stdout.write para perguntar e stdin.readLineSync() para ler a resposta.
  • O readLineSync() devolve String?: se a entrada acabar (Ctrl+D), vem null. O Dart obriga você a tratar isso antes de usar o texto; o jeito mais simples é ?? ''.
  • Evite o ! na leitura: se vier null, o programa quebra.
  • O que se digita é texto. Para fazer conta, converta com int.tryParse ou double.tryParse, que devolvem null em vez de quebrar. O int.parse quebra com FormatException.
  • Apare com .trim(), troque a vírgula por ponto, e use laços para ler vários valores (while (true) + break) ou pedir de novo (do-while).
