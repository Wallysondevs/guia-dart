Dart ?. , ?? e ??=

Na aula Tipos Anuláveis, você usou um String? conferindo com if (x != null). Funciona, mas ocupa quatro ou cinco linhas para uma coisa simples como "mostre o apelido, ou cliente se não tiver". O Dart tem três operadores feitos para isso: ?., ?? e ??=. Com eles, cada uma dessas conferências cabe em uma linha.

Você vai aprender
  • ?.: chama o método só se o valor não for null.
  • ??: usa um valor padrão quando o da esquerda é null.
  • ??=: preenche a variável só se ela estiver vazia.
  • A dupla x?.metodo() ?? padrao, a mais usada de todas.
  • Os parentes: ?[0] e o ?x dentro de listas.
  • Os erros reais: o resultado do ?. ainda é anulável, a ordem das operações com ??, e os avisos do dart analyze.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: três bilhetes para o funcionário da padaria

  • ?. — "Se tiver encomenda, embrulhe." Se não tiver, não faça nada (e o resultado é "nada").
  • ?? — "Entregue a encomenda; se não tiver, entregue um pão francês." Sempre sai alguma coisa.
  • ??= — "Se a vitrine estiver vazia, ponha 10 pães." Se já tiver pão, não mexa.

Todos os três têm o ?, o sinal do "talvez seja null" que você já conhece.

1. ?.: chamar só se não for null

void main() {
  String? apelido = 'Aninha';
  String? outro;
  print(apelido?.length);
  print(outro?.length);
  print(apelido?.toUpperCase());
  print(outro?.toUpperCase());
  print(outro?.toUpperCase().length);
}

$ dart run ponto.dart
6
null
ANINHA
null
null
apelido?.length
Lê-se "apelido, se existir, ponto length". Como apelido tem texto, funciona como o ponto comum: 6.
outro?.length
outro é null: o Dart não chama o length e o resultado de tudo é null. Sem erro.
outro?.toUpperCase().length
Quando o ?. encontra null, ele pula o resto da corrente inteira: nem o toUpperCase() nem o .length rodam. Por isso só precisa de um ?. no começo.

O nome técnico é acesso condicional (null-aware access, "acesso que sabe do null"). Ele é o que a mensagem de erro sugere quando você usa um anulável direto: Try accessing using ?. instead.

O resultado do ?. também é anulável

apelido?.length pode dar um número ou null; o tipo dele é int?, não int. O ?. não faz o null sumir: só evita o erro. Para ter um valor garantido, junte com o ?? (seção 4).

2. ??: o valor padrão

void main() {
  String? apelido;
  String nome = apelido ?? 'cliente';
  print('Olá, $nome!');
  apelido = 'Aninha';
  print('Olá, ${apelido ?? 'cliente'}!');
  int quantidade = int.tryParse('doze') ?? 1;
  print(quantidade);
  String? outro;
  print(outro?.length ?? 0);
  String? a;
  String? b;
  print(a ?? b ?? 'ninguém');
}

$ dart run padrao.dart
Olá, cliente!
Olá, Aninha!
1
0
ninguém
apelido ?? 'cliente'
"O apelido; se for null, 'cliente'." O resultado nunca é null, então cabe numa variável String comum. O ?? se chama operador de coalescência nula (if-null operator); a maioria das pessoas fala só "o ??".
${apelido ?? 'cliente'}
Dentro da interpolação, entre chaves. Agora o apelido existe, e saiu Aninha.
int.tryParse('doze') ?? 1
O par clássico da aula Conversão: se o texto não for número, use 1.
a ?? b ?? 'ninguém'
Em fila: o primeiro que não for null. Como a e b estavam vazios, sobrou 'ninguém'.

O ?? também resolve a busca no mapa que pode não achar a chave:

void main() {
  var precos = {'pão': 1, 'bolo': 25};
  int preco = precos['torta'] ?? 0;
  print('Torta: R\$ $preco');
  var estoque = {'pão': 30};
  estoque['café'] ??= 0;
  estoque['pão'] ??= 0;
  print(estoque);
  estoque['bolo'] = (estoque['bolo'] ?? 0) + 2;
  print(estoque);
}

$ dart run mapa.dart
Torta: R$ 0
{pão: 30, café: 0}
{pão: 30, café: 0, bolo: 2}

Lembra do erro A value of type 'int?' can't be assigned to a variable of type 'int'. com precos['torta'], na aula Null Safety? O ?? 0 é o conserto. As linhas com ??= são da próxima seção, e mapas têm aula própria: Mapas.

Missão: troque as seis linhas do if/else por um print só, usando ??: print('Cupom: ${cupom ?? 'nenhum'}');. A saída tem de continuar Cupom: nenhum.

void main() {
  String? cupom;
  String texto;
  if (cupom != null) {
    texto = cupom;
  } else {
    texto = 'nenhum';
  }
  print('Cupom: $texto');
}

void main() {
  String? cupom;
  print('Cupom: ${cupom ?? 'nenhum'}');
}

3. ??=: preencher só se estiver vazio

void main() {
  int? desconto;
  print(desconto);
  desconto ??= 10;
  print(desconto);
  desconto ??= 50;
  print(desconto);
}

$ dart run atribui.dart
null
10
10
desconto ??= 10;
"Se desconto for null, passe a valer 10." Ele era null: virou 10.
desconto ??= 50;
Agora ele já tem valor, então nada muda: continua 10. É o mesmo que desconto = desconto ?? 50;, mais curto.

No mapa da seção 2, estoque['café'] ??= 0 criou a chave café com 0 (ela não existia), e estoque['pão'] ??= 0 não mexeu no pão, que já tinha 30. É o jeito de dizer "garanta que existe, sem estragar o que já estava lá".

4. A dupla mais usada: ?. + ??

Juntos, os dois transformam um anulável num valor garantido, em uma linha:

String? apelido;
print(apelido?.toUpperCase() ?? 'SEM APELIDO');   // SEM APELIDO
print(apelido?.length ?? 0);                     // 0

Lê-se: "o apelido em maiúsculas, se existir; senão, SEM APELIDO". O ?. evita o erro; o ?? troca o null resultante por um valor de verdade. A seção 2 mostrou a segunda linha rodando no lab (outro?.length ?? 0 deu 0); a missão final usa a primeira.

5. Os parentes: ?[ ] e ?x nas listas

void main() {
  List<String>? pedidos;
  print(pedidos?[0]);
  pedidos = ['pão', 'café'];
  print(pedidos?[0]);
  String? brinde;
  var sacola = ['pão', ?brinde, 'leite'];
  print(sacola);
  brinde = 'bala';
  var sacola2 = ['pão', ?brinde, 'leite'];
  print(sacola2);
}

O ?. dos colchetes: pega o item 0 se a lista existir; se ela for null, dá null.
['pão', ?brinde, 'leite'] Dart 3.8
Um elemento condicional: o ? antes de brinde quer dizer "ponha na lista só se não for null". Sem brinde, a lista ficou com 2 itens; com 'bala', com 3. (Listas em Listas.)

Formas diferentes de fazer

"Mostre o apelido em maiúsculas, ou SEM APELIDO":

// 1. if/else: claro, mas longo
if (apelido != null) {
  print(apelido.toUpperCase());
} else {
  print('SEM APELIDO');
}

// 2. ?. e ??: uma linha
print(apelido?.toUpperCase() ?? 'SEM APELIDO');

// 3. ?? antes, depois o método (repare nos parênteses)
print((apelido ?? 'sem apelido').toUpperCase());

Achou que o ?. devolve um valor comum

"Um valor do tipo int? não pode ser atribuído a uma variável do tipo int." O ?. pode dar null, então o resultado é int?.

Como consertar: int tamanho = apelido?.length ?? 0;, ou declare int? tamanho.

Fez conta com o resultado do ?. 
void main() {
  String? apelido = 'Aninha';
  print(apelido?.length + 1);
}

$ dart run err_conta.dart
err_conta.dart:3:25: Error: Operator '+' cannot be called on 'int?' because it is potentially null.
  print(apelido?.length + 1);
                        ^

O mesmo motivo: apelido?.length é int?, e "nada + 1" não existe. Como consertar: (apelido?.length ?? 0) + 1, com parênteses.

A ordem das operações com ?? 
void main() {
  String? apelido;
  print('Olá, ' + apelido ?? 'cliente');
}

$ dart run err_ordem.dart
err_ordem.dart:3:19: Error: A value of type 'String?' can't be assigned to a variable of type 'String'.
  print('Olá, ' + apelido ?? 'cliente');
                  ^

O ?? é um dos últimos a ser feito numa expressão. O Dart tentou primeiro 'Olá, ' + apelido, e o + de texto não aceita um String?. O ?? 'cliente' ficaria para depois. Como consertar: parênteses, 'Olá, ' + (apelido ?? 'cliente'), ou, melhor, interpolação: 'Olá, ${apelido ?? 'cliente'}'.

A ordem também engana sem dar erro. Veja onde fica o toUpperCase():

void main() {
  String? apelido;
  print(apelido ?? 'cliente'.toUpperCase());
  apelido = 'aninha';
  print(apelido ?? 'cliente'.toUpperCase());
  print((apelido ?? 'cliente').toUpperCase());
}

$ dart run ordem2.dart
CLIENTE
aninha
ANINHA

Sem parênteses, o .toUpperCase() vale só para o 'cliente': o apelido aninha saiu em minúsculas. Com os parênteses da última linha, o método vale para o resultado do ??.

Missão final: os apelidos da turma

Missão: o cadastro tem um apelido para cada pessoa, mas a Bia não tem (null). O programa não compila. Use ?. e ?? na interpolação para mostrar o apelido em maiúsculas, ou SEM APELIDO: ${apelido?.toUpperCase() ?? 'SEM APELIDO'}.

void main() {
  var cadastro = {'Ana': 'Aninha', 'Bia': null, 'Caio': 'Caio'};
  for (var nome in cadastro.keys) {
    String? apelido = cadastro[nome];
    print('$nome: ${apelido.toUpperCase()}');
  }
}

void main() {
  var cadastro = {'Ana': 'Aninha', 'Bia': null, 'Caio': 'Caio'};
  for (var nome in cadastro.keys) {
    String? apelido = cadastro[nome];
    print('$nome: ${apelido?.toUpperCase() ?? 'SEM APELIDO'}');
  }
}

No lab, a solução mostrou:

$ dart run missao.dart
Ana: ANINHA
Bia: SEM APELIDO
Caio: CAIO

Resumo

  • x?.metodo() chama só se x não for null; se for, a corrente inteira dá null. O resultado continua anulável.
  • x ?? y dá x, ou y quando x é null. É o conserto para tryParse e mapas.
  • x ??= y preenche x só se estava vazio.
  • x?.metodo() ?? padrao transforma um anulável num valor garantido, em uma linha.
  • O ?? é feito por último: use parênteses ((a ?? b).metodo(), '…' + (x ?? y)).
  • ?? e ?. em tipos sem ? rodam, mas o dart analyze avisa: tem algo sobrando.
