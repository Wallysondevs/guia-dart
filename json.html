Dart JSON

Na aula de Arquivos, as notas da turma foram guardadas como Ana;9.5, uma por linha. Funciona, mas e se cada aluno tiver também uma lista de faltas, um e-mail que pode estar vazio, um "sim/não" de bolsista? Para guardar e trocar dados com estrutura, o mundo inteiro usa o mesmo formato de texto: o JSON. No Dart, quem traduz entre JSON e as coleções da linguagem é a biblioteca dart:convert ("converter").

Você vai aprender
  • O que é JSON e como ele se parece com os Mapas e Listas do Dart.
  • Como transformar texto JSON em dados com jsonDecode, e dados em texto JSON com jsonEncode.
  • Como deixar o JSON "bonito", com recuo, para pessoas lerem.
  • Como dizer ao Dart o tipo de cada campo com as.
  • Como converter uma classe sua de e para JSON (fromJson e toJson) e como salvar JSON num arquivo.
  • Os erros reais: JSON mal escrito (FormatException), tipo diferente do esperado, chave que não existe e objeto que não vira JSON.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a ficha que qualquer um entende

A padaria manda o pedido do dia para o fornecedor de farinha. Se cada um anotar do seu jeito ("2 sacos/farinha", "farinha x2", "dois sacos de farinha"), alguém vai errar. Então os dois combinam uma ficha padrão, com campos de nome fixo. O JSON (JavaScript Object Notation, "notação de objetos do JavaScript") é essa ficha padrão dos computadores: um aplicativo em Dart, um site em JavaScript e um servidor em Python leem o mesmo JSON do mesmo jeito.

Um JSON é texto e parece muito com um mapa do Dart:

{
  "nome": "Ana",
  "idade": 30,
  "cliente": true,
  "compras": ["pão", "leite"],
  "email": null
}
No JSONVira no Dart
{ "chave": valor, … } (objeto)Map<String, dynamic>
[ … ] (lista)List<dynamic>
"texto"String
30int
4.5double
true / falsebool
nullnull

As regras do JSON são mais rígidas que as do Dart: textos e chaves sempre com aspas duplas, nada de vírgula depois do último item, nada de comentários.

1. De texto para dados: jsonDecode

import 'dart:convert';

void main() {
  const texto = '{"nome": "Ana", "idade": 30, "cliente": true, "compras": ["pão", "leite"]}';
  final dados = jsonDecode(texto);
  print(dados);
  print(dados.runtimeType);
  print('Nome: ${dados['nome']}');
  print('Idade: ${dados['idade']}');
  print('Primeira compra: ${dados['compras'][0]}');
}
import 'dart:convert';
A biblioteca de conversões. Vem com o Dart, mas precisa do import.
const texto = '{"nome": …}';
O JSON é só uma String. As aspas simples de fora são do Dart; as duplas de dentro são do JSON. (Na vida real, esse texto vem de um arquivo ou da internet.)
jsonDecode(texto)
"Decodificar JSON": lê o texto e monta os dados do Dart (aqui, um mapa).
dados['compras'][0]
O valor da chave compras é uma lista; o [0] pega o primeiro item.
$ dart run decodificar.dart
{nome: Ana, idade: 30, cliente: true, compras: [pão, leite]}
_Map<String, dynamic>
Nome: Ana
Idade: 30
Primeira compra: pão

O print(dados) mostra o mapa do jeito do Dart (sem aspas): agora é um Map de verdade, não mais texto. O runtimeType ("tipo em tempo de execução") confirma: _Map<String, dynamic> (o _ é o nome interno da implementação; para você, é um Map<String, dynamic>). dynamic quer dizer que cada valor pode ser de um tipo diferente (veja dynamic e Object).

2. De dados para texto: jsonEncode

import 'dart:convert';

void main() {
  final pedido = {
    'cliente': 'Bia',
    'itens': ['bolo', 'sonho'],
    'total': 27.5,
    'entregue': false,
    'observacao': null,
  };
  final texto = jsonEncode(pedido);
  print(texto);
  print(texto.runtimeType);
  const bonito = JsonEncoder.withIndent('  ');
  print(bonito.convert(pedido));
}

$ dart run codificar.dart
{"cliente":"Bia","itens":["bolo","sonho"],"total":27.5,"entregue":false,"observacao":null}
String
{
  "cliente": "Bia",
  "itens": [
    "bolo",
    "sonho"
  ],
  "total": 27.5,
  "entregue": false,
  "observacao": null
}
  • jsonEncode(pedido) ("codificar em JSON") faz o caminho inverso: devolve uma String, com aspas duplas e sem espaços. É o formato compacto, bom para guardar e mandar pela internet.
  • JsonEncoder.withIndent(' ') cria um conversor "com recuo" de 2 espaços. .convert(pedido) devolve o mesmo JSON, quebrado em linhas: bom para pessoas lerem.
  • O null do Dart vira null no JSON; false vira false.

3. Dizendo o tipo de cada campo com as

Como os valores vêm como dynamic, o Dart não sabe que preco é número. É boa prática dizer o tipo logo ao ler, com as (veja is, is! e as). Assim, o resto do programa tem tipos claros, e se o JSON vier diferente do combinado, o erro aparece logo na leitura:

import 'dart:convert';

void main() {
  const texto = '{"produto": "pão de queijo", "preco": 4.5, "estoque": 30}';
  final dados = jsonDecode(texto) as Map<String, dynamic>;
  final produto = dados['produto'] as String;
  final preco = dados['preco'] as double;
  final estoque = dados['estoque'] as int;
  print('$produto: R\$ ${preco.toStringAsFixed(2)} (restam $estoque)');
  print('Valor do estoque: R\$ ${(preco * estoque).toStringAsFixed(2)}');
}

$ dart run tipos.dart
pão de queijo: R$ 4.50 (restam 30)
Valor do estoque: R$ 135.00

O \$ mostra um cifrão de verdade, em vez de começar uma interpolação. toStringAsFixed(2) mostra 2 casas decimais.

Cuidado com números inteiros num campo de preço

No JSON, 12 é inteiro e 12.0 é decimal. Se o preço vier como 12, as double dá erro. O jeito seguro para campos decimais é (dados['preco'] as num).toDouble(): num aceita os dois. É o que a classe da seção 5 faz.

4. Uma lista de objetos

O estoque da padaria vem como uma lista de objetos. O texto usa ''' (três aspas), que permite uma String de várias linhas (veja Strings):

import 'dart:convert';

void main() {
  const texto = '''
[
  {"nome": "pão francês", "quantidade": 120},
  {"nome": "sonho", "quantidade": 8},
  {"nome": "broa", "quantidade": 0}
]
''';
  final produtos = jsonDecode(texto) as List<dynamic>;
  for (final p in produtos) {
    final item = p as Map<String, dynamic>;
    print('${item['nome']}: ${item['quantidade']}');
  }
  final esgotados = produtos.where((p) => p['quantidade'] == 0).map((p) => p['nome']);
  print('Esgotados: ${esgotados.toList()}');
}

$ dart run lista.dart
pão francês: 120
sonho: 8
broa: 0
Esgotados: [broa]

Quando o JSON começa com [, o jsonDecode devolve uma List; cada item é um Map. Os métodos de map, where, reduce funcionam normalmente.

5. Classes: fromJson e toJson

Num programa maior, em vez de passar mapas para todo lado, você converte o JSON numa classe sua. A convenção do Dart (usada pelo Flutter e pelos pacotes) é ter dois métodos:

import 'dart:convert';

class Produto {
  final String nome;
  final double preco;

  Produto(this.nome, this.preco);

  factory Produto.fromJson(Map<String, dynamic> json) {
    return Produto(json['nome'] as String, (json['preco'] as num).toDouble());
  }

  Map<String, dynamic> toJson() => {'nome': nome, 'preco': preco};
}

void main() {
  final p = Produto.fromJson(jsonDecode('{"nome": "café", "preco": 12}'));
  print('${p.nome} custa ${p.preco}');

  final lista = [Produto('pão', 0.8), Produto('bolo', 25)];
  print(jsonEncode(lista));
}
factory Produto.fromJson(…)
Um construtor factory nomeado (veja Construtores Nomeados e factory) que recebe o mapa vindo do jsonDecode e monta o objeto. O (… as num).toDouble() aceita 12 e 12.0.
toJson()
Devolve um mapa com os campos. O nome toJson é especial: quando o jsonEncode encontra um objeto que não sabe converter, ele chama o toJson() desse objeto.
jsonEncode(lista)
Por isso uma lista de Produto vira JSON direto, sem você chamar nada.
$ dart run classe.dart
café custa 12.0
[{"nome":"pão","preco":0.8},{"nome":"bolo","preco":25.0}]

Repare: o 12 do JSON virou 12.0 (um double), e o Produto('bolo', 25) saiu como 25.0. Em projetos grandes, esses dois métodos costumam ser gerados por pacotes (como o json_serializable, do pub.dev); escrevê-los à mão, como aqui, é o primeiro passo.

6. JSON num arquivo

Juntando com a aula de Arquivos: gravar é jsonEncode + writeAsStringSync; ler é readAsStringSync + jsonDecode.

import 'dart:convert';
import 'dart:io';

void main() {
  final arquivo = File('estoque.json');
  final estoque = {'pão': 120, 'sonho': 8};
  arquivo.writeAsStringSync(jsonEncode(estoque));

  final lido = jsonDecode(arquivo.readAsStringSync()) as Map<String, dynamic>;
  lido['sonho'] = (lido['sonho'] as int) - 3;
  lido['broa'] = 15;
  arquivo.writeAsStringSync(jsonEncode(lido));
  print(arquivo.readAsStringSync());
}

$ dart run arquivo_json.dart
{"pão":120,"sonho":5,"broa":15}

Gravou, leu, vendeu 3 sonhos, cadastrou a broa e gravou de novo. Na próxima vez que o programa rodar, o estoque estará lá. O Projeto: Estoque da Lojinha faz isso completo.

Missão final: o pedido da padaria

Missão: o programa lê o pedido do Caio em JSON, mas ainda não calcula o total. Some quantidade * preco de cada item, guarde no mapa com pedido['total'] = total; e mostre o pedido de volta em JSON com print(jsonEncode(pedido));. O total deve dar 17.5.

import 'dart:convert';

void main() {
  const texto = '{"cliente": "Caio", "itens": [{"nome": "pão", "quantidade": 10, "preco": 0.75}, {"nome": "bolo", "quantidade": 1, "preco": 10}]}';
  final pedido = jsonDecode(texto) as Map<String, dynamic>;
  final itens = pedido['itens'] as List<dynamic>;

  var total = 0.0;
  // some quantidade * preco de cada item aqui

  print('Itens: ${itens.length}');
}

import 'dart:convert';

void main() {
  const texto = '{"cliente": "Caio", "itens": [{"nome": "pão", "quantidade": 10, "preco": 0.75}, {"nome": "bolo", "quantidade": 1, "preco": 10}]}';
  final pedido = jsonDecode(texto) as Map<String, dynamic>;
  final itens = pedido['itens'] as List<dynamic>;

  var total = 0.0;
  for (final item in itens) {
    final quantidade = item['quantidade'] as int;
    final preco = (item['preco'] as num).toDouble();
    total += quantidade * preco;
  }

  print('Itens: ${itens.length}');
  pedido['total'] = total;
  print(jsonEncode(pedido));
}

Resumo

  • JSON é um formato de texto para dados: objetos { }, listas [ ], textos com aspas duplas, números, true/false e null.
  • jsonDecode (de dart:convert) transforma o texto em Map<String, dynamic> / List<dynamic>; jsonEncode faz o contrário.
  • Diga o tipo de cada campo com as; para decimais, (x as num).toDouble(); para opcionais, as String? ?? 'padrão'.
  • Classes ganham fromJson (um factory) e toJson() (que o jsonEncode chama sozinho).
  • JSON mal escrito dá FormatException com a posição do caractere; tipo errado dá type '…' is not a subtype of type '…'.
