Dart if e else

Até aqui, os seus programas rodavam todas as linhas, de cima para baixo, sempre do mesmo jeito. Agora eles vão começar a decidir: mostrar "Aprovada" ou "Recuperação" conforme a nota, avisar do calor só quando está calor. Quem decide é o if, que em inglês quer dizer "se", com o seu parceiro else, "senão".

Você vai aprender
  • Como escrever um if: a condição entre parênteses e o bloco entre chaves.
  • O else: o que fazer quando a condição é falsa.
  • A cadeia else if, para mais de dois caminhos, e por que a ordem das condições importa.
  • if dentro de if.
  • Por que usar chaves sempre, e o que acontece com uma variável criada dentro do bloco.
  • Os erros reais: if sem parênteses, elif, else com condição, chave esquecida, número no lugar de bool e o ; depois do if, que não dá erro nenhum.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: o bilhete na geladeira

A mãe da Ana deixou um bilhete na geladeira: "Se chover, leve o guarda-chuva. Senão, leve o boné." Ana olha pela janela (a condição), e só um dos dois conselhos vale naquele dia. O outro é ignorado. E, chova ou não, ela sai de casa: o resto do dia continua igual.

O if funciona do mesmo jeito: testa uma condição (uma pergunta de sim ou não, como as da aula Comparação) e, conforme a resposta, roda um bloco de código ou outro.

1. O primeiro if

void main() {
  final temperatura = 32;
  print('Temperatura: $temperatura °C');
  if (temperatura > 30) {
    print('Está calor! Leve uma garrafa de água.');
  }
  print('Bom dia!');
}
if
A palavra-chave: "se".
(temperatura > 30)
A condição, sempre entre parênteses. Tem de dar um bool: true ou false.
{ … }
O bloco: as linhas entre as chaves rodam só se a condição for true. Os 2 espaços a mais na frente mostram, para quem lê, que elas estão dentro do if.
print('Bom dia!');
Fora das chaves: roda sempre, com calor ou sem.
$ dart run if1.dart
Temperatura: 32 °C
Está calor! Leve uma garrafa de água.
Bom dia!

Com temperatura = 22, a condição 22 > 30 é false, e o Dart pula o bloco inteiro:

$ dart run if2.dart
Temperatura: 22 °C
Bom dia!

Repare que não tem ; depois do ) nem depois do }: o ; fecha instruções, e o if com o seu bloco é uma instrução composta (veja Instruções, Ponto e Vírgula e Blocos). Um ; logo depois do if (…) é um dos erros mais traiçoeiros do Dart; ele está em Quando dá errado.

2. else: senão

void main() {
  final nota = 5.5;
  if (nota >= 6) {
    print('Aprovada!');
  } else {
    print('Recuperação.');
  }
  print('Nota lançada: $nota');
}

$ dart run else.dart
Recuperação.
Nota lançada: 5.5

O else vem logo depois da chave que fecha o if (} else {, na mesma linha, é o estilo do Dart) e tem o seu próprio bloco. Ele não tem condição: roda quando a condição do if deu false. Com if e else, sempre roda um dos dois blocos, e nunca os dois.

3. Mais de dois caminhos: else if

A escola da Ana dá conceitos: A para 9 ou mais, B para 7 ou mais, C para 5 ou mais, D para o resto. São quatro caminhos. Para isso, encadeie else if ("senão, se"):

void main() {
  final nota = 7.8;
  if (nota >= 9) {
    print('Conceito A');
  } else if (nota >= 7) {
    print('Conceito B');
  } else if (nota >= 5) {
    print('Conceito C');
  } else {
    print('Conceito D');
  }
}

$ dart run elseif.dart
Conceito B

O Dart testa as condições de cima para baixo e para na primeira verdadeira:

TesteCom nota = 7.8O que acontece
nota >= 9falsePassa para o próximo
nota >= 7trueMostra Conceito B e sai da cadeia inteira
nota >= 5não é testado(seria true também, mas o Dart nem olha)
elsenão rodasó rodaria se todas dessem false

Por isso o else if (nota >= 7) não precisa dizer "e menor que 9": se a nota fosse 9 ou mais, a primeira condição já teria pegado. Mas isso só funciona com as condições na ordem certa, da mais exigente para a menos exigente. Veja o que acontece com a ordem trocada, numa nota 9.5:

void main() {
  final nota = 9.5;
  if (nota >= 5) {
    print('Conceito C');
  } else if (nota >= 7) {
    print('Conceito B');
  } else if (nota >= 9) {
    print('Conceito A');
  } else {
    print('Conceito D');
  }
}

$ dart run ordem_err.dart
Conceito C

Nota 9.5 e conceito C! O 9.5 >= 5 é verdade, e a cadeia parou ali. O Dart não avisa nada, porque o código está correto do ponto de vista dele; o erro é de lógica. Os testes de >= 7 e >= 9 nunca vão ser alcançados.

4. if dentro de if

Dentro de um bloco pode ir qualquer coisa, inclusive outro if. No cinema, maiores de 18 entram; menores, só com um responsável:

void main() {
  final idade = 16;
  final comResponsavel = true;
  if (idade >= 18) {
    print('Pode entrar.');
  } else {
    if (comResponsavel) {
      print('Pode entrar acompanhado.');
    } else {
      print('Não pode entrar.');
    }
  }
}

$ dart run aninhado.dart
Pode entrar acompanhado.

Cada nível ganha 2 espaços a mais de recuo, e é isso que permite enxergar qual else pertence a qual if. A mesma regra poderia ser escrita sem aninhar, com else if (comResponsavel), ou com os operadores lógicos (idade >= 18 || comResponsavel, aula Operadores Lógicos): veja Formas diferentes.

5. Chaves sempre, e o que nasce dentro do bloco

Sem chaves, só uma linha conta

O Dart deixa escrever um if sem chaves, mas aí só a primeira instrução depois dele faz parte do if. O recuo não conta nada para o Dart:

void main() {
  final estoque = 0;
  if (estoque == 0) print('Acabou o pão!');
  if (estoque > 0)
    print('Tem pão.');
    print('Pode passar no caixa.');
}

$ dart run semchave.dart
Acabou o pão!
Pode passar no caixa.

A linha Pode passar no caixa. parece estar dentro do segundo if, mas está fora: ela roda sempre, mesmo sem pão. O guia de estilo do Dart (Effective Dart) aceita o if sem chaves só quando ele cabe inteiro numa linha, como o primeiro. Para não cair nessa, a regra deste guia é simples: use chaves sempre.

Variável criada dentro do bloco some no }

Uma variável criada dentro de um bloco só existe dentro dele. Para usar o resultado de um if depois dele, crie a variável antes, e dê o valor dentro dos blocos:

void main() {
  final nota = 8;
  String mensagem;
  if (nota >= 6) {
    mensagem = 'Aprovada';
  } else {
    mensagem = 'Recuperação';
  }
  print(mensagem);
}

$ dart run escopo_ok.dart
Aprovada

O String mensagem; cria a variável sem valor. O Dart confere que os dois caminhos dão um valor a ela antes do print; se um caminho esquecer, o programa não compila (veja Quando dá errado). Para escolher entre dois valores assim, existe uma forma mais curta, o operador ternário.

Formas diferentes de fazer

A regra do cinema, de três jeitos:

// 1) if dentro de else (a da seção 4)

// 2) else if
if (idade >= 18) {
  print('Pode entrar.');
} else if (comResponsavel) {
  print('Pode entrar acompanhado.');
} else {
  print('Não pode entrar.');
}

// 3) operador lógico, quando a mensagem é a mesma
if (idade >= 18 || comResponsavel) {
  print('Pode entrar.');
} else {
  print('Não pode entrar.');
}
SituaçãoUse
Fazer algo só em um casoif (…) { … }
Dois caminhosif (…) { … } else { … }

Quando dá errado

Um ; depois do if (…): sem erro, e tudo errado 
void main() {
  final saldo = 50;
  if (saldo > 100); {
    print('Compra aprovada!');
  }
}

$ dart run pontoevirgula.dart
Compra aprovada!

Saldo 50, compra de mais de 100, e a compra foi aprovada! O ; logo depois do ) é uma instrução vazia: o if ficou sendo "se o saldo for maior que 100, não faça nada". As chaves de baixo viraram um bloco solto, que roda sempre. O Dart compila sem reclamar. Como consertar: nunca ponha ; entre o ) do if e o {.

Escreveu elif (ou elseif) 
void main() {

  } elif (nota >= 7) {

  } elif (nota >= 7) {

"Era esperado ) antes disto." Uma mensagem estranha, porque o Dart não conhece elif: ele achou que elif(nota …) fosse a chamada de uma função chamada elif e se perdeu no >=. Como consertar: no Dart são duas palavras, separadas: } else if (nota >= 7) {.

Uma condição que não é bool 
void main() {
  final itens = 3;
  if (itens) {
    print('Tem itens no carrinho');
  }
}

$ dart run intcond.dart
intcond.dart:3:7: Error: A value of type 'int' can't be assigned to a variable of type 'bool'.
  if (itens) {
      ^

Em outras linguagens, um número diferente de zero "vale" verdadeiro. No Dart, a condição do if tem de ser um bool de verdade. O mesmo erro aparece com if (saldo = 100), com um = só (aula Comparação). Como consertar: escreva a pergunta inteira: if (itens > 0).

Resumo

  • if (condição) { … } roda o bloco só quando a condição é true. A condição vai entre parênteses e tem de ser um bool.
  • else { … } roda quando a condição é false; não leva condição.
  • else if encadeia mais caminhos; o Dart para na primeira condição verdadeira, então ordene da mais exigente para a menos.
  • Use chaves sempre; sem elas, só a primeira instrução faz parte do if. E nunca ponha ; logo depois do if (…).
  • Variável criada dentro de um bloco some no }: para usar depois, crie antes e dê valor em todos os caminhos.
