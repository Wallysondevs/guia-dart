Projeto: Jogo de Adivinhação

Hora de juntar o que você aprendeu num programa de verdade: o clássico jogo de adivinhação. O computador pensa num número de 1 a 100; você chuta; ele responde "é maior" ou "é menor", até você acertar. Parece simples, e é por isso que é o primeiro projeto de tanta gente: usa leitura do teclado, comparações, laço, contador, números aleatórios e tratamento de entrada inválida. Vamos construir em cinco versões, cada uma com uma novidade, testando a cada passo.

Você vai usar
  • stdin.readLineSync() e stdout.write (aula Lendo o Teclado).
  • int.parse e int.tryParse (aula Conversão de Tipos).
  • if/else if, while, continue e return (aulas if e else, while, break e continue).
  • Random da biblioteca dart:math, com e sem semente.

Todas as sessões abaixo rodaram no Dart SDK 3.13.5 da máquina da Ana (usuária ana, computador notebook), numa pasta adivinha, com o texto digitado por ela aparecendo depois das perguntas. No editor do guia, o que você "digitaria" vem do campo de entrada da caixa (ou é pedido na hora).

O plano

  1. Versão 1: um número secreto fixo e um palpite.
  2. Versão 2: repetir até acertar (while), com as dicas.
  3. Versão 3: contar as tentativas.
  4. Versão 4: sortear o número de verdade (Random), e a semente para testar.
  5. Versão 5: aguentar entrada errada e limitar as tentativas.

Construir aos poucos é o jeito profissional: cada versão roda, e se algo quebrar você sabe que foi a última mudança.

Versão 1: um palpite só

Primeiro, o esqueleto: o número secreto é fixo (42), o programa lê um palpite e compara.

import 'dart:io';

void main() {
  const segredo = 42;
  stdout.write('Adivinhe o número (1 a 100): ');
  final palpite = int.parse(stdin.readLineSync()!);
  if (palpite == segredo) {
    print('Acertou!');
  } else if (palpite < segredo) {
    print('Errou: o número é maior que $palpite.');
  } else {
    print('Errou: o número é menor que $palpite.');
  }
}

Versão 2: repetir até acertar

Um palpite só não é jogo. Queremos repetir enquanto o palpite for diferente do segredo: é o while.

import 'dart:io';

void main() {
  const segredo = 42;
  var palpite = 0;
  while (palpite != segredo) {
    stdout.write('Seu palpite: ');
    palpite = int.parse(stdin.readLineSync()!);
    if (palpite < segredo) {
      print('É maior!');
    } else if (palpite > segredo) {
      print('É menor!');
    }
  }
  print('Acertou! Era $segredo.');
}

O que mudou:

  • var palpite = 0; agora é var (muda a cada volta) e começa com 0, um valor que com certeza não é o segredo, para o laço entrar na primeira vez.
  • while (palpite != segredo): "enquanto o palpite for diferente do segredo". O != é "diferente".
  • Dentro do laço, só as dicas. O "Acertou!" saiu para depois do laço: se o programa chegou lá, é porque acertou.

A estratégia de quem joga bem

Repare nos palpites: 50 (o meio de 1 a 100), depois 25 (o meio do que sobrou)… Chutar sempre no meio corta as possibilidades pela metade a cada vez. Com essa estratégia, 7 palpites bastam para qualquer número de 1 a 100 (porque 27 = 128 > 100). Esse é o número de tentativas da versão 5.

Versão 3: contando as tentativas

Um placar deixa o jogo mais divertido. Basta uma variável contadora, criada antes do laço e aumentada a cada palpite:

import 'dart:io';

void main() {
  const segredo = 42;
  var palpite = 0;
  var tentativas = 0;
  while (palpite != segredo) {
    stdout.write('Seu palpite: ');
    palpite = int.parse(stdin.readLineSync()!);
    tentativas++;
    if (palpite < segredo) {
      print('É maior!');
    } else if (palpite > segredo) {
      print('É menor!');
    }
  }
  print('Acertou em $tentativas tentativas!');
}

Versão 4: o número sorteado

Com o segredo sempre 42, o jogo perde a graça na segunda partida. A biblioteca dart:math tem a classe Random ("aleatório"), que sorteia números:

import 'dart:math';

void main() {
  final dado = Random();
  print('Sem semente: ${dado.nextInt(100) + 1}, ${dado.nextInt(100) + 1}, ${dado.nextInt(100) + 1}');
  final fixo = Random(42);
  print('Semente 42: ${fixo.nextInt(100) + 1}, ${fixo.nextInt(100) + 1}, ${fixo.nextInt(100) + 1}');
}

$ dart run sorteio.dart
Sem semente: 58, 56, 59
Semente 42: 88, 59, 5
$ dart run sorteio.dart
Sem semente: 4, 40, 45
Semente 42: 88, 59, 5
Random()
Um sorteador. Cada vez que o programa roda, sai uma sequência diferente (58, 56, 59 na primeira vez; 4, 40, 45 na segunda).
.nextInt(100)
"Próximo inteiro" de 0 até 99 (o 100 não entra). Por isso o + 1: assim vai de 1 a 100.
Random(42)
Um sorteador com semente (seed) 42. A semente decide a sequência: com a mesma semente, sai sempre a mesma (88, 59, 5 nas duas vezes). Parece inútil num jogo, mas é ótimo para testar: você sabe qual vai ser o segredo.

No jogo, troque o const segredo = 42 por um sorteio (e const vira final, porque o valor só é conhecido quando o programa roda):

import 'dart:io';
import 'dart:math';

void main() {
  final segredo = Random().nextInt(100) + 1;
  var palpite = 0;
  var tentativas = 0;
  while (palpite != segredo) {
    stdout.write('Seu palpite: ');
    palpite = int.parse(stdin.readLineSync()!);
    tentativas++;
    if (palpite < segredo) {
      print('É maior!');
    } else if (palpite > segredo) {
      print('É menor!');
    }
  }
  print('Acertou em $tentativas tentativas! Era $segredo.');
}

A semente é para testar, não para jogar

Com Random(42), o segredo é sempre 88: quem jogar duas vezes descobre. Na versão de verdade, use Random() sem semente. E use a semente só para ter repetição durante o teste: não escreva programas cuja lógica dependa de "a semente 42 dá 88".

Versão 5: à prova de erros, com limite

A versão final conserta os dois problemas e acrescenta um limite de 7 tentativas:

import 'dart:io';
import 'dart:math';

const maxTentativas = 7;

void main() {
  final segredo = Random().nextInt(100) + 1;
  print('Pensei num número de 1 a 100. Você tem $maxTentativas tentativas.');
  var tentativas = 0;
  while (tentativas < maxTentativas) {
    stdout.write('Tentativa ${tentativas + 1}: ');
    final texto = stdin.readLineSync();
    if (texto == null) {
      print('\nTchau!');
      return;
    }
    final palpite = int.tryParse(texto.trim());
    if (palpite == null || palpite < 1 || palpite > 100) {
      print('Digite um número inteiro de 1 a 100.');
      continue;
    }
    tentativas++;
    if (palpite == segredo) {
      print('Acertou em $tentativas tentativas!');
      return;
    }
    print(palpite < segredo ? 'É maior!' : 'É menor!');
  }
  print('Acabaram as tentativas. Era $segredo.');
}
const maxTentativas = 7;
O limite, numa constante com nome (fora do main). Para mudar a dificuldade, muda-se num lugar só.
while (tentativas < maxTentativas)
Agora o laço para por dois motivos: acabaram as tentativas (a condição fica falsa) ou o jogador acertou (o return).
if (texto == null) { … return; }
Se a entrada acabou, despede-se e sai do main, sem ! e sem exceção. Depois desse if, o Dart sabe que texto não é nulo.
int.tryParse(texto.trim())
"Tenta converter": devolve o número, ou null se o texto não for número, sem exceção. O trim() tira espaços das pontas (' 50 ' vira '50').
palpite == null || palpite < 1 || palpite > 100
Inválido se não for número ou estiver fora de 1 a 100.
continue;
Volta para o começo do laço sem contar a tentativa: o jogador não perde a vez por digitar errado.
palpite < segredo ? 'É maior!' : 'É menor!'
O operador ternário: escolhe uma das duas dicas.

Ideias para continuar

  • Perguntar "Jogar de novo? (s/n)" no fim e repetir tudo com outro while por fora.
  • Níveis: fácil (1 a 50, 10 tentativas), difícil (1 a 1000, 10 tentativas).
  • Guardar o recorde (menor número de tentativas) num arquivo (aula Lendo e Escrevendo Arquivos).
  • Transformar a comparação numa função String dica(int palpite, int segredo) e testá-la com package:test (aula Testes).

import 'dart:io';
import 'dart:math';

const maxTentativas = 7;

void main() {
  final segredo = Random().nextInt(100) + 1;
  var tentativas = 0;
  while (tentativas < maxTentativas) {
    stdout.write('Tentativa ${tentativas + 1}: ');
    final palpite = int.tryParse(stdin.readLineSync() ?? '');
    if (palpite == null) {
      print('Digite um número inteiro de 1 a 100.');
      continue;
    }
    tentativas++;
    if (palpite == segredo) {
      print('Acertou em $tentativas tentativas!');
      return;
    }
    print(palpite < segredo ? 'É maior!' : 'É menor!');
  }
  print('Acabaram as tentativas. Era $segredo.');
}

Resumo

  • Construa aos poucos: segredo fixo → laço → contador → sorteio → validação. Cada versão roda antes da próxima.
  • stdout.write pergunta sem pular linha; stdin.readLineSync() lê a resposta (String?).
  • while (palpite != segredo) repete até acertar; o "Acertou" fica depois do laço.
  • Random().nextInt(100) + 1 sorteia de 1 a 100; Random(42) repete sempre a mesma sequência, útil para testar.
  • int.parse com texto inválido lança FormatException, e o ! com entrada vazia lança Null check operator used on a null value; int.tryParse + checagem de null + continue deixam o jogo à prova de erros.
