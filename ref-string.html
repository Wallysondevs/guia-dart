Dart Métodos de String

Esta é a página de consulta dos métodos de String: o que dá para perguntar e fazer com um texto em Dart. A explicação com calma de cada grupo está nas aulas Strings, Métodos de String e Interpolação; aqui ficam as tabelas para consulta rápida.

Como ler as tabelas
  • Nos exemplos, s é 'Padaria do Bairro' (17 caracteres; o primeiro, P, está na posição 0).
  • Resultado é o que o Dart SDK 3.13.5 mostrou no computador da Ana. Os colchetes em [Ana ] foram postos no print para os espaços aparecerem.
  • Uma String nunca muda. Todo método que "altera" devolve uma String nova; a original continua igual. Para guardar o resultado: nome = nome.trim();.

Tentando mudar uma letra 
void main() {
  var nome = 'ana';
  nome[0] = 'A';
  print(nome);
}

$ dart run trocar.dart
trocar.dart:3:7: Error: The operator '[]=' isn't defined for the type 'String'.

      ^

"O operador []= (escrever numa posição) não existe para String." Strings não mudam: monte uma nova, por exemplo nome = nome[0].toUpperCase() + nome.substring(1);.

Experimente

Missão: o cadastro chegou com espaços sobrando e tudo em minúsculas. Deixe o nome como Ana Clara Souza: tire os espaços das pontas, separe as palavras, ponha a primeira letra de cada uma em maiúscula e junte de novo com um espaço.

void main() {
  final cadastro = '   ana clara souza  ';
  print(cadastro);
}

void main() {
  final cadastro = '   ana clara souza  ';
  final palavras = cadastro.trim().split(' ');
  final arrumadas = palavras.map((p) => p[0].toUpperCase() + p.substring(1));
  print(arrumadas.join(' '));
}

Livre: o programa que gerou todos os resultados das tabelas (cada linha começa com um número, para achar na tabela). Mude o texto de s e rode.

void main() {
  const s = 'Padaria do Bairro';
  // tamanho e acesso
  print('1 ${s.length}');
  print('2 ${s[0]} ${s[s.length - 1]}');
  print('3 ${s.isEmpty} ${''.isEmpty} ${'  '.isNotEmpty}');
  // maiúsculas
  print('4 ${s.toUpperCase()} | ${s.toLowerCase()}');
  print('5 ${'ação'.toUpperCase()}');
  // procurar
  print('6 ${s.contains('do')} ${s.contains('DO')}');
  print('7 ${s.startsWith('Pad')} ${s.endsWith('ro')}');
  print('8 ${s.indexOf('a')} ${s.lastIndexOf('a')} ${s.indexOf('z')}');
  print('9 ${s.indexOf('a', 2)}');
  // pedaços
  print('10 ${s.substring(0, 7)} | ${s.substring(11)}');
  print('11 ${s.split(' ')}');
  print('12 ${'a,b,,c'.split(',')} ${'abc'.split('')}');
  // limpar
  print('13 [${'  Ana  '.trim()}] [${'  Ana  '.trimLeft()}] [${'  Ana  '.trimRight()}]');
  // trocar
  print('14 ${s.replaceAll('a', '4')}');
  print('15 ${s.replaceFirst('a', '4')}');
  print('16 ${'banana'.replaceAll(RegExp('[an]'), '*')}');
  print('17 ${s.replaceRange(0, 7, 'Doceria')}');
  // completar
  print('18 [${'7'.padLeft(3, '0')}] [${'Ana'.padRight(6)}] [${'Ana'.padLeft(6)}]');
  // repetir / juntar
  print('19 ${'-' * 10} ${['a', 'b', 'c'].join(' - ')}');
  // comparar
  print('20 ${'abc'.compareTo('abd')} ${'b'.compareTo('a')} ${'a'.compareTo('a')}');
  print('21 ${'Ana' == 'ana'} ${'Ana'.toLowerCase() == 'ana'}');
  // códigos
  print('22 ${'A'.codeUnitAt(0)} ${String.fromCharCode(66)} ${'Olá'.codeUnits}');
  print('23 ${'Olá'.runes.length} ${'👍'.length} ${'👍'.runes.length}');
  // conversões
  print('24 ${int.parse('42') + 1} ${double.parse('3.5') * 2} ${int.tryParse('x')}');
  print('25 ${42.toString()} ${3.14159.toStringAsFixed(2)} ${7.toString().padLeft(3, '0')}');
  // regex
  print('26 ${RegExp(r'\d+').allMatches('Rua 12, casa 7').map((m) => m[0]).toList()}');
  print('27 ${'Rua 12'.contains(RegExp(r'\d'))}');
  // interpolação e multilinha
  final nome = 'Ana';
  print('28 Olá, $nome! Você tem ${nome.length} letras.');
  print('''29 linha 1
linha 2''');
  print(r'30 sem interpolação: $nome \n');
  // splitMapJoin / isNotEmpty extras
  print('31 ${'Ana Souza'.split(' ').map((p) => p[0]).join()}');
  print('32 ${'oi'.allMatches('oioioi').length}');
  final sb = StringBuffer()
    ..write('Pão')
    ..write(', ')
    ..writeAll(['leite', 'café'], ', ');
  print('33 $sb');
}

Resumo

  • Strings não mudam: os métodos devolvem uma String nova (nome = nome.trim();).
  • Posições começam em 0; substring(inicio, fim) não inclui o fim; fora da faixa, RangeError.
  • Procurar: contains, startsWith, endsWith, indexOf (-1 = não achou).
  • Cortar e juntar: split e join; limpar: trim; trocar: replaceAll; alinhar: padLeft/padRight.
  • Converter: int.parse/tryParse e toStringAsFixed.
