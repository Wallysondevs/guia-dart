Dart final e const

Na aula Variáveis, o var criava potes cujo conteúdo dava para trocar quando quisesse. Só que, num programa de verdade, a maioria dos valores não deveria mudar: o nome da cliente do pedido, o preço do pão de hoje, o número de dias da semana. Para esses, o Dart tem duas palavras: final ("final": recebe o valor uma vez e pronto) e const ("constante": um valor fixo, conhecido antes mesmo de o programa rodar).

Você vai aprender
  • A criar variáveis com final, que recebem valor uma única vez.
  • A criar constantes com const e o que quer dizer "conhecido antes de rodar".
  • A diferença entre var, final e const, e qual usar em cada caso.
  • Por que o costume em Dart é usar final sempre que der.
  • O que acontece com uma lista final e uma lista const.
  • Os erros reais: trocar um final, usar um valor que muda num const, e mexer numa lista const.

Os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook), dentro da pasta fc, com dart run arquivo.dart.

A ideia: lápis, caneta e placa pintada

A Ana anota as coisas da padaria de três jeitos:

  • O estoque do dia, a lápis no quadro: apaga e reescreve toda hora. É o var.
  • O nome no pedido, a caneta na comanda: só se escreve quando a cliente chega, mas depois de escrito não se apaga. É o final.
  • O horário de funcionamento, pintado na placa da porta: decidido antes de a padaria abrir e igual todos os dias. É o const.

1. final: uma vez só

void main() {
  final cliente = 'Bia';
  final int pedidos = 3;
  print(cliente);
  print(pedidos);
}

$ dart run final1.dart
Bia
3
final cliente = 'Bia';
No lugar do var, a palavra final. O tipo continua sendo descoberto pelo valor (String).
final int pedidos = 3;
Também dá para escrever o tipo, entre o final e o nome.

Até aqui, nada de diferente do var. A diferença aparece quando alguém tenta trocar o valor:

void main() {
  final cliente = 'Bia';
  cliente = 'Caio';
  print(cliente);
}

$ dart run final_muda.dart
final_muda.dart:3:3: Error: Can't assign to the final variable 'cliente'.
  cliente = 'Caio';
  ^^^^^^^
$ echo $?
254

"Não é possível atribuir à variável final cliente." É um erro de compilação: o Dart percebe antes de rodar e não deixa o programa nem começar. É exatamente para isso que o final serve: se você (ou um colega) trocar sem querer um valor que não devia mudar, o Dart avisa na hora.

Valor decidido depois, mas uma vez só

Como a comanda, o final pode ficar em branco por um tempo, desde que receba o valor uma única vez antes de ser usado:

void main() {
  final int total;
  total = 12 + 8;
  print(total);
}

$ dart run final_depois.dart
20

Nesse caso, escreva o tipo (final int total;). Mais adiante, com if e else, isso vai ser útil: "se for sábado, o total é este; senão, é aquele", e o valor nunca mais muda.

Missão: o nome no pedido não deveria mudar. Troque o var por final e rode: o Dart vai apontar a linha que estraga o pedido. Apague essa linha.

void main() {
  var cliente = 'Bia';
  print('Pedido de $cliente');
  cliente = 'Caio';
  print('Pedido de $cliente');
}

void main() {
  final cliente = 'Bia';
  print('Pedido de $cliente');
  print('Pedido de $cliente');
}

2. const: conhecido antes de rodar

O const também não deixa trocar o valor, mas exige mais: o valor tem de ser conhecido na compilação, aquela conferência que o Dart faz antes de rodar (aula O que é Dart). Valem números, textos, true/false escritos direto no código, e contas feitas só com eles ou com outros const:

void main() {
  const precoPao = 0.9;
  const paesPorSaco = 10;
  const precoSaco = precoPao * paesPorSaco;
  print(precoSaco);
}

$ dart run const1.dart
9.0
const precoPao = 0.9;
Um número escrito no código: o Dart já sabe o valor antes de rodar.
const precoSaco = precoPao * paesPorSaco;
Uma conta só com constantes também é constante: o Dart pode fazer essa conta durante a compilação. O resultado, 0.9 * 10, é 9.0 (um double, por causa do 0.9).

Já um valor que só existe com o programa rodando não pode ser const. Quantos pães há em paes? Depende do que aconteceu até aquela linha, e o Dart não aceita:

void main() {
  var paes = 30;
  const total = paes * 2;
  print(total);
}

$ dart run const_var.dart
const_var.dart:3:17: Error: Not a constant expression.
  const total = paes * 2;
                ^^^^

"Não é uma expressão constante." O ^ aponta para paes, uma variável comum. Com final, o mesmo código funciona, porque o final aceita valores decididos na hora de rodar:

void main() {
  var paes = 30;
  final total = paes * 2;
  print(total);
}

$ dart run final_var.dart
60

3. Os três juntos

void main() {
  var estoque = 30;
  final cliente = 'Bia';
  const precoPao = 0.9;
  estoque = estoque - 5;
  print(estoque);
  print(cliente);
  print(precoPao * 5);
}

$ dart run tres.dart
25
Bia
4.5

O estoque muda (var), o nome da cliente foi escrito uma vez (final) e o preço do pão é fixo no código (const). Só o estoque pode aparecer do lado esquerdo de um = depois de criado.

Qual usar

PerguntaResposta
O valor vai mudar depois?Sim → var (ou o tipo: int estoque = 30;)
Não muda, e é um valor fixo, escrito no código?const (const diasDaSemana = 7;)
Não muda, mas depende de algo que só se sabe rodando (uma conta com variáveis, o que a pessoa digitou, a data de hoje)?final
Na dúvida entre final e const?final: funciona sempre que o const funcionaria
Por que usar final sempre que der

Em código Dart profissional, a maior parte das variáveis é final, e var fica para o que realmente muda (contadores, totais que vão acumulando). O motivo: quando você lê final total = …, sabe que aquele valor nunca muda dali em diante, e não precisa procurar no resto do código se alguém o trocou. E, se alguém tentar, o Dart avisa. Este guia segue esse costume a partir daqui.

Um detalhe de estilo: em Dart, constantes usam o mesmo formato de nome que as variáveis (precoPao, diasDaSemana), e não letras maiúsculas como PRECO_PAO, que é o costume de outras linguagens. Mais em Nomes de Variáveis.

4. Listas final e const

Com listas (aula Listas), aparece uma diferença importante. Uma lista final não pode ser trocada por outra lista, mas o conteúdo dela pode mudar:

void main() {
  final compras = ['pão', 'leite'];
  compras.add('café');
  print(compras);
}

$ dart run lista_final.dart
[pão, leite, café]

O compras.add('café') ("acrescente café") funcionou. O final protege a etiqueta: compras sempre vai ser esta mesma lista. Pôr outra lista no lugar, aí sim, é erro:

$ dart run lista_final_troca.dart
lista_final_troca.dart:3:3: Error: Can't assign to the final variable 'compras'.
  compras = ['café'];
  ^^^^^^^

Já uma lista const é congelada por inteiro: nem a etiqueta nem o conteúdo mudam. E aqui o erro só aparece com o programa rodando:

void main() {
  const dias = ['seg', 'ter', 'qua'];
  print(dias);
  dias.add('qui');
  print(dias);
}

$ dart run lista_const.dart

Quando dá errado

Trocar o valor de um const 
void main() {
  const taxa = 0.1;
  taxa = 0.2;
  print(taxa);
}

$ dart run const_muda.dart
const_muda.dart:3:3: Error: Can't assign to the const variable 'taxa'.
  taxa = 0.2;
  ^^^^

"Não é possível atribuir à variável const taxa". Igual ao final. Como consertar: se o valor precisa mudar, use var; se não, apague a linha que troca.

final recebendo valor duas vezes 
void main() {
  final int total;
  total = 20;
  total = 25;
  print(total);
}

$ dart run final_duas.dart
final_duas.dart:4:3: Error: Final variable 'total' might already be assigned at this point.
  total = 25;
  ^^^^^

"A variável final total pode já ter recebido valor neste ponto." A linha 3 está certa (a primeira atribuição); a 4 é a segunda, e o final só aceita uma. Como consertar: fique com uma só, ou use var se o total precisa mudar.

const sem valor 
void main() {
  const taxa;
  print(taxa);
}

$ dart run const_sem_valor.dart
const_sem_valor.dart:2:9: Error: The const variable 'taxa' must be initialized.
Try adding an initializer ('= expression') to the declaration.
  const taxa;
        ^^^^

"A variável const taxa precisa ser inicializada. Tente acrescentar um inicializador (= expressão) à declaração." Diferente do final, o const não pode receber o valor depois: tem de nascer com ele. Como consertar: const taxa = 0.1;.

Algo do momento num const: a data de hoje 
void main() {
  const agora = DateTime.now();
  print(agora);
}

$ dart run const_agora.dart
const_agora.dart:2:26: Error: Cannot invoke a non-'const' constructor where a const expression is expected.
Try using a constructor or factory that is 'const'.
  const agora = DateTime.now();
                         ^^^

DateTime.now() é "a data e a hora de agora": muda a cada vez que o programa roda, então não tem como ser conhecida antes. A mensagem fala em construtor (o jeito de criar um objeto, aula Construtores): "não é possível chamar um construtor que não é const onde se espera uma expressão constante". Junto com o Not a constant expression da seção 2, é o sinal de que você quis um const onde cabia um final. Como consertar: final agora = DateTime.now();.

Missão: o programa tem dois erros de Not a constant expression. O preço do pão é fixo e deve ser const; já o pedido depende de quantos sacos a cliente quis, e não pode ser const. Conserte trocando só as palavras const/final/var, sem mudar os valores.

void main() {
  var precoPao = 0.9;
  const paesPorSaco = 10;
  var sacos = 2;
  final cliente = 'Bia';
  const precoSaco = precoPao * paesPorSaco;
  const pedido = sacos;
  print('Saco com $paesPorSaco pães: R\$ $precoSaco');
  print('Pedido de $cliente: $pedido sacos');
}

void main() {
  const precoPao = 0.9;
  const paesPorSaco = 10;
  var sacos = 2;
  final cliente = 'Bia';
  const precoSaco = precoPao * paesPorSaco;
  final pedido = sacos;
  print('Saco com $paesPorSaco pães: R\$ $precoSaco');
  print('Pedido de $cliente: $pedido sacos');
}

O \$ dentro do texto mostra um cifrão de verdade, em vez de procurar uma variável (aula Interpolação).

Missão final: a etiqueta de preço

Missão: declare desconto como const (é a regra da loja: 0.1), produto e precoFinal como final, e estoque como var (ele muda: um caderno foi vendido). Os valores já estão certos; só troque as palavras do começo de cada linha.

void main() {
  ? desconto = 0.1;
  ? produto = 'Caderno';
  ? preco = 20;
  ? precoFinal = preco - preco * desconto;
  ? estoque = 10;
  estoque = estoque - 1;
  print('Produto: $produto');
  print('Preço com desconto: $precoFinal');
  print('Estoque: $estoque');
}

void main() {
  const desconto = 0.1;
  final produto = 'Caderno';
  final preco = 20;
  final precoFinal = preco - preco * desconto;
  var estoque = 10;
  estoque = estoque - 1;
  print('Produto: $produto');
  print('Preço com desconto: $precoFinal');
  print('Estoque: $estoque');
}

Resumo

  • var: o valor pode mudar. final: recebe valor uma vez só. const: valor fixo, conhecido antes de rodar.
  • final aceita valores calculados ao rodar; const só aceita valores escritos no código e contas com outros const.
  • final pode receber o valor depois (uma vez); const tem de nascer com ele.
  • Use final sempre que o valor não for mudar; const para os valores fixos; var só para o que muda.
  • Lista final: o conteúdo muda, a etiqueta não. Lista const: nada muda (add → exceção).
  • Constantes têm nome como variáveis: precoPao, não PRECO_PAO.
