Dart Closures

Você já viu que o print de uma função anônima mostra Closure: …. Esta aula explica o nome. Uma closure (em inglês, algo como "fechamento") é uma função que lembra das variáveis do lugar onde foi criada, e continua podendo usá-las e mudá-las mesmo depois que esse lugar terminou. Parece mágica, mas é uma das ferramentas mais usadas do Dart (no Flutter, então, está em toda tela).

Você vai aprender
  • Que uma função pode usar as variáveis do bloco em volta dela.
  • O exemplo clássico: uma "fábrica" de contadores, em que cada contador guarda a sua própria contagem.
  • Como criar funções sob medida: a fábrica de descontos.
  • Que a closure guarda a variável, não uma cópia do valor: se a variável muda, a closure vê.
  • Como somar dentro de um forEach e por que o for do Dart cria uma variável nova a cada volta.
  • Os erros reais: Undefined name, Can't assign to the final variable e o LateInitializationError.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart. Antes, convém ter visto Funções Anônimas e Funções como Valores.

A ideia: a máquina de senhas da padaria

Na padaria, cada balcão tem uma maquininha de senhas. Você aperta o botão e sai a próxima senha: 1, 2, 3… A maquininha não precisa que ninguém diga "a última foi a 2": ela guarda o número lá dentro. E a maquininha do balcão de frios conta separado da do balcão de pães: cada uma tem o seu número guardado.

Uma closure é essa maquininha: uma função (o botão) mais as variáveis que ela carrega junto (o número guardado dentro dela).

1. A função enxerga as variáveis em volta

Comece pelo mais simples. Uma função anônima criada dentro do main pode usar as variáveis do main:

void main() {
  final nome = 'Ana';
  final saudar = () => print('Olá, $nome!');
  saudar();
}

$ dart run lembra.dart
Olá, Ana!

A função saudar não tem parâmetro nenhum, e mesmo assim usou nome. Ela enxerga as variáveis do bloco onde foi escrita, porque está dentro dele. Essa regra se chama escopo léxico: o que uma função enxerga depende de onde ela está escrita no código (veja também Funções).

Até aqui, nada demais. A parte interessante vem quando a função sai do lugar onde nasceu.

2. A fábrica de contadores

int Function() criarContador() {
  var senha = 0;
  return () {
    senha = senha + 1;
    return senha;
  };
}

void main() {
  final caixa1 = criarContador();
  final caixa2 = criarContador();
  print('Caixa 1 chamou a senha ${caixa1()}');
  print('Caixa 1 chamou a senha ${caixa1()}');
  print('Caixa 2 chamou a senha ${caixa2()}');
  print('Caixa 1 chamou a senha ${caixa1()}');
}

$ dart run contador.dart
Caixa 1 chamou a senha 1
Caixa 1 chamou a senha 2
Caixa 2 chamou a senha 1
Caixa 1 chamou a senha 3
int Function() criarContador()
Uma função que devolve uma função (que, por sua vez, não recebe nada e devolve int). É a "fábrica de maquininhas".
var senha = 0;
Uma variável local da criarContador. Normalmente, uma variável local some quando a função termina.
return () { senha = senha + 1; return senha; };
A função devolvida usa e muda a senha. Por isso, a senha não some: ela fica presa à closure, viva enquanto a closure existir. (O ; depois da } fecha o return.)
final caixa1 = criarContador();
Chama a fábrica: cria uma senha nova, valendo 0, e devolve uma maquininha presa a ela.
final caixa2 = criarContador();
Chama a fábrica de novo: outra senha, outra maquininha. Por isso a caixa 2 começa do 1, enquanto a caixa 1 segue sozinha para o 3.

Repare: depois que criarContador() terminou, ninguém consegue mais escrever senha no main. A única forma de mexer nela é apertar o botão (caixa1()). A closure protege a variável.

3. Funções sob medida: a fábrica de descontos

A closure também lembra dos parâmetros da função onde nasceu. A lojinha da Ana tem vários descontos; em vez de escrever uma função para cada um, ela escreve uma fábrica:

double Function(double) criarDesconto(double porcento) {
  return (preco) => preco * (1 - porcento / 100);
}

void main() {
  final desconto10 = criarDesconto(10);
  final desconto25 = criarDesconto(25);
  print(desconto10(200.0));
  print(desconto25(200.0));
  print(desconto10(50.0));
}

$ dart run multiplicador.dart
180.0
150.0
45.0

desconto10 é uma função que lembra de porcento = 10; desconto25 lembra de porcento = 25. As duas foram feitas pela mesma fábrica, mas cada uma carrega o seu valor. R$ 200 com 10% dá 180; com 25%, 150.

4. A closure guarda a variável, não uma foto dela

Uma dúvida comum: a closure guarda o valor que a variável tinha quando ela nasceu, ou a própria variável? Teste:

void main() {
  var taxa = 2.0;
  final comTaxa = (double preco) => preco + taxa;
  print(comTaxa(10.0));
  taxa = 5.0;
  print(comTaxa(10.0));
}

$ dart run muda.dart
12.0
15.0

A segunda chamada usou a taxa nova. A closure guarda a variável (a "caixinha"), e olha o que tem dentro na hora em que é chamada. Se você quer que o valor não mude, declare a variável com final (veja final e const).

Somar dentro de um forEach

É por guardar a variável que este programa funciona: a função anônima muda o total que mora no main:

void main() {
  final compras = [4.5, 12.9, 3.25];
  var total = 0.0;
  compras.forEach((preco) {
    total = total + preco;
  });
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

$ dart run total.dart
Total: R$ 20.65

(Para somar uma lista, há caminhos mais diretos, como o for-in ou o fold de map, where, reduce e Outros. Aqui o objetivo é ver a closure mudando uma variável de fora.)

5. Closures criadas num laço

A Ana guarda três avisos numa lista, cada um criado numa volta do for, e só depois chama todos:

void main() {
  final avisos = <void Function()>[];
  for (var i = 1; i <= 3; i++) {
    avisos.add(() => print('Aviso número $i'));
  }
  for (final aviso in avisos) {
    aviso();
  }
}

$ dart run laco.dart
Aviso número 1
Aviso número 2
Aviso número 3

Cada aviso lembrou o seu próprio número. Isso acontece porque, no Dart, o for (var i = …) cria uma variável i nova a cada volta, e cada closure ficou presa à sua. (Em linguagens mais antigas, como o JavaScript com var, as três funções dividiriam a mesma variável e mostrariam o mesmo número. O Dart foi feito para evitar essa armadilha.)

Experimente: faça o laço criar 4 avisos e confira que cada um lembra do seu número.

void main() {
  final avisos = <void Function()>[];
  for (var i = 1; i <= 3; i++) {
    avisos.add(() => print('Aviso número $i'));
  }
  for (final aviso in avisos) {
    aviso();
  }
}

void main() {
  final avisos = <void Function()>[];
  for (var i = 1; i <= 4; i++) {
    avisos.add(() => print('Aviso número $i'));
  }
  for (final aviso in avisos) {
    aviso();
  }
}

Formas diferentes de fazer a mesma coisa

Para "uma coisa que conta e lembra da contagem", há dois caminhos no Dart:

// 1) closure: a fábrica devolve o botão
int Function() criarContador() {
  var senha = 0;
  return () => ++senha;
}

// 2) classe: um objeto com a contagem e um método
class Contador {
  var senha = 0;
  int proxima() => ++senha;
}

(++senha soma 1 e devolve o valor novo; veja Atribuição e Incremento.)

SituaçãoQual usar
Uma ação só (um "botão"), com pouca coisa guardada, ou uma função sob medida (criarDesconto(10))Closure
Várias ações sobre os mesmos dados (próxima senha, zerar, mostrar), ou dados que outras partes precisam lerClasse (veja Classes)
Passar uma regra que usa um valor do momento para um método (where, sort…)Closure anônima, escrita ali mesmo: notas.where((n) => n >= minima)

Quando dá errado

A função está fora do bloco da variável

A Ana tentou separar a soma numa função com nome, escrita fora do main:

void somar(double preco) {
  total = total + preco;
}

void main() {
  var total = 0.0;
  somar(4.5);
  print(total);
}

$ dart run err_fora.dart
err_fora.dart:2:11: Error: Undefined name 'total'.
  total = total + preco;
          ^^^^^
err_fora.dart:2:3: Error: Setter not found: 'total'.
  total = total + preco;
  ^^^^^
Error: Undefined name 'total'.
"Nome não definido: total", na leitura (coluna 11, o total da direita).
Error: Setter not found: 'total'.
"Não encontrei como atribuir a total", na escrita (coluna 3, o total da esquerda). O mesmo problema, visto dos dois lados do =.

O total mora dentro do main, e a somar está escrita fora dele: ela não enxerga. O que conta é onde a função está escrita, não de onde é chamada. Como consertar: escreva a função dentro do main (como a função anônima do forEach, na seção 4), ou faça a somar receber e devolver o total: double somar(double total, double preco) => total + preco;.

A variável guardada é final 
int Function() criarContador() {
  final senha = 0;
  return () {
    senha = senha + 1;
    return senha;
  };
}

void main() {
  final caixa = criarContador();
  print(caixa());
}

$ dart run err_final.dart
err_final.dart:4:5: Error: Can't assign to the final variable 'senha'.
    senha = senha + 1;
    ^^^^^

"Não dá para atribuir à variável final senha." O hábito de usar final por padrão é bom, mas a contagem precisa mudar. Como consertar: var senha = 0;.

Esqueceu os parênteses: mostrou a maquininha, não a senha

Com a mesma criarContador da seção 2 no começo do arquivo:

void main() {
  print(criarContador());
  print(criarContador());
}

$ dart run err_chamou.dart
Closure: () => int
Closure: () => int

Sem erro nenhum, mas sem senha também: criarContador() devolve a função, e o print mostrou a função. Pior: cada linha criou uma maquininha nova. Como consertar: guarde a maquininha numa variável e chame-a: final caixa = criarContador(); print(caixa());.

A closure foi chamada antes de a variável ter valor

Missão: complete a fábrica criarCofrinho: ela cria uma variável saldo (começando em 0) e devolve uma função que recebe um valor, soma no saldo e devolve o saldo novo. Depositando 10, 20 e 5, deve aparecer Saldo: R$ 35.0.

double Function(double) criarCofrinho() {
  // crie o saldo e devolva a função aqui
  return (valor) => 0;
}

void main() {
  final cofrinho = criarCofrinho();
  cofrinho(10);
  cofrinho(20);
  final saldo = cofrinho(5);
  print('Saldo: R\$ $saldo');
}

double Function(double) criarCofrinho() {
  var saldo = 0.0;
  return (valor) {
    saldo = saldo + valor;
    return saldo;
  };
}

void main() {
  final cofrinho = criarCofrinho();
  cofrinho(10);
  cofrinho(20);
  final saldo = cofrinho(5);
  print('Saldo: R\$ $saldo');
}

Resumo

  • Uma closure é uma função que lembra das variáveis do lugar onde foi escrita, mesmo depois que esse lugar terminou.
  • Uma fábrica (criarContador(), criarDesconto(10)) devolve closures; cada chamada da fábrica cria variáveis novas, então cada closure tem as suas.
  • A closure guarda a variável, não uma cópia: se ela muda, a closure vê o valor novo.
  • No for (var i = …) do Dart, cada volta tem um i novo, então closures criadas no laço lembram números diferentes.
  • Uma função só enxerga as variáveis dos blocos em volta de onde está escrita: fora deles, Undefined name.
