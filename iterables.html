Dart map, where, reduce e Outros

Três coisas que você vai fazer com coleções o tempo todo: transformar cada item (todos os preços com desconto), filtrar (só as notas boas) e resumir tudo num valor só (o total da compra). Até agora, você fazia isso com um for e uma variável. O Dart tem métodos prontos para cada uma, que cabem numa linha: map, where, reduce e fold. E eles têm uma surpresa: devolvem um Iterable, e não uma lista.

Você vai aprender
  • map: transformar cada item.
  • where: ficar só com os itens que obedecem a uma regra.
  • O que é um Iterable, por que o print mostra (2, 4, 6) com parênteses, e o .toList().
  • Como encadear: where(…).map(…).toList().
  • reduce e fold: resumir a coleção num valor só (soma, maior, contagem).
  • any, every, firstWhere, take e skip.
  • Que o Iterable é "preguiçoso": só calcula quando alguém pede.
  • Os erros reais: reduce e firstWhere sem resultado (Bad state: No element), o Iterable guardado como List, o [0] e o fold dentro do print.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart. Todos os métodos recebem uma função, quase sempre anônima: se precisar, reveja Funções Anônimas.

A ideia: a esteira da fábrica de biscoitos

Numa fábrica de biscoitos, a massa passa por uma esteira com várias máquinas:

  • a máquina que transforma: cada bolinha de massa vira um biscoito assado (é o map: entra um, sai um, transformado);
  • o funcionário que separa os quebrados: só os inteiros seguem (é o where: alguns passam, outros não);
  • a balança no fim, que resume tudo num número: o peso da caixa (é o reduce/fold).

E as máquinas são ligadas uma na outra: o que sai de uma entra na próxima. No Dart, isso é encadear métodos.

1. map: transformar cada item

void main() {
  final numeros = [1, 2, 3];
  final dobros = numeros.map((n) => n * 2);
  print(dobros);
  print(dobros.runtimeType);
  final lista = dobros.toList();
  print(lista);
  final precos = [10.0, 25.0, 4.5];
  final comDesconto = precos.map((p) => p * 0.9).toList();
  print(comDesconto);
  final nomes = ['ana', 'bia'];
  print(nomes.map((n) => n.toUpperCase()).toList());
  print(nomes.map((n) => n.length).toList());
}

map ("mapear", no sentido de "fazer corresponder") chama a função para cada item e junta os resultados, na mesma ordem. Entram 3 itens, saem 3 itens. A lista original não muda. (Não confunda com o tipo Map, de Mapas: o nome é igual, a ideia é outra.)

Parênteses, não colchetes! O map não devolve uma List: devolve um Iterable, e é assim que o print mostra um Iterable.

O tipo exato, interno do Dart: "um Iterable feito de um map sobre uma lista, de int para int". Para você, basta saber que é um Iterable<int>.

"Para lista": transforma o Iterable numa List de verdade, com colchetes.
map((n) => n.length)
O tipo pode mudar: entra String, sai int (o tamanho de cada nome).

O que é um Iterable?

Iterable (de "iterar", percorrer) é qualquer coisa que dá para percorrer item por item com um for-in. Listas e conjuntos são Iterables; as keys e os values de um mapa também. A diferença é que um Iterable "puro" é só uma sequência: ele não tem [0], add nem sort. Na maioria das vezes, depois do map ou do where, você vai querer o .toList().

Missão: a padaria aumentou tudo em 50%. Use map para multiplicar cada preço por 1.5 e mostre como lista: [1.5, 3.0, 4.5].

void main() {
  final precos = [1.0, 2.0, 3.0];
  print(precos);
}

void main() {
  final precos = [1.0, 2.0, 3.0];
  print(precos.map((p) => p * 1.5).toList());
}

2. where: filtrar

void main() {
  final notas = [8.5, 5.0, 7.0, 9.5, 4.0];
  final aprovadas = notas.where((n) => n >= 7);
  print(aprovadas);
  print(aprovadas.length);
  final recuperacao = notas.where((n) => n < 7).toList();
  print(recuperacao);
  final produtos = ['pão', 'pão de queijo', 'leite', 'pão doce'];
  print(produtos.where((p) => p.startsWith('pão')).toList());
}

$ dart run filtrar.dart
(8.5, 7.0, 9.5)
3
[5.0, 4.0]
[pão, pão de queijo, pão doce]

where ("onde") chama a função para cada item; ela responde true (fica) ou false (sai). Os que ficam mantêm a ordem. De novo, o resultado é um Iterable (parênteses), que tem length e pode virar lista com .toList().

3. Encadeando: filtrar, depois transformar

O que sai do where é um Iterable, e todo Iterable tem map. Então dá para ligar as máquinas da esteira:

void main() {
  final precos = [4.5, 32.0, 12.9, 55.0, 3.25];
  final caros = precos
      .where((p) => p > 10)
      .map((p) => 'R\$ ${p.toStringAsFixed(2)}')
      .toList();
  print(caros);
}

$ dart run encadear.dart
[R$ 32.00, R$ 12.90, R$ 55.00]

Leia de cima para baixo: dos preços, fique com os maiores que 10; transforme cada um num texto com R$; faça uma lista. Um passo por linha, cada linha começando com o ponto, é o jeito que o dart format organiza uma cadeia longa.

Missão: dos alunos, fique só com os aprovados (nota 7 ou mais) e mostre os nomes em maiúsculas, numa lista: [ANA, CAIO]. Dica: os itens são records (nome, nota); use a.$1 para o nome e a.$2 para a nota (veja Records).

void main() {

  print(alunos);
}

void main() {
  final alunos = [('Ana', 9.5), ('Bia', 6.0), ('Caio', 8.0)];

4. reduce e fold: resumir num valor só

void main() {
  final precos = [4.5, 12.9, 3.25];
  final total = precos.reduce((soma, p) => soma + p);
  print(total);
  final maior = precos.reduce((a, b) => a > b ? a : b);
  print(maior);
  final total2 = precos.fold(0.0, (soma, p) => soma + p);
  print(total2);
  final vazio = <double>[];
  final totalVazio = vazio.fold(0.0, (soma, p) => soma + p);
  print(totalVazio);
  final nomes = ['Ana', 'Bia', 'Caio'];
  final letras = nomes.fold(0, (soma, nome) => soma + nome.length);
  print(letras);
}

reduce ("reduzir") começa com o primeiro item e vai combinando com o próximo: 4.5 + 12.9 = 17.4; 17.4 + 3.25 = 20.65. O primeiro parâmetro (soma) é o resultado acumulado até ali; o segundo (p), o item da vez.
reduce((a, b) => a > b ? a : b)
A mesma ideia, guardando sempre o maior dos dois (veja O Operador Ternário): o maior preço.
precos.fold(0.0, (soma, p) => soma + p)
fold ("dobrar") é igual, mas você dá o valor inicial (aqui, 0.0) em vez de começar pelo primeiro item.
vazio.fold(…) → 0.0
Com a lista vazia, o fold devolve o valor inicial. (O reduce, sem primeiro item para começar, dá erro: veja Quando dá errado.)
nomes.fold(0, (soma, nome) => soma + nome.length) → 10
Com o fold, o resultado pode ser de outro tipo: os itens são String, o resultado é int (o total de letras: 3 + 3 + 4).

5. Perguntas sobre a coleção: any, every e firstWhere

void main() {
  final notas = [8.5, 5.0, 7.0, 9.5];
  print(notas.any((n) => n < 6));
  print(notas.every((n) => n >= 5));
  print(notas.every((n) => n >= 7));
  print(<double>[].every((n) => n >= 7));
  print(notas.contains(7.0));
  final primeiraBaixa = notas.firstWhere((n) => n < 7);
  print(primeiraBaixa);
  final dez = notas.firstWhere((n) => n == 10, orElse: () => -1);
  print(dez);
}

any((n) => n < 6) → true
"Algum item obedece?" Basta um (o 5.0). Ele para de olhar assim que acha.
every((n) => n >= 5) → true
"Todos obedecem?" Todas as notas são 5 ou mais.
every((n) => n >= 7) → false
O 5.0 não obedece, então não são todos.
<double>[].every(…) → true
Curiosidade da lógica: numa coleção vazia, "todos obedecem" é verdade (não há ninguém que desobedeça). E any numa vazia dá false.
firstWhere((n) => n < 7) → 5.0
"O primeiro que obedece": devolve o item, não a posição.
firstWhere(…, orElse: () => -1) → -1.0
Nenhuma nota é 10: o orElse ("senão") dá o valor de reserva. Sem ele, seria uma exceção. (Saiu -1.0 porque a lista é de double.)

6. Pedaços: take e skip

void main() {
  final fila = ['Ana', 'Bia', 'Caio', 'Davi', 'Edu'];
  print(fila.take(2));
  print(fila.skip(2));
  print(fila.skip(1).take(3).toList());
  print(fila.map((n) => n[0]).join());
  print(fila.toSet().runtimeType);
  for (final inicial in fila.map((n) => n[0])) {
    print(inicial);
  }
}

  • take(2): "pegue" os 2 primeiros. skip(2): "pule" os 2 primeiros e fique com o resto. Encadeados, pegam um pedaço do meio.
  • join() funciona em qualquer Iterable: aqui, juntou as iniciais (n[0] é a primeira letra do texto) sem separador.
  • toSet() também existe em qualquer Iterable (veja Conjuntos).
  • E dá para percorrer um Iterable com for-in sem transformá-lo em lista.

7. O Iterable é preguiçoso

Um detalhe que surpreende: o map e o where não calculam nada na hora. Eles guardam a "receita" e só fazem as contas quando alguém pede os itens. Veja, com um print dentro da função:

void main() {
  final numeros = [1, 2, 3];
  final dobros = numeros.map((n) {
    print('calculando $n');
    return n * 2;
  });
  print('antes de usar');
  print(dobros.first);
  print('de novo:');
  print(dobros.toList());
}

$ dart run preguica.dart
antes de usar
calculando 1
2
de novo:
calculando 1
calculando 2
calculando 3
[2, 4, 6]

Nada foi calculado na linha do map: o antes de usar saiu primeiro. O first calculou só o primeiro item. E o toList() calculou tudo de novo, inclusive o 1. Por isso, se você vai usar o resultado mais de uma vez (ou a função é pesada), guarde o .toList() numa variável: assim as contas são feitas uma vez só.

Formas diferentes de fazer a mesma coisa

Somar os preços acima de R$ 10, de dois jeitos:

// 1) for e variável
var total = 0.0;
for (final p in precos) {
  if (p > 10) {
    total = total + p;
  }
}

// 2) where e fold
final total = precos.where((p) => p > 10).fold(0.0, (s, p) => s + p);

Os métodos deixam claro o que você quer (filtrar, transformar, somar); o for mostra como. Os dois estão certos: use o que ficar mais fácil de ler. Para montar uma lista com condições, há ainda o if e o for dentro dos colchetes (aula if e for Dentro de Coleções).

Missão final: o relatório da turma

Missão: sem nenhum for, mostre três linhas: a média das notas (some com fold ou reduce e divida pelo length), quantas são 7 ou mais (where + length) e se todas são maiores que 5 (every). Deve aparecer Média: 7.5, Aprovados: 4 e Todos passaram de 5? true.

void main() {
  final notas = [8.0, 6.0, 9.5, 7.0, 7.0];
  print(notas);
}

void main() {
  final notas = [8.0, 6.0, 9.5, 7.0, 7.0];
  final soma = notas.fold(0.0, (s, n) => s + n);
  print('Média: ${soma / notas.length}');
  print('Aprovados: ${notas.where((n) => n >= 7).length}');
  print('Todos passaram de 5? ${notas.every((n) => n > 5)}');
}

Resumo

  • map transforma cada item; where filtra. Os dois devolvem um Iterable, que o print mostra com parênteses: (2, 4, 6).
  • Um Iterable se percorre, mas não tem [i], add nem sort: use .toList() quando precisar de lista.
  • Os métodos se encadeiam: where(…).map(…).toList().
  • reduce e fold resumem a coleção num valor; prefira fold, que aceita coleção vazia e outro tipo de resultado.
  • any/every respondem "algum?"/"todos?"; firstWhere precisa de orElse quando pode não achar.
  • O Iterable é preguiçoso: calcula só quando alguém pede, e recalcula a cada uso.
