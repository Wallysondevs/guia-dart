Dart Mensagens de Erro Comuns

As mensagens do Dart saem sempre em inglês. Esta página reúne as que mais aparecem para quem está começando, todas colhidas no computador da Ana (Dart SDK 3.13.5), com a tradução, a causa mais comum e o conserto. Procure pelo começo da mensagem com Ctrl+F. Para aprender a ler uma mensagem do zero, veja a aula Lendo uma Mensagem de Erro.

Missão: este compila, mas quebra ao rodar com Bad state: No element. Use o orElse do firstWhere (ou outro jeito) para mostrar Nenhum produto custa mais de 100. quando nenhum preço passar de 100.

void main() {
  final precos = [4.5, 12.0, 30.0];
  final caro = precos.firstWhere((p) => p > 100);
  print('Primeiro acima de 100: $caro');
}

void main() {
  final precos = [4.5, 12.0, 30.0];
  final caro = precos.firstWhere((p) => p > 100, orElse: () => -1);
  if (caro < 0) {
    print('Nenhum produto custa mais de 100.');
  } else {
    print('Primeiro acima de 100: $caro');
  }
}

Resumo

  • arquivo:linha:coluna: Error: = erro de compilação (nada roda, código 254). Unhandled exception: = exceção (código 255).
  • Comece pelo primeiro erro da lista: os seguintes costumam ser consequência dele.
  • No stack trace, procure a primeira linha com file:///home/ana/…: é onde o seu código estava.
  • Os mais comuns: Expected ';', Undefined name, A value of type … can't be assigned, isn't defined for the type, potentially null, RangeError, Null check operator, FormatException.
