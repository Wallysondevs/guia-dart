Dart Strings

Nome da cliente, endereço, a mensagem "Volte sempre!": boa parte do que um programa guarda é texto. No Dart, texto é do tipo String (em inglês, "corda", "fileira": uma fileira de letras, como contas num colar). Nesta aula você vai ver como escrever textos no código, como pôr aspas, acentos e quebras de linha dentro deles, como juntá-los e como pegar uma letra só.

Você vai aprender
  • Como criar uma String com aspas simples ou duplas, e qual usar.
  • Como pôr um apóstrofo (d'água) ou aspas dentro do texto.
  • Os caracteres de escape: \n (nova linha), \t (tabulação), \\ e \$.
  • Textos de várias linhas com ''' e textos "crus" com r'…'.
  • Como juntar (+), repetir (*), medir (length) e pegar uma letra ([0]).
  • Os erros reais: a aspa que não fecha, 'texto' + número, o $ solto e a letra que não existe.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a placa da padaria

Pense na placa de letras da padaria, aquela em que o dono encaixa letra por letra: HOJE TEM SONHO. O computador vê um texto do mesmo jeito: uma fileira de letras (e espaços, números, sinais), uma depois da outra, cada uma numa posição. As aspas são a moldura da placa: mostram ao Dart onde o texto começa e onde termina. Tudo o que está entre as aspas é texto, e o Dart não tenta entender aquilo como código.

1. Criando uma String

void main() {
  String nome = 'Ana';
  String padaria = "Padaria do Bairro";
  var vazio = '';
  print(nome);
  print(padaria);
  print(vazio);
  print('Fim');
}
String nome = 'Ana';
Uma variável do tipo String com o texto Ana. As aspas não fazem parte do texto: são a moldura.
"Padaria do Bairro"
Aspas duplas também servem. Para o Dart, 'Ana' e "Ana" são o mesmo texto.
var vazio = '';
Duas aspas coladas: o texto vazio, com zero letras. Ele existe, só não tem nada dentro. O var descobre sozinho que o tipo é String.
print(vazio)
Mostra o texto vazio: na saída, aparece uma linha em branco.
$ dart run textos.dart
Ana
Padaria do Bairro

Fim
Qual aspa usar?

O guia de estilo oficial do Dart (Effective Dart) e os avisos do dart analyze preferem aspas simples: 'Ana'. Use as duplas só quando o texto tem um apóstrofo dentro, como você vai ver agora.

2. Aspas dentro do texto

O pão d'água tem um apóstrofo no nome. Se o texto começa com ', o Dart acha que o apóstrofo de d'água fecha o texto (veja o erro em Quando dá errado). Há dois jeitos de resolver:

void main() {
  print("Pão d'água");
  print('Pão d\'água');
  print('Ela disse: "bom dia"');
  print("Ela disse: \"bom dia\"");
}

$ dart run aspas.dart
Pão d'água
Pão d'água
Ela disse: "bom dia"
Ela disse: "bom dia"
"Pão d'água"
Com aspas duplas por fora, o apóstrofo de dentro é só mais uma letra.
'Pão d\'água'
A barra invertida \ antes do apóstrofo avisa: "este aqui não fecha o texto, é uma letra". Isso se chama escapar o caractere.
'Ela disse: "bom dia"'
O contrário: aspas simples por fora, duplas por dentro.

3. Caracteres especiais: \n, \t e companhia

A barra invertida também cria letras que não dá para digitar direto no meio do texto:

void main() {
  print('Pão\nLeite\nCafé');
  print('Item\tPreço');
  print('Pão\t4.50');
  print('Barra invertida: \\');
  print('Preço em R\$');
  print('Coração: \u2764');
}

EscritaVira
\nNova linha (new line): o texto continua na linha de baixo
\tTabulação (tab): pula até a próxima "coluna", bom para alinhar tabelas
\' e \"O apóstrofo e as aspas, sem fechar o texto

Acentos (ã, é, ç) você digita direto, sem barra nenhuma: o Dart entende o texto em UTF-8, o padrão do mundo todo.

Lista de compras:

''' … '''
Três aspas (simples ou duplas) abrem um texto que pode ter várias linhas. As quebras de linha do código entram no texto. (A primeira quebra, logo depois do ''', o Dart ignora.)
r'C:\novos\textos'
O r na frente faz uma string crua (raw): a barra invertida vira letra comum. Útil para caminhos de pasta do Windows.
'C:\novos\textos' (sem o r)
Olhe o estrago na última saída: o \n de \novos virou nova linha e o \t de \textos virou tabulação. Sem erro nenhum, só um texto errado.

5. Juntar e repetir

void main() {
  var nome = 'Ana';
  var sobrenome = 'Souza';
  var completo = nome + ' ' + sobrenome;
  print(completo);
  var aviso = 'Hoje tem '
      'pão de queijo '
      'quentinho!';
  print(aviso);
  print('-' * 20);
  print('ha' * 3);
}

$ dart run juntar.dart
Ana Souza
Hoje tem pão de queijo quentinho!
--------------------
hahaha
nome + ' ' + sobrenome
O + entre textos junta (programadores dizem concatenar). O ' ' do meio é um texto com um espaço: sem ele, sairia AnaSouza.
'Hoje tem ' 'pão de queijo ' …
Textos escritos lado a lado, sem nada entre eles, o Dart junta sozinho. É o jeito de quebrar um texto comprido em várias linhas do código.
'-' * 20
O * com um texto e um número repete o texto: 20 tracinhos, bom para fazer linhas.

Para pôr números e variáveis no meio do texto, o Dart tem um jeito bem melhor que o +: 'Olá, $nome'. É o assunto da próxima aula, Interpolação.

Formas diferentes de fazer

O mesmo texto com apóstrofo, de três jeitos, e a mesma frase longa, de dois:

var a = "Pão d'água";        // aspas duplas por fora
var b = 'Pão d\'água';       // escapar o apóstrofo
var c = '''Pão d'água''';    // três aspas também aceitam

var longa1 = 'Hoje tem ' + 'pão de queijo';   // com +
var longa2 = 'Hoje tem ' 'pão de queijo';     // lado a lado (preferido)

Somou texto com número 
void main() {
  int idade = 30;
  print('Idade: ' + idade);
}

$ dart run err_mais.dart

"Um valor do tipo int não pode ser atribuído a uma variável do tipo String." O + de um texto só aceita outro texto. Outras linguagens convertem o número sozinhas; o Dart não, de propósito, para você não juntar coisas sem querer. Como consertar: print('Idade: $idade'); (a Interpolação, o jeito preferido) ou print('Idade: ' + idade.toString()); (veja Conversão de Tipos).

Resumo

  • Texto é String, escrito entre aspas simples (preferidas) ou duplas. As aspas são a moldura, não fazem parte do texto.
  • A barra invertida escapa caracteres: \n, \t, \', \\, \$. Com r'…', ela vira letra comum.
  • '''…''' faz textos de várias linhas.
  • + junta textos (só texto com texto); * repete; textos lado a lado se juntam sozinhos.
  • length dá o tamanho; [i] dá a letra na posição i, contando do zero até length - 1.
  • A String é imutável: os métodos devolvem um texto novo.
  • Aspa que não fecha gera várias mensagens: leia a primeira.
