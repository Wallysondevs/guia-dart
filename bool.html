Dart bool

A padaria está aberta? Tem pão de queijo? A Ana é maior de idade? Essas perguntas só têm duas respostas: sim ou não. Para guardar respostas assim, o Dart tem o tipo bool (de booleano, em homenagem ao matemático George Boole), que só aceita dois valores: true ("verdadeiro") e false ("falso"). É o tipo que decide o caminho do programa em todo if e todo laço.

Você vai aprender
  • Como criar variáveis bool com true e false.
  • Que comparações (>=, ==) e propriedades como isEmpty respondem um bool.
  • Como o bool decide um if, e o !, o && e o || numa primeira olhada.
  • Como dar bons nomes a variáveis bool.
  • Como transformar o texto 'true' em bool com bool.parse.
  • Os erros reais: o Dart não aceita número nem texto no lugar de bool.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: o interruptor de luz

Um interruptor só tem duas posições: ligado ou desligado. Não existe "meio ligado". Uma variável bool é um interruptor: ou ela vale true, ou vale false. Parece pouco, mas é com interruptores assim que o programa decide tudo: "se a padaria está aberta, mostre o cardápio; senão, mostre o horário".

1. Criando variáveis bool

void main() {
  bool aberta = true;
  bool temSonho = false;
  print(aberta);
  print(temSonho);
  print('A padaria está aberta? $aberta');
  print(aberta.runtimeType);
}

2. Perguntas que respondem bool

Quase nunca se escreve true ou false à mão. O mais comum é o bool ser a resposta de uma pergunta:

void main() {
  var idade = 17;
  var estoque = 0;
  var nome = 'Ana';
  bool maiorDeIdade = idade >= 18;
  bool acabou = estoque == 0;
  print(maiorDeIdade);
  print(acabou);
  print(nome.isEmpty);
  print(nome.startsWith('A'));
  print(10.isEven);
}

3. O bool decide o caminho

O lugar onde o bool trabalha de verdade é o if ("se"). Entre os parênteses do if vai sempre um bool:

void main() {
  var aberta = true;
  if (aberta) {
    print('Pode entrar!');
  } else {
    print('Volte amanhã.');
  }
  aberta = false;
  if (aberta) {
    print('Pode entrar!');
  } else {
    print('Volte amanhã.');
  }
}

$ dart run decisao.dart
Pode entrar!
Volte amanhã.

O mesmo if, duas respostas diferentes: com aberta valendo true, roda o primeiro bloco; com false, roda o bloco do else ("senão"). Repare que se escreve if (aberta), e não if (aberta == true): a variável já é a resposta. O if tem aula própria: if e else.

Combinando respostas: !, && e ||

void main() {
  var aberta = true;
  var temPao = false;
  print(!aberta);
  print(aberta && temPao);
  print(aberta || temPao);
  var vaiComprar = aberta && !temPao;
  print(vaiComprar);
}

$ dart run combinar.dart
false

true
true

4. Bons nomes para bool

Uma variável bool deve ler como uma pergunta de sim ou não. Assim o if fica parecendo uma frase em português:

Bom nomePor quêEvite
aberta, ativoUm estado: if (aberta) = "se aberta"status (status de quê? sim ou não?)
temEstoque, temDesconto"tem …?"estoque (parece um número)
podeComprar, podeEntrar"pode …?"comprar (parece uma ação, uma função)
maiorDeIdade, estaPago"é / está …?"naoPago (negações confundem: !naoPago)

O Effective Dart, o guia de estilo oficial, recomenda o mesmo: nomes que soam como afirmação (isEmpty, hasElements, canClose) e, de preferência, na forma positiva.

5. De texto para bool, e de volta

Às vezes a resposta chega como texto: 'true', lido de um arquivo ou do teclado. Texto e bool são tipos diferentes, e é preciso converter:

void main() {
  print(true.toString());
  print(bool.parse('true'));
  print(bool.parse('TRUE', caseSensitive: false));
  print(bool.tryParse('sim'));
  print('true' == true);
}

Quando dá errado

Em muitas linguagens (JavaScript, Python, C), número e texto valem como "verdadeiro" ou "falso" num if: 0 é falso, 5 é verdadeiro. No Dart, não: só um bool serve. É de propósito, para evitar enganos.

Número no lugar de bool no if 
void main() {
  var estoque = 5;
  if (estoque) {
    print('Tem produto');
  }
}

Missão: a Bia tem 16 anos e está acompanhada. Crie maiorDeIdade com a pergunta idade >= 18, e podeEntrar: ela pode entrar se for maior de idade ou estiver acompanhada (||). A saída deve ser Maior de idade: false e Pode entrar: true.

void main() {
  var idade = 16;
  bool acompanhada = true;
  // crie maiorDeIdade e podeEntrar aqui
  print('Maior de idade: ');
  print('Pode entrar: ');
}

void main() {
  var idade = 16;
  bool acompanhada = true;
  bool maiorDeIdade = idade >= 18;
  bool podeEntrar = maiorDeIdade || acompanhada;
  print('Maior de idade: $maiorDeIdade');
  print('Pode entrar: $podeEntrar');
}

Resumo

  • bool guarda só true ou false: sem aspas e em minúsculas.
  • Comparações (==, >=…) e propriedades como isEmpty respondem bool; guarde a resposta direto: bool acabou = estoque == 0;.
  • O if só aceita bool. Número e texto não valem como verdadeiro/falso no Dart: escreva a comparação.
  • !, && e || combinam respostas (aula Operadores Lógicos).
  • Dê nomes que soam como pergunta de sim ou não: aberta, temEstoque, podeComprar.
  • bool.parse transforma 'true'/'false' em bool (outro texto: FormatException); bool.tryParse devolve null em vez de parar.
