Dart Percorrendo Mapas

Na aula Mapas, você leu e gravou um valor de cada vez, pela chave. Mas a Ana quer imprimir o cardápio inteiro, a professora quer o boletim de todos os alunos, e o dono da padaria quer saber quantas vezes cada produto foi pedido. Para isso é preciso percorrer o mapa, par por par, e usar os métodos que mexem em vários pares de uma vez.

Você vai aprender
  • Três jeitos de percorrer: pelas chaves (keys), pelos valores (values) e pelos pares (entries).
  • O forEach com dois parâmetros: chave e valor.
  • O jeito do Dart 3: for (final MapEntry(:key, :value) in mapa.entries).
  • O padrão mais útil dos mapas: contar quantas vezes cada coisa aparece.
  • update, putIfAbsent, addAll e removeWhere.
  • Como mostrar o mapa em ordem alfabética ou do maior valor para o menor.
  • Os erros reais: remover durante o for, o update numa chave que não existe, o forEach com um parâmetro só e o keys[0].

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: ler o cardápio de cima a baixo

Para ler o cardápio na parede inteiro, você pode:

  • ler só a coluna dos nomes ("o que tem hoje?"): as chaves;
  • ler só a coluna dos preços ("quanto dá tudo?"): os valores;
  • ler linha por linha, nome e preço juntos: os pares (em inglês, entries, "entradas").

Os três existem no Dart. A ordem é sempre a mesma em que os pares entraram no mapa.

1. Pelas chaves e pelos valores

void main() {
  final precos = {'pão': 0.75, 'leite': 5.49, 'café': 18.90};
  for (final produto in precos.keys) {
    print('$produto custa R\$ ${precos[produto]}');
  }
  var soma = 0.0;
  for (final preco in precos.values) {
    soma = soma + preco;
  }
  print('Soma: R\$ ${soma.toStringAsFixed(2)}');
}

$ dart run chaves.dart
pão custa R$ 0.75
leite custa R$ 5.49
café custa R$ 18.9
Soma: R$ 25.14
for (final produto in precos.keys)
Percorre as chaves, uma por volta (veja for-in). Com a chave na mão, precos[produto] busca o valor.
for (final preco in precos.values)
Percorre só os valores. Bom para somar, achar o maior, contar… quando a chave não importa.

Dentro do primeiro laço, precos[produto] ainda é um double? (veja Mapas): mostrar funciona, mas fazer conta com ele exigiria !. O próximo jeito evita isso.

2. Pelos pares: entries

void main() {
  final precos = {'pão': 0.75, 'leite': 5.49, 'café': 18.90};
  for (final par in precos.entries) {
    print('${par.key}: R\$ ${par.value.toStringAsFixed(2)}');
  }
  print(precos.entries.first);
}

$ dart run entries.dart
pão: R$ 0.75
leite: R$ 5.49
café: R$ 18.90
MapEntry(pão: 0.75)
precos.entries
Uma sequência de pares. Cada par é um objeto MapEntry ("entrada do mapa"), como mostra o último print: MapEntry(pão: 0.75).
par.key / par.value
A chave e o valor daquele par. Aqui, par.value é um double de verdade (não double?): o par existe, então o valor também. Por isso o toStringAsFixed(2) funcionou direto.

Desmontando o par com um padrão Dart 3.0

Desde o Dart 3.0, dá para "desmontar" o par já no for, dando nomes à chave e ao valor (isso é um padrão; veja Patterns):

void main() {
  final notas = {'Ana': 9.5, 'Bia': 6.0, 'Caio': 8.0};
  for (final MapEntry(key: aluno, value: nota) in notas.entries) {
    print('$aluno tirou $nota');
  }
  for (final MapEntry(:key, :value) in notas.entries) {
    print('$key -> $value');
  }
}

$ dart run padrao.dart
Ana tirou 9.5
Bia tirou 6.0
Caio tirou 8.0
Ana -> 9.5
Bia -> 6.0
Caio -> 8.0

MapEntry(key: aluno, value: nota) quer dizer "pegue o key do par e chame de aluno; pegue o value e chame de nota". A forma curta MapEntry(:key, :value) usa os próprios nomes key e value como variáveis.

3. forEach: uma função para cada par

O forEach do mapa chama uma função para cada par, entregando dois argumentos: a chave e o valor (veja Funções Anônimas):

void main() {
  final notas = {'Ana': 9.5, 'Bia': 6.0, 'Caio': 8.0};
  notas.forEach((aluno, nota) {
    final situacao = nota >= 7 ? 'aprovado' : 'recuperação';
    print('$aluno: $nota ($situacao)');
  });
}

$ dart run foreach.dart
Ana: 9.5 (aprovado)
Bia: 6.0 (recuperação)
Caio: 8.0 (aprovado)

Missão: mostre o boletim da turma, um aluno por linha, no formato Ana: 9.5. Acrescente (recuperação) depois da nota de quem tirou menos de 7. Use o jeito de percorrer que preferir.

void main() {
  final notas = {'Ana': 9.5, 'Bia': 6.0, 'Caio': 8.0};
  print(notas);
}

void main() {
  final notas = {'Ana': 9.5, 'Bia': 6.0, 'Caio': 8.0};
  for (final MapEntry(key: aluno, value: nota) in notas.entries) {
    if (nota < 7) {
      print('$aluno: $nota (recuperação)');
    } else {
      print('$aluno: $nota');
    }
  }
}

4. Contando com um mapa

O dono da padaria tem a lista de pedidos do dia e quer saber quantos de cada produto saíram. A ideia: um mapa produto → quantidade, começando vazio; para cada pedido, soma 1 na quantidade daquele produto.

void main() {
  final pedidos = ['pão', 'leite', 'pão', 'café', 'pão', 'leite'];
  final contagem = <String, int>{};
  for (final item in pedidos) {
    contagem[item] = (contagem[item] ?? 0) + 1;
  }
  print(contagem);
  final contagem2 = <String, int>{};
  for (final item in pedidos) {
    contagem2.update(item, (n) => n + 1, ifAbsent: () => 1);
  }
  print(contagem2);
}

$ dart run contar.dart
{pão: 3, leite: 2, café: 1}
{pão: 3, leite: 2, café: 1}
contagem[item] = (contagem[item] ?? 0) + 1;
"A contagem do item passa a ser a contagem atual (ou 0, se ele ainda não apareceu) mais 1." Na primeira vez que o pão aparece, contagem['pão'] é null, o ?? troca por 0, e o pão fica com 1.
update(item, (n) => n + 1, ifAbsent: () => 1)
O mesmo, com o método update ("atualizar"): se a chave existe, aplica a função ao valor atual (n + 1); se não existe (ifAbsent, "se ausente"), grava o valor da outra função (1).

Os dois jeitos dão o mesmo resultado. O primeiro é mais fácil de ler no começo; o segundo deixa claro o que acontece nos dois casos.

5. Mexendo em vários pares: putIfAbsent, update, addAll e removeWhere

void main() {
  final estoque = {'pão': 30};
  estoque.putIfAbsent('pão', () => 99);
  estoque.putIfAbsent('bolo', () => 5);
  print(estoque);
  estoque.update('pão', (q) => q - 10);
  print(estoque);
  estoque.addAll({'leite': 12, 'bolo': 8});
  print(estoque);
  estoque.removeWhere((produto, qtd) => qtd < 10);
  print(estoque);
}

$ dart run putifabsent.dart
{pão: 30, bolo: 5}
{pão: 20, bolo: 5}
{pão: 20, bolo: 8, leite: 12}
{pão: 20, leite: 12}
putIfAbsent('pão', () => 99)
"Ponha se estiver ausente": o pão já existia, então nada muda (continua 30).
putIfAbsent('bolo', () => 5)
O bolo não existia: entra com 5.
update('pão', (q) => q - 10)
Vendeu 10 pães: o valor novo é calculado a partir do antigo.
addAll({…})
Grava vários pares de uma vez: o leite entra, e o bolo, que já existia, é trocado para 8.
removeWhere((produto, qtd) => qtd < 10)
Tira todos os pares em que a regra dá true. A função recebe chave e valor. O bolo (8) saiu.

6. Mostrando em ordem

O mapa guarda a ordem de inserção. Para mostrar em outra ordem, ordene uma lista feita a partir dele:

void main() {
  final notas = {'Caio': 8.0, 'Ana': 9.5, 'Bia': 6.0};
  final nomes = notas.keys.toList()..sort();
  for (final nome in nomes) {
    print('$nome: ${notas[nome]}');
  }
  final ranking = notas.entries.toList()
    ..sort((a, b) => b.value.compareTo(a.value));
  for (final par in ranking) {
    print('${par.key} (${par.value})');
  }
}

$ dart run ordenar.dart
Ana: 9.5
Bia: 6.0
Caio: 8.0
Ana (9.5)
Caio (8.0)
Bia (6.0)
  • notas.keys.toList()..sort(): faz uma lista das chaves e a ordena. Os dois pontos .. (a cascata) chamam o sort e devolvem a própria lista, não o resultado do sort (que é void; veja Métodos de Lista).
  • notas.entries.toList()..sort((a, b) => b.value.compareTo(a.value)): uma lista de pares, ordenada pelo valor, do maior para o menor: o ranking da turma.

Formas diferentes de percorrer

EscritaQuando usar
for (final k in mapa.keys)Só precisa das chaves (ou vai buscar o valor só às vezes)
for (final v in mapa.values)Só precisa dos valores (somar, achar o maior)
for (final MapEntry(:key, :value) in mapa.entries)Precisa dos dois: o jeito mais claro no Dart 3, e aceita break e continue
for (final par in mapa.entries) + par.key/par.valueO mesmo, sem padrão
mapa.forEach((k, v) { … })Uma ação curta para cada par. O guia de estilo do Dart prefere o for-in quando o corpo tem mais de uma linha.

Quando dá errado

Removendo durante o for 
void main() {
  final estoque = {'pão': 30, 'leite': 0, 'bolo': 4};
  for (final produto in estoque.keys) {
    if (estoque[produto] == 0) {
      estoque.remove(produto);
    }
  }
  print(estoque);
}

Como consertar: estoque.removeWhere((produto, qtd) => qtd == 0);. Se precisar mesmo de um laço, percorra uma cópia das chaves: for (final produto in estoque.keys.toList()).

Contando sem tratar o null 
void main() {
  final contagem = <String, int>{};
  for (final item in ['pão', 'pão']) {
    contagem[item] = contagem[item] + 1;
  }
}

$ dart run err_acrescenta.dart

    contagem[item] = contagem[item] + 1;
                                    ^

    contagem[item] = contagem[item] + 1;

Dois erros no mesmo lugar. O primeiro é o que importa: "o operador + não pode ser usado num int?, porque ele pode ser null" (na primeira vez, o item não está no mapa). O segundo é consequência do primeiro. Como consertar: (contagem[item] ?? 0) + 1.

forEach com um parâmetro só

Missão final: as letras de um nome

Missão: conte quantas vezes cada letra aparece em 'anasouza', num mapa de letra → quantidade. (texto.split('') separa o texto em letras; veja Métodos de String.) Deve aparecer {a: 3, n: 1, s: 1, o: 1, u: 1, z: 1}.

void main() {
  final texto = 'anasouza';
  final contagem = <String, int>{};
  // conte aqui
  print(contagem);
}

void main() {
  final texto = 'anasouza';
  final contagem = <String, int>{};
  for (final letra in texto.split('')) {
    contagem[letra] = (contagem[letra] ?? 0) + 1;
  }
  print(contagem);
}

Resumo

  • Percorra um mapa pelas chaves (keys), pelos valores (values) ou pelos pares (entries, cada um com .key e .value).
  • No Dart 3, for (final MapEntry(:key, :value) in mapa.entries) desmonta o par direto no for.
  • O forEach de um mapa recebe uma função com dois parâmetros.
  • Para contar: mapa[k] = (mapa[k] ?? 0) + 1 ou update(k, …, ifAbsent: …).
  • Para tirar vários pares, removeWhere; nunca remova dentro do for que percorre o mapa.
  • Para mostrar em ordem, ordene uma lista feita das chaves ou dos pares (toList()..sort(…)).
