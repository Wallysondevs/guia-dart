Dart Atribuição e Incremento

Você já sabe criar uma variável e fazer contas (Variáveis e Operadores Aritméticos). Agora falta o mais comum de tudo: mudar o valor de uma variável que já existe. Somar 5 no saldo, contar mais uma visita, descontar o troco. Para isso existem o = (atribuição), os atalhos como += e os operadores ++ e --, que somam ou tiram 1.

Você vai aprender
  • O que o = faz de verdade: "guarde este valor nesta caixa", e não "é igual a".
  • Os atalhos +=, -=, *=, /=, ~/= e %=.
  • O ++ e o --, e a diferença entre a++ e ++a.
  • Como acumular um total, passo a passo.
  • Os erros reais: mudar uma final, pôr double numa variável int, usar uma variável sem valor, + = com espaço e =+ trocado.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: o cofrinho

Pense numa variável como um cofrinho com uma etiqueta (o nome). Atribuir é trocar o que está dentro. Quando a Ana guarda mais 5 reais, ela faz três coisas: olha quanto tem (10), soma 5 de cabeça (15) e deixa o cofrinho com 15. O valor antigo não fica guardado em lugar nenhum: o cofrinho agora tem 15, e pronto.

1. O =: guardar um valor

void main() {
  var saldo = 10;
  print('Começo: $saldo');
  saldo = saldo + 5;
  print('Depois de guardar 5: $saldo');
  saldo = 3;
  print('Trocou tudo por 3: $saldo');
}
var saldo = 10;
Cria a variável e dá o primeiro valor. O var só aparece aqui, na criação (veja Variáveis).
saldo = saldo + 5;
Lê-se da direita para a esquerda: primeiro o Dart calcula saldo + 5 com o valor atual (10 + 5 = 15); depois guarda o 15 em saldo. Em matemática, "saldo = saldo + 5" seria um absurdo; em programação, é uma ordem: "o saldo passa a valer o que valia, mais 5".
saldo = 3;
Joga fora o 15 e guarda 3. Sem var: a variável já existe.
$ dart run cofrinho.dart
Começo: 10
Depois de guardar 5: 15
Trocou tudo por 3: 3
= não é "igual a"

Um = sozinho guarda. Para perguntar se duas coisas são iguais, o Dart usa == (dois sinais), assunto da aula Comparação.

2. Os atalhos: +=, -=, *= e companhia

Escrever saldo = saldo + 20 repete o nome da variável. O atalho saldo += 20 faz exatamente a mesma coisa, mais curto. Existe um atalho para cada operador de conta:

void main() {
  var saldo = 100;
  saldo += 20;
  print('saldo += 20  → $saldo');
  saldo -= 30;
  print('saldo -= 30  → $saldo');
  saldo *= 2;
  print('saldo *= 2   → $saldo');
  saldo ~/= 7;
  print('saldo ~/= 7  → $saldo');
  saldo %= 10;
  print('saldo %= 10  → $saldo');
  var preco = 9.0;
  preco /= 2;
  print('preco /= 2   → $preco');
  var nome = 'Ana';
  nome += ' Souza';
  print('nome += …    → $nome');
}

$ dart run atalhos.dart
saldo += 20  → 120
saldo -= 30  → 90
saldo *= 2   → 180
saldo ~/= 7  → 25
saldo %= 10  → 5
preco /= 2   → 4.5
nome += …    → Ana Souza

x -= 30x = x - 30120 → 90
x *= 2x = x * 290 → 180
x ~/= 7x = x ~/ 7180 → 25 (180 ÷ 7 = 25, sobra 5)
x %= 10x = x % 1025 → 5
x /= 2x = x / 2 (só serve para double)9.0 → 4.5

O símbolo da conta vem antes do =, grudado nele: +=, e não =+ nem + = (os dois dão erro; veja Quando dá errado). Repare também que o /= foi usado num double: num int ele não compila, porque o / sempre dá double.

E o ??=?

Existe mais um atalho, o ??=: "guarde este valor só se a variável estiver vazia (null)". Ele é assunto de null safety, na aula ?. , ?? e ??=.

3. Acumular: somar aos poucos

No caixa da padaria, a Ana passa um item de cada vez. A variável total começa em zero e vai acumulando:

void main() {
  var total = 0.0;
  total += 4.50;
  total += 12.90;
  total += 3.25;
  print('Total: R\$ ${total.toStringAsFixed(2)}');
}

$ dart run total.dart
Total: R$ 20.65

O total começou em 0.0, e não em 0, por um motivo importante: com var total = 0; o Dart decide que a variável é int, e aí total += 4.50 não compila (veja o erro em Quando dá errado). Uma variável acumuladora como essa é a base dos laços que você vai ver em for e while.

4. ++ e --: mais um, menos um

Somar 1 é tão comum (contar visitas, voltas, pessoas na fila) que ganhou um operador só para isso: ++ ("mais mais"). O -- tira 1.

void main() {
  var visitas = 0;
  visitas++;
  visitas++;
  visitas++;
  print('Visitas: $visitas');
  visitas--;
  print('Depois de um --: $visitas');
}

$ dart run incremento.dart
Visitas: 3
Depois de um --: 2

visitas++ é o mesmo que visitas += 1, que é o mesmo que visitas = visitas + 1. Somar 1 se chama incrementar; tirar 1, decrementar.

Antes ou depois: a++ e ++a

O ++ pode vir depois da variável (a++, pós-incremento) ou antes (++a, pré-incremento). Sozinhos numa linha, os dois fazem a mesma coisa. A diferença aparece quando você usa o valor na mesma hora, por exemplo dentro de um print:

void main() {
  var a = 5;
  print(a++);
  print(a);
  var b = 5;
  print(++b);
  print(b);
}

$ dart run prefixo.dart
5
6
6
6
print(a++) → 5
"Use o valor e depois some 1". O print recebeu o 5 antigo; logo em seguida, a virou 6.
print(a) → 6
Prova de que o incremento aconteceu.
print(++b) → 6
"Some 1 primeiro e depois use". O b virou 6, e o print recebeu o 6.

Na fila do açougue, o painel mostra a próxima senha:

void main() {
  var senha = 41;
  print('Chamando a senha ${++senha}');
  print('Chamando a senha ${++senha}');
  var ticket = 41;
  print('Chamando a senha ${ticket++}');
  print('Agora ticket vale $ticket');
}

$ dart run fila.dart
Chamando a senha 42
Chamando a senha 43
Chamando a senha 41
Agora ticket vale 42

Com ++senha, o painel chamou 42 e 43, as próximas. Com ticket++, chamou a 41 de novo (o valor antigo) e só depois avançou. Para não se confundir, a recomendação é simples: use o ++ sozinho na linha (senha++;) e o valor na linha seguinte. Fica claro para qualquer um.

Missão: o painel está chamando a senha 7 duas vezes, porque o ++ está depois da variável. Faça ele chamar 8 e depois 9.

Formas diferentes de fazer

As três linhas abaixo somam 1 em contador. Todas funcionam:

contador = contador + 1;
contador += 1;
contador++;

Somar, tirar, multiplicar por outro valortotal += preco, estoque -= vendidos, valor *= 2

Uma curiosidade: a atribuição também devolve o valor guardado, por isso dá para escrever a = b = 0; (o b = 0 guarda 0 em b e devolve 0, que vai para a). No lab, print(x = 10); mostrou 10. Funciona, mas deixa o código difícil de ler: prefira uma atribuição por linha.

Quando dá errado

Tentou mudar uma variável final 
void main() {
  final saldo = 10;
  saldo += 5;
  print(saldo);
}

$ dart run err_final.dart
err_final.dart:3:3: Error: Can't assign to the final variable 'saldo'.
  saldo += 5;
  ^^^^^
err_final.dart:3:3:
Arquivo, linha 3, coluna 3: o começo de saldo.
Error: Can't assign to the final variable 'saldo'.
"Não é possível atribuir à variável final saldo." Uma final recebe valor uma vez só, na criação.
^^^^^
Os acentos circunflexos sublinham a variável culpada, letra por letra.

O ++, o -- e todos os atalhos (+=, -=…) também são atribuições, e dão o mesmo erro. Como consertar: se o valor precisa mudar, declare com var (var saldo = 10;).

Somou um double numa variável int 
void main() {
  var total = 0;
  total += 4.50;
  print(total);
}

$ dart run err_var_int.dart
err_var_int.dart:3:9: Error: A value of type 'double' can't be assigned to a variable of type 'int'.
  total += 4.50;
        ^

"Um valor do tipo double não pode ser atribuído a uma variável do tipo int." O var total = 0 fez o Dart decidir, de uma vez por todas, que total é int (o tipo vem do primeiro valor). total + 4.50 dá um double, que não cabe. Como consertar: comece com 0.0 (var total = 0.0;) ou declare double total = 0;. O mesmo acontece com fatias /= 2 num int (err_divint.dart:3:10: Error: A value of type 'double' can't be assigned to a variable of type 'int'.): use fatias ~/= 2.

Usou a variável antes de dar um valor 
void main() {
  int pontos;
  pontos += 5;
  print(pontos);
}

$ dart run err_null.dart
err_null.dart:3:3: Error: Non-nullable variable 'pontos' must be assigned before it can be used.
  pontos += 5;
  ^^^^^^

"A variável não anulável pontos precisa receber um valor antes de ser usada." O pontos += 5 precisa ler o valor atual para somar 5, e não há valor nenhum. ("Não anulável" quer dizer que ela não pode ficar vazia, null; veja Null Safety.) Como consertar: dê o valor inicial: int pontos = 0;.

Esqueceu de criar a variável 
void main() {
  contador = 1;
  print(contador);
}

$ dart run err_semvar.dart
err_semvar.dart:2:3: Error: Setter not found: 'contador'.
  contador = 1;
  ^^^^^^^^
err_semvar.dart:3:9: Error: Undefined name 'contador'.
  print(contador);
        ^^^^^^^^

Dois erros de uma vez. O primeiro, Setter not found: 'contador', quer dizer "não achei onde guardar contador" (um setter é "quem guarda"). O segundo, Undefined name 'contador', "nome não definido". Em Dart, a variável tem de ser criada (com var, final ou um tipo) antes de receber valor. Como consertar: var contador = 1;.

Escreveu + = com espaço, ou =+ ao contrário 
void main() {
  var pontos = 10;
  pontos + = 5;
  print(pontos);
}

$ dart run err_espaco.dart
err_espaco.dart:3:12: Error: Expected an identifier, but got '='.
Try inserting an identifier before '='.
  pontos + = 5;
           ^
err_espaco.dart:3:12: Error: Can't assign to this.
  pontos + = 5;
           ^

Com o espaço, o + e o = viram dois operadores separados, e o Dart se perde: "esperava um nome, mas veio =" e "não dá para atribuir a isto". Já o =+ invertido dá outro erro:

$ dart run err_ordem.dart
err_ordem.dart:3:11: Error: '+' is not a prefix operator.
Try removing '+'.
  pontos =+ 5;
          ^

"+ não é um operador de prefixo": o Dart leu pontos = +5, e um + na frente de um número não existe no Dart (o - existe; o +, não). Como consertar: pontos += 5;, com o sinal da conta antes do = e os dois grudados.

++ num número 
$ dart run err_lit.dart
err_lit.dart:2:9: Error: Can't assign to this.
  print(5++);
        ^

"Não dá para atribuir a isto." O ++ guarda o novo valor de volta, então só funciona numa variável. Um número escrito direto, como o 5, não é uma caixa: não tem onde guardar o 6. Como consertar: print(5 + 1);.

Missão final: o cofrinho da semana

Missão: a Ana começa a semana com 10 reais no cofrinho. Usando só atalhos (+=, -=, *=) na variável saldo: na segunda ela guarda 8; na quarta tira 5 para o lanche; no domingo a avó dobra o que tem no cofrinho. Depois disso, ela gasta 3 no sorvete. O programa deve mostrar Saldo final: 23.

void main() {
  var saldo = 10;
  // segunda, quarta, domingo e o sorvete aqui

  print('Saldo final: $saldo');
}

void main() {
  var saldo = 10;
  saldo += 8;
  saldo -= 5;
  saldo *= 2;
  saldo -= 3;
  print('Saldo final: $saldo');
}

Conta de conferência: 10 + 8 = 18; 18 − 5 = 13; 13 × 2 = 26; 26 − 3 = 23. No lab, a solução mostrou Saldo final: 23.

Resumo

  • = guarda um valor numa variável que já existe; a conta da direita é feita primeiro, com o valor antigo. Não é "igual a" (esse é o ==).
  • x += v é x = x + v; idem -=, *=, /=, ~/= e %=. O sinal vem antes do =, grudado.
  • x++ soma 1 e x-- tira 1. Dentro de outra expressão, x++ entrega o valor antigo e ++x o novo; o mais claro é usar sozinho na linha.
  • Um acumulador começa em zero (0.0, se vai receber double) e cresce com +=.
  • Uma final não muda; uma int não aceita double; e a variável precisa existir e ter valor antes do += ou do ++.
