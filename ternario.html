Dart O Operador Ternário

Na aula if e else, escolher entre "Aprovada" e "Recuperação" ocupou seis linhas: criar a variável, o if, o else, as chaves. Quando a escolha é só entre dois valores, o Dart tem um atalho de uma linha: o operador ternário, condição ? valor1 : valor2. Ele se chama ternário porque tem três partes.

Você vai aprender
  • Como ler e escrever condição ? valorSeVerdade : valorSeFalso.
  • A diferença entre o ternário (escolhe um valor) e o if (escolhe o que fazer).
  • Como usar o ternário dentro de um texto: "1 item", "3 itens".
  • O tipo do resultado quando os dois lados são diferentes (int e double).
  • Ternários encadeados, e quando é melhor voltar para o if.
  • Os erros reais: o : esquecido, tipos que não combinam, o if usado como valor, a condição que não é bool e o ternário fora das chaves da interpolação.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook) com dart run arquivo.dart. Você pode rodar cada um no editor do guia.

A ideia: "chá ou café?"

A avó da Ana pergunta toda manhã: "Está frio? Então é chá; senão, é café." A resposta da pergunta não é uma tarefa, é uma coisa: chá ou café. O ternário faz isso: olha a condição e devolve um de dois valores.

        está frio  ?   'chá'   :   'café'
        └─ pergunta ┘ └─ se sim ┘ └─ se não ┘

1. O primeiro ternário

void main() {
  final nota = 7.5;
  final situacao = nota >= 6 ? 'Aprovada' : 'Recuperação';
  print('Situação: $situacao');
}
nota >= 6
A condição: uma pergunta que dá true ou false.
?
Separa a pergunta das respostas. Lê-se "então".
'Aprovada'
O valor que o ternário devolve se a condição for true.
:
Separa as duas respostas. Lê-se "senão".
'Recuperação'
O valor devolvido se a condição for false.
final situacao = …
O valor escolhido vai para a variável, como o resultado de qualquer conta.
$ dart run ter1.dart
Situação: Aprovada

Em voz alta: "a situação é: a nota é maior ou igual a 6? Então 'Aprovada', senão 'Recuperação'".

O mesmo, com if e com ternário

void main() {
  final nota = 4.0;
  String situacao;
  if (nota >= 6) {
    situacao = 'Aprovada';
  } else {
    situacao = 'Recuperação';
  }
  print('Com if: $situacao');
  final situacao2 = nota >= 6 ? 'Aprovada' : 'Recuperação';
  print('Com ternário: $situacao2');
}

$ dart run ter_if.dart
Com if: Recuperação
Com ternário: Recuperação

Mesmo resultado. Com o ternário, a variável pode ser final (recebe o valor uma vez só, na criação), e o leitor vê numa linha só tudo o que pode acontecer com ela.

2. O ternário dentro de um texto

Como o ternário é um valor, ele pode ir em qualquer lugar onde cabe um valor, inclusive dentro de ${ … } num texto. O carrinho da loja escreve "1 item", mas "3 itens":

void main() {
  final itens = 1;
  print('Você tem $itens ${itens == 1 ? 'item' : 'itens'} no carrinho');
  final itens2 = 3;
  print('Você tem $itens2 ${itens2 == 1 ? 'item' : 'itens'} no carrinho');
}

$ dart run ter_interp.dart
Você tem 1 item no carrinho
Você tem 3 itens no carrinho

Dentro do ${ … } pode ir uma expressão inteira, e as aspas simples de 'item' não atrapalham o texto de fora, porque estão dentro das chaves. Sem as chaves, o ternário vira texto comum: veja Quando dá errado.

Missão: o programa sempre diz "dia de trabalho". Troque o texto fixo por um ternário: se fimDeSemana for true, 'folga'; senão, 'trabalho'.

void main() {
  final fimDeSemana = true;
  final tipo = 'trabalho';
  print('Hoje é dia de $tipo');
}

void main() {
  final fimDeSemana = true;
  final tipo = fimDeSemana ? 'folga' : 'trabalho';
  print('Hoje é dia de $tipo');
}

3. Ternário com números

void main() {
  final total = 120.0;
  final frete = total >= 100 ? 0 : 15;
  print('Frete: $frete');
  final desconto = total > 100 ? total * 0.1 : 0;
  print('Desconto: $desconto');
  print(desconto.runtimeType);
  final aPagar = total - desconto + frete;
  print('A pagar: $aPagar');
}

$ dart run ter_num.dart
Frete: 0
Desconto: 12.0
double
A pagar: 108.0

O frete é 0 ou 15: os dois lados são int, e frete é int. Já no desconto, um lado é double (120.0 * 0.1) e o outro é int (0). Nesse caso o Dart dá à variável o tipo num, que aceita os dois (veja Números). Desta vez saiu o lado double, e o runtimeType mostrou double. Se os dois lados forem de tipos que não têm nada a ver (um número e um texto), o tipo vira Object, e aí uma variável int não aceita (veja Quando dá errado). Para ficar tudo double, escreva 0.0 no lugar do 0.

4. Ternários encadeados

A parte do "senão" pode ser outro ternário. Para escolher a roupa conforme a temperatura:

void main() {
  final temperatura = 18;
  final roupa = temperatura > 28
      ? 'camiseta'
      : temperatura > 15
          ? 'blusa leve'
          : 'casaco';
  print('Hoje: $roupa');
}

$ dart run ter_aninhado.dart
Hoje: blusa leve

Funciona como um if … else if … else: 18 não é maior que 28, então vai para o "senão", que pergunta de novo: 18 é maior que 15? Sim: 'blusa leve'. Quebrar em linhas, com o ? e o : no começo de cada uma, é o jeito que o dart format organiza. Mesmo assim, dois níveis já é o limite: com mais que isso, use if … else if ou um switch.

Formas diferentes de fazer

SituaçãoUse
Escolher entre dois valores para uma variável, um texto ou um argumentoternário: final s = nota >= 6 ? 'A' : 'R';
Escolher entre duas ações (vários comandos, prints diferentes)if … else
Três ou mais caminhosif … else if ou switch (no máximo dois ternários encadeados)
"Este valor, ou um padrão se ele for null"nome ?? 'visitante' (aula ?. , ?? e ??=), em vez de nome != null ? nome : 'visitante'
Um item a mais numa lista, só se…o if dentro de coleções (aula if e for Dentro de Coleções)

Dá para usar o ternário para escolher uma ação, como em chovendo ? print('Leve o guarda-chuva') : print('Leve o boné'); (no lab, mostrou Leve o guarda-chuva). Funciona, mas confunde quem lê: o ternário existe para escolher valores. Nesse caso, prefira print(chovendo ? 'Leve o guarda-chuva' : 'Leve o boné');, ou um if.

Quando dá errado

Esqueceu a parte do "senão" 
void main() {
  final nota = 7;
  final situacao = nota >= 6 ? 'Aprovada';
  print(situacao);
}

                                         ^
err_semdois.dart:3:42: Error: Expected an identifier, but got ';'.

  final situacao = nota >= 6 ? 'Aprovada';
                                         ^
err_semdois.dart:3:42:
Linha 3, coluna 42: o ; do fim.
Error: Expected ':' before this.
"Era esperado : antes disto." O ternário sempre tem as duas respostas: o Dart chegou no ; esperando o : e o valor do "senão".
Expected an identifier, but got ';'.
Consequência do mesmo problema: depois do : que faltou, viria um valor, e veio o ;.

Como consertar: dê as duas respostas: nota >= 6 ? 'Aprovada' : 'Recuperação'. Se não existe resposta para o "senão", você quer um if sem else, não um ternário.

Os dois lados com tipos que não combinam 
void main() {
  final nota = 7;
  final int pontos = nota >= 6 ? 10 : 'zero';
  print(pontos);
}

$ dart run err_tipo.dart
err_tipo.dart:3:32: Error: A value of type 'Object' can't be assigned to a variable of type 'int'.
 - 'Object' is from 'dart:core'.
  final int pontos = nota >= 6 ? 10 : 'zero';
                               ^

"Um valor do tipo Object não pode ser atribuído a uma variável int." Um lado é int (10), o outro é String ('zero'); o único tipo que serve para os dois é Object ("qualquer coisa"), e uma variável int não aceita "qualquer coisa". O Dart reclama mesmo sabendo que, com nota 7, sairia o 10: ele confere os dois caminhos. Como consertar: os dois lados do mesmo tipo: nota >= 6 ? 10 : 0.

Tentou usar o if como valor 
void main() {
  final nota = 7;
  final situacao = if (nota >= 6) 'Aprovada' else 'Recuperação';
  print(situacao);
}

$ dart run err_ifexpr.dart

                   ^^
err_ifexpr.dart:3:18: Error: Expected ';' after this.

                 ^
err_ifexpr.dart:3:35: Error: Expected ';' after this.

"Era esperado um nome (um valor), mas veio if." Em linguagens como Kotlin e Python, o if pode devolver um valor. No Dart, não: o if é uma instrução, não um valor. (A exceção é o if dentro de listas, da aula if e for Dentro de Coleções.) Como consertar: é exatamente o trabalho do ternário: final situacao = nota >= 6 ? 'Aprovada' : 'Recuperação';.

O ternário fora das chaves, dentro do texto 
void main() {
  final nota = 4;
  print('Situação: ${nota >= 6} ? Aprovada : Recuperação');
}

$ dart run err_interp2.dart
Situação: false ? Aprovada : Recuperação

Compila, roda, e mostra o código em vez do resultado! As chaves fecharam logo depois do 6: só a comparação foi calculada (false); o resto, ? Aprovada : Recuperação, ficou sendo texto comum. E com $nota sem chaves e aspas no meio, 'Situação: $nota >= 6 ? 'Aprovada' : 'Recuperação'', o lab mostrou nove erros, o primeiro deles Error: The non-ASCII character 'ç' (U+00E7) can't be used in identifiers, only in strings and comments.: as aspas de 'Aprovada' fecharam o texto, e o Recuperação ficou fora das aspas, como se fosse um nome de variável (que não pode ter "ç"). Como consertar: o ternário inteiro dentro de ${ … }: 'Situação: ${nota >= 6 ? 'Aprovada' : 'Recuperação'}'.

Uma condição que não é bool 
$ dart run err_cond.dart
err_cond.dart:3:9: Error: A value of type 'int' can't be assigned to a variable of type 'bool'.
  print(estoque ? 'tem' : 'acabou');
        ^

A mesma regra do if: antes do ? vem uma pergunta de sim ou não, e um número não é. Como consertar: estoque > 0 ? 'tem' : 'acabou'.

O ternário "engoliu" o texto da frente 
$ dart run err_mais.dart
err_mais.dart:3:22: Error: A value of type 'int' can't be assigned to a variable of type 'String'.
  print('Pontos: ' + pontos > 0 ? 'positivo' : 'zero');
                     ^
err_mais.dart:3:29: Error: The operator '>' isn't defined for the type 'String'.
Try correcting the operator to an existing operator, or defining a '>' operator.
  print('Pontos: ' + pontos > 0 ? 'positivo' : 'zero');
                            ^

O ternário tem a prioridade mais baixa de todas as contas: o Dart faz tudo o que está antes do ? primeiro. Aqui, ele tentou 'Pontos: ' + pontos (texto mais número: primeiro erro) e depois … > 0 com um texto (segundo erro). Como consertar: use interpolação: 'Pontos: ${pontos > 0 ? 'positivo' : 'zero'}', ou parênteses em volta do ternário.

Missão final: a mensagem do carrinho

Missão: complete as duas linhas com ternários. A palavra deve ser 'produto' se quantidade for 1, senão 'produtos'; o frete deve ser 0 se o total for 100 ou mais, senão 20. Com 1 produto de 45 reais, deve aparecer Carrinho: 1 produto, frete R$ 20.

void main() {
  final quantidade = 1;
  final total = 45;
  final palavra = 'produtos'; // use um ternário
  final frete = 0; // use um ternário
  print('Carrinho: $quantidade $palavra, frete R\$ $frete');
}

void main() {
  final quantidade = 1;
  final total = 45;
  final palavra = quantidade == 1 ? 'produto' : 'produtos';
  final frete = total >= 100 ? 0 : 20;
  print('Carrinho: $quantidade $palavra, frete R\$ $frete');
}

Resumo

  • condição ? valorSeVerdade : valorSeFalso devolve um de dois valores. As três partes são obrigatórias.
  • Use o ternário para escolher valores (variáveis, pedaços de texto); para escolher ações, use if.
  • Dentro de texto, o ternário inteiro vai entre ${ … }.
  • Os dois lados devem ter o mesmo tipo; int com double dá num, número com texto dá Object.
  • O ternário tem a prioridade mais baixa: na dúvida, parênteses. E no máximo dois ternários encadeados.
