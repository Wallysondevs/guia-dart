Dart Funções como Valores

Um número pode ser guardado numa variável, passado para uma função e devolvido por ela. No Dart, uma função também pode. Funções são valores como 42 ou 'Ana': dá para guardá-las em variáveis, colocá-las em listas e mapas, entregá-las a outras funções e recebê-las de volta. Os programadores dizem que, no Dart, funções são cidadãs de primeira classe.

Você vai aprender
  • A diferença entre saudar (a função) e saudar('Ana') (a chamada).
  • Como guardar uma função numa variável e chamá-la pela variável.
  • Como se escreve o tipo de uma função: double Function(double).
  • Como uma função recebe outra como parâmetro, e por que isso é útil.
  • Atalhos como forEach(print) e map(int.parse), um mapa de operações e o typedef (dar nome a um tipo de função).
  • Uma função que devolve outra função.
  • Os erros reais: os parênteses a mais, o tipo de função errado, a função que pode ser null e o NoSuchMethodError.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), com dart run arquivo.dart.

A ideia: a receita e o bolo

Pense numa receita de bolo escrita num papel. Você pode:

  • fazer o bolo seguindo a receita: isso é chamar a função, e o resultado é um bolo;
  • ou entregar o papel da receita para a vizinha, guardar numa pasta, tirar uma cópia: isso é tratar a função como valor. Ninguém fez bolo nenhum ainda; você passou a receita adiante.

No Dart, a diferença está nos parênteses: saudar('Ana') é "faça o bolo agora"; saudar, sem parênteses, é "o papel com a receita".

1. Guardando uma função numa variável

void saudar(String nome) {
  print('Olá, $nome!');
}

void main() {
  final cumprimentar = saudar;
  cumprimentar('Ana');
  saudar('Bia');
  print(cumprimentar);
  print(cumprimentar.runtimeType);
}

$ dart run variavel.dart
Olá, Ana!
Olá, Bia!
Closure: (String) => void from Function 'saudar': static.
(String) => void
final cumprimentar = saudar;
Sem parênteses: a variável recebe a própria função, não o resultado dela. Nada é mostrado nesta linha. (O nome técnico de pegar uma função assim, sem chamar, é tear-off, "destacar".)
cumprimentar('Ana');
Agora sim, com parênteses: chama a função guardada. É exatamente o mesmo que saudar('Ana'); são dois nomes para a mesma receita.
Closure: (String) => void from Function 'saudar': static.
O que o print mostra de uma função: "uma função que recebe uma String e não devolve nada (void), que veio da função saudar". (static aqui quer dizer que é uma função de primeiro nível do arquivo, fora de qualquer classe.)
(String) => void
O runtimeType (o tipo em tempo de execução) da variável: o tipo da função, escrito à moda do Dart.

O tipo de uma função

Se você quiser escrever o tipo da variável, em vez de deixar o Dart descobrir, ele se escreve assim:

void Function(String) cumprimentar = saudar;
double Function(double) regra = (p) => p * 0.9;
int Function(int, int) conta = (a, b) => a + b;

Leia da esquerda para a direita: double Function(double) = "uma função que devolve double e recebe um double". Primeiro o tipo de retorno, depois a palavra Function, depois os tipos dos parâmetros entre parênteses.

2. Passando uma função para outra função

Aqui está a grande utilidade. A lojinha da Ana mostra a tabela de preços, mas a regra muda: hoje tem 10% de desconto, amanhã tem taxa de entrega. Em vez de escrever uma função de tabela para cada regra, a Ana escreve uma função de tabela que recebe a regra como parâmetro:

double comDesconto(double preco) => preco * 0.9;
double comTaxa(double preco) => preco + 2.0;

void mostrarPrecos(List<double> precos, double Function(double) regra) {
  for (final preco in precos) {
    final novo = regra(preco);
    print('R\$ $preco -> R\$ ${novo.toStringAsFixed(2)}');
  }
}

void main() {
  final precos = [10.0, 25.0];
  print('Com desconto:');
  mostrarPrecos(precos, comDesconto);
  print('Com taxa de entrega:');
  mostrarPrecos(precos, comTaxa);
  print('Em dobro:');
  mostrarPrecos(precos, (p) => p * 2);
}

$ dart run parametro.dart
Com desconto:
R$ 10.0 -> R$ 9.00
R$ 25.0 -> R$ 22.50
Com taxa de entrega:
R$ 10.0 -> R$ 12.00
R$ 25.0 -> R$ 27.00
Em dobro:
R$ 10.0 -> R$ 20.00
R$ 25.0 -> R$ 50.00
double Function(double) regra
O segundo parâmetro de mostrarPrecos: "uma função que recebe um double e devolve um double". Qualquer função com esse formato serve.
final novo = regra(preco);
Lá dentro, o parâmetro é chamado como uma função qualquer. A mostrarPrecos não sabe qual regra é; ela só sabe que pode chamá-la.
mostrarPrecos(precos, comDesconto);
Passa a função comDesconto, sem parênteses.
mostrarPrecos(precos, (p) => p * 2);
Também serve uma função anônima, escrita na hora (veja Funções Anônimas). O Dart sabe que p é double pelo tipo do parâmetro.
'R\$ …'
O \$ mostra um cifrão de verdade, em vez de começar uma interpolação (veja Strings).

Uma função que recebe (ou devolve) outra função se chama função de ordem superior. Você já usou várias sem saber: forEach, sort e where são assim.

Missão: crie a regra blackFriday, que tira R$ 5 do preço (preco - 5), e passe-a para mostrarPrecos no lugar de comDesconto.

3. Atalhos: passar funções prontas

Qualquer função com o formato certo pode ser passada, inclusive as do próprio Dart:

void main() {
  final compras = ['pão', 'leite'];
  compras.forEach(print);
  final textos = ['3', '10', '7'];
  final numeros = textos.map(int.parse).toList();
  print(numeros);
  final gritar = 'oi'.toUpperCase;
  print(gritar());
}

$ dart run tearoff.dart
pão
leite
[3, 10, 7]
OI
  • compras.forEach(print): o print recebe um valor, e é isso que o forEach entrega. Não precisa escrever (item) => print(item).
  • textos.map(int.parse): o map passa cada texto para o int.parse e junta os resultados (o map e o toList estão em map, where, reduce e Outros).
  • 'oi'.toUpperCase: até um método de um objeto pode ser destacado. A variável gritar guarda "deixar 'oi' em maiúsculas", e só faz isso quando chamada.
Boa prática

O guia de estilo do Dart (Effective Dart) recomenda o atalho: se a função anônima só repassa o argumento ((x) => print(x)), escreva a função direto (print). Menos coisa para ler.

4. Funções dentro de um mapa

Como funções são valores, elas podem morar numa lista ou num mapa (veja Mapas). Uma calculadora pode guardar uma função para cada símbolo:

int somar(int a, int b) => a + b;
int subtrair(int a, int b) => a - b;
int multiplicar(int a, int b) => a * b;

void main() {
  final operacoes = {
    '+': somar,
    '-': subtrair,
    '*': multiplicar,
  };
  for (final simbolo in operacoes.keys) {
    final conta = operacoes[simbolo]!;
    print('8 $simbolo 2 = ${conta(8, 2)}');
  }
}

$ dart run lista.dart
8 + 2 = 10
8 - 2 = 6
8 * 2 = 16

operacoes[simbolo] pega a função guardada naquele símbolo. O ! diz ao Dart "eu garanto que ela existe" (um mapa devolve null para chave que não existe; veja late e o Operador !). Depois, conta(8, 2) chama a função. Acrescentar a divisão é só uma linha a mais no mapa, sem mexer no for.

5. typedef: um nome para o tipo da função

Quando o tipo da função é comprido ou aparece em vários lugares, dê um nome a ele com typedef ("definição de tipo"):

typedef RegraDePreco = double Function(double preco);

double aplicar(double preco, RegraDePreco regra) => regra(preco);

void main() {
  RegraDePreco promocao = (p) => p / 2;
  print(aplicar(30.0, promocao));
  promocao = (p) => p - 5;
  print(aplicar(30.0, promocao));
}

$ dart run typedef.dart
15.0
25.0

RegraDePreco passa a ser um apelido para double Function(double preco). O nome do tipo segue o padrão das classes, UpperCamelCase. Repare também que a variável promocao não é final: ela recebeu uma função e, depois, outra, como uma variável qualquer.

6. Uma função que devolve outra função

O caminho inverso também vale: uma função pode devolver uma função.

double Function(double) escolherRegra(bool clienteFiel) {
  if (clienteFiel) {
    return (preco) => preco * 0.8;
  }
  return (preco) => preco;
}

void main() {
  final regra = escolherRegra(true);
  print(regra(50.0));
  print(escolherRegra(false)(50.0));
}

$ dart run devolver.dart
40.0
50.0

O tipo de retorno de escolherRegra é double Function(double): ela não devolve um preço, devolve uma regra. Na segunda chamada, os dois pares de parênteses seguidos fazem as duas coisas de uma vez: escolherRegra(false) devolve a função, e (50.0) a chama. Funções que devolvem funções ficam ainda mais poderosas quando a função devolvida "lembra" de valores de onde nasceu: é o assunto da próxima aula, Closures.

Experimente: acrescente uma entrada 'metade': (p) => p / 2 no mapa de regras e rode. Depois, troque o 'normal' do main por 'metade'.

void main() {
  final regras = <String, double Function(double)>{
    'normal': (p) => p,
    'desconto': (p) => p * 0.9,
  };
  final regra = regras['normal']!;
  print('R\$ ${regra(14.0).toStringAsFixed(2)}');
}

void main() {
  final regras = <String, double Function(double)>{
    'normal': (p) => p,
    'desconto': (p) => p * 0.9,
    'metade': (p) => p / 2,
  };
  final regra = regras['metade']!;
  print('R\$ ${regra(14.0).toStringAsFixed(2)}');
}

A função tem o formato errado

  for (final preco in precos) {
    print(regra(preco));
  }

  mostrarPrecos([10.0, 25.0], dobro);
}

$ dart run err_tipo.dart
err_tipo.dart:10:31: Error: The argument type 'int Function(int)' can't be assigned to the parameter type 'double Function(double)'.
  mostrarPrecos([10.0, 25.0], dobro);
                              ^

"O tipo do argumento, int Function(int), não pode ser atribuído ao tipo do parâmetro, double Function(double)." O Dart confere o formato da função antes de rodar: a regra tinha de receber e devolver double. Como consertar: double dobro(double x) => x * 2;.

A variável da função pode ser null 
void main() {
  void Function()? aviso;
  aviso();
}

$ dart run err_nulo.dart
err_nulo.dart:3:8: Error: Can't use an expression of type 'void Function()?' as a function because it's potentially null.
Try calling using ?.call instead.
  aviso();
       ^

"Não dá para usar uma expressão do tipo void Function()? como função, porque ela pode ser null. Tente chamar com ?.call." O ? no fim do tipo diz que a variável pode estar vazia (veja Tipos Anuláveis), e chamar "nada" não dá. Como consertar: aviso?.call(); chama só se houver uma função guardada; se for null, não faz nada.

Resumo

  • No Dart, funções são valores: saudar (sem parênteses) é a função; saudar('Ana') é a chamada.
  • Uma função pode ser guardada em variável, lista ou mapa, passada como argumento e devolvida por outra função.
  • O tipo de uma função se escreve Retorno Function(Parâmetros), como double Function(double); o typedef dá um nome a ele.
  • Funções prontas também podem ser passadas: forEach(print), map(int.parse).
  • Passar f() em vez de f chama a função na hora (erro de argumentos). Evite o tipo Function sozinho: os erros só aparecem rodando, como NoSuchMethodError.
