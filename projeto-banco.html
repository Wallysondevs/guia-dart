Projeto Conta Bancária

A Ana quer controlar o dinheiro dela: quanto entrou, quanto saiu e quanto sobrou. Uma conta de banco é o exemplo clássico de classe: ela tem dados (o titular e o saldo) e ações (depositar e sacar), e tem regras que ninguém pode furar, como "não dá para sacar mais do que tem". Neste projeto você constrói essa conta em quatro versões, cada uma consertando um problema da anterior.

Você vai praticar
  • Criar uma classe com campos, construtor e métodos.
  • Esconder o saldo com _ e deixá-lo só para leitura com um get.
  • Barrar operações erradas com throw e uma exceção própria, tratada com try e catch.
  • Guardar o extrato como uma lista de records e mostrar a conta com toString.
  • Criar uma poupança que herda da conta, com super e @override.

O que vamos construir

No fim, a Ana terá uma conta comum e uma poupança que rende juros, cada uma com o seu extrato:

$ dart run conta.dart
Conta de Ana (saldo R$ 2500.00)
Poupança de Ana (saldo R$ 1005.00)

Extrato de Ana
Guardado              R$ 1000.00
Rendimento               R$ 5.00
Saldo                 R$ 1005.00
  1. A classe ContaBancaria: campos, construtor, depositar e sacar.
  2. Regras: saldo protegido e exceções.
  3. O extrato: records, parâmetros nomeados e toString.
  4. A poupança: herança.

Crie a pasta do projeto e entre nela; o programa vai se chamar conta.dart:

$ cd banco

Versão 1 · A classe ContaBancaria

Uma classe é a forma do bolo; cada conta criada com ela é um bolo feito naquela forma (um objeto). A forma diz o que toda conta tem: um titular, um saldo e duas ações.

class ContaBancaria {
  final String titular;
  double saldo = 0;

  ContaBancaria(this.titular);

  void depositar(double valor) {
    saldo += valor;
  }

  void sacar(double valor) {
    saldo -= valor;
  }
}

void main() {
  final conta = ContaBancaria('Ana');
  conta.depositar(500);
  conta.sacar(120.50);
  print('${conta.titular}: R\$ ${conta.saldo.toStringAsFixed(2)}');

  conta.sacar(1000);
  print('${conta.titular}: R\$ ${conta.saldo.toStringAsFixed(2)}');
}

Versão 2 · Regras: saldo protegido e exceções

Pense no caixa eletrônico: você vê o saldo, mas não pode digitar um saldo novo; e, se pedir mais do que tem, a máquina recusa com uma mensagem. Em Dart:

  • o saldo de verdade vira _saldo: o _ na frente o torna privado;
  • um get saldo deixa o resto do programa ler, mas não escrever;
  • os métodos conferem as regras e, se algo estiver errado, lançam uma exceção com throw.
class SaldoInsuficienteException implements Exception {
  final double saldo;
  final double pedido;

  SaldoInsuficienteException(this.saldo, this.pedido);

  @override
  String toString() => 'Saldo insuficiente: pediu R\$ ${pedido.toStringAsFixed(2)}, '
      'mas só tem R\$ ${saldo.toStringAsFixed(2)}.';
}

class ContaBancaria {
  final String titular;
  double _saldo = 0;

  ContaBancaria(this.titular);

  double get saldo => _saldo;

  void depositar(double valor) {
    if (valor <= 0) {
      throw ArgumentError.value(valor, 'valor', 'o depósito precisa ser positivo');
    }
    _saldo += valor;
  }

  void sacar(double valor) {
    if (valor <= 0) {
      throw ArgumentError.value(valor, 'valor', 'o saque precisa ser positivo');
    }
    if (valor > _saldo) {
      throw SaldoInsuficienteException(_saldo, valor);
    }
    _saldo -= valor;
  }
}

void main() {
  final conta = ContaBancaria('Ana');
  conta.depositar(500);
  conta.sacar(120.50);
  print('Saldo: R\$ ${conta.saldo.toStringAsFixed(2)}');

  try {
    conta.sacar(1000);
  } on SaldoInsuficienteException catch (e) {
    print(e);
  }

  try {
    conta.depositar(-50);
  } on ArgumentError catch (e) {
    print('Erro: ${e.message}');
  }

  print('Saldo: R\$ ${conta.saldo.toStringAsFixed(2)}');
}

Versão 3 · O extrato

O banco não guarda só o saldo: guarda cada movimento, com uma descrição. Cada movimento vira um record (descricao: …, valor: …) numa lista privada; o saque entra com valor negativo. Três novidades:

  • depositar e sacar ganham um parâmetro nomeado opcional, descricao, com valor padrão;
  • o método mostrarExtrato imprime a lista;
  • a conta ganha um toString, para que print(conta) mostre algo útil.
class SaldoInsuficienteException implements Exception {
  final double saldo;
  final double pedido;

  SaldoInsuficienteException(this.saldo, this.pedido);

  @override
  String toString() => 'Saldo insuficiente: pediu R\$ ${pedido.toStringAsFixed(2)}, '
      'mas só tem R\$ ${saldo.toStringAsFixed(2)}.';
}

String reais(double valor) => 'R\$ ${valor.toStringAsFixed(2)}';

class ContaBancaria {
  final String titular;
  double _saldo = 0;
  final _movimentos = <({String descricao, double valor})>[];

  ContaBancaria(this.titular);

  double get saldo => _saldo;

  void depositar(double valor, {String descricao = 'Depósito'}) {
    if (valor <= 0) {
      throw ArgumentError.value(valor, 'valor', 'o depósito precisa ser positivo');
    }
    _saldo += valor;
    _movimentos.add((descricao: descricao, valor: valor));
  }

  void sacar(double valor, {String descricao = 'Saque'}) {
    if (valor <= 0) {
      throw ArgumentError.value(valor, 'valor', 'o saque precisa ser positivo');
    }
    if (valor > _saldo) {
      throw SaldoInsuficienteException(_saldo, valor);
    }
    _saldo -= valor;
    _movimentos.add((descricao: descricao, valor: -valor));
  }

  void mostrarExtrato() {
    print('Extrato de $titular');
    for (final (:descricao, :valor) in _movimentos) {
      print('${descricao.padRight(20)}${reais(valor).padLeft(12)}');
    }
    print('${'Saldo'.padRight(20)}${reais(_saldo).padLeft(12)}');
  }

  @override
  String toString() => 'Conta de $titular (saldo ${reais(_saldo)})';
}

void main() {
  final conta = ContaBancaria('Ana');
  conta.depositar(2500, descricao: 'Salário');
  conta.sacar(120.50, descricao: 'Padaria do bairro');
  conta.sacar(800, descricao: 'Aluguel');
  conta.depositar(45.90);

  print(conta);
  print('');
  conta.mostrarExtrato();
}

Dinheiro e double

O double guarda números com casas decimais de forma aproximada (0.1 + 0.2 dá 0.30000000000000004; veja Números). Para um projeto de estudo, o toStringAsFixed(2) na hora de mostrar resolve. Sistemas de banco de verdade guardam centavos num int (R$ 120,50 = 12050) e só dividem por 100 na hora de mostrar.

Versão 4 · A poupança

A Ana abriu uma poupança. Ela é uma conta como as outras (tem titular, saldo, extrato, depósito e saque) e mais uma coisa: rende juros todo mês. Em vez de copiar a classe inteira, a poupança herda da conta com extends ("estende") e acrescenta só o que é dela. As classes SaldoInsuficienteException e ContaBancaria e a função reais ficam iguais à versão 3; o arquivo ganha a classe nova e um main novo:

class ContaPoupanca extends ContaBancaria {
  final double taxaMensal;

  ContaPoupanca(super.titular, {required this.taxaMensal});

  void renderJuros() {
    final juros = saldo * taxaMensal;
    if (juros > 0) depositar(juros, descricao: 'Rendimento');
  }

  @override
  String toString() => 'Poupança de $titular (saldo ${reais(saldo)})';
}

void main() {
  final contas = <ContaBancaria>[
    ContaBancaria('Ana'),
    ContaPoupanca('Ana', taxaMensal: 0.005),
  ];

  contas[0].depositar(2500, descricao: 'Salário');
  contas[1].depositar(1000, descricao: 'Guardado');

  for (final conta in contas) {
    if (conta is ContaPoupanca) {
      conta.renderJuros();
    }
    print(conta);
  }

  print('');
  contas[1].mostrarExtrato();
}

class ContaPoupanca extends ContaBancaria {
  final double taxaMensal;

  ContaPoupanca(super.titular, {required this.taxaMensal});

  void renderJuros() {
    final juros = saldo * taxaMensal;
    depositar(juros);
  }

  @override
  String toString() => 'Poupança de $titular (saldo ${reais(saldo)})';
}

void main() {
  final poupanca = ContaPoupanca('Ana', taxaMensal: 0.005);
  poupanca.depositar(1000);
  poupanca.renderJuros();
  print(poupanca);

Resumo

  • Uma classe junta dados (campos) e ações (métodos); o construtor ContaBancaria(this.titular) preenche os campos.
  • _saldo privado + get saldo = saldo só de leitura; tentar conta.saldo = … dá The setter 'saldo' isn't defined.
  • throw barra a operação errada; uma exceção própria (implements Exception) com toString explica o problema; try/on … catch trata, e sem tratamento o programa termina com Unhandled exception e código 255.
  • Records guardam o extrato; parâmetros nomeados com valor padrão deixam a descrição opcional; toString faz o print(conta) mostrar algo útil.
  • extends herda tudo; super.titular repassa ao construtor de cima; @override troca um método; is pergunta o tipo.
