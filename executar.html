Dart dart run

Você escreveu um programa Dart num arquivo. E agora? Para ele fazer alguma coisa, alguém precisa rodá-lo (também se diz "executar"). No seu computador, quem faz isso é o comando dart run, digitado no terminal. Esta aula mostra o caminho completo: criar o arquivo, rodar, mudar e rodar de novo, e entender as respostas que o dart dá quando alguma coisa está no lugar errado.

Você vai aprender
  • O ciclo de todo programador: escrever → salvar → rodar → ver a saída.
  • A criar um arquivo .dart e rodá-lo com dart run arquivo.dart.
  • Por que a pasta em que o terminal está faz diferença, e como rodar um programa de outra pasta.
  • O atalho dart arquivo.dart, sem o run.
  • O que é o código de saída (0, 254, 255) e como vê-lo com echo $?.
  • Os erros reais Could not find file e Found no `pubspec.yaml` file.

Para esta aula você precisa do Dart instalado (aula Instalar o Dart). Sem ele, use as caixas "Experimente": o botão Rodar faz o mesmo que um dart run main.dart (aula O Editor do Guia). Os terminais abaixo foram colhidos na máquina fictícia da Ana (usuária ana, computador notebook, Ubuntu) com o Dart SDK 3.13.5.

A ideia: a receita e o cozinheiro

O arquivo .dart é a receita escrita. Ela pode ficar na gaveta para sempre: enquanto ninguém a seguir, nenhum bolo sai do forno. O dart run é o cozinheiro: você entrega a receita, ele lê e faz. E, se você mudar a receita, precisa pedir de novo para o cozinheiro fazer; o bolo de ontem não muda sozinho.

PassoOndeO que você faz
1. EscreverNum editor de texto (VS Code, Gedit, Bloco de Notas…)Digita o programa
2. SalvarNo editor (Ctrl+S)Grava o arquivo com o nome terminado em .dart
3. RodarNo terminaldart run nome.dart
4. VerNo terminalLê a saída (ou a mensagem de erro) e volta ao passo 1

1. Criando o arquivo

Abra o seu editor de texto, digite o programa abaixo e salve na sua pasta pessoal (no Linux, /home/seu-nome; no Windows, C:\Users\seu-nome) com o nome ola.dart:

void main() {
  print('Olá, Ana!');
}
Cuidado com o nome do arquivo

O nome tem de terminar em .dart. No Windows, o Bloco de Notas às vezes salva como ola.dart.txt sem você perceber: na janela de salvar, escolha "Todos os arquivos" no tipo. E, pelo estilo oficial do Dart, nomes de arquivo usam só letras minúsculas, sem acento, com _ no lugar do espaço: lista_compras.dart.

Agora abra o terminal. Ele começa na sua pasta pessoal, a mesma onde está o arquivo. Dois comandos ajudam a se localizar: pwd ("em que pasta estou?") e cat (mostra o conteúdo de um arquivo):

$ pwd
/home/ana
$ cat ola.dart
void main() {
  print('Olá, Ana!');
}

2. Rodando: dart run

$ dart run ola.dart
Olá, Ana!
dart
O programa do Dart SDK.
run
A ferramenta escolhida: "rodar".
ola.dart
O arquivo a rodar. O dart procura esse nome na pasta em que o terminal está.
Olá, Ana!
A saída: o que o programa mostrou. Depois dela, o terminal mostra o $ de novo, pronto para o próximo comando.

Por trás desse comando, o dart leu o arquivo inteiro, conferiu se está bem escrito, compilou (traduziu para a linguagem da máquina) e só então rodou o main. Tudo isso leva em torno de um segundo, por isso a resposta não é instantânea.

Missão: este é o mesmo ola.dart. Faça ele cumprimentar a Bia e clique em Rodar (no seu computador, seria salvar e digitar dart run ola.dart de novo).

void main() {
  print('Olá, Ana!');
}

void main() {
  print('Olá, Bia!');
}

3. Mudou o arquivo? Rode de novo

A Ana criou um recado.dart e rodou. Depois acrescentou uma linha no editor, salvou e rodou de novo. (Aqui, para você ver o arquivo nas duas versões, ela escreveu o arquivo direto no terminal com cat >; no dia a dia, use o editor.)

$ cat > recado.dart <<'FIM'
> void main() {
>   print('Bom dia!');
> }
> FIM
$ dart run recado.dart
Bom dia!
$ cat > recado.dart <<'FIM'
> void main() {
>   print('Bom dia!');
>   print('O pão já saiu.');
> }
> FIM
$ dart run recado.dart
Bom dia!
O pão já saiu.

A cada dart run, o Dart lê o arquivo como ele está no disco naquele momento. Por isso o erro mais comum de quem começa é mudar o código, esquecer de salvar e rodar: sai a versão antiga, e parece que "o Dart não obedeceu". Salvou, rodou.

Atalho do terminal

Para repetir um comando, aperte a seta para cima e depois Enter: o terminal traz de volta o último comando digitado. Você vai fazer isso centenas de vezes.

4. A pasta em que o terminal está

A Ana organizou os programas da padaria numa pasta chamada programas. Do jeito que o terminal está (na pasta pessoal), o dart não acha o arquivo:

$ dart run padaria.dart
Could not find file `padaria.dart`
$ ls programas
padaria.dart

"Não encontrei o arquivo padaria.dart". O arquivo existe (o ls programas, "liste a pasta programas", mostra), mas está numa pasta dentro da pasta pessoal, e o dart só procura onde o terminal está. Há dois jeitos de resolver:

Jeito 1: dizer o caminho

$ dart run programas/padaria.dart
Padaria do Bairro
Pão francês saindo às 7h

programas/padaria.dart é o caminho do arquivo: "dentro da pasta programas, o arquivo padaria.dart". A barra / separa as pastas (no Windows também se usa \).

Jeito 2: entrar na pasta com cd

$ cd programas
$ pwd
/home/ana/programas
$ dart run padaria.dart
Padaria do Bairro
Pão francês saindo às 7h

O cd (change directory, "mude de pasta") leva o terminal para dentro de programas. A partir daí, o nome sozinho basta. Para voltar uma pasta, cd ...

No VS Code

Abra a pasta do projeto pelo menu Arquivo → Abrir Pasta e use o terminal embutido (menu Terminal → Novo Terminal): ele já abre dentro da pasta, e o dart run arquivo.dart funciona direto.

5. O atalho: dart arquivo.dart

Para rodar um arquivo, o run pode ficar de fora:

$ dart ola.dart
Olá, Ana!

O resultado é o mesmo. Este guia escreve sempre dart run arquivo.dart, que deixa claro o que está acontecendo, mas você vai ver o atalho em tutoriais e respostas na internet.

Formas de rodar: qual usar

FormaQuando usar
dart run arquivo.dartO padrão deste guia: um arquivo na pasta do terminal
dart arquivo.dartO mesmo, mais curto
dart run pasta/arquivo.dartO arquivo está em outra pasta
dart run (sem arquivo)Só dentro de um projeto com pubspec.yaml (aula Criando um Projeto)
Botão Rodar das caixas "Experimente"Sem instalar nada, no navegador

6. O código de saída: echo $?

Todo programa, ao terminar, devolve ao terminal um número escondido: o código de saída. 0 quer dizer "deu tudo certo"; qualquer outro número quer dizer "algo deu errado". O terminal guarda o código do último comando em $?, e o echo $? o mostra:

$ dart run ola.dart
Olá, Ana!
$ echo $?
0
CódigoQuando o dart run devolve
0O programa rodou até o fim sem problemas
254Erro de compilação: o arquivo nem chegou a rodar
255O programa parou por uma exceção não tratada, ou o dart não achou o que rodar

Você vai ver o 254 e o 255 nos exemplos de erro de cada aula (os primeiros estão em O que é Dart). Um programa também pode escolher o próprio código com exit(N), assunto da aula Argumentos da Linha de Comando.

Quando dá errado

As mensagens do dart saem em inglês. Abaixo, cada uma explicada.

Nome do arquivo diferente do que está no disco 
$ dart run olá.dart
Could not find file `olá.dart`
$ echo $?
255
$ dart run Ola.dart
Could not find file `Ola.dart`

"Não encontrei o arquivo". O arquivo se chama ola.dart, sem acento e com o minúsculo. Para o Linux e o macOS, olá.dart, Ola.dart e ola.dart são três nomes diferentes. Os acentos graves ` em volta do nome são só o jeito de o dart destacá-lo. Como consertar: digite o nome exatamente como está; o ls mostra os arquivos da pasta. Dica: digite dart run ol e aperte Tab: o terminal completa o nome sozinho.

O arquivo está em outra pasta 
$ dart run padaria.dart
Could not find file `padaria.dart`

A mesma mensagem, outra causa: o nome está certo, mas o terminal está na pasta errada (seção 4). Como consertar: dart run programas/padaria.dart, ou cd programas antes.

Esqueceu o .dart (ou o nome inteiro) 
$ dart run ola
Found no `pubspec.yaml` file in `/home/ana` or parent directories
$ dart run
Found no `pubspec.yaml` file in `/home/ana` or parent directories
$ echo $?
255

"Não encontrei um arquivo pubspec.yaml em /home/ana nem nas pastas acima". Esta assusta, mas é simples: sem um nome terminado em .dart, o dart run acha que você quer rodar um projeto Dart (ou um pacote chamado ola), e todo projeto tem um arquivo pubspec.yaml com a sua descrição. Como a pasta pessoal da Ana não é um projeto, ele não achou. Projetos e o pubspec.yaml têm aulas próprias: Criando um Projeto e O pubspec.yaml. Como consertar: escreva o nome completo, dart run ola.dart.

Rodou e saiu a versão antiga

Não aparece mensagem de erro nenhuma: você mudou o código, rodou e a saída é a de antes. O arquivo não foi salvo (no VS Code, uma bolinha branca na aba do arquivo avisa que há mudanças não salvas). Como consertar: Ctrl+S e rode de novo.

Missão: este é o padaria.dart da Ana. Acrescente uma terceira linha que mostre Bolo de fubá saindo às 9h e rode de novo.

void main() {
  print('Padaria do Bairro');
  print('Pão francês saindo às 7h');
}

void main() {
  print('Padaria do Bairro');
  print('Pão francês saindo às 7h');
  print('Bolo de fubá saindo às 9h');
}

Resumo

  • O ciclo: escrever → salvar → dart run arquivo.dart → ler a saída → voltar.
  • O dart procura o arquivo na pasta em que o terminal está; para outra pasta, use o caminho (pasta/arquivo.dart) ou cd pasta.
  • dart arquivo.dart é um atalho para dart run arquivo.dart.
  • Cada dart run lê o arquivo como está salvo naquele momento.
  • Código de saída (echo $?): 0 deu certo; 254 erro de compilação; 255 exceção ou arquivo não encontrado.
  • Could not find file = nome ou pasta errados; Found no `pubspec.yaml` file = faltou o .dart.
