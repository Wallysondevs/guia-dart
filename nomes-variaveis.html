Dart Nomes de Variáveis

Toda variável precisa de um nome, a etiqueta do pote. Você escolhe o nome, mas o Dart tem regras (o que não segue a regra não compila) e a comunidade Dart tem um estilo (o que não segue o estilo compila, mas fica estranho para todo mundo que lê). Esta aula mostra as duas coisas, e os erros que aparecem quando um nome quebra uma regra, como o mais comum entre quem fala português: o acento.

Você vai aprender
  • As regras: quais caracteres valem num nome e onde.
  • Por que preço não pode, e preco pode.
  • Que nome, Nome e NOME são três variáveis diferentes.
  • As palavras reservadas, que não podem ser nomes.
  • O estilo oficial: lowerCamelCase para variáveis e constantes, e os outros formatos que você vai ver no guia.
  • O que faz um nome ser bom.
  • Os erros reais de nome com acento, com número no começo, com espaço, com hífen e com palavra reservada.

Os programas desta aula foram rodados com o Dart SDK 3.13.5 na máquina fictícia da Ana (usuária ana, computador notebook), dentro da pasta nv, com dart run arquivo.dart.

A ideia: etiquetas que a máquina consegue ler

Pense numa etiquetadora de supermercado, aquela que imprime etiquetas com um teclado pequeno. O teclado dela só tem letras sem acento, números e alguns sinais. Você pode escrever PRECO, mas não PREÇO; e um espaço no meio faria parecer que são duas etiquetas. Os nomes no Dart funcionam assim: só um conjunto pequeno de caracteres, tudo grudado.

Em programação, um nome desses se chama identificador (em inglês, identifier). A palavra aparece em várias mensagens de erro desta aula.

O _ no começo tem um significado

Um nome que começa com _ é privado: só pode ser usado dentro do próprio arquivo. Dentro do main isso não faz diferença, mas com funções e classes faz (aula Privacidade (_)). Por isso, não comece nomes com _ sem motivo. E o $, embora permitido, quase ninguém usa em nomes: ele já tem outro papel dentro dos textos (Interpolação).

2. Maiúsculas e minúsculas contam

void main() {
  var nome = 'Ana';
  var Nome = 'Bia';
  var NOME = 'Caio';
  print(nome);
  print(Nome);
  print(NOME);
}

$ dart run maiusculas.dart
Ana
Bia
Caio

Três variáveis diferentes, cada uma com o seu valor. O Dart compara os nomes letra por letra, e n e N são letras diferentes. Funciona, mas é uma péssima ideia: quem lê vai confundir. A lição é a outra direção: se você criou precoPao, tem de escrever precoPao sempre, com o mesmo P maiúsculo; precopao seria outro nome, que não existe (Undefined name, aula Variáveis).

3. Palavras reservadas

Algumas palavras são da própria linguagem: var, final, const, void, if, else, for, while, class, true, false, null, return e outras. Elas são reservadas: não podem ser usadas como nome de variável. A lista completa está em Palavras Reservadas.

Uma armadilha para quem fala português: class é reservada, mas classe e turma não são. Escrever os nomes em português tem essa vantagem extra: quase nunca bate com uma palavra do Dart.

Missão: os dois nomes deste programa quebram regras (rode e veja). Troque-os por turma e quantidadeAlunos em todos os lugares em que aparecem.

void main() {
  var class = 'Turma A';
  var quantidade de alunos = 32;
  print(class);
  print(quantidade de alunos);
}

void main() {
  var turma = 'Turma A';
  var quantidadeAlunos = 32;
  print(turma);
  print(quantidadeAlunos);
}

4. O estilo: lowerCamelCase

Quando o nome tem mais de uma palavra, como "preço do pão", é preciso grudar as palavras. O estilo oficial do Dart (o guia Effective Dart) manda escrever variáveis e constantes em lowerCamelCase: tudo junto, a primeira palavra em minúsculas e cada palavra seguinte começando com maiúscula, como as corcovas de um camelo:

IdeiaNome em lowerCamelCase
preço do pãoprecoDoPao ou precoPao
quantidade de alunosquantidadeAlunos
está abertaestaAberta
taxa de entrega (uma constante)taxaEntrega

Outros formatos aparecem em outros lugares, cada um com o seu uso:

Acento ou ç no nome 
void main() {
  var preço = 0.9;
  print(preço);
}

The non-ASCII character 'ç' (U+00E7)
"O caractere não ASCII ç". O ASCII é a tabela antiga de caracteres dos computadores, com só as letras do inglês, sem acentos. O U+00E7 é o número oficial do ç na tabela Unicode, que tem todas as letras do mundo.
can't be used in identifiers, only in strings and comments.
"Não pode ser usado em nomes, só em textos e comentários." Ou seja: 'preço' entre aspas pode; preço como nome, não.
Try using an US-ASCII letter, a digit, '_' …, or '$' …
A dica: use uma letra sem acento, um dígito, _ ou $. São exatamente as regras da seção 1.
coluna 10 e coluna 12
O ^ aponta para o próprio ç, e o erro aparece em cada lugar em que o nome foi escrito.

Como consertar: preco. Vale para todos os acentos: açúcar → acucar, pão → pao, média → media.

O hífen é o sinal de menos: o Dart leu preco - pao, uma conta. Daí o Undefined name 'pao' (não existe variável pao para subtrair) e o Can't assign to this ("não dá para guardar valor nisto": não se guarda nada numa conta). Como consertar: precoPao.

Palavra reservada 
void main() {
  var class = 'Turma A';
  print(class);
}

$ dart run reservada.dart
reservada.dart:2:7: Error: 'class' can't be used as an identifier because it's a keyword.
Try renaming this to be an identifier that isn't a keyword.
  var class = 'Turma A';
      ^^^^^
reservada.dart:3:9: Error: 'class' can't be used as an identifier because it's a keyword.
Try renaming this to be an identifier that isn't a keyword.
  print(class);
        ^^^^^

"class não pode ser usada como nome porque é uma palavra-chave (keyword). Tente renomear para um nome que não seja palavra-chave." Esta é a mensagem mais clara do grupo. Com outras palavras reservadas, como if, a mensagem é menos direta: Expected an identifier, but got 'if'., seguida de várias outras. Como consertar: turma.

Curiosidade: int, double e String não são reservadas (são nomes de tipos), e o Dart até aceita var int = 3;. Mas não faça isso: a partir dessa linha, int deixa de ser o tipo naquele trecho, e o código fica confuso.

Resumo

  • Nomes (identificadores) usam letras sem acento, dígitos (não no começo), _ e $. Nada de espaço, hífen ou ç.
  • Acento só dentro de aspas e comentários: 'pão' pode; pão como nome, não.
  • Maiúsculas contam: nome e Nome são variáveis diferentes.
  • Palavras reservadas (class, if, do, var…) não podem ser nomes.
  • Estilo: variáveis e constantes em lowerCamelCase (precoDoPao), tipos em UpperCamelCase, arquivos em snake_case.dart. O dart analyze de um projeto avisa quando o nome foge do estilo.
  • Bons nomes dizem o que guardam: totalCompra, estaAberta, nomes.
