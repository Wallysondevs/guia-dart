Dart Argumentos da Linha de Comando

Na aula Lendo o Teclado, o programa perguntava e esperava a resposta. Há outro jeito de passar informação para um programa: escrever tudo junto com o comando, na mesma linha: dart run tabuada.dart 7. Esse 7 é um argumento da linha de comando, e ele chega no main numa lista chamada args. É assim que funcionam quase todos os comandos do terminal (ls receitas, cat compras.txt), e o próprio dart (run é um argumento dele).

Você vai aprender
  • Como o main recebe os argumentos: void main(List<String> args).
  • Como o terminal separa os argumentos (espaços) e como juntar palavras num argumento só (aspas).
  • Como tratar o caso de nenhum argumento e como converter um argumento em número.
  • Como mostrar uma mensagem de uso no stderr e sair com um código de erro (exit).
  • Como aceitar opções do tipo --gritar.
  • Os erros reais: args[0] sem argumento, int.parse de um texto, main com o tipo errado e a opção no lugar errado.

Todos os programas desta aula rodaram no Dart 3.13.5 da máquina da Ana (usuária ana, computador notebook), no terminal, com dart run arquivo.dart seguido dos argumentos.

A ideia: o pedido já vem escrito no bilhete

Você pode chegar à padaria e esperar o atendente perguntar "o que vai ser?" (é o stdin). Ou pode entregar um bilhete já escrito: "3 pães, 1 leite". O atendente não pergunta nada: lê o bilhete e trabalha. Os argumentos são o bilhete: vêm escritos no comando, antes de o programa começar.

A vantagem do bilhete: dá para repetir o mesmo pedido sem digitar de novo (a seta para cima no terminal traz o comando de volta), e outros programas e scripts conseguem chamar o seu programa passando o pedido pronto.

1. Recebendo os argumentos

void main(List<String> args) {
  print('Recebi ${args.length} argumento(s): $args');
  for (var i = 0; i < args.length; i++) {
    print('args[$i] = ${args[i]}');
  }
}
void main(List<String> args)
O mesmo main de sempre, agora com um parâmetro: uma lista de textos. O nome args (de arguments) é só costume; poderia ser palavras. O tipo, não: tem de ser List<String>.
args.length
Quantos argumentos vieram.
args[i]
Cada argumento, a partir do índice 0. O nome do programa (mostrar.dart) não entra na lista.
$ dart run mostrar.dart
Recebi 0 argumento(s): []
$ dart run mostrar.dart pão leite café
Recebi 3 argumento(s): [pão, leite, café]
args[0] = pão
args[1] = leite
args[2] = café

Sem nada depois do nome do arquivo, a lista vem vazia (não dá erro). Com três palavras, três argumentos: o terminal separa nos espaços.

Argumento com espaço: aspas

E se o item for "pão de queijo"? Sem aspas, seriam 3 argumentos (pão, de, queijo). Com aspas, duplas ou simples, vira um só:

$ dart run mostrar.dart "pão de queijo" 'bolo de fubá' 3
Recebi 3 argumento(s): [pão de queijo, bolo de fubá, 3]
args[0] = pão de queijo
args[1] = bolo de fubá
args[2] = 3

As aspas são do terminal: ele as usa para agrupar e as tira antes de entregar ao Dart (por isso não aparecem na saída). E repare no 3: ele chegou como o texto '3', não como número. Todo argumento é String.

void main(List<String> args) {
  print('Recebi ${args.length} argumento(s): $args');
  for (var i = 0; i < 2; i++) {
    print('args[$i] = ${args[i]}');
  }
}

2. E se não vier nenhum?

Quem usa o programa pode esquecer o argumento. Confira com args.isEmpty antes de usar args[0]:

void main(List<String> args) {
  if (args.isEmpty) {
    print('Olá, pessoa sem nome!');
  } else {
    print('Olá, ${args[0]}!');
  }
}

$ dart run saudar.dart
Olá, pessoa sem nome!
$ dart run saudar.dart Ana
Olá, Ana!

Sem essa conferência, args[0] numa lista vazia derruba o programa (veja Quando dá errado).

3. Argumentos que são números

Como tudo chega como texto, para fazer conta é preciso converter (veja Conversão de Tipos). Esta calculadora soma todos os preços passados:

void main(List<String> args) {
  var total = 0.0;
  for (final arg in args) {
    total += double.parse(arg);
  }
  print('Total: ${total.toStringAsFixed(2)}');
}

$ dart run somar.dart 4.50 12 0.75
Total: 17.25

Repare que no terminal o decimal se escreve com ponto (4.50), como no Dart. Com vírgula (4,50), o double.parse dá erro.

4. Mensagem de uso, stderr e exit

Programas de terminal bem-educados, quando recebem argumentos errados, explicam como usar e terminam com um código de saída diferente de 0 (o 0 quer dizer "deu tudo certo"). Para isso, duas ferramentas do dart:io:

  • stderr.writeln(…): escreve na saída de erros (standard error). No terminal aparece igual ao print, mas é um canal separado: quem guarda a saída do programa num arquivo não recebe as mensagens de erro misturadas.
  • exit(n): termina o programa na hora, com o código n. O 64 é o código tradicional para "uso incorreto do comando".
import 'dart:io';

void main(List<String> args) {
  if (args.length != 1) {
    stderr.writeln('Uso: dart run tabuada.dart NUMERO');
    exit(64);
  }
  final numero = int.tryParse(args[0]);
  if (numero == null) {
    stderr.writeln('Erro: "${args[0]}" não é um número inteiro.');
    exit(64);
  }
  for (var i = 1; i <= 3; i++) {
    print('$numero x $i = ${numero * i}');
  }
}

$ dart run tabuada.dart 7
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
$ dart run tabuada.dart
Uso: dart run tabuada.dart NUMERO
$ echo $?
64
$ dart run tabuada.dart sete
Erro: "sete" não é um número inteiro.
$ echo $?
64
args.length != 1
Exatamente um argumento; nem zero, nem dois.
int.tryParse(args[0])
"Tenta converter": devolve o número, ou null se o texto não for um inteiro. Diferente do int.parse, não derruba o programa.
echo $?
Comando do terminal que mostra o código de saída do último programa: 64, o que o exit(64) pediu.

Para ver que o stderr é mesmo outro canal, o terminal pode jogar fora só ele com 2>/dev/null ("mande a saída de erros para o nada"):

$ dart run tabuada.dart 7 2>/dev/null
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
$ dart run tabuada.dart 2>/dev/null

Com o argumento certo, nada mudou (tudo era print). Sem argumento, a mensagem de uso sumiu: ela ia pelo stderr.

5. Opções: --gritar

Muitos comandos aceitam opções que começam com -- e ligam um comportamento. Um jeito simples: procure a opção na lista com contains, e trate o resto como dados:

void main(List<String> args) {
  final gritar = args.contains('--gritar');
  final nomes = args.where((a) => !a.startsWith('--')).toList();
  for (final nome in nomes) {
    final frase = 'Bom dia, $nome!';
    print(gritar ? frase.toUpperCase() : frase);
  }
}

$ dart run opcoes.dart Ana Bia
Bom dia, Ana!
Bom dia, Bia!
$ dart run opcoes.dart --gritar Ana Bia
BOM DIA, ANA!
BOM DIA, BIA!

where((a) => !a.startsWith('--')) fica só com o que não começa com -- (veja map, where…), e o ternário escolhe entre a frase normal e a gritada.

Para muitas opções: o pacote args

Quando o programa tem várias opções (--saida=arquivo.txt, -v, --help), fazer tudo à mão cansa. A equipe do Dart mantém o pacote args, que lê as opções e monta a ajuda sozinho. Ele é instalado com dart pub add args, assunto da aula Pacotes do pub.dev.

Resumo

  • O que vem depois do nome do arquivo em dart run arquivo.dart … chega em main(List<String> args).
  • O terminal separa nos espaços; aspas juntam palavras num argumento só. Todo argumento é String: converta com int.tryParse / double.parse.
  • Sem argumentos, a lista vem vazia: confira com args.isEmpty antes de usar args[0].
  • Argumento errado: mensagem de uso no stderr e exit(64).
  • Opções do seu programa vão depois do nome do arquivo; antes dele, são opções do dart run.
