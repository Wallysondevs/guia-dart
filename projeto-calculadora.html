Projeto: Calculadora

A Ana quer uma calculadora no terminal para as contas da padaria: digita 3 + 4, aperta Enter, e aparece 3 + 4 = 7. Neste projeto você vai construí-la em quatro versões, da mais ingênua até uma que aguenta qualquer coisa que o usuário digitar e ainda mostra o histórico no fim. No caminho, vai encontrar um dos números mais estranhos da computação: o Infinity.

Você vai usar
  • Operações com double (aula Operadores Aritméticos).
  • stdin.readLineSync(), double.parse e double.tryParse (aulas Lendo o Teclado e Conversão).
  • switch comum e a expressão switch (aula switch).
  • Funções, split, listas, while (true) com break e continue.

As sessões abaixo rodaram no Dart SDK 3.13.5 da máquina da Ana (usuária ana, computador notebook), numa pasta calc; o que ela digitou aparece depois de cada pergunta. No editor do guia, a entrada "digitada" vem pronta na caixa.

O plano

  1. Versão 1: as quatro contas com números fixos.
  2. Versão 2: perguntar os números e a operação; escolher com switch.
  3. Versão 3: uma função calcular e a conta digitada numa linha só (3 + 4).
  4. Versão 4: repetir até "sair", validar tudo, recusar divisão por zero, mostrar o histórico.

Um double (número com casas decimais). Usamos double porque uma calculadora precisa de 10 / 4 = 2.5.
'$a + $b = ${a + b}'
Interpolação: $a mostra a variável; ${a + b}, com chaves, mostra o resultado de uma conta. Sem as chaves, '$a + b' mostraria só o a e o texto "+ b".
*
Multiplicação (o "×" da escola).
/
Divisão. No Dart, / sempre dá double, mesmo com inteiros: 12 / 4 é 3.0.

Repare no .0 em tudo: é assim que o Dart mostra um double sem parte decimal. Na versão 3 vamos deixar mais bonito.

Versão 2: perguntando ao usuário

Agora o programa pergunta os dois números e a operação, e usa um switch para escolher a conta:

import 'dart:io';

void main() {
  stdout.write('Primeiro número: ');
  final a = double.parse(stdin.readLineSync()!);
  stdout.write('Operação (+ - * /): ');
  final op = stdin.readLineSync()!;
  stdout.write('Segundo número: ');
  final b = double.parse(stdin.readLineSync()!);

  switch (op) {
    case '+':
      print('Resultado: ${a + b}');
    case '-':
      print('Resultado: ${a - b}');
    case '*':
      print('Resultado: ${a * b}');
    case '/':
      print('Resultado: ${a / b}');
    default:
      print('Operação desconhecida: $op');
  }
}
double.parse(stdin.readLineSync()!)
Lê a linha e transforma o texto em double. Aceita 12, 12.5 e -3; o separador decimal é o ponto, não a vírgula.
final op = stdin.readLineSync()!;
A operação fica como texto mesmo: '+', '/'…
switch (op) { case '+': … }
Compara op com cada case e roda o que bater. No Dart 3 não precisa de break no fim de cada caso.
default:
"Padrão": o que fazer se nenhum caso bater.

Segundo número: 4
Resultado: 3.0
$ dart run calc2.dart
Primeiro número: 10
Operação (+ - * /): x
Segundo número: 2

E dividir por zero?

$ dart run calc2.dart
Primeiro número: 9
Operação (+ - * /): /
Segundo número: 0
Resultado: Infinity

Não deu erro! Com double, o Dart segue a regra da computação de números com vírgula (o padrão IEEE 754): um número positivo dividido por zero dá Infinity ("infinito"). E 0 / 0 dá NaN (Not a Number, "não é um número"). Para uma calculadora de padaria, "infinito" não é uma resposta útil; a versão 4 vai recusar a divisão por zero.

Versão 3: uma função e a conta numa linha

Duas melhorias. Primeiro, a conta vira uma função calcular, que recebe os números e a operação e devolve o resultado. Isso separa o "fazer a conta" do "conversar com o usuário", e permite usar a mesma função em outros lugares (e testá-la). Segundo, o usuário digita tudo numa linha, como numa calculadora de verdade:

import 'dart:io';

double calcular(double a, String op, double b) {
  return switch (op) {
    '+' => a + b,
    '-' => a - b,
    '*' => a * b,
    '/' => a / b,
    _ => throw ArgumentError('operação desconhecida: $op'),
  };
}

String formatar(double x) {
  if (x == x.truncateToDouble()) {
    return x.toInt().toString();
  }
  return x.toString();
}

void main() {
  stdout.write('Conta (ex.: 3 + 4): ');
  final partes = stdin.readLineSync()!.split(' ');
  final a = double.parse(partes[0]);
  final op = partes[1];
  final b = double.parse(partes[2]);
  print('= ${formatar(calcular(a, op, b))}');
}
return switch (op) { '+' => a + b, … }
A expressão switch: em vez de rodar comandos, ela vale um resultado, que o return devolve. Cada linha é "padrão => valor".
_ => throw ArgumentError(…)
O _ é o "qualquer outra coisa". Uma operação desconhecida lança um erro de argumento (veja throw): a função não tem um número honesto para devolver.
formatar
Se o número não tem parte decimal (7.0 é igual a 7.0 truncado), mostra como inteiro (7); senão, como está (2.5).
.split(' ')
"Divide" o texto em pedaços a cada espaço: '3 + 4' vira a lista ['3', '+', '4']. Os pedaços são partes[0], partes[1] e partes[2].

$ dart run calc3.dart

= 2.5

Número com vírgula ou por extenso

2,5 * 2 ou dez + 1 dão o mesmo FormatException: Invalid double: o double.parse só entende ponto como separador decimal, e só algarismos. A solução para todos esses casos é a mesma: conferir antes de usar, com tryParse e if.

Versão 4: a calculadora completa

import 'dart:io';

const operacoes = ['+', '-', '*', '/'];

double calcular(double a, String op, double b) {
  return switch (op) {
    '+' => a + b,
    '-' => a - b,
    '*' => a * b,
    '/' => a / b,
    _ => throw ArgumentError('operação desconhecida: $op'),
  };
}

String formatar(double x) {
  if (x == x.truncateToDouble()) {
    return x.toInt().toString();
  }
  return x.toString();
}

void main() {
  print('Calculadora da Ana. Digite contas como 3 + 4, ou "sair".');
  final historico = <String>[];
  while (true) {
    stdout.write('> ');
    final linha = stdin.readLineSync();
    if (linha == null || linha.trim() == 'sair') {
      break;
    }
    final partes = linha.trim().split(RegExp(r'\s+'));
    if (partes.length != 3) {
      print('Use o formato: número operação número (ex.: 3 + 4)');
      continue;
    }
    final a = double.tryParse(partes[0]);
    final op = partes[1];
    final b = double.tryParse(partes[2]);
    if (a == null || b == null) {
      print('Número inválido.');
      continue;
    }
    if (!operacoes.contains(op)) {
      print('Operação desconhecida: $op (use + - * /)');
      continue;
    }
    if (op == '/' && b == 0) {
      print('Não dá para dividir por zero.');
      continue;
    }
    final conta = '${partes.join(' ')} = ${formatar(calcular(a, op, b))}';
    print(conta);
    historico.add(conta);
  }
  print('Contas feitas: ${historico.length}');
  for (final conta in historico) {
    print('  $conta');
  }
}
while (true) { … break; … }
Um laço "para sempre", que só termina pelo break: quando a entrada acaba (null) ou o usuário digita sair.
linha.trim().split(RegExp(r'\s+'))
trim() tira os espaços das pontas; split(RegExp(r'\s+')) divide em "um ou mais espaços". Assim, 100 - 1 também vira ['100', '-', '1'].
partes.length != 3
Se não vieram exatamente 3 pedaços (como em 3+4), explica o formato e pede de novo (continue). Isso evita o RangeError.
double.tryParse
Devolve null em vez de lançar FormatException.
operacoes.contains(op)
A operação está na lista? O ! na frente inverte: "se não contém".
op == '/' && b == 0
Recusa a divisão por zero antes de chegar no Infinity.
historico.add(conta)
Guarda cada conta feita numa lista, mostrada no fim.

Ideias para continuar

  • Aceitar a vírgula: double.tryParse(partes[0].replaceAll(',', '.')).
  • Uma "memória": a palavra ans no lugar de um número usa o último resultado.
  • Receber a conta pela linha de comando, dart run calc.dart 3 + 4, com main(List<String> args) (aula Argumentos da Linha de Comando), e compilar com dart compile exe (aula Compilando).
  • Testar a função calcular com package:test (aula Testes).

Missão final: sem divisão por zero

Resumo

  • Use double numa calculadora: / sempre devolve double, e o separador decimal é o ponto.
  • switch comum escolhe o que fazer; a expressão switch escolhe um valor, ótima para uma função calcular.
  • split divide a linha 3 + 4 em pedaços; trim e RegExp(r'\s+') toleram espaços a mais.
  • Divisão de double por zero dá Infinity (e 0 / 0 dá NaN), sem erro; Infinity.toInt() é que quebra.
  • Confira antes de usar: tryParse + null, contains, o divisor zero, e continue para pedir de novo. Guarde o histórico numa lista.
